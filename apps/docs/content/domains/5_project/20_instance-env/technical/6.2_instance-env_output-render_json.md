# JSON Renderer: `orbit instance:env`

[Back to `instance:env` technical contract.](1_instance-env.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shapes

### List

```json
{
  "success": {
    "data": {
      "scope": "instance",
      "project": "billing",
      "instance": "development",
      "workspace": null,
      "path": "/home/orbit/apps/billing-development/.env",
      "stored": false,
      "applied": false,
      "runtime_restarted": false,
      "variables": [
        {
          "key": "APP_DEBUG",
          "value": "false",
          "secret": false
        }
      ]
    },
    "meta": []
  }
}
```

### Set

```json
{
  "success": {
    "data": {
      "scope": "instance",
      "project": "billing",
      "instance": "development",
      "workspace": null,
      "path": "/home/orbit/apps/billing-development/.env",
      "stored": true,
      "applied": true,
      "runtime_restarted": true,
      "variable": {
        "key": "APP_DEBUG",
        "value": "false",
        "secret": false
      },
      "apply": {
        "env_path": "/home/orbit/apps/billing-development/.env",
        "cache_cleared": true,
        "runtime_outcome": "recreated"
      }
    },
    "meta": []
  }
}
```

`apply` is present only when the request includes `apply=true`.

### Render

```json
{
  "success": {
    "data": {
      "scope": "instance",
      "project": "billing",
      "instance": "development",
      "workspace": null,
      "path": "/home/orbit/apps/billing-development/.env",
      "stored": false,
      "applied": false,
      "runtime_restarted": false,
      "variables": {
        "APP_DEBUG": {
          "value": "false",
          "secret": false
        },
        "DB_PASSWORD": {
          "value": null,
          "secret": true
        }
      }
    },
    "meta": []
  }
}
```

## Error Shapes

Command-specific errors use the standard error envelope. Common validation,
authorization, and gateway failures follow the shared command contract.
