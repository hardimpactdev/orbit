---
title: "orbit database:show"
sidebarTitle: "database:show"
description: "Show one connection with its driver, Node association, host, port, database, path, username, `has_password`, and the recorded user count."
---

```bash
orbit database:show <slug> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `slug` | yes | Connection slug. |
