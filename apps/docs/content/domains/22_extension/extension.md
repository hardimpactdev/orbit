# Extension

## Purpose

This domain owns the command contracts and product vocabulary for Orbit's
extension command family. See [Extension command contracts](README.md).

## Responsibilities

These responsibilities scope what the extension domain owns within Orbit's
documentation.

- Keep local and gateway extension enablement contracts aligned with Orbit's
  current behavior.
- Document the built-in extension slugs that Orbit ships in this release.
- Preserve the boundary that downloadable extensions are not part of this
  command surface.

## Boundaries

This landing page is an index for Librarian's domain spine. It does not change
Orbit behavior; detailed contracts remain in the linked command and technical
documents.
