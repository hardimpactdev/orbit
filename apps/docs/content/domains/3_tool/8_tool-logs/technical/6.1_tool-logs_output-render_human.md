# Human Renderer: `orbit tool-logs`

[Back to `tool-logs` technical contract.](1_tool-logs.md)

**Renderer:** Human renderer.

## Primitive

None. Retained log lines are written directly.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered. This command performs one bounded read and writes
the returned retained lines directly.

## Success Output

Each available line is written in runtime order. A non-empty timestamp is
rendered before the message. When the snapshot is empty, output is:

```text
No log lines found.
```

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose
error, and actionable recovery guidance when the operator can resolve it.
