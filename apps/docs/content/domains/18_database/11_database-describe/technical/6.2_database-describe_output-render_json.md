# JSON Renderer: `orbit database:describe`

[Back to `database:describe` technical contract.](1_database-describe.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

The gateway returns the generic query-runner result shape: `data` holds the
driver-reported `columns` and `rows` for the table description, and the resolved
connection identity lives in `meta` (`connection`, `driver`) alongside the
read-query metadata.

```json
{
  "success": {
    "data": {
      "columns": ["column_name", "data_type", "is_nullable", "column_default"],
      "rows": [
        { "column_name": "id", "data_type": "integer", "is_nullable": "NO", "column_default": null },
        { "column_name": "email", "data_type": "varchar", "is_nullable": "NO", "column_default": null }
      ]
    },
    "meta": {
      "connection": "acme",
      "driver": "pgsql",
      "mode": "read",
      "limit": 10000,
      "total_rows": 2,
      "returned_rows": 2,
      "truncated": false,
      "truncated_by": [],
      "max_json_bytes": 1048576,
      "duration_ms": 2
    }
  }
}
```

## Error Shape

The top-level envelope is either `success` or `error`.
