---
title: "orbit project:show"
sidebarTitle: "project:show"
description: "Show one Project with its source access, source defaults, task check, task workspace routing, and excluded Nodes. Human detail output labels the boolean `Task workspace routed`; JSON uses `task_workspace_routed`. Null `default_branch` or root values mean the source defaults are incomplete, and new Instance creation fails with `project.source_defaults_incomplete` until they exist. A null task check means tasks run no check command. Human output also lists the Project's Instances with ID, name, environment, Node, domain, and status. In a terminal, selecting an Instance opens `instance:show`."
---

```bash
orbit project:show <project> [--json]
```
