# Human Renderer: `orbit proxy:remove`

[Back to `proxy:remove` technical contract.](1_proxy-remove.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and destructive confirmation, before backend cleanup or gateway configuration removal begins.

```text
┌ Removing Proxy Route
○ Confirm destructive removal
○ Resolve proxy route
○ Remove backend proxy route
○ Remove route-scoped TLS material
○ Apply and verify proxy removal
└ Working...
```

If TLS material is shared by another route, the TLS cleanup step completes as a skip/warning step and the route removal remains successful.

## Success Output

Render the removed domain, kind, serving node, target, and whether backend and TLS cleanup completed or were skipped. When `success.meta.removal_reason` is `orphan_owner`, also render the prior owner as `tool` and a plain safety line that the recorded tool owner is absent, so force removal was allowed.

## Failure Output

Validation failures render the rejected field. Missing destructive consent renders a direct message that `--force` is required in non-interactive mode. Owned-route denial names the living owner that still controls removal. Cleanup failures render the next doctor command for recovery.
