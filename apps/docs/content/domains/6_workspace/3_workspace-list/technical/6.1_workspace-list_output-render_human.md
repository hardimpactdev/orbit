# Human Renderer: `orbit workspace:list`

[Back to `workspace:list` technical contract.](1_workspace-list.md)

This page describes the human-rendered output for `workspace:list`.

**Renderer:** Human renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered because `workspace:list` is expected to stay below
one second. It performs a fast gateway database read and does not perform slow
external work, network probes, or remote node application.

## Success Render

The success output is a table of workspaces grouped by parent project within owning
node. Node groups are ordered alphabetically by node name (case-insensitive).
Within each node, app groups are ordered alphabetically by project name
(case-insensitive). Within each app group, workspaces are ordered alphabetically
by workspace name (case-insensitive). This matches the JSON renderer's flat-array
ordering, so callers reading either output form see the same workspaces in the
same relative order.

### Example output

```text
Node: app-1
App: docs
+--------------+--------------------------------+------------------+
| WORKSPACE    | URL                            | LIFECYCLE STATUS |
+--------------+--------------------------------+------------------+
| feature-docs | https://feature-docs.docs.test | expected         |
| main         | https://docs.test              | expected         |
+--------------+--------------------------------+------------------+

Node: app-2
App: orbit
+-----------+-------------------------+------------------+
| WORKSPACE | URL                     | LIFECYCLE STATUS |
+-----------+-------------------------+------------------+
| main      | https://main.orbit.test | setup-pending    |
+-----------+-------------------------+------------------+
```

### Empty result

When no workspaces match the filters or the visible set is empty:

```text
No workspaces found.
```

## Error Render

Errors are rendered as concise prose messages.

### Invalid filter value

```text
Unknown app: 'unknown-app'.
```

```text
Unknown node: 'unknown-node'.
```

### Gateway unavailable

```text
Gateway connection is required to list workspaces.
```

### Authorization failed

```text
This node is not authorized to read the workspace registry.
```
