# JSON Renderer: `orbit tool:restart`

[Back to `tool-restart` technical contract.](1_tool-restart.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a single machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

Use `--stream-json` instead of `--json` only when callers need
newline-delimited progress frames. That renderer follows the shared
[Stream JSON Frames](../../../README.md#stream-json-frames) contract.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "tool": {
        "name": "orbstack",
        "node": "mac-1",
        "action": "restart"
      }
    },
    "meta": []
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "tool.unsupported_action",
    "message": "Tool 'composer' does not support restart.",
    "meta": {
      "tool": "composer",
      "action": "restart"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `orbit_agent_unavailable`, `tool.not_found`, `tool.unsupported_action`, `tool.unsupported_on_node`, `tool.runtime_missing`, `tool.runtime_ambiguous`, `tool.remote_action_failed` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.meta` | object | Field, target, caller, runtime, or remote-action context for automation. |

`orbit_agent_unavailable` includes `error.meta.reason=agent_push_unavailable`
and `error.meta.platform`. On macOS the CLI also includes
`error.meta.remediation` instructing the operator to open Orbit Desktop.
