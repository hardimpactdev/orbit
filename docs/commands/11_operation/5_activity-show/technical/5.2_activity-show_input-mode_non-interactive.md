# Non-Interactive Input Mode: `orbit activity:show [id]`

[Back to `activity:show` technical contract.](1_activity-show.md)

This page describes how non-interactive input mode resolves `activity:show`
input without prompts.

**Input mode:** Non-interactive.

## Selection

Use this input mode when either condition is true:

- the command is running without a TTY;
- `--json` is present.

`--json` selects the JSON renderer and forces this input mode even when the
process has a TTY.

## Responsibilities

- Read supplied arguments and options.
- Never render prompts.
- Fail before side effects when required input is absent.
- Fail before side effects when supplied input is invalid.
- Evaluate path eligibility as soon as the id is resolved.

## Required Input Failures

| Field | Missing when | Behavior |
| --- | --- | --- |
| `id` | `[id]` is absent. | Fail before gateway history read. |

The failure uses `error.code=validation_failed` with `error.meta.field=id`.

## Validation Failures

Fail before side effects when:

- `id` is not a positive integer.

The selected output renderer owns how these failures are displayed.
