# JSON Renderer: `orbit schedule:remove`

[Back to `schedule:remove` technical contract.](1_schedule-remove.md)

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "schedule": {
        "name": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs",
          "node": "app-1"
        },
        "interval": "every minute",
        "timezone": "Europe/Amsterdam",
        "execution": {
          "type": "command",
          "value": "php artisan schedule:run"
        },
        "enabled": false,
        "status": "removed",
        "last_run": null
      }
    },
    "meta": {
      "timer_removed": true,
      "service_removed": true,
      "history_retained": true
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "schedule.cleanup_failed",
    "message": "Schedule 'laravel-scheduler' was removed from gateway intent, but backend cleanup failed.",
    "data": {
      "schedule": {
        "name": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs",
          "node": "app-1"
        },
        "interval": "every minute",
        "timezone": "Europe/Amsterdam",
        "execution": {
          "type": "command",
          "value": "php artisan schedule:run"
        },
        "enabled": false,
        "status": "removed_with_drift",
        "last_run": null
      }
    },
    "meta": {
      "next_command": "doctor --family=schedule --fix"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.schedule` | object | Removed schedule entity. |
| `success.meta.timer_removed` | boolean | Whether timer cleanup completed. |
| `success.meta.service_removed` | boolean | Whether service cleanup completed. |
| `success.meta.history_retained` | boolean | Whether durable run history remains available. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `schedule.not_found`, `destructive_consent_required`, `schedule.cleanup_failed` | Stable command failure code. |
| `error.data.schedule` | object | Removed schedule when cleanup failed after gateway state changed. |
| `error.meta` | object | Field, scope, caller, or recovery context for automation. |
