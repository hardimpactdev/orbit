# JSON Renderer: `orbit extension:list`

[Back to `extension:list` technical contract.](1_extension-list.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success

```json
{
  "success": {
    "data": {
      "extensions": [
        {
          "slug": "solo",
          "label": "Solo",
          "description": "Solo API command family through the Orbit gateway.",
          "commands": ["solo:projects"],
          "permissions": ["solo:*"],
          "local_enabled": true,
          "gateway_enabled": false
        }
      ]
    },
    "meta": []
  }
}
```

When gateway state cannot be read, `gateway_enabled` is `null` and the success
metadata carries the gateway warning.

The `solo` extension can appear in this list before Solo command/API proxying
exists. Its command names are reserved for the built-in extension contract and
are not runnable until that deferred command family lands.

## Error

Hard failures use the shared error envelope:

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway is unavailable.",
    "meta": []
  }
}
```
