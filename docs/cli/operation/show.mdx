---
title: "orbit operation:show"
sidebarTitle: "operation:show"
description: "Show the parent Operation, including its kind, target, status, error code, result and times."
---

```bash
orbit operation:show <operation> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `operation` | yes | Numeric operation ID. |

JSON returns the parent record, as `GET /api/v1/operations/{operation}` does. The command exits `0` for any status; read `status` for the outcome. `overdue_since` records when a running Operation passed its soft limit. Human output shows it as `Overdue since`. An overdue Operation keeps running; only its [hard limit](/reference/operations#native-run-budgets) requests cancellation.


```bash
orbit operation:show 42
```
