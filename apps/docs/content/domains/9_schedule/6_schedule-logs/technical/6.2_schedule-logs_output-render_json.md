# JSON Renderer: `orbit schedule:logs`

[Back to `schedule:logs` technical contract.](1_schedule-logs.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "run": {
        "id": 18,
        "schedule": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs",
          "node": "app-1"
        },
        "status": "completed",
        "exit_code": 0,
        "started_at": "2026-05-02T08:10:00Z",
        "finished_at": "2026-05-02T08:10:03Z"
      },
      "output": {
        "stdout": "No scheduled commands are ready to run.\n",
        "stderr": ""
      }
    },
    "meta": {
      "lines": 100,
      "truncated": false
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "schedule.run_not_found",
    "message": "Run '19' was not found for schedule 'laravel-scheduler'.",
    "meta": {
      "name": "laravel-scheduler",
      "run": 19
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.run` | object | Durable run-history record selected for display. |
| `success.data.output` | object | Captured run output after line limiting. |
| `success.meta.lines` | integer | Applied line limit. |
| `success.meta.truncated` | boolean | Whether output was truncated by the line limit. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `schedule.not_found`, `schedule.run_not_found`, `schedule.log_read_failed` | Stable command failure code. |
| `error.meta` | object | Field, schedule, run id, scope, caller, or storage context for automation. |
