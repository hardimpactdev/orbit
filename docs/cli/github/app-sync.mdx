---

```bash
orbit github:app:sync [--json]
```

The Gateway signs a short-lived App JWT, lists the App's installations on GitHub, stores the public observation, and answers like [`github:app:show`](/cli/github/app-show). It starts no Operation and no Swamp run; the App key never leaves the Gateway. When GitHub fails, the last observation stays and the command returns `github.unavailable`.
