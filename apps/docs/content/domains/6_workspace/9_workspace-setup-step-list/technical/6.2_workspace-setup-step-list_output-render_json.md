# JSON Renderer: `orbit workspace-setup-step:list`

[Back to `workspace-setup-step:list` technical contract.](1_workspace-setup-step-list.md)

This page describes the JSON-rendered output for
`workspace-setup-step:list`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The step array is rendered as a flat array under `success.data.steps`.
Steps are sorted by `order` ascending. This matches the order shown in the
human renderer, so both renderers represent the same result. Pagination,
count, or other execution context attaches to `success.meta.*`; it is not
nested inside `success.data`. Array length serves as the count.

## Success Shape

```json
{
  "success": {
    "data": {
      "steps": [
        {
          "id": 12,
          "app": "hauser",
          "instance": "nmbp",
          "phase": "setup",
          "order": 1,
          "command": "composer install",
          "timeout_seconds": 600
        },
        {
          "id": 13,
          "app": "hauser",
          "instance": "nmbp",
          "phase": "setup",
          "order": 2,
          "command": "npm install",
          "timeout_seconds": 300
        }
      ]
    },
    "meta": []
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `steps` | array | Ordered list of setup steps for the resolved `(instance, phase=setup)`. |
| `steps[].id` | integer | Gateway-assigned step identifier. Stable across re-runs and accepted by [`workspace-setup-step:remove`](../../10_workspace-setup-step-remove/workspace-setup-step-remove.md). |
| `steps[].app` | string | App slug of the resolved instance. |
| `steps[].instance` | string | Required instance that owns the step. |
| `steps[].phase` | string | Always `"setup"` for this command. |
| `steps[].order` | integer | Absolute execution position within `(instance, phase=setup)`, ascending. |
| `steps[].command` | string | Shell command string as supplied to [`workspace-setup-step:add`](../../8_workspace-setup-step-add/workspace-setup-step-add.md). Not parsed or expanded by the gateway. |
| `steps[].timeout_seconds` | integer | Strict positive integer step timeout in seconds. |

The `steps[]` record shape is the shared step shape published by every
`workspace-setup-step:*` command. Fields such as `name`,
`working_directory`, `env_overrides`, and per-step `on_failure` are
explicitly absent and must not be added to a single command in the family
without updating the rest.

### Empty result

When the resolved app has no configured setup steps:

```json
{
  "success": {
    "data": {
      "steps": []
    },
    "meta": []
  }
}
```

## Error Shapes

### Validation failure (app)

Returned when the instance cannot be resolved in non-interactive mode.

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Could not resolve instance.",
    "meta": {
      "field": "instance",
      "reason": "missing_required_input"
    }
  }
}
```

### Instance not found

```json
{
  "error": {
    "code": "instance.not_found",
    "message": "Instance 'my-app.development' not found.",
    "meta": {
      "app": "my-app"
    }
  }
}
```

### Unauthorized app

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "You are not authorized to read setup-step policy for 'my-app'.",
    "meta": {
      "app": "my-app"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to list setup steps.",
    "meta": []
  }
}
```

## Common Error Codes

| Code | Meaning |
| --- | --- |
| `validation_failed` | A supplied input failed gateway-side static validation (one concrete instance could not be resolved). `error.meta.field` names the offending input. |
| `instance.not_found` | Resolved instance selector does not exist in gateway configuration. `error.meta.instance`. |
| `workspace.unsupported_for_production` | The selected instance is served by an `app-prod` node, where workspace policy is disabled. |
| `authorization_failed` | The caller is not authorized to read setup-step policy for the target app. `error.meta.instance`. |
| `gateway_unavailable` | The CLI cannot reach the gateway API. |

The `error.code` values listed here are exhaustive for
`workspace-setup-step:list`. Add a new value to this renderer contract
before implementing another JSON failure code.
