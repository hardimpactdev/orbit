# JSON Renderer: `orbit app:agent-ide`

[Back to `app:agent-ide` technical contract.](1_app-agent-ide.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

The JSON renderer returns the canonical app entity, resulting adapter
configuration, and any cleanup results under the standard `success`/`error`
envelope.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](5.2_app-agent-ide_input-mode_non-interactive.md),
even when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

### App override set with post-configuration cleanup warnings

Cleanup failures after the app configuration write are successful command outcomes.
The warnings use the same structured warning shape and warning vocabulary as
`app:prune` and `workspace:remove`.

```json
{
  "success": {
    "data": {
      "app": {
        "name": "my-app",
        "node": "app-1",
        "url": "https://my-app.test",
        "path": "/home/my-app/app",
        "root": "public",
        "repository": null,
        "runtime": "php",
        "runtime_config": {
          "proxy_transport": "http"
        },
        "php_version": "8.5",
        "adopted": false
      },
      "agent_ide": {
        "adapter": "opencode",
        "source": "app",
        "effective_adapter": "opencode"
      },
      "cleanup": {
        "workspaces_removed": ["stale-ws-1"],
        "workspaces_failed": ["stale-ws-2"]
      },
      "action": "set"
    },
    "meta": {
      "warnings": [
        {
          "code": "workspace.artifact_extra",
          "family": "workspace",
          "message": "Workspace cleanup for 'stale-ws-2' could not remove all node-side artifacts.",
          "next_command": "doctor --family=workspace --restore"
        }
      ]
    }
  }
}
```

### Fields

| Field | Type | Meaning |
| --- | --- | --- |
| `app` | object | Canonical app JSON entity defined in [`5_app/README.md`](../../README.md#app-json-entity). |
| `agent_ide.adapter` | string \| null | The explicit app-level value: an adapter name (e.g. `"opencode"`), the literal `"none"` for an explicit disable, or `null` when the app override was cleared with `inherit`. |
| `agent_ide.source` | string | Where the effective adapter resolves from. See source values below. |
| `agent_ide.effective_adapter` | string \| null | The adapter used after resolution. `null` when the effective state is "agent IDE disabled" (`agent_ide.adapter` is `"none"`) or when the chain resolves to no adapter. |
| `cleanup.workspaces_removed` | array of strings | List of workspace names removed during the switch. Empty list when no cleanup ran. |
| `cleanup.workspaces_failed` | array of strings | List of workspace names whose cleanup could not finish after the configuration write. Empty or omitted when every cleanup target completed. |
| `action` | string | `"set"` when the value changed; `"converged"` when the value already matched. |

`agent_ide.source` resolves to `"app"` when the app holds an explicit override
(adapter name or `"none"`), `"node"` when the app cleared with `inherit` and the
owning node holds a default, and `"default"` when the chain resolves to no
adapter.

`success.meta.warnings` is omitted when cleanup has no warnings. When present,
each entry carries `code`, `family`, `message`, and `next_command`.

## Error Shapes

### Missing required input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "App is required.",
    "meta": {
      "field": "app"
    }
  }
}
```

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Agent IDE adapter is required.",
    "meta": {
      "field": "agent_ide"
    }
  }
}
```

### App not found

```json
{
  "error": {
    "code": "app.not_found",
    "message": "App 'my-app' not found.",
    "meta": {
      "app": "my-app"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'app:agent' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "app:agent",
      "serving_node": "app-1"
    }
  }
}
```

### Unsupported adapter

```json
{
  "error": {
    "code": "app.unsupported_adapter",
    "message": "The adapter \"invalid-adapter\" is not supported.",
    "meta": {
      "adapter": "invalid-adapter",
      "supported": ["inherit", "none", "opencode", "polyscope"]
    }
  }
}
```

`error.meta.supported` lists the reserved input values (`inherit`, `none`)
followed by every adapter currently registered with the gateway-owned
adapter registry. Extension-supplied adapters appear in the list once
registered.

### Missing destructive consent

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Workspaces would be removed during the adapter switch. Pass --force to proceed.",
    "meta": {
      "field": "force",
      "app": "my-app",
      "previous_adapter": "polyscope",
      "next_adapter": "opencode",
      "workspaces_at_risk": ["stale-ws-1", "stale-ws-2"]
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to validate the adapter or list registered adapters.",
    "meta": []
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `action` | `set`, `converged` |
| `agent_ide.source` | `app`, `node`, `default` |
| `error.code` | `validation_failed`, `app.not_found`, `authorization_failed`, `app.unsupported_adapter`, `gateway_unavailable` |

The `error.code` values listed here are exhaustive for `app:agent-ide`. Add a
new value to this renderer contract before implementing another JSON failure
code.
