# Human Renderer: `orbit app:agent-ide`

[Back to `app:agent-ide` technical contract.](1_app-agent-ide.md)

The human renderer summarizes the configured app default, effective resolution,
and any workspace cleanup that ran.

## Progress Tree

Execution may take longer than one second when an adapter switch triggers
workspace removal side effects over SSH.

```text
◌ Configure app agent IDE...
├── ◌ Validate adapter... [DONE]
├── ◌ Check for workspace cleanup... [CLEANUP NEEDED]
├── ◌ Remove stale workspaces... [DONE]
│   ├── ◌ Remove workspace: legacy-ws-1... [DONE]
│   └── ◌ Remove workspace: legacy-ws-2... [DONE]
└── ◌ Update app intent... [DONE]
```

If no cleanup is needed, the tree is shorter:

```text
◌ Configure app agent IDE...
├── ◌ Validate adapter... [DONE]
└── ◌ Update app intent... [DONE]
```

## Output Strings

The renderer uses the same `action` vocabulary as the JSON renderer
(`set` for changed values, `converged` for no-op). Human strings phrase the
state in plain language; the JSON renderer is authoritative for machine
consumers.

If post-intent workspace cleanup cannot finish, the command still renders the
success line for the app intent update and then renders warning lines from
`success.meta.warnings[]` with each warning's `next_command`.

### Success (Set, app holds the override)
```text
App "my-app" agent IDE set to "opencode" (effective: "opencode").
```

### Success (Set with `inherit`, falls through to node default)
```text
App "my-app" agent IDE set to inherit (effective: "polyscope" from node "app-1").
```

### Success (Set with `inherit`, chain resolves to no adapter)
```text
App "my-app" agent IDE set to inherit (effective: none).
```

### Success (Set with `none`, app explicitly disables agent IDE)
```text
App "my-app" agent IDE set to none (effective: none).
```

### Success (Converged / No Change)
```text
App "my-app" agent IDE already set to "opencode".
```

### Cleanup Summary
When workspaces are removed, they are listed:

```text
Removed 2 stale workspaces during adapter switch:
- legacy-ws-1
- legacy-ws-2
```

## Failure Output

### App-node caller denied

```text
This command may only be run from a control or gateway node.
```
