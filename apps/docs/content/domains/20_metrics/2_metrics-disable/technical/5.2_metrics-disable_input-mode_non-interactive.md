# Non-Interactive Input Mode: `orbit metrics:disable`

[Back to `metrics:disable` technical contract.](1_metrics-disable.md)

**Input mode:** Non-interactive.

## Mode Selection

This contract applies without a TTY or when `--json` is present. `--json`
forces non-interactive input mode.

## Behavior

No prompts are rendered. `--node` and `--force` must resolve from options before
side effects. Non-interactive mode requires `--force`. Missing `--force` fails
before side effects with `error.code=validation_failed`,
`error.meta.field=force`, and
`error.meta.reason=destructive_consent_required`.

`--json` selects the JSON renderer only. It does not change validation, does
not grant authorization, and does not imply destructive consent.

## Required Inputs

| Field | Missing behavior |
| --- | --- |
| `node` | Fail before side effects with `validation_failed` and `error.meta.field=node`. |
| `force` | Fail before side effects with `validation_failed`, `error.meta.field=force`, and `error.meta.reason=destructive_consent_required`. |
