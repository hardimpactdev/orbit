# JSON Renderer: `orbit gateway:add [gateway_ip]`

[Back to `gateway:add` technical contract.](1_gateway-add.md)

This page describes the JSON-rendered output for `gateway:add`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](5.2_gateway-add_input-mode_non-interactive.md), even
when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Input mode failures, domain validation failures, authorization failures,
network failures, and local write failures must all use this envelope.

## Enum and identifier values

JSON enum values and structured identifiers are part of the renderer contract:

| Field | Values |
| --- | --- |
| `result.action` | `added`, `converged` |
| `gateway.status`, `local_node.status` | `active` |
| `gateway.platform`, `local_node.platform` | Normalized platform-version identifier such as `ubuntu_24-04` or `macos_15-4`; use `unknown` only when the value is structurally required but unavailable from the verified source. |
| `error.meta.reason` | `missing`, `invalid_ip`, `not_supported_on_gateway`, `unsupported_trust_store` |
| `error.code` | `validation_failed`, `gateway_unavailable`, `node.identity_unknown`, `node.gateway_api_error`, `node.unsupported_platform`, `node.local_config_write_failed` |

The `error.code` values listed here are exhaustive for `gateway:add`. Add a new
value to this renderer contract before implementing another JSON failure code.

Gateway and local-node objects are verified references. They do not imply that
`gateway:add` created or updated node records.

## Success: Added

```json
{
  "success": {
    "data": {
      "result": {
        "action": "added"
      },
      "gateway": {
        "name": "gateway-1",
        "status": "active",
        "platform": "ubuntu_24-04",
        "addresses": {
          "wireguard": "10.6.0.2"
        }
      },
      "local_node": {
        "name": "control-1",
        "status": "active",
        "platform": "macos_15-4",
        "addresses": {
          "wireguard": "10.6.0.8"
        }
      },
      "local_onboarding": {
        "gateway_trust": "trusted",
        "gateway_config": "stored",
        "gateway_api": "verified"
      }
    }
  }
}
```

## Success: Converged

When local gateway trust, settings, and identity are already configured and
verified:

```json
{
  "success": {
    "data": {
      "result": {
        "action": "converged"
      },
      "gateway": {
        "name": "gateway-1",
        "status": "active",
        "platform": "ubuntu_24-04",
        "addresses": {
          "wireguard": "10.6.0.2"
        }
      },
      "local_node": {
        "name": "control-1",
        "status": "active",
        "platform": "macos_15-4",
        "addresses": {
          "wireguard": "10.6.0.8"
        }
      },
      "local_onboarding": {
        "gateway_trust": "already_trusted",
        "gateway_config": "already_stored",
        "gateway_api": "verified"
      }
    }
  }
}
```

## Validation Error: Missing Gateway IP

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Gateway IP is required when it cannot be derived from an active WireGuard network.",
    "meta": {
      "field": "gateway_ip",
      "reason": "missing"
    }
  }
}
```

## Validation Error: Invalid Gateway IP

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Gateway IP must be a valid Orbit WireGuard address.",
    "meta": {
      "field": "gateway_ip",
      "reason": "invalid_ip"
    }
  }
}
```

## Gateway Host Error

```json
{
  "error": {
    "code": "validation_failed",
    "message": "This command is not supported on gateway nodes.",
    "meta": {
      "reason": "not_supported_on_gateway"
    }
  }
}
```

## Identity Unknown Error

```json
{
  "error": {
    "code": "node.identity_unknown",
    "message": "This peer is not registered on the gateway at 10.6.0.2. Ask your admin to register this machine on the gateway, then retry.",
    "meta": {
      "gateway_ip": "10.6.0.2"
    }
  }
}
```

## Gateway Unavailable Error

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway at 10.6.0.2 returned HTTP 500 for /api/me.",
    "meta": {
      "gateway_ip": "10.6.0.2",
      "status": 500

  }
}
```

## Gateway API Error

