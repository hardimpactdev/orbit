# Interactive Input Mode: `orbit profile [url]`

[Back to `profile` technical contract.](1_profile.md)

**Input mode:** Interactive.

## Selection

This mode applies only with a TTY and without `--json`. `--json` always selects
[non-interactive input](5.2_profile_input-mode_non-interactive.md).

## Prompt Contract

| Prompt id | Field | Primitive | Label | Validation |
| --- | --- | --- | --- | --- |
| `profile.url` | `url` | `text` | `URL to profile` | Required absolute `http` or `https` URL with a host. |

## Resolution Rules

- An explicit `[url]` wins and suppresses the prompt.
- Otherwise resolve the nearest ancestor `.env` `APP_URL` locally; a valid
  value suppresses the prompt.
- Prompt when no source supplies a URL or when the nearest `.env` supplies an
  invalid `APP_URL`.
- An invalid explicit URL fails immediately and never falls through to the
  prompt.
- Prompt abort or invalid input emits a human validation failure and performs no
  HTTP request.
- No instance selector, gateway request, node filter, or auth-mode prompt exists.
