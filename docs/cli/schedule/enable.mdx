---
title: "orbit schedule:enable"
sidebarTitle: "schedule:enable"
description: "Set the trigger of one Schedule. The command is idempotent. Use it after `schedule:create --no-start`, or for a copy that production preparation created disabled. `schedule` is the UUID of an installed Schedule."
---

```bash
orbit schedule:enable <schedule> [--idempotency-key=KEY] [--json]
```

An existing workflow keeps its fixed intent; enable only sets its trigger. A copied Project definition with no workflow gets its command copy and workflow first.
