# Non-Interactive Input: `orbit node role:update`

[Back to `node role:update` technical contract.](1_node-role-update.md)

**Input mode:** Non-interactive.

Applies without a TTY or when `--json` is present.

`--json` forces non-interactive input mode.

## Responsibilities

- Read supplied arguments and options.
- Apply documented defaults.
- Never render prompts.
- Fail before side effects when required input is absent or invalid.
