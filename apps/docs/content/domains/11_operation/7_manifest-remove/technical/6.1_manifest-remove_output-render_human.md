# Human Renderer: `orbit manifest:remove`

[Back to `manifest:remove` technical contract.](1_manifest-remove.md)

**Renderer:** Human renderer.

## Primitive

None. The command renders concise status lines.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered. The command performs one bounded gateway write.

## Success Output

```text
Release manifest URL removed.
Source: default
URL: https://github.com/hardimpactdev/orbit/releases/latest/download/orbit-release-manifest.json
```

## Failure Output

Human-rendered failures show the error code and message without a JSON envelope.
