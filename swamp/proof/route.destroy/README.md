# Certificate account-home refusal through Route removal

`account-home.json` is the home-validation variant of the `route.destroy` proof. This F13 fixture drives the real CLI, Gateway admission, native Route parent and terminal projection. `prepare` creates one private custom proxy Route on the disposable app-dev target and captures the Route ID from the final Operation result. `request` uses `orbit route:destroy` and captures its Operation ID from `$.id`, matching the current CLI output. `envelope` is a partial comparison against the actual admitted `Operation.input`; it contains no hand-built SSH envelope, generated scopes, digests or fixed resource IDs. The topology Gateway owns signing for prepare.

The frozen order is **prepare → before_request → request → parity**. `before_request.py` runs on the proof VM host and uses `PROOF_EXEC app-dev --argv=...` to inject the fault only on the workload VM. It discovers the one real prepared Route certificate scope, creates public markers there and in an unrelated scope, and changes the same account’s NSS home spelling to the same physical directory with a trailing `/.`. It leaves the prepared Caddy configuration, leaf key and SSH authorized keys intact. It refuses a target with zero or multiple Route scopes. The hook uses the frozen `[{"argv": [...], "timeout_seconds": 60}]` grammar. It runs from `PROOF_KIND_DIR` with only `PROOF_EXEC`, `PROOF_RUN` and `PROOF_KIND_DIR`; no Operation ID exists yet.

The expected outcome is the exact `certificate.account_invalid` public refusal from the canonical `route-certificate-remove` child’s `certificate/remove` action. The parent fails and retains its cleanup state. The output selector must resolve the child job within the real parent history. An earlier SSH, Caddy, copy or prepare failure must fail this proof. Parity first checks the exact public refusal in `PROOF_OUTPUTS`, then uses `PROOF_EXEC` to check the NSS spelling and both public markers; it restores the original NSS spelling after those checks. Preserved files alone do not prove that the intended refusal occurred.

Pinned e459 can omit outputs from failed steps. Until the shared F1/proof reader can match the child’s exact refusal, this fixture fails closed and #2307 stays draft. `bin/swamp-proof` and the F13 topology are not available in this checkout, so no proof run or receipt is claimed.

The provisional run budget is 300 seconds, including the Route parent’s withdrawal; the certificate refusal phase has 10 seconds. Production p95 has not been measured. The unchanged parent currently inherits a 600-second queue default, recorded literally here; the Route owner must set explicit parent and child queue budgets before F13 acceptance. Setup and VM lifecycle are outside the kind run measurement. This fixture only targets the disposable topology.
