# Interactive Input Mode: `orbit firewall:allow`

[Back to `firewall-allow` technical contract.](1_firewall-allow.md)

**Input mode:** Interactive.

## Mode Selection

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Flow

Prompts render after gateway reachability is known and before any gateway write or backend apply.

| Prompt ID | Primitive | Rendered when | Validation |
| --- | --- | --- | --- |
| `firewall.node` | `datatable` | No `--node` and no local default node resolves. | Visible active Ubuntu node with at least one active role assignment. |
| `firewall.name` | `text` | `name` argument omitted. | Unique rule name on the selected node. |
| `firewall.port` | `text` | `--port` omitted. | Destination port or supported port range. |
| `firewall.direction` | `select` | Operator did not pass `--direction` and the command needs confirmation of the default. | `incoming` or `outgoing`; default `incoming`. |

Invalid prompt answers re-prompt until the value is valid or the operator
aborts. Abort fails before side effects.
