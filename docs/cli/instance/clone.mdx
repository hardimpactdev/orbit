```bash
orbit instance:clone <candidate> <node> <name> --preview-name=NAME [--branch=BRANCH] [--sqlite-source-path=PATH] [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `candidate` | yes | Numeric ID of the candidate Instance. |
| `node` | yes | Numeric ID of the destination Node, which has the active `app-prod` role. A web Project also needs the Node's TLD. |
| `name` | yes | Name of the new production Instance, a lowercase DNS label. |

| Option | Default | Meaning |
| --- | --- | --- |
| `--preview-name=NAME` | prompt | Preview name that Orbit combines with the destination Node's TLD: `shop.com` on a Node with the TLD `prod.orbit` becomes `shop.com.prod.orbit`. A non-web Project gets no Route but still needs the name. |
| `--branch=BRANCH` | the candidate's branch | Target branch in the Project repository. A branch that does not exist fails the task at the fetch. |
| `--sqlite-source-path=PATH` | none | Absolute path to one SQLite database on the candidate, to seed `database.sqlite`. |
| `--idempotency-key=KEY` | generated | Reuse a key to retry the same [Operation start](/reference/operations#start-an-operation). |
| `--json` | off | Print the final task as JSON, with every step, and nothing while it follows. |

```bash
orbit node:add production production.example --role=app-prod --tld=prod.orbit
orbit instance:clone 12 9 primary --preview-name=shop.com --sqlite-source-path=/srv/orbit/apps/acme/default/database/database.sqlite
```

In a terminal, an omitted candidate is chosen from an interactive list of active development Instances, an omitted Node from the active `app-prod` Nodes, and an omitted name and preview name are asked for as text. A noninteractive or `--json` call that omits one is refused with `instance.candidate_id_invalid`, `node.id_invalid`, `instance.name_required` or `instance.preview_name_required`, and sends no request. For a web Project, give the production Node a TLD with `node:add --tld` first. An empty `--branch=` or `--sqlite-source-path=` is read as absent.

The candidate supplies the source, the stored environment values and an optional SQLite snapshot. It must be an active Instance of the Project, have a recorded source profile, keep its branch checked out, be clean, have no submodules, and have its commit in the Project repository. The Project supplies the production Process and Schedule definitions. Cloning copies no working files, dependencies or logs, and the candidate keeps running. See [Instance cloning](/reference/instance-cloning).

The command starts a task and follows it until it ends, as [`instance:deploy`](/cli/instance/deploy) does: a progress tree of the steps, Ctrl-C stops following and not the clone and exits 130, and `--json` prints nothing while it follows. The clone creates the production account and its home on the destination, fetches the committed source into the initial release, writes the `.env` from the candidate's stored values without `DB_*` and WebSocket credentials and with production mode forced, prepares the pinned Vite+ runtime, seeds `database.sqlite` when asked, installs the Project's Processes and Schedules enabled but not started, and for a web Project publishes a private preview Route and probes it over TLS.

Cloning ends with an active Instance and no release. The result lists key-only warnings for copied development service references and paths outside the production home; `--json` returns them in `warnings`. Review them with `env:update` and `env:sync`, record deploy steps, then run [`instance:deploy`](/cli/instance/deploy). See [Next steps](/reference/instance-cloning#next-steps).

A failed or cancelled clone keeps the new Instance reserved and records the error on it and on its pending Route. What the destination got stays; the candidate is unchanged. Run the identical command again to reuse the Instance and repeat only what is missing. A changed candidate, Node, preview name, branch or SQLite path is refused with `instance.clone_retry_conflict`. A new name is a new target: the Project already has a production Instance on the Node, so it is refused with `instance.production_placement_conflict`. An identical request after completion returns the first successful admission.

## Errors

| Code | Meaning |
| --- | --- |
| `instance.candidate_id_invalid`, `node.id_invalid` | The candidate or Node is missing in a call that cannot prompt, or is not a positive integer. |
| `instance.name_required`, `instance.preview_name_required` | The name or preview name is missing in a call that cannot prompt. |
| `input.cancelled` | You cancelled a list. |
| `instance.name_invalid` | The name is not a lowercase DNS label. Fails today: the request validation answers first, with `validation.failed`. |
| `validation.failed` | The name, preview name, branch or SQLite path is not valid. |
| `instance.clone_candidate_inactive` | The candidate, or its Node, is not active. |
| `instance.source_profile_missing` | The candidate has no recorded source profile. |
| `instance.clone_candidate_source_invalid` | The candidate is dirty, has submodules, has another branch checked out, or its origin is not the Project's. |
| `instance.clone_candidate_changed` | The candidate's commit moved after admission. |
| `operation.github_token_forbidden` | The repository access token cannot be minted for this Project. |
| `instance.clone_candidate_branch_invalid` | The candidate has no configured branch to inherit. |
| `instance.node_inactive`, `instance.node_not_app_prod` | The Node is inactive or not Linux, or has no active `app-prod` role. |
| `instance.production_placement_conflict` | The Project already has a production Instance on the Node. |
| `route.tld_required` | A web Project's Node has no TLD. |
| `route.domain_conflict` | Another Route owns the preview domain. |
| `operation.kind_unavailable` | The Node, or the candidate's Node, is a task VM, a web Project's Node is in an active Cluster, or the candidate has an attached Database connection. |
| `instance.clone_database_slug_taken` | The cloned database connection slug is taken by another owner. |
| `instance.removal_conflict` | The target Instance of this name is being removed. |
| `instance.clone_retry_conflict` | A different request is unfinished for this target. |
| `http.404` | The candidate or the Node is unknown. |
| `node_access.required` | The caller has no access grant to the candidate's Node or to the destination Node. |

The run can also fail with `env.configuration_missing`, with the codes of [`route:create`](/cli/route/create) for the preview Route, and with the error code of the failed step.
