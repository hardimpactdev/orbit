# Non-Interactive Input Mode: `orbit profile [url]`

[Back to `profile` technical contract.](1_profile.md)

**Input mode:** Non-interactive.

## Selection

This contract applies without a TTY or when `--json` is present. `--json`
forces non-interactive input mode. Never render prompts in this mode.

## Resolution Rules

- Use explicit `[url]` first.
- Otherwise read `APP_URL` from the nearest ancestor `.env`, starting at
  `ORBIT_HOST_CWD` or the process working directory.
- If neither source yields a URL, fail before cURL with
  `validation_failed`, `field=url`, `reason=missing_required_input`.
- Invalid explicit or `.env` values fail with
  `validation_failed`, `field=url`, `reason=invalid_url`.
- Combined auth modes fail with
  `validation_failed`, `field=auth`, `reason=conflicting_auth_modes`.
- `--json` changes only the renderer and prompt availability. It does not
  change the URL, auth headers, request origin, or TLS rules.

## Failure Mapping

| Condition | `error.code` | `error.meta` |
| --- | --- | --- |
| No explicit or local `.env` URL | `validation_failed` | `field=url`, `reason=missing_required_input` |
| Invalid absolute URL | `validation_failed` | `field=url`, `reason=invalid_url` |
| Both auth flags | `validation_failed` | `field=auth`, `reason=conflicting_auth_modes` |
