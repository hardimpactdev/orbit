# Human Renderer: `orbit deploy:step-list`

[Back to `deploy:step-list` technical contract.](1_deploy-step-list.md)

**Renderer:** Human terminal renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`deploy:step-list` is a read-only gateway registry query. Execution is expected
to complete below one second and does not perform slow external work. No
progress tree is rendered.

## Success Output

Render a `Laravel\Prompts\table` with one row per deployment step, including the
command body in the table. Empty cells render as `—` (em dash).

| Column | Meaning |
| --- | --- |
| ID | Gateway-assigned step id. |
| ORDER | Step order. |
| TITLE | Display label. |
| COMMAND | Step command script. |
| TIMEOUT | Step timeout in seconds. |

When no steps are configured, render the empty state for the selected
production instance:

```text
No deployment steps found for <project.instance>.
```

## Failure Output

Validation, gateway, authorization, app-not-found, and production-app
eligibility failures render one concise error line with the rejected field or
instance selector when available.
