# JSON Renderer: `orbit app-setup-step:list`

[Back to `app-setup-step:list` technical contract.](1_app-setup-step-list.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

`success.data.steps` contains setup step entities. `success.meta.count`
contains the row count.

## Error Shape

The top-level envelope is either `success` or `error`.

Exhaustive command-specific codes:

- `app.not_found`
- `authorization_failed`
