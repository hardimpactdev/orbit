# JSON Renderer: `orbit vpn-client:new <name>`

[Back to `vpn-client:new` technical contract.](1_vpn-client-new.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "client": {
        "id": "client-1",
        "name": "laptop",
        "address": "10.6.0.7",
        "enabled": true,
        "latest_handshake_at": null,
        "kind": "admin",
        "config": "[Interface]\n..."
      }
    },
    "meta": {
      "config_included": true
    }
  }
}
```

When `--config` is absent, omit `client.config` and set
`success.meta.config_included=false`.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "VPN client name is already in use.",
    "meta": {
      "field": "name",
      "reason": "duplicate_client"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.client` | object | Created admin VPN client. |
| `success.data.client.config` | string | Generated WireGuard config. Present only when `--config` is supplied. Its `DNS =` line points only at the WireGuard server DNS endpoint. |
| `success.meta.config_included` | boolean | Whether the config was included in the payload. |
| `error.code` | `validation_failed`, `vpn_runtime_unavailable`, `authorization_failed`, `vpn_backend_unavailable`, `vpn_backend_auth_failed` | Stable command failure code. |
| `error.meta` | object | Validation, authorization, backend, or authentication failure context. |
