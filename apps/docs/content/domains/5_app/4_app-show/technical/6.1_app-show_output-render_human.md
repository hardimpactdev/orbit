# Human Renderer: `orbit app:show [app]`

[Back to `app:show` technical contract.](1_app-show.md)

This page describes the human-rendered terminal output for `app:show`.

**Renderer:** Human renderer.

## Primitive

- Detail: [Show detail](../../../../ux/commands/details/show-detail.md)
- Placement table: [Table](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. Prompt behavior belongs to
[`interactive input mode`](5.1_app-show_input-mode_interactive.md).
Non-interactive validation failures are rendered here as prose errors when
`--json` is absent.

## Progress Tree

`app:show` is a registry read. Execution is expected to complete below one
second and does not perform slow external work or live instance-role probes. No
progress tree is rendered.

## Success Output

When the app is found:

```text

┌  App: docs
│
├  Repository    git@github.com:my/repo.git
│
├  PHP           8.5
│
├  Processes     vite (development)
│
├  Routes        docs.test
│
└  App deps      findings (2 danger, 14 warning)

+----------------+-----------+-------+--------------------------------+--------------------------------+
| NAME           | DRIVER    | NODE  | URL                            | APP DEPS                       |
+----------------+-----------+-------+--------------------------------+--------------------------------+
| development    | orbit     | app-1 | https://docs.test              | findings (2 danger, 14 warning) |
| ├─ feature-docs| workspace | app-1 | https://feature-docs.docs.test | —                              |
| └─ main        | workspace | app-1 | https://main.docs.test         | —                              |
+----------------+-----------+-------+--------------------------------+--------------------------------+
```

Instances render as table rows in name order. Each instance's workspaces follow
as indented rows in workspace-name order. Missing values render as `—`.
Processes and routes render as app-level summaries above the table.

The app summary never renders a server, path, root, URL, domain, or
environment. Placement facts appear only in instance and workspace table rows.

`App deps` remains in the logical summary and repeats on instance rows as the
logical app aggregate. Workspace rows render `—`.

When the app has no registered instances, the detail summary is
followed by:

```text
No instances found.
```

## Failure Output

Human-rendered failures must show:

- the failing phase or field;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the operator can act on it.

### Missing input

```text
The app argument is required.
```

### App not found

```text
App 'docs' not found or not visible.
```

### Not authorized

```text
This caller is not authorized to inspect 'docs'.
```

### Gateway unavailable

```text
Gateway connection is required to show app details.
```

### Local context invalid

```text
Local node role setting is invalid.
```
