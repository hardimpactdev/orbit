# Human Renderer: `orbit schedule:logs`

[Back to `schedule:logs` technical contract.](1_schedule-logs.md)

**Renderer:** Human terminal renderer.

## Primitive

None. Renderer prints concise prose or detail lines via `$this->line(...)` and does not render a table, prompt, spinner, or progress tree.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`schedule:logs` is a read-only gateway run-history query. Execution is expected to complete below one second and does not perform slow external work. No progress tree is rendered.

## Success Output

Render the schedule name, scope, target, run id, status, exit code, started and finished timestamps, then captured stdout and stderr sections. Empty output sections render `-`.

## Failure Output

Validation, not-found, gateway, authorization, and log-read failures render one concise error line with the rejected field, schedule name, run id, or selected scope when available.
