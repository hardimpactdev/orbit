# JSON Renderer: `orbit metrics:enable`

[Back to `metrics:enable` technical contract.](1_metrics-enable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "node": "app-1",
      "assignment": {
        "role": "metrics",
        "status": "active",
        "settings": {}
      }
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The node option is required.",
    "meta": {
      "field": "node"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.node` | string | Target node. |
| `success.data.assignment.role` | string | Always `metrics`. |
| `success.data.assignment.status` | string | Role assignment convergence status. |
| `success.data.assignment.settings` | object | Empty object for the metrics role. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `node_role.convergence_failed` | Stable command failure code. |
