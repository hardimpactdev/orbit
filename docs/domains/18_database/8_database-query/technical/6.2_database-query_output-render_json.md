# JSON Renderer: `orbit database:query`

[Back to `database:query` technical contract.](1_database-query.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "connection": "acme",
      "driver": "pgsql",
      "statement_class": "select",
      "columns": ["id", "email"],
      "rows": [
        { "id": 1, "email": "a@example.test" }
      ],
      "row_count": 1,
      "affected_count": 0
    },
    "meta": {
      "target": "acme",
      "target_type": "app",
      "elapsed_ms": 12,
      "truncated": false
    }
  }
}
```

## Error Shape

The top-level envelope is either `success` or `error`.

Exhaustive command-specific codes:

- `database_connection.not_found`
- `database_connection.target_not_found`
- `database_query.connection_ambiguous`
- `database_query.write_not_allowed`
- `database_query.execution_failed`

`--json` forces non-interactive input mode; this command never prompts for SQL.
