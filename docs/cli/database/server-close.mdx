Give the user `default` the admin password on an [adopted Valkey server](/reference/database-servers#close-an-adopted-server), so a client without a password gets no access.

```bash
orbit database:server:close <slug> [--idempotency-key=KEY] [--json]
```

The Gateway refuses with `database.server_in_use` while a connection on the server has no password, or while a client other than the Gateway is logged in as `default`. A server that is already closed runs a readiness check. The command exists only for the adopted Valkey Processes.
