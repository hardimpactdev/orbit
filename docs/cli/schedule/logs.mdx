title: "orbit schedule:logs"
sidebarTitle: "schedule:logs"
description: "Return the newest complete lines of the Schedule's service journal. `schedule` is the UUID of an installed Schedule."
---

```bash
orbit schedule:logs <schedule> [--lines=COUNT] [--follow] [--json]
```

| Option | Default | Meaning |
| --- | --- | --- |
| `--lines=COUNT` | `100` | 1 through 1,000 lines. |
| `--follow` | off | Reserved; refuses until the fixed Agent is pinned. |

Orbit returns a bounded snapshot of the service journal. For a [migrated Instance Schedule](/reference/schedules#checkout-migration), it combines retained service entries and later container-command entries from the Node journal; the read keeps at most 4 MiB and waits at most 120 seconds. It redacts the owning Instance's stored environment values.

`--follow` currently refuses with `schedule.follow_unavailable`: Schedule follow needs orbit-agent 0.14.0. The fixed Agent must be released, pinned and installed before follow is enabled. See [Agent releases](/reference/node-agent#releases).
