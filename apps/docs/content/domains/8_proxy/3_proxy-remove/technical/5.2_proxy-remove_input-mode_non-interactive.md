# Non-Interactive Input Mode: `orbit proxy:remove`

[Back to `proxy:remove` technical contract.](1_proxy-remove.md)

**Input mode:** Non-interactive.

## Mode Selection

This contract applies without a TTY or when `--json` is present. `--json` forces non-interactive input mode.

## Behavior

No prompts are rendered. `domain` must resolve from arguments, and `--force`
is required before side effects. Missing `domain` fails before side effects
with `error.code=validation_failed`. Missing `--force` fails before side
effects with `error.code=validation_failed`, `error.meta.field=force`, and
`error.meta.reason=destructive_consent_required`.

`--json` selects the JSON renderer only. It does not change validation, does not grant authorization, and does not imply destructive consent.
