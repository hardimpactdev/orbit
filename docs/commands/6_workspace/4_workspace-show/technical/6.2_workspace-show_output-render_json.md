# JSON Renderer: `orbit workspace:show [name]`

[Back to `workspace:show` technical contract.](1_workspace-show.md)

This page describes the JSON-rendered output for `workspace:show`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](5.2_workspace-show_input-mode_non-interactive.md),
even when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "workspace": {
        "name": "feature-docs",
        "app": "docs",
        "branch": "feature/docs",
        "path": "/home/orbit/apps/docs/.worktrees/feature-docs",
        "url": "https://feature-docs.docs.test",
        "node": {
          "name": "app-1",
          "host": "1.2.3.4"
        },
        "agent_ide": {
          "adapter": "opencode",
          "inherited_from": "app",
          "workspace_discovery": "available"
        },
        "runtime_expectations": {
          "php_version": "8.5",
          "php_version_inherited_from": "app",
          "fpm_pool": "orbit-docs-feature-docs",
          "hostname": "feature-docs.docs.test"
        },
        "inherited_processes": [
          { "name": "vite" }
        ],
        "route": {
          "host": "feature-docs.docs.test",
          "kind": "workspace",
          "owner": "workspace"
        },
        "latest_setup_run": {
          "run_id": 12345,
          "status": "completed",
          "completed_at": "2026-04-30 18:00:00"
        }
      }
    },
    "meta": {
      "registry_only": true
    }
  }
}
```

## Success Fields

| Field | Type | Meaning |
| --- | --- | --- |
| `workspace.name` | string | Workspace slug. Unique within the parent app. |
| `workspace.app` | string | Parent app slug. |
| `workspace.branch` | string \| null | Branch recorded for the workspace. `null` when not recorded. |
| `workspace.path` | string | Configured workspace path on the owning app node. |
| `workspace.url` | string | Canonical HTTPS URL. |
| `workspace.node.name` | string | Owning app-node slug (the parent app's node). |
| `workspace.node.host` | string | Owning app-node host or address recorded in node configuration. |
| `workspace.agent_ide.adapter` | string \| null | Effective agent IDE adapter for this workspace. `null` when no adapter is configured at any level. |
| `workspace.agent_ide.inherited_from` | string | Resolution source for the rendered adapter. See [Agent IDE Resolution Reporting](#agent-ide-resolution-reporting). |
| `workspace.agent_ide.workspace_discovery` | string \| null | Whether the resolved adapter exposes workspace discovery for the parent app. `null` when `workspace.agent_ide.adapter` is `null`. |
| `workspace.runtime_expectations.php_version` | string | Effective PHP version (e.g. `8.5`). |
| `workspace.runtime_expectations.php_version_inherited_from` | string | Source of the effective PHP version. See [PHP Version Resolution Reporting](#php-version-resolution-reporting). |
| `workspace.runtime_expectations.fpm_pool` | string | PHP-FPM pool name for the workspace. |
| `workspace.runtime_expectations.hostname` | string | Derived workspace hostname. |
| `workspace.inherited_processes[]` | object[] | Full registry list of process definitions inherited from the parent app. Not truncated. Runtime status belongs to the `process` family / process events, not `workspace:show`. |
| `workspace.inherited_processes[].name` | string | Process slug. |
| `workspace.route` | object \| null | Workspace-owned proxy route. `null` when no workspace-owned route exists. |
| `workspace.route.host` | string | Route hostname as recorded in `proxy`. |
| `workspace.route.kind` | string | Route kind. Always `workspace` for workspace-owned routes. |
| `workspace.route.owner` | string | Route owner family. Always `workspace` for workspace-owned routes. |
| `workspace.latest_setup_run` | object \| null | Summary of the most recent setup run. `null` if never run. |
| `workspace.latest_setup_run.run_id` | integer | Setup run identifier. |
| `workspace.latest_setup_run.status` | string | Setup run status. See [Setup Run Status Enum](#setup-run-status-enum). |
| `workspace.latest_setup_run.completed_at` | string \| null | Completion timestamp (ISO 8601 `YYYY-MM-DD HH:MM:SS`). `null` when the run has not yet completed. |
| `meta.registry_only` | boolean | Always `true` for this command. Signals the payload is a registry read rather than a live probe result. |

`workspace:show` is a registry read. It does not return live PHP-FPM,
document-root, route, process, or node-reachability checks. It does not
report a "stale-versus-tracked" indicator either: detecting workspaces that
were archived in an external agent IDE adapter requires a live probe and
belongs to `app:prune` and the agent IDE adapter, not to `workspace:show`.
Use [`doctor --family=workspace --json`](../../workspace-doctor.md) for
workspace runtime artifact drift output. Setup-time HTTP probe results belong
to `workspace:setup` command metadata, not this registry view.

If real-world workspaces grow inherited-process lists large enough to require
pagination, paging metadata will be added under `success.meta` (mirroring
`app:list`). The default contract emits full lists with no truncation
indicator.

### Agent IDE Resolution Reporting

`workspace.agent_ide` reports the effective resolved view, not the full chain.
The resolution order defined in
[`ARCHITECTURE.md` §Agent IDE integration](../../../../ARCHITECTURE.md#agent-ide-integration) is collapsed
into one effective adapter plus one source label. `workspace:show` is the
deepest viewer in the chain, so `inherited_from` carries the full enum.

`workspace.agent_ide.inherited_from` values:

| Value | Meaning |
| --- | --- |
| `workspace` | The workspace has an explicit agent IDE setting and that setting is in effect. Reserved for the future workspace-level override per [`ARCHITECTURE.md` §Agent IDE integration](../../../../ARCHITECTURE.md#agent-ide-integration). |
| `app` | The workspace inherits, and the parent app has an explicit agent IDE setting. |
| `node` | Both the workspace and the parent app inherit, and the owning node has a node-level adapter set. |
| `default` | Neither the workspace, the parent app, nor the owning node has an explicit setting; no agent IDE is configured. |

`workspace.agent_ide.workspace_discovery` values:

| Value | Meaning |
| --- | --- |
| `available` | The resolved adapter implements workspace discovery for the parent app. |
| `unavailable` | Reserved for a future explicit live adapter check. `workspace:show` does not emit this value in its registry-only read path. |
| `unsupported` | The resolved adapter does not implement workspace discovery. |
| `null` | `workspace.agent_ide.adapter` is `null`; no discovery is meaningful. |

### PHP Version Resolution Reporting

`workspace.runtime_expectations.php_version_inherited_from` reports whether
the effective PHP version is a workspace-level override or inherited from the
parent app, per
[`workspace-concepts.md` §PHP Version](../../workspace-concepts.md#php-version).

| Value | Meaning |
| --- | --- |
| `workspace` | The workspace row stores an explicit PHP version override and that value is in effect. |
| `app` | The workspace inherits the parent app's PHP version. |

### Setup Run Status Enum

`workspace.latest_setup_run.status` values:

| Value | Meaning |
| --- | --- |
| `pending` | The run is queued and has not started. |
| `running` | The run is currently executing. |
| `completed` | The run finished successfully. |
| `failed` | The run finished with an error. |
| `cancelled` | The run was cancelled before completion. |

`workspace:history` and `workspace:log` are the dedicated views for full run
history and per-run logs.

## Error Shapes

### Missing required input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Workspace name is required.",
    "meta": {
      "field": "name"
    }
  }
}
```

### Workspace not found

```json
{
  "error": {
    "code": "workspace.not_found",
    "message": "Workspace 'feature-docs' not found or not visible.",
    "meta": {
      "name": "feature-docs"
    }
  }
}
```

### Ambiguous workspace

```json
{
  "error": {
    "code": "workspace.ambiguous_name",
    "message": "Workspace name 'feature-docs' is ambiguous.",
    "meta": {
      "name": "feature-docs",
      "apps": ["docs", "api"]
    }
  }
}
```

### Not authorized

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This caller is not authorized to inspect 'feature-docs'.",
    "meta": {
      "name": "feature-docs",
      "app": "docs",
      "caller_role": "control"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to show workspace details.",
    "meta": {}
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `workspace.agent_ide.inherited_from` | `workspace`, `app`, `node`, `default` |
| `workspace.agent_ide.workspace_discovery` | `available`, `unavailable`, `unsupported`, `null` |
| `workspace.runtime_expectations.php_version_inherited_from` | `workspace`, `app` |
| `workspace.route.kind` | `workspace` |
| `workspace.route.owner` | `workspace` |
| `workspace.latest_setup_run.status` | `pending`, `running`, `completed`, `failed`, `cancelled` |
| `error.code` | `validation_failed`, `workspace.not_found`, `workspace.ambiguous_name`, `authorization_failed`, `gateway_unavailable` |

The `error.code` values listed here are exhaustive for `workspace:show`. Add a
new value to this renderer contract before implementing another JSON failure
code. Live check outcomes never appear here: the registry read either succeeds
or the read itself fails with one of the codes above.
