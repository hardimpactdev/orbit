# JSON Renderer: `orbit gateway:use <name>`

[Back to `gateway:use` technical contract.](1_gateway-use.md)

This page describes the JSON-rendered output for `gateway:use`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "result": {
        "action": "selected"
      },
      "gateway": {
        "name": "default",
        "url": "https://10.6.0.2",
        "wireguard_ip": "10.6.0.2"
      }
    }
  }
}
```

## Error Shapes

### Invalid name

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Gateway name is invalid.",
    "meta": {
      "field": "name",
      "reason": "invalid_name"
    }
  }
}
```

### Unknown gateway

```json
{
  "error": {
    "code": "validation_failed",
    "message": "No gateway named 'default' is configured.",
    "meta": {
      "field": "name",
      "reason": "not_found"
    }
  }
}
```
