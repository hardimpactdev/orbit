# Non-Interactive Input Mode: `orbit tool-stop`

[Back to `tool-stop` technical contract.](1_tool-stop.md)

**Input mode:** Non-interactive.

## Mode Selection

This contract applies without a TTY or when `--json` is present. `--json`
forces non-interactive input mode.

No prompts are rendered.

## Required Input

The command requires a tool name and a resolvable target before side effects.

Target resolution uses this hierarchy:

1. `--app` selector: app slug, app domain, or `<slug>.<node-tld>`.
2. `--node`.
3. Local `node:default`.
4. Gateway-known caller identity.

When `--app` and `--node` are both present, they must resolve to the same node.

## Missing Target

If no target resolves, the command fails before side effects:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A node or app target is required. Provide --node, --app, configure node:default, or select a target interactively.",
    "meta": {
      "fields": ["target"]
    }
  }
}
```

Human non-interactive output uses the same message as prose.
