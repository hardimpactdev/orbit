# JSON Renderer: `orbit app:instance`

[Back to `app:instance` technical contract.](1_app-instance.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shapes

### List

```json
{
  "success": {
    "data": {
      "instances": [
        {
          "app": "billing",
          "name": "production-cloud",
          "driver": "laravel-cloud",
          "driver_config": {
            "application_id": "app_123",
            "environment_id": "env_123"
          },
          "runtime": {
            "runtime_kind": "php",
            "php_version": "8.5",
            "frankenphp_image": "dunglas/frankenphp:1-php8.5",
            "mode": "classic",
            "configured_mounts": [],
            "required_php_extensions": ["intl", "redis"]
          },
          "latest_deployment_status": null,
          "latest_deployment_run_id": null
        }
      ]
    },
    "meta": {
      "count": 1
    }
  }
}
```

### Show or add

```json
  "success": {
    "data": {
      "instance": {
        "app": "billing",
        "name": "production-cloud",
        "driver": "laravel-cloud",
        "driver_config": {
          "application_id": "app_123",
          "environment_id": "env_123"
        },
        "runtime": {
          "runtime_kind": "php",
          "php_version": "8.5",
          "frankenphp_image": "dunglas/frankenphp:1-php8.5",
          "mode": "classic",
          "configured_mounts": [],
          "required_php_extensions": ["intl", "redis"]
        },
        "latest_deployment_status": null,
        "latest_deployment_run_id": null

```

### Remove

```json
{
  "success": {
    "data": {
      "result": {
        "action": "removed",
        "app": "billing",
        "instance": "production-cloud"
      }
    }
  }
}
```

## Error Shapes

Command-specific errors use the standard error envelope. Common validation,
authorization, and gateway failures follow the shared command contract.
