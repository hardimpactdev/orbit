# Native Node removal

The Node removal rewrite supplies complete forward and restore inputs at admission. It records the membership transition and Route withdrawal intent in that transaction. Native placed command/shell steps perform each effect; steps do not refresh their intent or report progress through the Gateway.

Restoration uses the captured prior publication and native step results. Terminal projection restores the Gateway journal or records the completed deletion. An uncertain retirement retains the Node record. Secrets and terminal history decoding use the shared SwampCommandStep helper. The hub, Route, certificate and Metrics owners supply their native action contracts; removal does not wrap their old Gateway clients.

Every operational script is inline in run and passes shellcheck. Logical Nodes 1 and 18 require the shared built-in shell proxy transport before any live effect. The existing TypeScript proxy transport is not proof of built-in shell placement. A live removal test requires an explicitly selected disposable target.
