# JSON Renderer: `orbit version`

[Back to `version` technical contract.](1_version.md)

This page describes the JSON-rendered output for `orbit version`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success output uses the top-level `success.data` object. Failures while looking
up release metadata do not produce an error envelope; unexpected framework
validation failures still use the shared top-level `error` envelope.

## Success Shape

JSON output uses the standard success envelope. Timestamp values are ISO 8601
strings when known and `null` when unknown:

```json
{
    "success": {
        "data": {
            "version": "0.1.105",
            "latest_version": "0.1.108",
            "update_available": true,
            "released_at": "2026-06-17T10:47:00+00:00",
            "installed_at": "2026-06-17T10:54:00+00:00"
        },
        "meta": []
    }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `version` | string | Installed Orbit CLI version. |
| `latest_version` | string \| null | Latest configured Orbit release when known; `ORBIT_RELEASE_MANIFEST_URL` takes precedence over public GitHub releases, and an installed version newer than the release source is reported as the latest version. |
| `update_available` | boolean | Whether `latest_version` is newer than `version`. |
| `released_at` | string \| null | ISO 8601 publish timestamp for the installed version. |
| `installed_at` | string \| null | ISO 8601 timestamp for when this CLI version was installed locally. |

When `--local` is present, the same shape is emitted, but release-source fields
are intentionally unset: `latest_version=null`, `update_available=false`, and
`released_at=null`.

## Error Shapes

| Failure | `error.code` | Notes |
| --- | --- | --- |
| Zsh shell integration failed under `--local` | `shell_integration_failed` | Only when the login shell is zsh and ensure cannot write the managed snippet or rc block. |

Other failures are not emitted: release-source unavailability stays a success
payload with null release fields.

Release metadata lookup failures return a success envelope with missing release
metadata. Validation or framework failures use the shared JSON envelope.
