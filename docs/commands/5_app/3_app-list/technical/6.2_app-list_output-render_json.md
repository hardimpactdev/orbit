# JSON Renderer: `orbit app:list`

[Back to `app:list` technical contract.](1_app-list.md)

This page describes the JSON-rendered output for `app:list`.

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The app array is rendered as a flat array under `success.data.apps`. Apps are
sorted by owning node name (ascending, case-insensitive) and then by app name
(ascending, case-insensitive). This matches the order shown in human output, so
both renderers represent the same result.

`app:list` does not include `success.data.context`. Its `--node` and
`--environment` inputs are registry filters, not a resolved execution context.
Use `success.meta` for stable filter echoes if a future renderer contract needs
to expose them.

## Success Shape

```json
{
  "success": {
    "data": {
      "apps": [
        {
          "name": "docs",
          "node": "app-1",
          "environment": "development",
          "url": "https://docs.test",
          "path": "/home/docs/app",
          "root": "public",
          "repository": null,
          "php_version": "8.5",
          "adopted": false
        }
      ]
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `app` | array | Ordered list of visible apps matching the applied filters. |
| `apps[]` | object | Canonical app JSON entity defined in [`5_app/README.md`](../../README.md#app-json-entity). App registry rows are desired-state rows; no separate `status` field is emitted by `app:list`. |

## Error Shapes

### Invalid filter value

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Invalid value for --environment: 'staging'. Allowed values: development, production.",
    "meta": {
      "field": "environment",
      "value": "staging",
      "allowed": ["development", "production"]
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to list apps.",
    "meta": {}
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized to read the app registry.",
    "meta": {
      "caller_role": "app"
    }
  }
}
```
