# Human Output Renderer: `orbit workspace-teardown-step:remove`

[Back to `workspace-teardown-step:remove` technical contract.](1_workspace-teardown-step-remove.md)

This page describes the human-readable output for
`workspace-teardown-step:remove`.

**Renderer:** Human renderer.

## Primitive

None. The human renderer prints short prose/status lines only and does not render a table, spinner, or progress tree.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered because policy removal and order compaction are
expected to stay below one second and perform no slow external work. The command
writes gateway configuration only and does not contact nodes.

## Success Output

Render a confirmation message when the step is removed and remaining teardown
steps are compacted.

```text
Removed teardown step 18 from app instance 'hauser.nmbp'.
Remaining steps renumbered.
```

If the removed step was the only teardown step for the app instance:

```text
Removed teardown step 18 from app instance 'hauser.nmbp'.
App instance 'hauser.nmbp' now has no workspace teardown steps.
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no
JSON envelope, and next-step guidance only when the operator can act on it.

| Scenario | Message |
| --- | --- |
| Missing destructive consent | `This is a destructive operation. Use --force or confirm the prompt.` |
| Cancelled confirmation | `Operation cancelled.` |
| Step not found | `Teardown step 18 not found for app 'docs'.` |
| App not found | `Could not resolve app: docs` |
| Authorization failed | `This node is not authorized for 'workspace:write' on 'app-1'.` |
