# JSON Renderer: `orbit process:list`

[Back to `process:list` technical contract.](1_process-list.md)

This page describes the JSON-rendered output for `process:list`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces non-interactive input mode.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the resolved context and process definitions with latest durable lifecycle event data when present.

`success.data.context` is present because `process:list` must resolve one app or workspace execution scope before it can list app-owned process definitions. This does not imply a context block for registry list commands whose inputs are only filters.

## Success Example

```json
{
  "success": {
    "data": {
      "context": {
        "app": "docs",
        "workspace": "feature-docs"
      },
      "processes": [
        {
          "name": "vite",
          "command": "npm run dev",
          "restart_policy": "never",
          "crash_notification": "agent_ide",
          "runtime_unit": "orbit_docs_feature-docs_vite",
          "last_event": {
            "id": 123,
            "type": "started"
          }
        }
      ]
    },
    "meta": {}
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "validation_failed",
    "message": "An app context is required.",
    "meta": {
      "field": "app"
    }
  }
}
```

## Caller Role Error

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "The gateway did not authorize this caller for the command.",
    "meta": {
      "caller_role": "unknown"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: app or workspace context is missing, invalid, or ambiguous in non-interactive input mode.
- `caller_role_not_allowed`: caller role is `unknown`.
- `authorization_failed`: caller cannot read process configuration for the target context.
- `gateway_unavailable`: the CLI cannot reach the gateway API.
