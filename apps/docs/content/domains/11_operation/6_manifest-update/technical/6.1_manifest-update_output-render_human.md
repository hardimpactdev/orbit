# Human Renderer: `orbit manifest:update <url>`

[Back to `manifest:update` technical contract.](1_manifest-update.md)

**Renderer:** Human renderer.

## Primitive

None. The command renders concise status lines.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered. The command performs one bounded gateway write.

## Success Output

```text
Release manifest URL updated.
Source: custom
URL: https://artifacts.example.com/channels/live-test/orbit-release-manifest.json
```

## Failure Output

Human-rendered failures show the error code and message without a JSON envelope.
