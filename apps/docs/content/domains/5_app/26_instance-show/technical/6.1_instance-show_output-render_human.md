# Human Renderer: `orbit instance:show`

[Back to `instance:show` technical contract.](1_instance-show.md)

**Renderer:** Human renderer.

## Primitive

None. The command writes a compact key/value summary.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered because this is a fast registry read.

## Success Render

Print the dotted instance, driver, node, URL, path, runtime mode, PHP version,
extensions, and latest deployment status when present.

## Error Render

Render validation, not-found, and authorization failures directly.
