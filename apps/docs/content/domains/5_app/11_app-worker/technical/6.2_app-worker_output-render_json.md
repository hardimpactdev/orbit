# JSON Renderer: `orbit app:worker`

[Back to `app:worker` technical contract.](1_app-worker.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via
`$this->line(...)`.

The JSON renderer returns the worker payload under the standard
`success`/`error` envelope.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts even when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shapes

### Show — worker disabled

```json
{
  "success": {
    "data": {
      "app": "docs",
      "worker_enabled": false,
      "worker_config": null
    }
  }
}
```

### Show — worker enabled

```json
{
  "success": {
    "data": {
      "app": "docs",
      "worker_enabled": true,
      "worker_config": {
        "workers": "auto",
        "max_requests": 500
      }
    }
  }
}
```

### Enable — readiness passed and state mutated

```json
{
  "success": {
    "data": {
      "app": "docs",
      "worker_enabled": true,
      "worker_config": {
        "workers": "auto",
        "max_requests": 500
      },
      "changed": true
    }
  }
}
```

### Enable — already enabled (no-op)

```json
{
  "success": {
    "data": {
      "app": "docs",
      "worker_enabled": true,
      "worker_config": {
        "workers": "auto",
        "max_requests": 500
      },
      "changed": false
    }
  }
}
```

### Disable — state mutated, configuration retained

```json
{
  "success": {
    "data": {
      "app": "docs",
      "worker_enabled": false,
      "worker_config": {
        "workers": "auto",
        "max_requests": 500
      },
      "changed": true
    }
  }
}
```

### Disable — already disabled (no-op)

```json
{
  "success": {
    "data": {
      "app": "docs",
      "worker_enabled": false,
      "worker_config": null,
      "changed": false
    }
  }
}
```

### Fields

| Field | Type | Meaning |
| --- | --- | --- |
| `app` | string | App identity slug. |
| `worker_enabled` | boolean | Whether FrankenPHP worker mode is enabled for this app. |
| `worker_config` | object \| null | Worker policy stored on the app. `null` only when worker mode has never been enabled. |
| `worker_config.workers` | string \| integer | `"auto"` lets FrankenPHP pick a count based on CPU; an integer pins the worker count. |
| `worker_config.max_requests` | integer | Requests each worker handles before recycling. Surfaced to the worker process as the `MAX_REQUESTS` env consumed by Laravel's stock `public/frankenphp-worker.php`. |
| `changed` | boolean | Whether the action mutated state. Present on `enable` and `disable`; omitted from `show`. |

## Error Shapes

### Missing or invalid action

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Action must be one of: show, enable, disable.",
    "meta": {
      "field": "action",
      "allowed": ["show", "enable", "disable"]
    }
  }
}
```

### Missing app

```json
{
  "error": {
    "code": "validation_failed",
    "message": "App is required.",
    "meta": {
      "field": "app"
    }
  }
}
```

### App not found

```json
{
  "error": {
    "code": "app.not_found",
    "message": "App 'docs' not found.",
    "meta": {
      "app": "docs"
    }
  }
}
```

### Unsupported runtime

```json
{
  "error": {
    "code": "app.worker_unsupported_runtime",
    "message": "Worker mode requires runtime_kind=php; app 'docs' uses 'static'.",
    "meta": {
      "app": "docs",
      "missing": ["runtime_kind=php"],
      "runtime_kind": "static"
    }
  }
}
```

### Owning node record missing

```json
{
  "error": {
    "code": "app.worker_unknown_node",
    "message": "App 'docs' has no owning node; cannot validate worker readiness.",
    "meta": {
      "app": "docs",
      "missing": ["owning_node"]
    }
  }
}
```

### App source path missing

```json
{
  "error": {
    "code": "app.worker_missing_path",
    "message": "App 'docs' has no source path; cannot validate worker readiness.",
    "meta": {
      "app": "docs",
      "missing": ["app_path"]
    }
  }
}
```

### Readiness failed

`error.meta.missing` enumerates every unmet condition. The worker-file entry
in `missing` and `error.meta.worker_file` always reflect the configured
`document_root`. For example, an app with `document_root=web` reports
`web/frankenphp-worker.php` instead of `public/frankenphp-worker.php`.
`error.meta.probe_output` contains the raw probe stdout for debugging.

```json
{
  "error": {
    "code": "app.worker_readiness_failed",
    "message": "App 'docs' is not ready for worker mode.",
    "meta": {
      "app": "docs",
      "missing": [
        "vendor/laravel/octane",
        "public/frankenphp-worker.php",
        "octane.server=frankenphp"
      ],
      "probe_output": "",
      "worker_file": "public/frankenphp-worker.php"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'app:worker' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "app:worker",
      "serving_node": "app-1"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to manage worker mode.",
    "meta": {}
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `action` argument | `show`, `enable`, `disable` |
| `worker_config.workers` | `"auto"` or a positive integer |
| `error.code` | `validation_failed`, `app.not_found`, `app.worker_unsupported_runtime`, `app.worker_unknown_node`, `app.worker_missing_path`, `app.worker_readiness_failed`, `authorization_failed`, `gateway_unavailable` |

The `error.code` values listed here are exhaustive for `app:worker`. Add a
new value to this renderer contract before implementing another JSON failure
code.

## Test Mapping

| Path | Coverage |
| --- | --- |
| `apps/gateway/tests/Feature/Commands/Apps/AppWorkerCommandTest.php` | JSON envelope shape, worker payload for show/enable/disable, the `changed` flag, and the error codes `validation_failed`, `app.not_found`, `app.worker_unsupported_runtime`, `app.worker_missing_path`, `app.worker_readiness_failed`, and `gateway_unavailable` (forwarded operator-mode caller). |
| `apps/gateway/tests/Feature/Http/Api/AppWorkerControllerTest.php` | API JSON envelope shape, success payload, HTTP status mapping for `app.not_found` (404) and `app.worker_readiness_failed` (422), and `authorization_failed` for the `app:worker` permission. |
| `apps/gateway/tests/Unit/Services/Apps/AppWorkerReadinessTest.php` | Service-level `app.worker_unknown_node` (no owning node relation) and `app.worker_missing_path` (empty source path) error code paths. |

The `app.worker_unknown_node` path cannot be reached from the command test
because the SQLite foreign-key constraint on the `apps` `node_id` column
blocks the orphan scenario; the unit test exercises it directly against the
readiness service.
