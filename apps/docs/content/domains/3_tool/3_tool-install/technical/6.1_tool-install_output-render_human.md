# Human Renderer: `orbit tool-install`

[Back to `tool-install` technical contract.](1_tool-install.md)

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and before gateway reads, node inspection, or node apply begins.

```text
┌ Installing Tool
○ Resolve target
○ Read gateway tool configuration
○ Run command action
└ Working...
```

## Success Output

Human output presents the selected tool state using Orbit product vocabulary: tool, node, expected lifecycle state, observed state when available, managed flag, and version/config metadata when tracked by the tool definition.

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose error, and actionable recovery guidance when the operator can resolve the issue.

Unsupported status values are rendered as validation failures, for example:
`Invalid --status value 'foo'. Valid values: installed, running.`

Missing target source failures tell the operator to provide `--node`, provide
`--app`, configure `node:default`, or run interactively to select a target.
