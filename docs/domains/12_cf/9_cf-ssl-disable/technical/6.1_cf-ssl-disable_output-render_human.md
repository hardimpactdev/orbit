# Human Renderer: `orbit cf-ssl:disable`

[Back to `cf-ssl:disable` technical contract.](1_cf-ssl-disable.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`cf-ssl:disable` resolves provider state and performs an external provider
write. After input resolution and before the Cloudflare SSL request begins,
render this progress tree:

```text
┌ Disabling Cloudflare SSL
○ Resolve Cloudflare zone
○ Confirm destructive SSL change
○ Update Cloudflare SSL mode
└ Working...
```

## Success Output

Render one concise success line:

```text
Cloudflare SSL disabled for example.com
```

## Failure Output

Validation, missing destructive consent, gateway, authorization, and Cloudflare
failures render one concise error line.
