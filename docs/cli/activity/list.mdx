---
title: "orbit activity:list"
sidebarTitle: "activity:list"
description: "List Activity records, newest first. Filters combine. A value that matches nothing returns an empty list."
---

```bash
orbit activity:list [--limit=COUNT] [--request-id=UUID] [--before-id=ID] [--status=STATUS] [--command=COMMAND] [--caller=ID] [--target=ID] [--json]
```

| Option | Default | Meaning |
| --- | --- | --- |
| `--limit=COUNT` | `25` | Maximum rows, from 1 through 200. The CLI rejects another value with `activity.limit_invalid`. |
| `--request-id=UUID` | none | Return only the attempt with this exact API request UUID. The CLI rejects a value that is not a UUID with `activity.request_id_invalid`. |
| `--before-id=ID` | none | Return rows whose id is smaller than this positive integer, which is the next older page. The CLI rejects another value with `activity.before_id_invalid`. |
| `--status=STATUS` | none | Only `running`, `succeeded`, or `failed`. Another value fails with `activity.status_invalid`. |
| `--command=COMMAND` | none | Only rows whose command equals this name, from 1 to 255 characters. Another value fails with `activity.command_invalid`. |
| `--caller=ID` | none | Only rows whose caller Node is this positive integer. A null caller does not match. Another value fails with `activity.caller_invalid`. |
| `--target=ID` | none | Only rows whose target Node is this positive integer. A null target does not match. Another value fails with `activity.target_invalid`. |

The CLI sends the filters as `before_id`, `status`, `command`, `caller_node_id`, and `target_node_id`. The Gateway rejects an invalid filter with `validation.failed` (422). The list never includes the list request itself. Fewer rows than `--limit` means there is no older page.

```bash
orbit activity:list --limit=50
orbit activity:list --request-id=9d6b1e5c-4a3f-4a1b-9f0e-6d2c3f5a7b81
orbit activity:list --status=failed --command=instance:deploy --target=4
orbit activity:list --before-id=480 --caller=2
```

Human output is one table with the columns ID, TIME, COMMAND, STATUS, CALLER, TARGET, and ERROR, followed by the request ID of the list call.
