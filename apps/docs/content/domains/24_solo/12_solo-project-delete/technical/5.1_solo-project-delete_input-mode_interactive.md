# Interactive Input Mode: `orbit solo:project:delete`

[Back to the canonical contract.](1_solo-project-delete.md)

**Input mode:** Interactive.

This mode applies only with a TTY and without `--json`.

## Prompt Behavior

After resolving the node
and project, Orbit asks `Run destructive Solo command
'solo:project:delete' for project '<project>'?` unless `--force` is present.
The confirmation uses the [`confirm`](../../../../ux/commands/inputs/confirm-prompt.md)
primitive and defaults to no.

A declined confirmation fails before side effects with
`error.code=validation_failed`, `error.meta.field=force`, and
`error.meta.reason=destructive_consent_required`. `--force` is explicit
destructive consent and skips the prompt.
