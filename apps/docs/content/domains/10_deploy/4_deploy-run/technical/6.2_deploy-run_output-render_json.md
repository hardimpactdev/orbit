# JSON Renderer: `orbit deploy:run`

[Back to `deploy:run` technical contract.](1_deploy-run.md)

**Renderer:** JSON and stream-JSON renderers.

## Primitive

None. JSON and stream-JSON write machine-readable operation frames directly.

## Selection

- `--json` consumes intermediate operation frames silently and emits exactly
  one terminal frame.
- `--stream-json` emits newline-delimited `tree` and `step` frames followed by
  one canonical terminal frame.
- `--json` and `--stream-json` are mutually exclusive.
- `--detach --json` returns the gateway operation descriptor immediately and
  does not subscribe.

## Envelope

Terminal and detached JSON use the shared [JSON Envelope](../../../README.md#json-envelope).
Stream JSON emits the operation frame contract described below.

## Foreground JSON Terminal Shape

```json
{
  "event": "complete",
  "data": {
    "exit_code": 0,
    "data": {
      "run": {
        "id": 42,
        "project": "docs",
        "instance": "production",
        "status": "completed",
        "exit_code": 0
      },
      "output": {
        "stdout": "Already up to date.\n",
        "stderr": ""
      },
      "footer": "Deployment completed"
    }
  }
}
```

Intermediate frames are not emitted in this mode. A terminal failure uses
`event=error`, preserves the gateway-authored error payload, and exits `1`.

## Stream JSON Shape

```text
{"event":"tree","data":{"title":"Running Deployment","steps":[]}}
{"event":"step","data":{"key":"resolve-app","status":"done","message":"docs.production"}}
{"event":"complete","success":{"data":{"run":{"id":42},"footer":"Deployment completed"},"meta":[]}}
```

Frames are emitted in operation sequence order. Replay de-duplicates sequences
already received over WebSocket.

## Detached JSON Shape

```json
{
  "success": {
    "data": {
      "operation": {
        "uuid": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
        "stream_descriptor_url": "/api/operations/3fa85f64-5717-4562-b3fc-2c963f66afa6/stream",
        "events_url": "/api/operations/3fa85f64-5717-4562-b3fc-2c963f66afa6/events"
      }
    },
    "meta": {
      "detached": true
    }
  }
}
```

`--detach --stream-json` emits one canonical `complete` frame whose success data
contains the same operation descriptor.

## Failure Codes

Pre-subscription failures use the shared JSON error envelope. Stable codes
include `validation_failed`, `gateway_unavailable`, `authorization_failed`,
`instance.not_found`, `deploy.production_project_required`,
`deploy.instance_driver_unsupported`, `deploy.pipeline_empty`,
`node.agent_unreachable`, `deploy.execution_failed`, `deploy.step_failed`, and
`deploy.history_write_failed`.

`node.agent_unreachable` includes `error.meta.reason=agent_push_unavailable`.
