# JSON Renderer: `orbit process:logs [name]`

[Back to `process:logs` technical contract.](1_process-logs.md)

This page describes the JSON-rendered output for `process:logs`.

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present. `--json` also forces
non-interactive input mode. JSON output is bounded and cannot be combined with
`--follow`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the process runtime context and bounded log lines.

## Success Example

```json
{
  "success": {
    "data": {
      "logs": {
        "process": "vite",
        "app": "docs",
        "workspace": "feature-docs",
        "runtime_unit": "orbit_docs_feature-docs_vite.service",
        "lines": [
          {
            "timestamp": "2026-04-30T12:00:00Z",
            "message": "Vite ready"
          }
        ]
      }
    },
    "meta": {
      "line_count": 1
    }
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "validation_failed",
    "message": "--json cannot be combined with --follow.",
    "meta": {
      "field": "json"
    }
  }
}
```

## Caller Role Error

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "The local Orbit caller role could not be resolved.",
    "meta": {
      "caller_role": "unknown"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: process, app, or workspace context is missing, invalid,
  or ambiguous in non-interactive input mode; `--lines` is invalid; or `--json`
  is combined with `--follow`.
- `caller_role_not_allowed`: caller role is `unknown`.
- `authorization_failed`: caller cannot read process logs for the target
  context.
- `process.not_found`: the named process does not exist for the owning app.
- `process.log_read_failed`: the gateway cannot read logs from the owning app
  node runtime backend.
