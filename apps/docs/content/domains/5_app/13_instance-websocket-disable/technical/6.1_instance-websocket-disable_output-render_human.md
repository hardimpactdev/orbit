# Human Renderer: `orbit instance:websocket disable`

[Back to `instance:websocket disable` technical contract.](1_instance-websocket-disable.md)

This page describes the human-rendered output for `instance:websocket disable`.

**Renderer:** Human renderer.

## Primitive

None. Output is emitted as prose lines via `$this->line(...)`.

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered. The disable operation is a fast gateway write
and route sync; no slow external work is performed from the CLI side.

## Success Render

The success output presents the resulting binding fields as labeled key-value
output. The `binding:` label precedes the binding data showing the `internal_host`,
the cleared `public_hosts` list, and the `allowed_origins`.

### Example output

```text
binding:
  app: docs
  instance: production
  serving_node: app-prod-1
  internal_host: websocket.orbit
  public_hosts: []
  allowed_origins:
    - https://docs.example.com
```

## Error Render

Errors are rendered as concise prose messages.
