# Technical Contract: `orbit app:register` (Interactive Input)

This contract defines behavior for **interactive input mode**.

[Back to the canonical contract.](1_app-register.md)

**Input mode:** Interactive.

Use this input mode only when both conditions are true:

- the command is running in a TTY;
- `--json` is not present.

When `--json` is present, use
[`5.2_app-register_input-mode_non-interactive.md`](5.2_app-register_input-mode_non-interactive.md)
even if the process has a TTY.

## Prompts

| ID | Primitive | Label | Required |
| --- | --- | --- | --- |
| `name` | `text` | App name | Yes |
| `node` | `select` | Target app node | Yes (if no default) |
| `path` | `text` | App path on node | Yes (for adoption) |

## Behavior

- **Validation**: Each field is validated as it is entered. Invalid values trigger a re-prompt with a validation message.
- **Node Selection**: If `--node` is missing, the user is presented with a list of authorized app nodes.
- **Path Adoption**: If the command detects that the app name is not registered but a path is provided, it confirms intent to adopt the existing path.
