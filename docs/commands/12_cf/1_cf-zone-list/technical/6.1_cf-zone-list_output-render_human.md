# Human Renderer: `orbit cf-zone:list`

[Back to `cf-zone:list` technical contract.](1_cf-zone-list.md)

**Renderer:** Human terminal renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`cf-zone:list` performs an external provider request and may take longer than
one second. After input resolution and before the Cloudflare request begins,
render this progress tree:

```text
┌ Listing Cloudflare zones
○ Validate provider access
○ Query Cloudflare zones
└ Working...
```

## Success Output

Render a table with one row per Cloudflare zone.

| Column | Meaning |
| --- | --- |
| Zone ID | Cloudflare zone identifier. |
| Domain | Zone name. |
| Status | Provider zone status, such as `active` or `pending`. |

Empty results render `No Cloudflare zones found.`

## Failure Output

Gateway, authorization, and Cloudflare failures render one concise error line.
Provider error details may be included when Cloudflare returns a stable message.
