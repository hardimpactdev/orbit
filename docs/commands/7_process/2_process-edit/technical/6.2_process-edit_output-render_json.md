# JSON Renderer: `orbit process:edit [name]`

[Back to `process:edit` technical contract.](1_process-edit.md)

This page describes the JSON-rendered output for `process:edit`.

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present. `--json` also forces
non-interactive input mode.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the updated process definition, changed fields, and
derived runtime units. Partial post-intent drift is reported under
`success.meta.warnings[]`.

Warning objects contain:

| Field | Meaning |
| --- | --- |
| `code` | Singular product warning code, such as `process.runtime_unit_missing`, with the owning family recorded separately. |
| `family` | State family that owns the warning. |
| `message` | Human-readable warning summary. |
| `next_command` | Suggested command to inspect or repair the warning. |

## Success Example

```json
{
  "success": {
    "data": {
      "process": {
        "name": "vite",
        "app": "docs",
        "command": "npm run dev",
        "restart_policy": "never",
        "crash_notification": "agent_ide"
      },
      "changed": [
        "command"
      ],
      "runtime_units": [
        {
          "name": "orbit_docs_main_vite.service",
          "context": "main"
        }
      ]
    },
    "meta": {
      "warnings": []
    }
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "validation_failed",
    "message": "At least one editable field is required.",
    "meta": {
      "field": "editable_fields"
    }
  }
}
```

## Caller Role Error

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "This command may only be run from a control or gateway node.",
    "meta": {
      "caller_role": "app"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: missing `name` or `app`, invalid enum value, empty
  `command`, or no editable fields supplied.
- `caller_role_not_allowed`: caller role is `app` or `unknown`.
- `authorization_failed`: caller cannot manage process intent for the target
  app.
- `process.not_found`: the named process does not exist for the owning app.
- `gateway_unavailable`: the CLI cannot reach the gateway API before intent is
  changed.
