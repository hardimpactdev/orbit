An [operation](/reference/operations) is a long piece of work, such as an Instance deploy or rollback, that Swamp runs as a native workflow. The Gateway records its intent, status and result. The command that starts it, such as [`instance:deploy`](/cli/instance/deploy) or [`instance:rollback`](/cli/instance/rollback), returns or stops following without stopping the operation. These commands find it again.

Starting commands follow the parent Operation until its result arrives. Ctrl-C stops following and leaves the Operation running. Read it again with `operation:show`.

## Commands

| Command | Result |
| --- | --- |
| [`operation:list`](/cli/operation/list) | List the newest operations, one page at a time. |
| [`operation:show`](/cli/operation/show) | Show one Operation and its native result. |
| [`operation:cancel`](/cli/operation/cancel) | Ask one operation to stop. |

Every command accepts `--json`.
