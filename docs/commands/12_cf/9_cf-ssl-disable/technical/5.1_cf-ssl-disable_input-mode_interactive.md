# Interactive Input Mode: `orbit cf-ssl:disable`

[Back to `cf-ssl:disable` technical contract.](1_cf-ssl-disable.md)

**Input mode:** Interactive.

## Selection

Use this input mode only when the process has a TTY and `--json` is not
present.

## Prompt Behavior

When `--force` is absent, render a confirmation prompt after `zone` resolves and
before side effects:

| Prompt ID | Primitive | Label | Default |
| --- | --- | --- | --- |
| `cf_ssl_disable_confirm` | `confirm` | `Disable Cloudflare SSL for <zone>?` | `false` |

Supplying `--force` is explicit destructive consent and skips the confirmation
prompt. Declining the prompt fails before side effects.
