# JSON Renderer: `orbit proxy:add`

[Back to `proxy:add` technical contract.](1_proxy-add.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "route": {
        "domain": "vite.docs.test",
        "kind": "proxy",
        "owner": {
          "type": "custom",
          "name": null
        },
        "node": "app-1",
        "target": {
          "type": "upstream",
          "value": "http://127.0.0.1:5173"
        },
        "redirect_code": null,
        "tls": {
          "managed_by": "orbit",
          "trusted_by_gateway_ca": true
        },
        "status": "enacted"
      }
    },
    "meta": {
      "action": "created"
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "proxy.enactment_failed",
    "message": "The proxy route was saved, but backend enactment failed.",
    "data": {
      "route": {
        "domain": "vite.docs.test",
        "kind": "proxy",
        "owner": {
          "type": "custom",
          "name": null
        },
        "node": "app-1",
        "target": {
          "type": "upstream",
          "value": "http://127.0.0.1:5173"
        },
        "redirect_code": null,
        "tls": {
          "managed_by": "orbit",
          "trusted_by_gateway_ca": true
        },
        "status": "expected"
      }
    },
    "meta": {
      "next_command": "doctor --family=proxy --fix --node=app-1"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.route` | object | Created or updated custom proxy route. |
| `success.meta.action` | `created`, `updated`, or `converged` | Command outcome. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `proxy.domain_conflict`, `proxy.replacement_consent_required`, `proxy.enactment_failed` | Stable command failure code. |
| `error.data.route` | object | Proxy route intent when a post-intent enactment failure occurred. |
| `error.meta` | object | Field, node, caller, conflicts, or recovery context for automation. |
