# JSON Renderer: `orbit node role:list [node]`

[Back to `node role:list` technical contract.](1_node-role-list.md)

## Primitive

None. JSON renderer emits the standard envelope only.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "node": "client-1",
      "roles": [
        {
          "role": "app-dev",
          "status": "active",
          "settings": {
            "tld": "test"
          },
          "last_error": null,
          "converged_at": "2026-05-17T12:00:00+00:00"
        }
      ]
    },
    "meta": []
  }
}
```

## Error Codes

- `validation_failed`
- `node.not_found`
- `gateway_unavailable`
- `authorization_failed`
