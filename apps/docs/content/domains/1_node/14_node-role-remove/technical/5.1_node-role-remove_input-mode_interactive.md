# Interactive Input: `orbit node role:remove`

[Back to `node role:remove` technical contract.](1_node-role-remove.md)

**Input mode:** Interactive.

Applies only with a TTY and without `--json`.

## Prompt Behavior

Prompt behavior:
- Render a destructive confirmation prompt before side effects when `--force` is absent.
- `--force` bypasses the confirmation prompt.
- The command still validates dependent cleanup rules before removal.

Confirmation prompt:
- `Remove role '<role>' from '<node>'?`
