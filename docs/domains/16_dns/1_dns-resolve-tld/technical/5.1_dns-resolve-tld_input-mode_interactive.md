# Interactive Input Mode: `orbit dns:resolve-tld [tld] [target]`

[Back to `dns:resolve-tld` technical contract.](1_dns-resolve-tld.md)

This page describes how interactive input mode resolves `dns:resolve-tld` input
before command behavior starts.

**Input mode:** Interactive.

## Selection

Use this input mode only when both conditions are true:

- the command is running in a TTY;
- `--json` is not present.

When `--json` is present, use
[`5.2_dns-resolve-tld_input-mode_non-interactive.md`](5.2_dns-resolve-tld_input-mode_non-interactive.md) even if the process has a TTY.

## Responsibilities

- Read supplied arguments and options.
- Prompt for `tld` when `[tld]` is missing.
- Prompt for `target` when `[target]` is missing and `--reset` is absent.
- Reject `target` when `--reset` is present.
- Prompt for destructive reset confirmation when `--reset` is present and
  `--force` is absent.
- Validate field-local values immediately when a supplied value is read or a
  prompt is submitted.
- Stop before side effects when the caller rejects reset confirmation or aborts
  any prompt.

### `dns_resolve_tld.reset_confirm`

| Property | Value |
| --- | --- |
| Primitive | `confirm` |
| Label | `Remove the local resolver override for .{tld}?` |
| Source | destructive confirmation |
| Required | yes when `--reset` is present and `--force` is absent |
| Choices | `yes`, `no` |
| Default | `no` |
| Validation timing | After `tld` is resolved and before resolver files are removed. |
| Invalid terminal behavior | A negative answer exits with the standard command failure status before side effects. |

## Failure Semantics

- Missing required input is collected by prompt before side effects.
- Invalid field-local input shows a validation message and re-prompts until the
  value is valid or the user aborts.
- If reset confirmation is rejected, exit with the standard command failure
  status and do not remove resolver configuration.
- If the user aborts a prompt, exit with the standard command failure status
  and do not start side effects.
