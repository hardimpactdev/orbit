# JSON Renderer: `orbit internal:database-query-local`

[Back to `internal:database-query-local` technical contract.](1_database-query-local.md)

## Primitive

None. This command writes one strict JSON document to stdout.

## Envelope

This internal command also uses the shared [JSON Envelope](../../../../README.md#json-envelope).

## Success Shape

Read queries return `success.data.columns` and `success.data.rows`. Write
queries return `success.data.affected_rows`. Execution metadata such as mode,
limits, truncation flags, row counts, max JSON bytes, and duration lives in
`success.meta`.

## Error Shape

Only these command-specific codes are allowed:

- `validation_failed`
- `missing_token`
- `invalid_token`
- `database_query.write_not_allowed`
- `database_query.execution_failed`
