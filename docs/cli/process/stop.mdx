---
title: "orbit process:stop"
sidebarTitle: "process:stop"
description: "Stop an installed Process and store the stopped desired state. A hibernation wake leaves a stopped Process stopped."
---

```bash
orbit process:stop <process> [--idempotency-key=KEY] [--json]
```

On a container Instance, a Process whose definition the Project removed answers `process.removing` (409). The next deployment of the default removes it.

When the Gateway runs `process.stop` on its engine and the Process's Node reports `process.ensure_state`, a host systemd unit, a host Docker container or a unit in a development Instance container changes through one signed executor order with the same result and error codes. A Vite dev Process, a production release layout, a Gateway release-container Process and a host Horizon Process always run the workflow below ([process.start and process.stop](/reference/gateway-engine#processstart-and-processstop)).
