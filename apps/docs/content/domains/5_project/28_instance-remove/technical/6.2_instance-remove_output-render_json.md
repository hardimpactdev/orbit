# JSON Renderer: `orbit instance:remove`

[Back to `instance:remove` technical contract.](1_instance-remove.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON uses the machine-readable envelope.

## Selection

Use this renderer when `--json` is present. `--json` never implies consent.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "result": {
        "action": "removed",
        "project": "billing",
        "instance": "development"
      }
    },
    "meta": []
  }
}
```

## Error Shapes

Without `--force`, return `validation_failed` with
`error.meta.field=force` only. Not-found and authorization
failures use the shared envelope.
