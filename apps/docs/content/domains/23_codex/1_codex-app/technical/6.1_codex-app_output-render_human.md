# Human Renderer: `orbit codex:app`

[Back to `codex:app` technical contract.](1_codex-app.md)

**Renderer:** Human renderer.

## Primitive

Use the shared [progress tree](../../../../ux/commands/progress/progress-tree.md)
primitive for `add` and `remove`. Use the shared
[table](../../../../ux/commands/lists/table.md) primitive for `list`.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

`add` and `remove` render a progress tree:

```text
┌ Updating Codex App project config
○ Resolve app and target node
○ Read Codex App config
○ Write Codex App config
○ Apply Codex App config
└ Working...
```

`list` renders a table of project entries and does not show a write progress
tree.

## Success Output

Add:

```text
Added docs to Codex App on mini.
```

Remove:

```text
Removed docs from Codex App on mini.
```

List:

```text
App   Label  Remote path
docs  docs   /home/orbit/apps/docs
```

Apply callback failures render as warnings after the success summary.
