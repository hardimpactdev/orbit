# Human Renderer: `orbit schedule:add`

[Back to `schedule:add` technical contract.](1_schedule-add.md)

**Renderer:** Human terminal renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and before gateway writes or
backend enactment begins.

```text
┌ Add Schedule
○ Validate schedule target
○ Validate execution source
○ Write gateway schedule intent
○ Render timer and service artifacts
○ Enable schedule
└ Schedule `laravel-scheduler` enabled for app `docs`
```

## Success Output

Render the schedule name, scope, target, interval, timezone, execution source,
enabled state, and backend enactment result.

## Failure Output

Validation failures render the rejected field. Gateway and authorization
failures render the selected scope when available. Enactment failures render the
created schedule name, drift status, and next doctor command:
`doctor --family=schedule --fix`.
