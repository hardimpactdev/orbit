# Human Renderer: `orbit vpn-client:enable <name>`

[Back to `vpn-client:enable` technical contract.](1_vpn-client-enable.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`vpn-client:enable` performs gateway-local backend authentication and writes
backend peer state, so the human renderer must render a progress tree after
input resolution and before side effects begin:

```text
┌ Enabling VPN client
○ Validate gateway access
○ Authenticate VPN backend
○ Enable VPN client
└ Working...
```

## Success Output

```text
VPN client `laptop` enabled
```

If the client was already enabled, render:

```text
VPN client `laptop` already enabled
```

## Failure Output

Human-rendered failures use one concise error line and no JSON envelope.
