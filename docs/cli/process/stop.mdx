---
title: "orbit process:stop"
sidebarTitle: "process:stop"
description: "Stop an installed Process and store the stopped desired state. A hibernation wake leaves a stopped Process stopped."
---

```bash
orbit process:stop <process> [--idempotency-key=KEY] [--json]
```

On a container Instance, a Process whose definition the Project removed answers `process.removing` (409). The next deployment of the default removes it.
