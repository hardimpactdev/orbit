# JSON Renderer: `orbit php:use`

[Back to `php:use` technical contract.](1_php-use.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "php": {
        "node": "app-1",
        "supported": ["8.5", "8.4", "8.3"],
        "available_images": ["8.5"],
        "app": {
          "name": "docs",
          "php_version": "8.5"
        },
        "workspace": null
      },
      "result": {
        "target": "app",
        "node": "app-1",
        "app": "docs",
        "workspace": null,
        "previous": "8.4",
        "version": "8.5",
        "image": "ghcr.io/hardimpactdev/orbit-frankenphp:1-php8.5-bookworm",
        "inherits": false,
        "changed": true
      }
    },
    "meta": {
      "warnings": []
    }
  }
}
```

App, workspace, and node CLI results include `success.data.result.image` with
the approved FrankenPHP image tag for the resolved version. Workspace results
report the image for the effective version after applying the override or
inheritance.

## Success with drift warning

If gateway configuration is written but node application fails, the command returns a
success envelope with a structured doctor handoff warning.

```json
{
  "success": {
    "data": {
      "php": {
        "node": "app-1",
        "supported": ["8.5", "8.4", "8.3"],
        "available_images": ["8.5"],
        "app": {
          "name": "docs",
          "php_version": "8.5"
        },
        "workspace": null
      },
      "result": {
        "target": "app",
        "node": "app-1",
        "app": "docs",
        "workspace": null,
        "previous": "8.4",
        "version": "8.5",
        "image": "ghcr.io/hardimpactdev/orbit-frankenphp:1-php8.5-bookworm",
        "inherits": false,
        "changed": true
      }
    },
    "meta": {
      "warnings": [
        {
          "code": "app.runtime_container_mismatch",
          "family": "app",
          "message": "runtime container configuration did not converge for app 'docs'.",
          "next_command": "doctor --family=app --app=docs --restore"
        }
      ]
    }
  }
}
```

Workspace application warnings use `workspace.runtime_container_mismatch` and
`doctor --family=workspace --workspace=<workspace> --restore`. Proxy
backend warnings use `proxy.route_mismatch` and
`doctor --family=proxy --restore`.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Required input is missing or invalid.",
    "meta": {
      "field": "version",
      "reason": "missing_required_input"
    }
  }
}
```

When `--node` names a node that does not own the resolved app or workspace,
the command fails before any gateway configuration write with this shape:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Node 'image-node' does not own app 'docs'.",
    "meta": {
      "field": "node",
      "reason": "target_mismatch",
      "node": "image-node",
      "app": "docs",
      "owning_node": "app-1"
    }
  }
}
```

For workspace targets, `meta.app` reports the parent app of the resolved
workspace and `meta.owning_node` reports the parent app's owning node.

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.php` | object | PHP runtime view after the gateway configuration write. |
| `success.data.result.target` | `app`, `workspace`, `node_cli` | Scope selected by the command. |
| `success.data.result.image` | string or null | Approved FrankenPHP image tag for the resolved version. `null` only when a workspace inheritance result has no effective version to resolve. |
| `success.data.result.changed` | boolean | Whether gateway configuration changed. |
| `success.meta.warnings[]` | array | Doctor handoff warnings for partial app, workspace, proxy, or node application. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed` | Stable command failure code. |
| `error.meta.field` | string | Input field the failure is attributed to (for example `version`, `node`). |
| `error.meta.reason` | `missing_required_input`, `mutually_exclusive_input`, `missing_target`, `unsupported`, `not_installed`, `target_mismatch` | Stable validation reason. |
| `error.meta.node` | string | Selected node name. Present on `target_mismatch` and `not_installed`. |
| `error.meta.app` | string | Resolved app name. Present on `target_mismatch` (parent app for workspace targets). |
| `error.meta.owning_node` | string | Owning node of the resolved app. Present on `target_mismatch`. |
