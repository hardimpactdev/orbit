# Human Renderer: `orbit agent-ide:message [message]`

[Back to `agent-ide:message` technical contract.](1_agent-ide-message.md)

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render this progress tree after input resolution and before adapter delivery
begins:

```text
┌ Sending Agent IDE message to docs
○ Resolve target
○ Resolve effective adapter
○ Find active session
○ Deliver message
└ Working...
```

For workspace targets, include the workspace name in the title:

```text
┌ Sending Agent IDE message to docs/feature-docs
○ Resolve target
○ Resolve effective adapter
○ Find active session
○ Deliver message
└ Working...
```

Use this label lifecycle:

| Pending | Active | Completed |
| --- | --- | --- |
| `Resolve target` | `Resolving target` | `Resolved target` |
| `Resolve effective adapter` | `Resolving effective adapter` | `Resolved effective adapter` |
| `Find active session` | `Finding active session` | `Found active session` |
| `Deliver message` | `Delivering message` | `Delivered message` |

When the command completes, replace the footer with the result:

```text
┌ Sending Agent IDE message to docs
● Resolved target
● Resolved effective adapter
● Found active session
● Delivered message
└ Sent Agent IDE message to docs through opencode
```

## Success Output

After the completed progress tree, render a short delivery summary:

```text
Sent message to docs through opencode.
```

Workspace target:

```text
Sent message to docs/feature-docs through polyscope.
```

## Failure Output

Human-rendered failures show the target or field, a clear prose error, and a
recovery command when one exists.

Missing message:

```text
Message is required.
```

Missing target:

```text
Run this command from an app/workspace directory or pass --app/--workspace.
```

No effective adapter:

```text
No Agent IDE adapter is configured for docs.
```

No active session:

```text
No active Agent IDE session found for docs.
```

Adapter delivery failed:

```text
Agent IDE adapter opencode could not deliver the message.
```

Render these recovery commands when their condition applies:

```text
Run orbit app:agent-ide docs opencode to configure an app adapter.
Run orbit node:agent-ide app-1 opencode to configure a node default.
Run doctor --family=tool --restore to repair managed adapter server tools.
```
