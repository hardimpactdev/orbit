---
title: "orbit tasks:group:comment:list"
sidebarTitle: "tasks:group:comment:list"
description: "Read group-owned history, newest first, even after completion and VM removal. This history is separate from every child's comments. The command selects only a group when its ID is omitted in a terminal. With `--json` or `-n`, supply the ID."
---

```bash
orbit tasks:group:comment:list [group] [--json]
```

Human output shows each comment's type, author, time and body, followed by the request ID. An empty history says `No comments.` JSON returns `comments` and `request_id`. The API and SDK also accept the existing `type` and `limit` history filters.
