# Native Node removal

The Node removal rewrite supplies complete forward and restore inputs at admission. It records the membership transition and Route withdrawal intent in that transaction. Native placed command/shell steps perform each effect; steps do not refresh their intent or report progress through the Gateway.

Restoration uses the captured prior publication and native step results. Terminal projection restores the Gateway journal or records the completed deletion. An uncertain retirement retains the Node record. Secrets and terminal history decoding use the shared SwampCommandStep helper. The hub, Route, certificate and Metrics owners supply their native action contracts; removal does not wrap their old Gateway clients.

The retirement manifest ships one-action Python files and their SSH helper through native additionalFiles. A pure metadata step resolves the cached file paths on the admitted executor. Each placed command step runs its own script. Public ownership checks run before the first vault resolution. The identity is removed from the SSH child environment, written to a mode-0600 temporary file, and removed after the action. Native dependencies stop all later required actions after a failure.

Admission uses SwampCommandStep::executionCopy for the existing Gateway retirement identity. The family projector supplies the outer intent and execution_secrets envelope. The parent is still a draft rewrite and has not opted into that envelope or terminal selector. It must switch with the complete native composition. Official remote vault-put stdin remains a shared blocker; no alternative transport is added.

Logical Nodes 1 and 18 require the shared built-in shell proxy transport before any live effect. The existing TypeScript proxy transport is not proof of built-in shell placement. The retirement SSH boundary applies only to the admitted target after its own worker stops; it does not route participant effects or replace the light-Node transport. A live removal test requires an explicitly selected disposable target.
