# Human Renderer: `orbit metrics:credentials`

[Back to `metrics:credentials` technical contract.](1_metrics-credentials.md)

**Renderer:** Human renderer.

## Primitive

Use [`table`](../../../../ux/commands/lists/table.md).

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered. The command performs a gateway configuration read,
or one bounded gateway configuration write when `--reset` is supplied, and does
not perform live Grafana probes.

## Success Output

Render a two-column table with these rows:

| Field | Value |
| --- | --- |
| `Node` | Selected metrics node. |
| `URL` | `https://metrics.orbit`. |
| `Admin User` | Grafana admin user. |
| `Admin Password` | Grafana admin password. |

## Failure Output

Render standard validation, gateway, authorization, and missing-credential
failures using the shared command error renderer.

CLI-only for this command.
