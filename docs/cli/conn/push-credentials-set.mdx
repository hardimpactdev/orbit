Store the Apple APNs `.p8` private key, Key ID, and Team ID in the Gateway's encrypted settings. One key serves both sandbox and production APNs hosts.

- **Key from stdin only:** pipe the `.p8` file into stdin. The command refuses an interactive terminal and never echoes, logs, or records the key in Activity.
- **Gateway access required:** requires the `conn` extension, `orbit.conn.push` enabled, and Gateway access.

## Usage

```sh
orbit conn:push-credentials:set --key-id=AB12CD34EF --team-id=TEAM987654 < AuthKey_AB12CD34EF.p8
orbit conn:push-credentials:set --key-id=AB12CD34EF --team-id=TEAM987654 --json < AuthKey_AB12CD34EF.p8
```

| Option | Meaning |
| --- | --- |
| `--key-id` | Apple APNs Key ID (1 to 32 alphanumeric characters). |
| `--team-id` | Apple Developer Team ID (1 to 32 alphanumeric characters). |
| `--json` | [Machine output](/reference/cli-ux#input-and-output-modes): `{"configured": true, "key_id": "...", "team_id": "...", "request_id": "..."}`. |

## How it works

<Flow name="conn/push-credentials" />

The CLI validates `--key-id`, `--team-id`, and non-empty piped stdin locally before sending `PUT /api/v1/conn/push-credentials` (`conn:push-credentials:set`). The Gateway verifies the EC P-256 PEM, stores `private_key` encrypted via `SettingValueProtection::Secret`, redacts `private_key` from Activity, and clears any cached ES256 JWT.

## Errors

| Code | Meaning |
| --- | --- |
| `conn.push_disabled` | `orbit.conn.push` is off on the Gateway. |
| `extension.disabled` | The Conn extension is off. |
| `node_access.required` | The caller does not have Gateway access. |
| `conn.push_key_id_invalid` | `--key-id` is missing or not 1 to 32 alphanumeric characters. |
| `conn.push_team_id_invalid` | `--team-id` is missing or not 1 to 32 alphanumeric characters. |
| `conn.push_private_key_invalid` | Stdin was a TTY, empty, or over 16 KiB. |
| `validation.failed` | The Gateway rejected the Key ID, Team ID, or EC P-256 PEM. |
