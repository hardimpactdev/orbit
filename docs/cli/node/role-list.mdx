## Usage

```bash
orbit node:role:list <node> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `node` | yes | Positive numeric Node ID. Names are not accepted. See the [shared input rules](/reference/cli-ux#input-and-output-modes) for omitted input. |

| Option | Default | Meaning |
| --- | --- | --- |
| `--json` | off | Use the [standard machine-output mode](/reference/cli-ux#input-and-output-modes). |

```bash
orbit node:role:list 7
```

## How it works

Orbit reads the Gateway's recorded role assignments. It contacts no Node, Grafana or other system, starts no Operation, and changes nothing. An unreachable Node or missing or stale agent facts do not delay or refuse the read: assignments are records, not agent observations. Running the command again reads the records again; it is not a skipped action and has no skip reason code.

Access uses the shared [NodeAccessAuthorizer rule](https://github.com/hardimpactdev/orbit/blob/main/apps/gateway/app/Domain/Nodes/NodeAccessAuthorizer.php) for the [Node family](/cli/node).

Every assigned role is included, with its state: `active`, `provisioning`, `failed`, or `removing`. The shared role projection supplies the same `role`, `status`, `failed_step` and `error_code` values to this command, [`node:list`](/cli/node/list) and [`node:show`](/cli/node/show).

| Column | JSON field | Meaning |
| --- | --- | --- |
| `ID` | `id` | Role assignment ID. |
| `ROLE` | `role` | Assigned role's name. |
| `STATUS` | `status` | Recorded lifecycle state. |
| `FAILED STEP` | `failed_step` | Recorded failed step, or `null` when unset. |
| `ERROR CODE` | `error_code` | Recorded failure code, or `null` when unset. |

Human output uses the columns above and [standard list rendering](/reference/cli-ux#results). With no assignments, it says `No roles.`. The JSON result contains `assignments` and `request_id`; an empty result has `assignments: []`.

## Errors

| Code | Meaning |
| --- | --- |
| `node.id_invalid` | The supplied Node ID is not a positive integer, or required input is missing in a noninteractive call. Orbit refuses locally. |
| `http.404` | The numeric Node ID is unknown. |
| `node_access.required` | The shared authority rule refuses this caller for the target Node. |
