# JSON Renderer: `orbit node:grant [consuming_node] [serving_node]`

[Back to `node:grant` technical contract.](1_node-grant.md)

This page describes the JSON-rendered output for `node:grant`.

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](../../../README.md#invocation-model), even
when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

### Newly granted

```json
{
  "success": {
      "data": {
        "consuming_node": "control-1",
        "serving_node": "app-1",
        "action": "granted",
        "already_granted": false
      }
    }
  }
```

### Already granted (idempotent)

```json
{
  "success": {
      "data": {
        "consuming_node": "control-1",
        "serving_node": "app-1",
        "action": "granted",
        "already_granted": true
      }
    }
  }
```

| Field | Type | Meaning |
| --- | --- | --- |
| `consuming_node` | string | The consuming node name. |
| `serving_node` | string | The serving node name. |
| `action` | string | Always `granted`. Idempotence is reported by `already_granted`, not by changing the action value. |
| `already_granted` | boolean | `true` when the grant already existed; `false` when this command created it. |

## Error Shapes

### Missing required input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Consuming node is required.",
    "meta": {
      "field": "consuming_node"
    }
  }
}
```

Or for the serving node:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Serving node is required.",
    "meta": {
      "field": "serving_node"
    }
  }
}
```

### Consuming node not found

```json
{
  "error": {
    "code": "node.not_found",
    "message": "Consuming node 'control-1' not found.",
    "meta": {
      "field": "consuming_node",
      "name": "control-1"
    }
  }
}
```

`node.not_found` covers both unknown names and node records that are not in
the `active` lifecycle (for example, records still in `provisioning`). Live
reachability is not probed; convergence checks belong to
`doctor --family=node`.

### Serving node not found

```json
{
  "error": {
    "code": "node.not_found",
    "message": "Serving node 'app-1' not found.",
    "meta": {
      "field": "serving_node",
      "name": "app-1"
    }
  }
}
```

### Grant policy violation

```json
{
  "error": {
    "code": "node.grant_policy_violation",
    "message": "Grant from 'control-1' to 'app-1' violates node access policy.",
    "meta": {
      "consuming_node": "control-1",
      "serving_node": "app-1",
      "reason": "unspecified"
    }
  }
}
```

`error.meta.reason` is required and discriminates the specific policy rule
that rejected the grant. The seed enum is documented below; new policy rules
must extend the enum in this contract before they are surfaced as a distinct
reason value.

#### Self-grant

```json
{
  "error": {
    "code": "node.grant_policy_violation",
    "message": "A node cannot be granted access to itself.",
    "meta": {
      "consuming_node": "control-1",
      "serving_node": "control-1",
      "reason": "self_grant"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to grant node access.",
    "meta": {}
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This control node is not authorized to grant node access.",
    "meta": {
      "required_node": "gateway-1",
      "caller_role": "control"
    }
  }
}
```

### Caller role not allowed

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "This command may only be run from a control or gateway node.",
    "meta": {
      "caller_role": "app"
    }
  }
}
```

### Local context invalid

```json
{
  "error": {
    "code": "local_context_invalid",
    "message": "Local node role setting is invalid.",
    "meta": {
      "setting": "general.local_node_role",
      "reason": "unsupported_value",
      "caller_role": "unknown"
    }
  }
}
```

## Enum And Identifier Values

| Field | Values |
| --- | --- |
| `data.action` | `granted` |
| `error.meta.reason` | `self_grant`, `unspecified`. Used with `node.grant_policy_violation` to discriminate which policy rule rejected the grant. Add a new reason value to this renderer contract before surfacing it. |
| `error.code` | `validation_failed`, `node.not_found`, `node.grant_policy_violation`, `gateway_unavailable`, `authorization_failed`, `caller_role_not_allowed`, `local_context_invalid` |

The `error.code` values listed here are exhaustive for `node:grant`. Add a new
value to this renderer contract before implementing another JSON failure code.
