# Human Renderer: `orbit deploy:step-add`

[Back to `deploy:step-add` technical contract.](1_deploy-step-add.md)

**Renderer:** Human terminal renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`deploy:step-add` writes one gateway policy row and performs no slow external
work. Execution is expected to complete below one second. No progress tree is
rendered.

## Success Output

Render the app, step id, title, command, order, and retention metadata.

## Failure Output

Validation, caller-role, gateway, authorization, app-not-found, and
production-app eligibility failures render one concise error line with the
rejected field or app selector when available.
