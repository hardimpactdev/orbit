# `orbit app-development-setup-step:update`

Update an app-owned development default without changing any existing instance.

```bash
orbit app-development-setup-step:update [app] --step=<id> [--command=<command>] [--before=<id> | --after=<id>] [--timeout=<seconds>] [--json]
```

Requires `app:write` and a visible app instance. See the [technical contract](technical/1_app-development-setup-step-update.md), [human output](technical/6.1_app-development-setup-step-update_output-render_human.md), and [JSON output](technical/6.2_app-development-setup-step-update_output-render_json.md).
