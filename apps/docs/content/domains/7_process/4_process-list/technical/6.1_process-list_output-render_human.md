# Human Renderer: `orbit process:list`

[Back to `process:list` technical contract.](1_process-list.md)

This page describes the human-rendered terminal output for `process:list`.

**Renderer:** Human renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered. `process:list` is expected to stay below one second in normal operation because it reads gateway configuration and latest durable events only, and performs no slow external work.

## Success Output

When processes exist:

```text
Processes for docs.production

 KEY           LABEL            SERVICE    VERSION    ENDPOINT         COMMAND        RESTART  TOOL  STATUS
 vite          vite             —          —          —                vp run dev    never    —     running
 postgres      postgres         postgres   16-alpine  10.6.0.4:5432    —              always   —     running
 postgres-food Postgres Food    postgres   18-alpine  10.6.0.4:5433    —              always   —     running
```

When no processes exist:

```text
No processes found.
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no JSON envelope, and next-step guidance only when the operator can act on it.
