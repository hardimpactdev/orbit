# JSON Renderer: `orbit dns:list`

[Back to `dns:list` technical contract.](1_dns-list.md)

This page describes the JSON-rendered output for `dns:list`.

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](../../../README.md#invocation-model), even when
the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Caller-role failures, local-context failures, unsupported-platform failures, and
resolver read failures must all use this envelope.

## Success Shape

```json
{
  "success": {
    "data": {
      "dns": [
        {
          "tld": "test",
          "target": "10.6.0.7",
          "source": "local_resolver",
          "resolver_backend": "dnsmasq",
          "status": "active"
        }
      ]
    },
    "meta": {
      "count": 1,
      "resolver_backend": "dnsmasq"
    }
  }
}
```

Empty results use the same shape with `dns: []` and `count: 0`.

| Field | Type | Meaning |
| --- | --- | --- |
| `dns[]` | array | Orbit-managed local resolver overrides. |
| `dns[].tld` | string | Development TLD without a leading dot. |
| `dns[].target` | string | Target IP address configured locally. |
| `dns[].source` | string | Always `local_resolver`. |
| `dns[].resolver_backend` | string | Platform resolver backend for the entry. |
| `dns[].status` | string | Local resolver entry status. |
| `count` | integer | Number of returned local resolver entries. |
| `resolver_backend` | string \| null | Detected platform resolver backend. |

## Error Shapes

### Caller role not allowed

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "This command may only be run from a control node.",
    "meta": {
      "caller_role": "app"
    }
  }
}
```

### Local context invalid

```json
{
  "error": {
    "code": "local_context_invalid",
    "message": "Local node role setting is invalid.",
    "meta": {
      "field": "general.local_node_role",
      "reason": "unsupported_value"
    }
  }
}
```

### Unsupported platform

```json
{
  "error": {
    "code": "node.unsupported_platform",
    "message": "This platform does not support automatic local DNS resolver inspection.",
    "meta": {
      "platform": "linux-unknown"
    }
  }
}
```

### Resolver read failed

```json
{
  "error": {
    "code": "local_resolver_read_failed",
    "message": "Could not read local DNS resolver configuration.",
    "meta": {
      "resolver_backend": "dnsmasq"
    }
  }
}
```

## Enum And Identifier Values

| Field | Values |
| --- | --- |
| `dns[].source` | `local_resolver` |
| `dns[].status` | `active`, `stale` |
| `error.meta.reason` | `unsupported_value`, `unreadable` |
| `error.code` | `caller_role_not_allowed`, `local_context_invalid`, `node.unsupported_platform`, `local_resolver_read_failed` |

The `error.code` values listed here are exhaustive for `dns:list`. Add a new
value to this renderer contract before implementing another JSON failure code.
