# Human Renderer: `orbit schedule:show`

[Back to `schedule:show` technical contract.](1_schedule-show.md)

**Renderer:** Human terminal renderer.

## Primitive

- Detail: [Show detail](../../../../ux/commands/details/show-detail.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`schedule:show` is a read-only gateway registry query. Execution is expected to complete below one second and does not perform slow external work. No progress tree is rendered.

## Success Output

Render a detail view keyed by the schedule name:

```text

┌  Schedule: laravel-scheduler
│
├  Scope       app
│
├  Target      docs.production
│
├  Node        app-1
│
├  Interval    every minute
│
├  Timezone    Europe/Amsterdam
│
├  Execution   command: php artisan schedule:run
│
├  Enabled     yes
│
├  Status      expected
│
└  Last run    —

```

## Failure Output

Validation, not-found, gateway, and authorization failures render one concise error line with the rejected field, schedule name, or selected scope when available.
