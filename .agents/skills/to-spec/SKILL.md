# To Spec

After a worktree exists and intake has no material ambiguity, serialize only
the settled Goal, Scope, authority, constraints, and proof focus into
`.orbit/loop.md`; this skill owns only that artifact. Do not interview again,
implement, create tickets. Do not use an external tracker. Do not install an upstream bundle.
