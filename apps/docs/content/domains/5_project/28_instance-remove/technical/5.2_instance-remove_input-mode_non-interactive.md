# Non-Interactive Input: `orbit instance:remove`

[Back to `instance:remove` technical contract.](1_instance-remove.md)

**Input mode:** Non-interactive.

Use this mode without a TTY or whenever `--json` is present. `--json` forces
non-interactive input mode, never supplies destructive consent, and can never
render prompts.

## Required Input

`--force` is required. When it is absent, validation fails before side effects
with `validation_failed`, `meta.field=force`, and
`meta.field=force` only. There are no fallback prompts.
