# Human Renderer: `orbit vpn-web-ui:change-password`

[Back to `vpn-web-ui:change-password` technical contract.](1_vpn-web-ui-change-password.md)

**Renderer:** Human terminal renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render the progress tree after input resolution and destructive consent, before
credential rotation begins:

```text
┌ Rotating VPN web UI password
○ Validate gateway access
○ Authenticate VPN backend
○ Update backend password
○ Rotate admin sessions
○ Apply and verify credential rotation
└ Working...
```

## Success Output

```text
VPN web UI password rotated
```

The new password is never printed.

## Failure Output

Human-rendered failures use one concise error line and no JSON envelope. The new
password must never appear in failure output.

### Missing destructive consent

```text
Use --force to rotate the VPN web UI password.
```

### Invalid password

```text
Password must be at least 12 characters.
```
