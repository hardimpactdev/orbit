# Human Renderer: `orbit tool:reload`

[Back to `tool-reload` technical contract.](1_tool-reload.md)

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and before runtime effects.

```text
┌ Reloading Tool
○ Resolve target
○ Read gateway tool configuration
○ Run command action
└ Working...
```

## Success Output

Human output finishes with `Tool reloaded` and may include the selected tool,
node, action, and resolved runtime from the gateway result.

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose
error, and actionable recovery guidance when the operator can resolve it.
