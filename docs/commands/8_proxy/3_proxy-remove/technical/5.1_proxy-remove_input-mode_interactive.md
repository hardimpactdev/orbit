# Interactive Input Mode: `orbit proxy:remove`

[Back to `proxy:remove` technical contract.](1_proxy-remove.md)

**Input mode:** Interactive.

## Mode Selection

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Flow

Prompts render after caller role and gateway reachability are known and before
any gateway write or backend cleanup.

| Prompt ID | Primitive | Rendered when | Validation |
| --- | --- | --- | --- |
| `proxy.domain` | `text` | `domain` argument omitted. | Existing custom route domain. |
| `proxy.confirm_remove` | `confirm` | Always after the custom route is resolved unless `--force` is present. | Explicit destructive consent. |

The confirmation text names the domain, route kind, serving node, target, and
whether route-scoped TLS material will be cleaned up.

Rejected confirmation fails before side effects with
`error.code=destructive_consent_required`.
