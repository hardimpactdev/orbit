---
title: "orbit fleet:rollout:status"
sidebarTitle: "fleet:rollout:status"
description: "Show the newest fleet rollout."
---

```bash
orbit fleet:rollout:status [--json]
```

The detail shows whether the rollout is on, its status, the commit the Gateway wants the fleet on, and, for a halted rollout, the Node, error code, and message. A table lists each Node in rollout order with its outcome, the step that stopped it, and the CLI and agent versions it runs. The last line names each Node the rollout leaves out, with its reason.

| Status | Meaning |
| --- | --- |
| `none` | No rollout ran yet |
| `waiting` | The CLI release of the commit is not published yet. The catch-up starts the rollout once it is |
| `running` | The rollout visits its Nodes |
| `completed` | Every Node was visited. Unreachable or busy Nodes wait for the catch-up |
| `halted` | A Node failed. Nothing runs until you resume |
| `superseded` | A newer desired state replaced the rollout |

`--json` returns `enabled`, `status`, `desired_commit`, `rollout` with `desired_state` and one entry per Node, including its `evidence`, and `excluded`.
