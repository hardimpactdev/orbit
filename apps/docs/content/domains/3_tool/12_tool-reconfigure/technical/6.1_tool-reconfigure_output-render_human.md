# Human Renderer: `orbit tool-reconfigure`

[Back to `tool-reconfigure` technical contract.](1_tool-reconfigure.md)

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and before gateway reads, node inspection, or node apply begins.

```text
┌ Reconfiguring Tool
○ Resolve target
○ Read gateway tool configuration
○ Run command action
└ Working...
```

## Success Output

Human output presents the selected tool state using Orbit product vocabulary: tool, node, expected capability state, observed state when available, managed flag, and version/config metadata when tracked by the tool definition.

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose error, and actionable recovery guidance when the operator can resolve the issue.
