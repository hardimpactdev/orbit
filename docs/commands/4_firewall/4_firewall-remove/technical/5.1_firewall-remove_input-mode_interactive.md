# Interactive Input Mode: `orbit firewall:remove`

[Back to `firewall-remove` technical contract.](1_firewall-remove.md)

**Input mode:** Interactive.

## Mode Selection

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Flow

Prompts render after caller role and gateway reachability are known and before
any side effect begins.

| Prompt ID | Primitive | Rendered when | Validation |
| --- | --- | --- | --- |
| `firewall.node` | `select` | No `--node` and no local default node resolves. | Visible active Ubuntu `gateway` or `app` node. |
| `firewall.remove_confirm` | `confirm` | Always unless `--force` is supplied. | Explicit confirmation is required before side effects. |

The destructive confirmation prompt is rendered after target and rule
resolution. If the operator declines or aborts, the command fails before backend
cleanup or gateway intent removal.
