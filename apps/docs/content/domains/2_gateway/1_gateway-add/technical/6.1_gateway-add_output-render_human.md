# Human Renderer: `orbit gateway:add [gateway_ip]`

[Back to `gateway:add` technical contract.](1_gateway-add.md)

This page describes the human-rendered terminal output for `gateway:add`.

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. Prompt behavior belongs to
[`interactive input mode`](5.1_gateway-add_input-mode_interactive.md).
Non-interactive validation failures are rendered here as prose errors when
`--json` is absent.

## Progress Tree

Render the complete progress tree before side effects begin. Steps must move
from pending to active to success, failure, or warning.

Full flow:

```text
┌ Joining Gateway
○ Resolve gateway
○ Fetch trust material
○ Trust gateway CA
○ Verify gateway API
○ Verify identity
○ Store local config
└ Working...
```

When the gateway is already configured and verified:

```text
┌ Joining Gateway
○ Resolve gateway
○ Verify gateway API
○ Verify identity
└ Gateway 10.6.0.2 is already configured
```

The converged footer must not include reset or rerun guidance.

## Success Output

Human output ends with:

- gateway name;
- local node name;
- action performed: added or converged.

## Failure Output

Human-rendered failures must show:

- the failing phase or field;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the operator can act on it.

Non-interactive input mode missing-field failures render as prose validation
errors and must not render prompts.

Missing gateway IP:

```text
Gateway IP is required when it cannot be derived from an active WireGuard network.
```

Invalid gateway IP:

```text
Gateway IP must be a valid Orbit WireGuard address.
```

Unregistered peer:

```text
This peer is not registered on the gateway at 10.6.0.2. Ask your admin to register this machine on the gateway, then retry.
```

Gateway host unsupported:

```text
This command is not supported on gateway nodes.
```

Gateway unavailable:

```text
Gateway at 10.6.0.2 returned HTTP 500 for /api/me.
```

Unsupported platform:

```text
This platform does not support automatic gateway CA trust installation.
```

Local config write failure:

```text
Failed to store local gateway configuration.
```
