# Non-Interactive Input Mode: `orbit firewall:remove`

[Back to `firewall-remove` technical contract.](1_firewall-remove.md)

**Input mode:** Non-interactive.

## Mode Selection

This contract applies without a TTY or when `--json` is present. `--json`
forces non-interactive input mode.

## Behavior

No prompts are rendered. `name` and target node must resolve from arguments,
options, local defaults, or gateway-visible state.

Because `--json` forces non-interactive input mode, it is not destructive consent and never grants destructive consent. Destructive removal requires `--force` whenever `--json` is present. Missing `--force` fails before side effects with `error.code=validation_failed` and `error.meta.field=force`.
