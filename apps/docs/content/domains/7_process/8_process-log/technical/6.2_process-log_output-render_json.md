# JSON Renderer: `orbit process:log [name]`

[Back to `process:log` technical contract.](1_process-log.md)

This page describes the JSON-rendered output for `process:log`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces non-interactive input mode. JSON output is bounded and cannot be combined with `--follow`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the process runtime context and bounded log lines.

## Success Example

```json
{
  "success": {
    "data": {
      "logs": {
        "process": "vite",
        "app": "docs",
        "instance": "development",
        "workspace": "feature-docs",
        "runtime_unit": "orbit_docs_development_feature-docs_vite",
        "lines": [
          {
            "timestamp": "2026-04-30T12:00:00Z",
            "message": "Vite ready"
          }
        ]
      }
    },
    "meta": {
      "line_count": 1
    }
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "validation_failed",
    "message": "--json cannot be combined with --follow.",
    "meta": {
      "field": "json"
    }
  }
}
```

## Authorization Error

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'process:log' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "process:log",
      "serving_node": "app-1"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: process name or node/instance/workspace context is missing, invalid, or ambiguous in non-interactive input mode; `--lines` is invalid; or `--json` is combined with `--follow`. An ambiguous bare app selector uses `error.meta.field=instance` and `error.meta.reason=instance_required`.
- `authorization_failed`: caller lacks `process:log` on the resolved node or instance serving node.
- `process.not_found`: the named process does not exist for the resolved context.
- `process.log_read_failed`: the gateway cannot read logs from the resolved node or instance serving node process manager.
