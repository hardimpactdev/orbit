# Human Renderer: `orbit process:update [name]`

[Back to `process:update` technical contract.](1_process-update.md)

This page describes the human-rendered terminal output for `process:update`.

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render the complete progress tree after input resolution and before side effects
begin. `process:update` writes gateway configuration and may re-render or
replace runtime units through Agent push.

```text
┌ Updating Process
○ Validate process
○ Apply and verify process change
○ Render runtime units
○ Remove old runtime units
○ Restart runtime units
└ Working...
```

Omit the removal step for replaced runtime units when `--name` is not present.
Omit the restart step when `--restart` is not present.

## Success Output

```text
Process 'vite' updated for instance 'docs.production'
```

When identity changes:

```text
Process 'mysql' renamed to 'app-mysql' on node 'database-1'
```

When runtime-unit apply leaves repairable drift:

```text
Process 'vite' updated for instance 'docs.production'
  Drift detected: process.runtime_unit_mismatch
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no JSON envelope, and next-step guidance only when the operator can act on it.
