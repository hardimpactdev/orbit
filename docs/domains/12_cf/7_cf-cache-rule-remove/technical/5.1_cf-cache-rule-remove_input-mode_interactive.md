# Interactive Input Mode: `orbit cf-cache-rule:remove`

[Back to `cf-cache-rule:remove` technical contract.](1_cf-cache-rule-remove.md)

**Input mode:** Interactive.

## Selection

Use this input mode only when the process has a TTY and `--json` is not
present.

## Prompt Behavior

When `--force` is absent, render a confirmation prompt after `app` resolves and
before side effects:

| Prompt ID | Primitive | Label | Default |
| --- | --- | --- | --- |
| `cf_cache_rule_remove_confirm` | `confirm` | `Remove Cloudflare cache rule for <app>?` | `false` |

Supplying `--force` is explicit destructive consent and skips the confirmation
prompt. Declining the prompt fails before side effects.
