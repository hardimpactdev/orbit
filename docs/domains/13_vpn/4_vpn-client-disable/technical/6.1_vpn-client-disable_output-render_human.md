# Human Renderer: `orbit vpn-client:disable <name>`

[Back to `vpn-client:disable` technical contract.](1_vpn-client-disable.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../commands/ux/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`vpn-client:disable` performs gateway-local backend authentication and writes
backend peer state, so the human renderer must render a progress tree after
input resolution and before side effects begin:

```text
┌ Disabling VPN client
○ Validate gateway access
○ Authenticate VPN backend
○ Disable VPN client
└ Working...
```

## Success Output

```text
VPN client `laptop` disabled
```

If the client was already disabled, render:

```text
VPN client `laptop` already disabled
```

## Failure Output

Human-rendered failures use one concise error line and no JSON envelope.
