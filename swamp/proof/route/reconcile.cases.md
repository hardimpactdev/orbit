# route.reconcile verification cases

The `orbit` CLI has no command for this kind. It is the child of the Cluster commands `cluster:update`, `cluster:activate`, `cluster:deactivate`, `cluster:node:add` and `cluster:node:remove`, so the proof runs those commands and reads the child's steps in the parent task, the Gateway records, Caddy, certificates, DNS and real HTTPS requests. Each Cluster command's own cases cover its guards and its other steps. See [verifying-commands](../../../.agents/skills/verifying-commands/SKILL.md).

| Case | Setup and action | Required observations |
| --- | --- | --- |
| Domain change | Run a parent command that moves a generated Route into another TLD. | The Gateway stores a pending replacement at admission. Its new site is published beside the old one on the workload Node and the Router, `APP_URL` is written for a Laravel target, and the probe passes. Private DNS moves after the probe, and the old placement is withdrawn last. The parent task succeeds and the new Route is active with a new Route ID. |
| Scope change | Run a parent command that changes only a Route's scope, for example from Node to Cluster. | The Route keeps its ID. The Gateway stores the old placement. The new sites are published beside the old ones, the private DNS answer moves from the workload Node to the Router, and the old placement is withdrawn after the grace. |
| Domain inside the TLD | A changed domain inside the TLD whose answer does not change. | No DNS record changes and the task does not wait for the grace. |
| Many Routes | A parent change that affects several Routes on several Nodes. | One batch of CSRs and one signing call. Private DNS moves in one step and the 31-second grace passes once. Every old placement is withdrawn only after every probe passed. |
| Route kinds | Affected Routes of each kind: generated, explicit, custom proxy and analytics tracking host. | A generated Route takes the new domain. An explicit Route keeps its domain. A custom proxy Route keeps its Node scope and keeps serving. A tracking host moves with its Instance's Route. Fails today: the legacy path refuses a tracking host with `route.analytics_native_required`. |
| Public Routes | Affected active public Routes under each parent command. | A public Route that the change would move is refused by the parent with `route.reconciliation_required`, before any task starts. |
| Staging certificates | After a domain change. | The staging certificates of the change are gone from the workload Node and the Router, and the live certificates name the new domain. |
| CSR or signing fails | Make the CSR on a Node fail, then the signing call. | The task fails at that step. Nothing is published, the old Routes serve, and the replacements are `failed`. A rerun after the fix succeeds. |
| LAN rule or publish fails | Make the LAN rule step fail, then a Caddy validation. | The task fails. The candidate file stays, Caddy keeps its last configuration, and the old sites serve. The replacements are `failed`. A rerun succeeds. |
| Probe or `APP_URL` fails | Make a new site fail the TLS probe, then the `APP_URL` write. | The task fails before the cutover. The old Routes stay authoritative, the Gateway restores the Laravel URLs and private DNS, and the replacements are `failed`. A rerun after the fix succeeds. |
| DNS move fails | Make the DNS move fail on the VPN Node. | The task fails before the cutover. Private DNS is republished for the old placement and the old Routes serve. A rerun finishes. |
| Grace or withdrawal fails | Make the wait or the withdrawal of an old placement fail. | The task fails after the cutover. The new placement is authoritative and the old one is `retiring`, and both answer. A rerun finishes the withdrawal and the old Routes are deleted. |
| Grace on a rerun | Stop the run between the DNS move and the withdrawal, then rerun after 10 seconds. | The rerun waits until 31 seconds after the stored time of the last move before it withdraws. |
| Resume | Rerun the parent command after each failure. | Every step runs again and skips what already matches. Nothing is duplicated: one replacement Route for each domain, one certificate for each scope, one DNS record for each name. |
| Interrupt | Cancel a run, let one time out, and stop the worker mid-run. | Each ends like a failed step and the rerun finishes. |
| No break in service | Probe every old and new domain over HTTPS during the whole run and each failure. | At every moment each domain has at least one working answer. |
| Secrets | After a run. | The task's intent and result hold no private key. The keys stay on their Nodes. |
