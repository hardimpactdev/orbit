# Human Renderer: `orbit vpn-client:remove <name>`

[Back to `vpn-client:remove` technical contract.](1_vpn-client-remove.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render the progress tree after input resolution and destructive consent, before
backend deletion begins:

```text
┌ Removing VPN client
○ Resolve VPN runtime
○ Authenticate VPN backend
○ Remove VPN client
└ Working...
```

## Success Output

```text
VPN client `laptop` removed
```

## Failure Output

Human-rendered failures use one concise error line and no JSON envelope.

### Missing destructive consent

```text
Use --force to remove this VPN client.
```

### Cancelled confirmation

```text
Operation cancelled.
```

### Active node peer

```text
VPN client `app-1` is an active Orbit node peer. Use `orbit node:remove app-1`.
```
