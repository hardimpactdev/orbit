---
title: "orbit project:document:read"
sidebarTitle: "project:document:read"
description: "Print a file's exact text on stdout with no added newline. Diagnostics go to stderr. `--json` returns the API envelope."
---

```bash
orbit project:document:read <project> <entry> [--version=ID] [--json]
```

`--version=ID` reads an earlier version. The newest version by default.
