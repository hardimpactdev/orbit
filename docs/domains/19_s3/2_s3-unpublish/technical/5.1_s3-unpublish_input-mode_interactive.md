# Interactive Input Mode: `orbit s3:unpublish`

[Back to `s3:unpublish` technical contract.](1_s3-unpublish.md)

**Input mode:** Interactive.

## Mode Selection

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Flow

Prompts render after gateway reachability is known and before any gateway write
or route cleanup.

| Prompt ID | Primitive | Rendered when | Validation |
| --- | --- | --- | --- |
| `s3.node` | `datatable` | `--node` is absent and more than one visible active s3 node exists. | Visible active node with the `s3` role. |
| `s3.host` | `text` | `host` argument omitted. | Published public S3 hostname. |
| `s3.unpublish_confirm` | `confirm` | Always before removal unless `--force` is present or the host is already absent. | Explicit destructive consent. |

`--force` bypasses the confirmation prompt after the host and selected S3 node
are resolved. Rejected confirmation fails before side effects with
`error.code=validation_failed`, `error.meta.field=force`, and
`error.meta.reason=destructive_consent_required`.

Invalid prompt answers re-prompt until the value is valid or the operator
aborts. Abort fails before side effects.
