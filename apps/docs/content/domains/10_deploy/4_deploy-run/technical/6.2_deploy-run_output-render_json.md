# JSON Renderer: `orbit deploy:run`

[Back to `deploy:run` technical contract.](1_deploy-run.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "run": {
        "id": 42,
        "app": "docs",
        "status": "completed",
        "exit_code": 0,
        "started_at": "2026-05-02T09:00:00Z",
        "finished_at": "2026-05-02T09:01:30Z",
        "context": {
          "release": "20260502_090000_42",
          "app_path": "/home/docs/app",
          "release_path": "/home/docs/app/releases/20260502_090000_42",
          "app_user": "docs"
        },
        "steps": [
          {
            "id": 12,
            "title": "Pull latest",
            "status": "completed",
            "exit_code": 0
          }
        ]
      },
      "output": {
        "stdout": "Already up to date.\n",
        "stderr": ""
      }
    },
    "meta": {
      "action": "completed",
      "duration_ms": 90000
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "deploy.step_failed",
    "message": "Deployment step 'Run migrations' failed for app 'docs'.",
    "data": {
      "run": {
        "id": 44,
        "app": "docs",
        "status": "failed",
        "exit_code": 1,
        "started_at": "2026-05-02T09:10:00Z",
        "finished_at": "2026-05-02T09:10:12Z",
        "context": {
          "release": "20260502_091000_44",
          "app_path": "/home/docs/app",
          "release_path": "/home/docs/app/releases/20260502_091000_44",
          "app_user": "docs"
        },
        "steps": [
          {
            "id": 13,
            "title": "Run migrations",
            "status": "failed",
            "exit_code": 1
          }
        ]
      },
      "output": {
        "stdout": "",
        "stderr": "Migration table is locked.\n"
      }
    },
    "meta": {
      "app": "docs",
      "step": "Run migrations",
      "duration_ms": 12000
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.run` | object | Deployment run entity. |
| `success.data.run.context` | object | Deployment run context generated before the first step. |
| `success.data.output` | object | Captured output for foreground deployment runs. Omitted for detached runs. |
| `success.meta.action` | `started` or `completed` | Command outcome. |
| `success.meta.detached` | boolean | Present and true for detached runs. |
| `success.meta.duration_ms` | integer | Runtime duration in milliseconds when known. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `app.not_found`, `deploy.production_app_required`, `deploy.pipeline_empty`, `deploy.execution_failed`, `deploy.step_failed`, `deploy.history_write_failed` | Stable command failure code. |
| `error.data.run` | object | Run record when a run was created before failure. |
| `error.data.output` | object | Captured output for step or execution failures. |
| `error.meta` | object | Field, missing permission, app selector, step, duration, or persistence context for automation. |
