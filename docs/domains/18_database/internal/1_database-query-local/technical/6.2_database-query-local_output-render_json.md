# JSON Renderer: `orbit database:query-local`

[Back to `database:query-local` technical contract.](1_database-query-local.md)

## Primitive

None. This command writes one strict JSON document to stdout.

## Envelope

This internal command also uses the shared [JSON Envelope](../../../../README.md#json-envelope).

## Success Shape

`success.data` mirrors the resolved execution result with `columns`, `rows`,
`row_count`, `affected_count`, and execution timing metadata.

## Error Shape

Only these command-specific codes are allowed:

- `validation_failed`
- `database_query.write_not_allowed`
- `database_query.execution_failed`
