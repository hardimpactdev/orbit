# Human Renderer: `orbit node:agent-ide [name] [agent_ide]`

[Back to `node:agent-ide` technical contract.](1_node-agent-ide.md)

This page describes the human-rendered terminal output for `node:agent-ide`.

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. Prompt behavior belongs to
[`interactive input mode`](5.1_node-agent-ide_input-mode_interactive.md).
Non-interactive validation failures are rendered here as prose errors when
`--json` is absent.

## Progress Tree

`node:agent-ide` performs a single gateway-owned registry write with no slow
external work. Execution is expected to complete in under one second. A progress
tree is not rendered.

## Success Output

When the adapter is set to a new value:

```text
Node 'app-1' agent IDE set to 'opencode'
```

When the adapter is cleared with `none`:

```text
Node 'app-1' agent IDE cleared
```

When the requested adapter already matches the current value:

```text
Node 'app-1' agent IDE already set to 'opencode'
```

## Failure Output

Human-rendered failures must show:

- the failing phase or field;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the caller can act on it.

Structured gateway failures are rendered with the gateway's original prose. In
particular, `authorization_failed`, `node.not_found`, and
`node.unsupported_adapter` are not collapsed into gateway unavailable prose.
Only unstructured transport failures render the gateway unavailable message.

### Missing node

```text
Node 'app-1' not found.
```

### Unsupported adapter

```text
Adapter 'unknown-ide' is not supported.
```

### Missing required input

```text
Node name is required.
```

```text
Agent IDE adapter is required.
```

### Gateway unavailable

```text
Gateway connection is required to update node configuration.
```

### Authorization failed

```text
This node is not authorized for 'node:agent' on 'app-1'.
```
