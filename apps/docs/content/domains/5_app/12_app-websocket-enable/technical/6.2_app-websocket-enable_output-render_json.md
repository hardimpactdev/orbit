# JSON Renderer: `orbit app:websocket enable`

[Back to `app:websocket enable` technical contract.](1_app-websocket-enable.md)

This page describes the JSON-rendered output for `app:websocket enable`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The binding object is returned under `success.data.binding`.

## Success Shape

```json
{
  "success": {
    "data": {
      "binding": {
        "app": "docs",
        "internal_host": "websocket.orbit",
        "public_hosts": ["ws.docs.example.com"],
        "allowed_origins": ["https://docs.example.com"]
      }
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `binding` | object | Resulting WebSocket binding state after the enable operation. |
| `binding.app` | string | App identity slug. |
| `binding.internal_host` | string | WireGuard-internal WebSocket service hostname. Always `websocket.orbit`. |
| `binding.public_hosts` | array | Public WebSocket hostnames bound to this app after the enable call. |
| `binding.allowed_origins` | array | Origins permitted by Reverb for this app. Derived from the app domain. |

## Error Shapes

### App not found

```json
{
  "error": {
    "code": "app.not_found",
    "message": "App 'docs' not found.",
    "meta": {
      "app": "docs"
    }
  }
}
```

### Validation failed

```json
{
  "error": {
    "code": "validation_failed",
    "message": "App is required.",
    "meta": {
      "field": "app"
    }
  }
}
```

### WebSocket prerequisite failed

```json
{
  "error": {
    "code": "websocket.prerequisite_failed",
    "message": "The websocket service route requires an active router node.",
    "meta": {
      "app": "docs"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'app:write' on 'app-1'.",
    "meta": {
      "missing_permission": "app:write",
      "serving_node": "app-1"
    }
  }
}
```
