# Non-Interactive Input Mode: `orbit proxy:add`

[Back to `proxy:add` technical contract.](1_proxy-add.md)

**Input mode:** Non-interactive.

## Mode Selection

This contract applies without a TTY or when `--json` is present. `--json` forces non-interactive input mode.

## Behavior

No prompts are rendered. `domain`, serving node, and exactly one route target must resolve from arguments, options, or gateway-visible state. Missing required input fails before side effects with `error.code=validation_failed`.

When an existing custom route differs from the requested target, non-interactive mode requires `--force`. Without `--force`, the command fails before side effects with `error.code=proxy.replacement_consent_required`.

`--json` selects the JSON renderer only. It does not change validation, does not grant authorization, and does not imply replacement consent.
