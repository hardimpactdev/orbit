# Human Renderer: `orbit cf-cache:flush`

[Back to `cf-cache:flush` technical contract.](1_cf-cache-flush.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`cf-cache:flush` resolves provider state and performs an external provider
write. After input resolution and before the Cloudflare purge request begins,
render this progress tree:

```text
┌ Flushing Cloudflare cache
○ Resolve Cloudflare zone
○ Request cache purge
└ Working...
```

## Success Output

Render one concise success line:

```text
Cloudflare cache flushed for example.com
```

## Failure Output

Validation, gateway, authorization, and Cloudflare failures render one concise
error line with the rejected zone when available.
