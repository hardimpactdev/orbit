# Human Renderer: `orbit dns:list`

[Back to `dns:list` technical contract.](1_dns-list.md)

This page describes the human-rendered terminal output for `dns:list`.

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. `dns:list` takes no required
arguments and does not prompt in any input mode.

## Progress Tree

`dns:list` is a local resolver configuration read. Execution is expected to
complete below one second and does not perform slow external work. No progress
tree is rendered.

## Success Output

When local DNS overrides exist:

```text
TLD    TARGET     SOURCE           BACKEND   STATUS
test   10.6.0.7   local_resolver   dnsmasq   active
```

When no Orbit-managed local DNS overrides exist:

```text
No local Orbit DNS overrides found.
```

## Failure Output

Human-rendered failures must show:

- the failing condition;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the operator can act on it.

Caller role not allowed:

```text
This command may only be run from a control node.
```

Unsupported platform:

```text
This platform does not support automatic local DNS resolver inspection.
```

Resolver read failed:

```text
Could not read local DNS resolver configuration.
```

Local context invalid:

```text
Local node role setting is invalid.
```
