# JSON Renderer: `orbit instance:log [target]`

[Back to `instance:log` technical contract.](1_instance-log.md)

This page describes the JSON-rendered output for `instance:log`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces non-interactive
input mode. JSON output is bounded and cannot be combined with `--follow`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the resolved instance target, serving node, fixed logical
path, requested line count, file existence, and bounded log lines.

## Success Example

```json
{
  "success": {
    "data": {
      "target": {
        "type": "instance",
        "app": "docs",
        "instance": "development",
        "workspace": null,
        "selector": "docs.development"
      },
      "node": "app-dev-1",
      "path": "storage/logs/laravel.log",
      "lines_requested": 100,
      "file_exists": false,
      "lines": []
    },
    "meta": []
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "validation_failed",
    "message": "--json cannot be combined with --follow.",
    "meta": {
      "field": "json"
    }
  }
}
```

## Authorization Error

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'instance:read' on 'app-dev-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "instance:read",
      "serving_node": "app-dev-1"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: target is missing, invalid, or ambiguous in non-interactive
  input mode; `--lines` is invalid; `--json` is combined with `--follow`; or
  `--node` does not match the serving node. Target failures use
  `error.meta.field=target`.
- `authorization_failed`: caller lacks `instance:read` on the resolved serving node.
- `instance.not_found`: the resolved instance does not exist or is not visible.
- `application_log.read_failed`: the gateway cannot read the fixed application
  log from the serving node.
- `gateway_unavailable`: the CLI cannot reach the Orbit gateway.
