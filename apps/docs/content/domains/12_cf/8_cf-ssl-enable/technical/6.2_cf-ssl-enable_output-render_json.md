# JSON Renderer: `orbit cf-ssl:enable`

[Back to `cf-ssl:enable` technical contract.](1_cf-ssl-enable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "ssl": {
        "zone": "example.com",
        "mode": "strict",
        "action": "enable",
        "status": "set"
      }
    },
    "meta": {
      "provider": "cloudflare"
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The selected Cloudflare SSL mode is invalid.",
    "meta": {
      "field": "mode",
      "allowed": ["strict", "full"]
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.ssl.zone` | string | Resolved Cloudflare zone. |
| `success.data.ssl.mode` | `strict` or `full` | Applied Cloudflare SSL mode. |
| `success.data.ssl.action` | `enable` | Command operation that completed. |
| `success.data.ssl.status` | `set` | Provider setting outcome. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `cloudflare_unavailable` | Stable command failure code. |
| `error.meta` | object | Field, zone, mode, gateway, authorization, token, or provider failure context. |
