# Interactive Input Mode: `orbit node:manage`

[Back to `node:manage` technical contract.](1_node-manage.md)

**Input mode:** Interactive.

## Selection

Use this input mode only when both conditions are true:

- the command is running in a TTY;
- `--json` is not present.

When `--json` is present, use
[`5.2_node-manage_input-mode_non-interactive.md`](5.2_node-manage_input-mode_non-interactive.md)
even if the process has a TTY.

## Responsibilities

Interactive mode resolves missing input from local defaults.

- If `--user` is omitted, use the current local user.
- Do not prompt for a node name. The target is always the authenticated caller
  returned by `/api/me`.
- If local user resolution fails, prompt for an SSH user before local file
  writes.
- Display progress while installing the key, persisting gateway metadata, and
  verifying SSH reachability.

Interactive mode must not silently continue after local key installation fails.
