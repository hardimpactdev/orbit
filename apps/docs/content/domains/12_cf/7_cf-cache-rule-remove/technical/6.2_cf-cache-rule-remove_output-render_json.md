# JSON Renderer: `orbit cf-cache-rule:remove`

[Back to `cf-cache-rule:remove` technical contract.](1_cf-cache-rule-remove.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "rule": {
        "project": "docs",
        "zone": "example.com",
        "action": "remove",
        "status": "removed"
      }
    },
    "meta": {
      "provider": "cloudflare"
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Removing a Cloudflare cache rule requires --force in non-interactive mode.",
    "meta": {
      "field": "force",
      "reason": "destructive_consent_required"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.rule.app` | string | App that owned the cache rule. |
| `success.data.rule.zone` | string | Resolved Cloudflare zone. |
| `success.data.rule.action` | `remove` | Command operation that completed. |
| `success.data.rule.status` | `removed` | Provider cache-rule outcome. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `cloudflare_unavailable` | Stable command failure code. |
| `error.meta` | object | Field, app, zone, consent, gateway, authorization, token, or provider failure context. |
