# JSON Renderer: `orbit cf-ssl:disable`

[Back to `cf-ssl:disable` technical contract.](1_cf-ssl-disable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "ssl": {
        "zone": "example.com",
        "mode": "off",
        "action": "disable",
        "status": "set"
      }
    },
    "meta": {
      "provider": "cloudflare"
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Disabling Cloudflare SSL requires --force in non-interactive mode.",
    "meta": {
      "field": "force",
      "reason": "destructive_consent_required"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.ssl.zone` | string | Resolved Cloudflare zone. |
| `success.data.ssl.mode` | `off` | Applied Cloudflare SSL mode. |
| `success.data.ssl.action` | `disable` | Command operation that completed. |
| `success.data.ssl.status` | `set` | Provider setting outcome. |
| `error.code` | `validation_failed`, `caller_role_not_allowed`, `gateway_unavailable`, `authorization_failed`, `cloudflare_unavailable` | Stable command failure code. |
| `error.meta` | object | Field, zone, consent, gateway, authorization, token, or provider failure context. |
