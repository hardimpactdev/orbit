Prepare one command for [stage 1 of the command development pipeline](/reference/command-development-pipeline#1-prep). An author agent drafts the chart, the docs page and the cases in a task VM, a review agent checks them, and Swamp opens a draft pull request as the Orbit App with the spec as its first commit. The Gateway only admits the run and records its end. See [Prepare a command](/reference/tasks#prepare-a-command).

There is no `orbit` command yet. Use the API or the MCP tool `task-prep`.

```bash
curl -X POST "$GATEWAY/api/v1/tasks/42/prep" \
  -H "Idempotency-Key: prep-42-firewall-deny" \
  -d '{"command": "firewall:deny"}'
```

The route needs a Node with an access grant to the Gateway and a required `Idempotency-Key`. The reply is `202` with the operation. Follow it with `operation:show` until it ends. A repeat with the same key returns the same operation.

| Input | Meaning |
| --- | --- |
| `group` | The numeric ID of a `todo` task group with no VM, made with `task:create`. It has one subtask with a deliverable. |
| `command` | The command in lower case: `family:command`, or `family:part:command` for a nested one. A nested command's files join the parts after the family with dashes, so `node:role:list` is `docs/cli/node/role-list.mdx`. |
| `brief` | Optional, up to 8,000 characters. What to change, for every agent of the run. |
| `reference` | Optional, up to 80,000 characters. Text for the author only, such as the files of a sibling spec that is not on the default branch yet. |

The run takes its mode from the review mode of the group, `manual` or `automatic`, at admission. In manual mode a succeeded run parks the task VM while the spec waits for the owner; in automatic mode nothing parks.

## Errors

| Code | When |
| --- | --- |
| `tasks.prep_command_invalid` | `command` is not `family:command` or `family:part:command` in lower case |
| `tasks.not_todo`, `tasks.group_closed`, `tasks.already_claimed` | the group is not an open `todo` group with no VM |
| `tasks.subtask_deliverables_missing` | the group has no subtask, or its first subtask has no deliverable |
| `tasks.capacity_unavailable` | no task VM host has room, or no host with room holds usable nested fleet copies for a VM that needs them; the group is unchanged |
| `tasks.prep_not_committed` | the draft or a fix left HEAD where it was |
| `tasks.prep_plan_failed` | the runner plan of the cases file failed to run, with an exit other than 0 or 3 |
| `tasks.prep_review_unresolved` | a finding is left after the last review round; nothing is published |
| `tasks.head_moved`, `tasks.not_fast_forward`, `tasks.push_failed`, `tasks.publish_failed` | publication failed; see [publish](/reference/tasks#publish-an-external-group) |
