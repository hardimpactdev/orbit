---
title: "orbit process:restart"
sidebarTitle: "process:restart"
description: "Restart an installed Process and store the running desired state."
---

```bash
orbit process:restart <process> [--idempotency-key=KEY] [--json]
```

On a container Instance, a Process whose definition the Project removed answers `process.removing` (409). The next deployment of the default removes it.
