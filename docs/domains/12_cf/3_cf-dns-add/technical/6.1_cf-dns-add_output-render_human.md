**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../commands/ux/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`cf-dns:add` validates provider state and performs an external provider write.
After input resolution and before the Cloudflare request begins, render this
progress tree:

```text
┌ Adding Cloudflare DNS record
○ Resolve Cloudflare zone
○ Check existing address records
○ Write Cloudflare DNS record
└ Working...
```

## Success Output

Render one concise success line:

```text
Cloudflare DNS record docs.example.com A -> 203.0.113.10 created
```

When an equivalent record already exists, replace `created` with
`already present`.

## Failure Output

Validation, gateway, authorization, and Cloudflare failures render one concise
error line. Conflict errors name the existing record ID when available.
