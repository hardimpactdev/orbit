# Human Renderer: `orbit doctor`

[Back to `doctor` technical contract.](1_doctor.md)

This page describes the human-rendered terminal output for `doctor`.

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. `doctor` has optional filters
and fails invalid combinations before probes or side effects.

## Progress Tree

`doctor` may perform gateway, remote probe, and repair/adoption work, so the
human renderer must show an in-progress tree after scope authorization and
before probes or side effects begin.

```text
┌ Running Orbit Doctor
○ Resolve scope
○ Probe node
○ Probe app
○ Probe workspace
○ Probe process
└ Working...
```

The family steps are populated from the resolved family scope. In `--fix` or
`--adopt` mode, action steps appear immediately after the family that owns them.

```text
┌ Running Orbit Doctor
○ Resolve scope
● Probe app
○ Fix app.fpm_config_missing for docs
└ Doctor actions complete
```

Each step is updated in place as it starts, succeeds, is skipped, or fails. The
final tree must make remaining drift and failed actions visible.

## Success Output

On healthy verify success:

```text
Doctor healthy.
Mode: verify
Scope: family=node self=true
```

On healthy fix or adopt success:

```text
Doctor healthy.
Mode: fix
Fixed: 2
Remaining issues: 0
```

Success output must not imply that unselected families, nodes, apps, or
workspaces were inspected.

## Failure Output

Human-rendered failures must show:

- selected mode and scope;
- remaining issue count grouped by family and kind;
- action results for `--fix` or `--adopt`;
- manual next steps when an issue cannot be fixed or adopted automatically;
- no JSON envelope.

Example verify failure:

```text
Doctor found drift.
Mode: verify
Scope: family=node node=app-1

node
  unverifiable
    node.app_ssh_unreachable: Gateway cannot reach app-1 over SSH.
      Next: check WireGuard and SSH reachability, then run doctor --family=node --node=app-1
```

Example fix failure:

```text
Doctor could not repair all drift.
Mode: fix
Fixed: 1
Remaining issues: 1

app
  missing
    app.path_missing: App path is missing on the owning node.
      Next: restore the app path or register a compatible existing path.
```
