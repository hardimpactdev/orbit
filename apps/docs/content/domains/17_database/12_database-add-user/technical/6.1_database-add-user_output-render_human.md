# Human Renderer: `orbit database:add-user`

[Back to `database:add-user` technical contract.](1_database-add-user.md)

## Primitive

None. Renderer prints concise success or failure lines and does not render a
table, prompt, spinner, or progress tree.

## Progress Tree

No progress tree. The command performs one gateway request and one bounded
node-local convergence operation. The gateway executes it locally for a gateway
owner and uses authenticated Agent push for a non-gateway owner.

## Human Strings

- Success: `Database user '{username}' ready on service '{service}'.`
- Success: `Database connection '{connection}' updated.`
- Failure: `validation_failed: {message}`
