# JSON Renderer: `orbit deploy:step-list`

[Back to `deploy:step-list` technical contract.](1_deploy-step-list.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "steps": [
        {
          "id": 12,
          "app": "docs",
          "instance": "production",
          "title": "Pull latest",
          "command": "git pull origin main",
          "order": 1,
          "timeout_seconds": 600,
          "retention": null
        }
      ]
    },
    "meta": {
      "app": "docs",
      "instance": "production",
      "count": 1
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "instance.not_found",
    "message": "Instance 'docs.production' was not found.",
    "meta": {
      "app": "docs",
      "instance": "production"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.steps[]` | array | Deploy step entities visible for the selected instance. |
| `success.meta.app` | string | Selected app. |
| `success.meta.instance` | string | Selected concrete instance. |
| `success.meta.count` | integer | Number of returned steps. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `instance.not_found`, `deploy.production_app_required` | Stable command failure code. `validation_failed` with `error.meta.reason=instance_required` reports an ambiguous bare app selector. |
| `error.meta` | object | Field, instance selector, instance environment, missing permission, or authorization context for automation. |
