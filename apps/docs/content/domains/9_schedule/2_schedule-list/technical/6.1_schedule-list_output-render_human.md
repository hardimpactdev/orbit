# Human Renderer: `orbit schedule:list`

[Back to `schedule:list` technical contract.](1_schedule-list.md)

**Renderer:** Human terminal renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`schedule:list` is a read-only gateway registry query. Execution is expected to complete below one second and does not perform slow external work. No progress tree is rendered.

## Success Output

Render a table with one row per schedule.

| Column | Meaning |
| --- | --- |
| Name | Schedule slug. |
| Scope | `app`, `node`, or `orbit`. |
| Target | App, node, or Orbit maintenance target. |
| Node | Node where the Orbit Scheduler executes runs for this schedule. |
| Interval | Portable Orbit interval expression. |
| Execution | Command or script summary. |
| Last Run | Latest durable run status and timestamp, or `-`. |
| Status | Gateway-configuration status. |

Empty results render a concise empty state that names the selected filter.

## Failure Output

Validation, gateway, and authorization failures render one concise error line with the rejected field or selected scope when available.
