# Human Renderer: `orbit process:logs [name]`

[Back to `process:logs` technical contract.](1_process-logs.md)

This page describes the human-rendered terminal output for `process:logs`.

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render a short progress tree after input resolution and before log output begins
because opening the remote log stream may take longer than one second.

```text
┌ Streaming Process Logs
○ Resolve runtime unit
○ Open log stream
└ Working...
```

After the footer, write log lines directly to the terminal. In follow mode, the
stream remains open until the operator interrupts it.

## Success Output

Bounded reads print log lines and then exit. Follow mode prints log lines until
interrupted.

When no logs are available:

```text
No log lines found.
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no
JSON envelope, and next-step guidance only when the operator can act on it.
