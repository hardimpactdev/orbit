# Non-Interactive Input Mode: `orbit tool-remove`

[Back to `tool-remove` technical contract.](1_tool-remove.md)

**Input mode:** Non-interactive.

This contract applies without a TTY or when `--json` is present. `--json` forces non-interactive input mode.

## Resolution Rules

No prompts are rendered. All required fields must be supplied by arguments,
options, or local defaults. Removal in non-interactive mode without `--json` requires `--force`;
missing `--force` fails before side effects with `validation_failed`,
`meta.field=force`, and `meta.reason=destructive_consent_required`.

`--json` forces non-interactive input mode and implies destructive consent.
`--force` is not required with `--json`; ordinary tool, target, authorization,
and existence validation still apply before side effects.
