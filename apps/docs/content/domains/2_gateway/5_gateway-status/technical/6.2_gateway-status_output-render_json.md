# JSON Renderer: `orbit gateway:status`

[Back to `gateway:status` technical contract.](1_gateway-status.md)

This page describes the JSON-rendered output for `gateway:status`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces non-interactive input
mode, even when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

All failures must use this envelope.

## Enum and identifier values

| Field | Values |
| --- | --- |
| `error.code` | `gateway_unavailable`, `gateway_unreachable_wireguard` |
| `success.meta.endpoint` | `/api/status` |

The `error.code` values listed here are exhaustive for `gateway:status`. Add a
new value to this renderer contract before implementing another JSON failure
code.

## Success

```json
{
  "success": {
    "data": {
      "gateway": {
        "status": "healthy",
        "version": "0.1.0"
      }
    },
    "meta": {
      "endpoint": "/api/status"
    }
  }
}
```

The `success.data` object contains the full response from the gateway
`/api/status` endpoint. The exact fields depend on the gateway version;
`gateway.status` and `gateway.version` are expected fields.

## Gateway WireGuard Unreachable Error

```json
{
  "error": {
    "code": "gateway_unreachable_wireguard",
    "message": "WireGuard route to the gateway is not established.",
    "meta": {
      "endpoint": "/api/status"
    }
  }
}
```

## Gateway Unavailable Error

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway request failed (HTTP 503) Body: gateway offline",
    "meta": {
      "endpoint": "/api/status",
      "status_code": 503,
      "body_excerpt": "gateway offline"
    }
  }
}
```

`error.meta.status_code` and `error.meta.body_excerpt` are included when
available from the HTTP failure response.
