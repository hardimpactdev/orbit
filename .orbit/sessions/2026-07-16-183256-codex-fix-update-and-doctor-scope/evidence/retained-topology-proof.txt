Gateway-local token round trip
------------------------------

The retained gateway used an `orbit-gateway` container alias whose
`/usr/local/bin/orbit` and `/usr/local/bin/orbit-cli` both executed the
source-mounted CLI. Registering Hauzer and Mealou executed backend operations
on app-prod and gateway-local router operations through the real gateway API,
operation-token authorization, container executor, and CLI guard.

With the gateway Caddy container intentionally absent, both registrations
failed at the exact expected operation:

- Hauzer: layer=router node=gateway operation=caddy.router.install
- Mealou: layer=router node=gateway operation=caddy.router.install

The router artifacts existed on the gateway after the failed reload, proving
the gateway-local token was authorized and the stdin payload was consumed:

- /etc/caddy/sites/hauzer.app.caddy
- /etc/caddy/sites/mealou.app.caddy

`proxy:list --json` reported both routes as `partial`; it did not infer
`expected` or `converged` from database intent.

Scoped single-run restore
-------------------------

Command:

  orbit doctor --app=hauzer-production --node=app-prod-1 --family=proxy --restore --dry-run --json

Result: exit 0. Exactly two Hauzer issues were planned:

- proxy.public_route_missing
- proxy.enactment_incomplete, with failure
  layer=router node=gateway operation=caddy.router.install

No Mealou issue or action appeared.

Command:

  orbit doctor --app=hauzer-production --node=app-prod-1 --family=proxy --restore --json

Result: exit 0, healthy=true, fixed=2, failed=0. The same run:

- restored the Hauzer public ingress artifact;
- re-enacted the complete backend -> router -> ingress operation plan.

Persisted Hauzer enactment after restore:

- status=converged
- all seven planned operations completed in order
- failure=null

Final verification
------------------

Command:

  orbit doctor --app=hauzer-production --node=app-prod-1 --family=proxy --json

Result: exit 0, healthy=true, issues=0.

Command:

  orbit proxy:list --json

Result:

- hauzer.app (`hauzer-production.production`): converged
- mealou.app (`mealou-production.production`): partial

Artifact inventory:

- app-prod/ingress Hauzer: backend and public route artifacts present
- gateway/router Hauzer: router artifact present
- app-prod/ingress Mealou: backend artifact only; no public route artifact
- gateway/router Mealou: router artifact from the intentionally failed reload

The Hauzer artifacts encode the intended topology:

  ingress app-prod-1 -> gateway/router 10.6.0.2:80
  gateway/router -> backend app-prod-1 10.6.0.5:8081
  backend -> orbit-app-hauzer-production:8080

The retained substrate's public TLS request failed at certificate negotiation
because the route requests an ACME certificate without public DNS reachability.
That is separate from operation-token authorization and proxy convergence, as
is the reported Cloudflare edge-certificate/API-token issue.
