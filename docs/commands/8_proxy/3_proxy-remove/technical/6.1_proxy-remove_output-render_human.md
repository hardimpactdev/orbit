# Human Renderer: `orbit proxy:remove`

[Back to `proxy:remove` technical contract.](1_proxy-remove.md)

**Renderer:** Human terminal renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and destructive confirmation,
before backend cleanup or gateway intent removal begins.

```text
┌ Removing Proxy Route
○ Confirm destructive removal
○ Resolve proxy route
○ Remove backend proxy route
○ Remove route-scoped TLS material
○ Apply and verify proxy removal
└ Working...
```

If TLS material is shared by another route, the TLS cleanup step completes as a
skip/warning step and the route removal remains successful.

## Success Output

Render the removed domain, kind, serving node, target, and whether backend and
TLS cleanup completed or were skipped.

## Failure Output

Validation failures render the rejected field. Missing destructive consent
renders a direct message that `--force` is required in non-interactive mode.
Owned-route denial names the owner command that controls removal. Cleanup
failures render the next doctor command for recovery.
