## Progress Tree

No progress tree. The command performs one metadata read through the selected
database connection and renders the result directly. SQLite locality is handled
by the gateway/local command split; the public human renderer must not fake
progress over a blocking remote JSON response.

## Human Strings

- Success: "Showing description for table '{table}'."
- Failure: "Failed to describe table '{table}'."
