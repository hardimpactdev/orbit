# JSON Renderer: `orbit deploy:log`

[Back to `deploy:log` technical contract.](1_deploy-log.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Error Shape

```json
{
  "error": {
    "code": "deploy.run_not_found",
    "message": "Deployment run 999 was not found for instance 'docs.production'.",
    "meta": {
      "project": "docs",
      "instance": "production",
      "run": 999
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.run` | object | Deployment run entity. |
| `success.data.steps` | array | Captured per-step output records after optional step filtering. |
| `success.meta.lines` | integer | Effective per-stream line limit. |
| `success.meta.truncated_by_filter` | boolean | True when any stream was shortened by `--lines`. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `instance.not_found`, `deploy.production_project_required`, `deploy.run_not_found`, `deploy.step_not_found`, `deploy.log_read_failed` | Stable command failure code. |
| `error.meta` | object | Field, app selector, run id, step id, line limit, missing permission, or authorization context for automation. |
