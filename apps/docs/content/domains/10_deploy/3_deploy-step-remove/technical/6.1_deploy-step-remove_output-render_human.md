# Human Renderer: `orbit deploy:step-remove`

[Back to `deploy:step-remove` technical contract.](1_deploy-step-remove.md)

**Renderer:** Human terminal renderer.

## Primitive

None. Renderer prints a concise success or failure line after destructive consent resolves.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`deploy:step-remove` removes one gateway policy row and performs no slow
external work. Execution is expected to complete below one second after
destructive consent is resolved. No progress tree is rendered.

## Success Output

Render the app, removed step id, title, previous order, and confirmation that
deployment history was preserved.

## Failure Output

Validation, destructive-consent, gateway, authorization,
app-not-found, production-app eligibility, and step-not-found failures render
one concise error line with the rejected field or selector when available.
