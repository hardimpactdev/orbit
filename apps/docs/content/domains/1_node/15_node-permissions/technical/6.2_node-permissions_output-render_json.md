# JSON Renderer: `orbit node:permissions`

[Back to `node:permissions` technical contract.](1_node-permissions.md)

## Primitive

None. JSON renderer emits the standard envelope only.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Top-level envelopes:
- Success: `{ "success": { ... } }`
- Error: `{ "error": { ... } }`

## Success Shape

`success.data.action` — `created`, `updated`, or `read`.

`success.data.consuming_node` — resolved consuming node name.

`success.data.serving_node` — resolved serving node name.

`success.data.permissions` — normalized permission set after the operation.

`success.data.mode` — the resolved mode: `read`, `preset`, `permissions`,
`add`, or `remove`.

`success.meta.warnings[]` — zero or more warning objects. Each warning
object carries:

| Warning field | Type | Meaning |
| --- | --- | --- |
| `code` | string | Stable warning code, such as `node.redundant_permissions`. |
| `family` | string | Owning command family for the warning. For this command, `node`. |
| `message` | string | One-line human-readable summary derived from the code. |
| `next_command` | string \| null | Suggested follow-up command, such as `node:permissions <consuming> <serving> --json`. May be `null` when no follow-up is appropriate. |

Redundant permissions normalized away are surfaced as `code:
node.redundant_permissions` with a `permissions` array beside the shared
warning fields containing the removed entries.

Example success payload after a `--preset=operator` replacement that created
the grant edge:

```json
{
  "success": {
    "data": {
      "action": "created",
      "consuming_node": "agent-1",
      "serving_node": "app-1",
      "mode": "preset",
      "permissions": [
        "app:read",
        "database:read",
        "doctor:verify",
        "firewall_rule:read",
        "node:read",
        "tool:read"
      ]
    },
    "meta": {
      "warnings": []
    }
  }
}
```

## Error Codes

- `validation_failed`
- `authorization_failed`
- `gateway_unavailable`
- `node.not_found`
- `node.grant_not_found`
