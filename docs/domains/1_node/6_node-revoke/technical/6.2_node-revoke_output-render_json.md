# JSON Renderer: `orbit node:revoke [consuming_node] [serving_node]`

[Back to `node:revoke` technical contract.](1_node-revoke.md)

This page describes the JSON-rendered output for `node:revoke`.

**Renderer:** JSON renderer.

## Primitive

None. JSON renderer emits the standard envelope only.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](5.2_node-revoke_input-mode_non-interactive.md), even
when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "consuming_node": "control-1",
      "serving_node": "app-1",
      "action": "revoked",
      "already_absent": false,
      "self_lockout": false
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `consuming_node` | string | The consuming node name. |
| `serving_node` | string | The serving node name. |
| `action` | string | Always `revoked`. |
| `already_absent` | boolean | `true` when the grant was already absent; `false` when it was deleted by this command. |
| `self_lockout` | boolean | `true` when the revocation removes the authenticated caller's own consuming→gateway grant; `false` otherwise. |

### Success when grant already absent

```json
{
  "success": {
    "data": {
      "consuming_node": "control-1",
      "serving_node": "app-1",
      "action": "revoked",
      "already_absent": true,
      "self_lockout": false
    }
  }
}
```

### Success when the revocation locks the caller out of the gateway

```json
{
  "success": {
    "data": {
      "consuming_node": "control-1",
      "serving_node": "gateway-1",
      "action": "revoked",
      "already_absent": false,
      "self_lockout": true
    }
  }
}
```

## Error Shapes

### Missing required input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Consuming node is required.",
    "meta": {
      "field": "consuming_node"
    }
  }
}
```

### Missing destructive consent

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Use --force to revoke this grant.",
    "meta": {
      "field": "force"
    }
  }
}
```

### Node not found

```json
{
  "error": {
    "code": "node.not_found",
    "message": "Node 'control-1' not found.",
    "meta": {
      "name": "control-1"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to revoke a grant.",
    "meta": {}
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This action requires the node:revoke permission on a grant to the gateway.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "node:revoke",
      "serving_node": "gateway-1"
    }
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `action` | `revoked` |
| `error.code` | `validation_failed`, `node.not_found`, `gateway_unavailable`, `authorization_failed` |

The `error.code` values listed here are exhaustive for `node:revoke`. Add a new
value to this renderer contract before implementing another JSON failure code.
