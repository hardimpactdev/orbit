# JSON Renderer: `orbit schedule:add`

[Back to `schedule:add` technical contract.](1_schedule-add.md)

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "result": {
        "action": "created",
        "enactment": "enabled"
      },
      "schedule": {
        "name": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs",
          "node": "app-1"
        },
        "interval": "every minute",
        "timezone": "Europe/Amsterdam",
        "execution": {
          "type": "command",
          "value": "php artisan schedule:run"
        },
        "enabled": true,
        "status": "expected",
        "last_run": null
      }
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "schedule.enactment_failed",
    "message": "Schedule 'laravel-scheduler' was recorded, but timer artifacts could not be enabled on node 'app-1'.",
    "data": {
      "schedule": {
        "name": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs",
          "node": "app-1"
        },
        "interval": "every minute",
        "timezone": "Europe/Amsterdam",
        "execution": {
          "type": "command",
          "value": "php artisan schedule:run"
        },
        "enabled": true,
        "status": "enactment_failed",
        "last_run": null
      }
    },
    "meta": {
      "node": "app-1",
      "next_command": "doctor --family=schedule --fix"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.result.action` | string | `created`. |
| `success.data.result.enactment` | string | Backend enactment result, usually `enabled`. |
| `success.data.schedule` | object | Schedule entity defined in [`9_schedule/README.md`](../../README.md#schedule-json-entity). |
| `error.code` | string | Stable command failure code. |
| `error.data.schedule` | object | Present when gateway intent exists after a partial enactment failure. |
| `error.meta.next_command` | string | Recovery command for partial enactment failures. |
