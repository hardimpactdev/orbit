# Human Renderer: `orbit firewall:allow`

[Back to `firewall-allow` technical contract.](1_firewall-allow.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../commands/ux/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and before gateway writes or backend apply begins.

```text
┌ Allowing Firewall Rule
○ Validate firewall target
○ Check baseline policy boundary
○ Apply and verify firewall rule
└ Working...
```

## Success Output

Render the rule name, node, action, direction, source, destination when present, port, protocol, and backend apply result.

## Failure Output

Validation failures render the rejected field. Gateway and authorization failures render the selected node. Backend apply failures render the next doctor command for recovery.
