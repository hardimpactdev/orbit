Stop an external task group's VM while its published PR waits for review. Run `orbit task:park TASK --idempotency-key=KEY`. The command follows the operation through the normal operation display; `--json` returns the final operation. Ctrl-C stops following, not parking. The optional `task` argument is the numeric task group ID; omitting it uses the standard selector. Omitting `--idempotency-key` generates a fresh key. Parking preserves the workspace and requires no destructive confirmation. See [external review parking](/reference/tasks#park-an-external-group-for-review) for admission, confirmed power and recovery.
