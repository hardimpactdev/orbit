# Human Renderer: `orbit workspace-setup-step:list`

[Back to `workspace-setup-step:list` technical contract.](1_workspace-setup-step-list.md)

This page describes the human-rendered output for
`workspace-setup-step:list`.

**Renderer:** Human renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered because `workspace-setup-step:list` is expected
to stay below one second. It performs a fast gateway database read and does
not perform slow external work, network probes, or remote node application.

## Success Render

The success output is a table of setup steps for the resolved app instance. Steps are
ordered by the `order` field ascending. Both renderers use this single
ordering, so callers reading either output form see the same steps in the
same relative order.

The `ID` column surfaces the durable gateway-assigned step identifier used
by the sibling write command
[`workspace-setup-step:remove`](../../10_workspace-setup-step-remove/workspace-setup-step-remove.md).
This matches the resolved list-exemplar precedent (`node:list`, `app:list`,
`workspace:list`) of surfacing the identifier each sibling write command
accepts.

### Example output

```text
Setup steps for hauser.nmbp:

+----+-------+----------------------+---------+
| ID | ORDER | COMMAND              | TIMEOUT |
+----+-------+----------------------+---------+
| 12 | 1     | composer install     | 600s    |
| 13 | 2     | npm install          | 300s    |
| 14 | 3     | php artisan migrate  | 60s     |
+----+-------+----------------------+---------+
```

### Empty result

When no steps are defined for the resolved app instance:

```text
No setup steps defined for hauser.nmbp.
```

## Error Render

Errors are rendered as concise prose messages.

### Validation failure (app)

```text
Could not resolve parent app. Pass `--app=<app>` or run from inside a registered app or workspace path.
```

### App not found

```text
App 'my-app' not found.
```

### Unauthorized app

```text
You are not authorized to read setup-step policy for 'my-app'.
```

### Gateway unavailable

```text
Gateway connection is required to list setup steps.
```
