# Non-Interactive Input Mode: `orbit s3:credentials`

[Back to `s3:credentials` technical contract.](1_s3-credentials.md)

**Input mode:** Non-interactive.

## Mode Selection

This contract applies without a TTY or when `--json` is present. `--json`
forces non-interactive input mode.

## Behavior

No prompts are rendered. The serving S3 node must resolve from options or
gateway-visible state before credential material is read. Missing required
input fails before side effects with `error.code=validation_failed`.

`--json` selects the JSON renderer only. It does not change validation and does
not grant authorization.

## Required Inputs

| Field | Missing behavior |
| --- | --- |
| `node` | Optional only when exactly one visible active s3 node exists. Otherwise fail before reading credentials with `validation_failed` and `error.meta.field=node`. |
