# Non-Interactive Input Mode: `orbit firewall:allow`

[Back to `firewall-allow` technical contract.](1_firewall-allow.md)

**Input mode:** Non-interactive.

## Mode Selection

This contract applies without a TTY or when `--json` is present. `--json`
forces non-interactive input mode.

## Behavior

No prompts are rendered. `name`, target node, and `--port` must resolve from arguments, options, local defaults, or gateway-visible state. Missing required input fails before side effects with `error.code=validation_failed`.

`--json` selects the JSON renderer only. It does not change validation, does not grant authorization, and does not imply consent for any future destructive behavior.
