title: "orbit tool:update"
sidebarTitle: "tool:update"
description: "Apply the desired version or update one unpinned Tool to its manager's candidate."
---

```bash
orbit tool:update <tool> [--tool-version=VERSION] [--repository=JSON] [--idempotency-key=KEY] [--json]
```

In database mode, `--tool-version` sets an exact desired version. Without it, Orbit keeps an existing pin or asks the manager for a candidate. In file mode, the active catalog supplies the coordinate and the command refuses overrides.

The result is `applied` when the version changed and `unchanged` when it did not. A floating candidate outside the stored constraint gives `blocked_by_constraint`; an unavailable exact version fails without substituting another version.
