# Reuse a parent tool contribution

`rolePrerequisiteSteps(name, intentExpr, fullGlobals, dependency?, preparedToolsExpr?)` keeps standalone prerequisite behavior when its final argument is absent. With that expression, its first pure metadata step proves a native receipt `{ready:true,node_id,packages}` names the same Node and covers every required OS package. Failure stops the composition before any target action.

The composing enrollment parent owns exact version, artifact, JavaScript and Composer verification before emitting that receipt. It must pass the actual native output, not an admission boolean. A valid contribution skips only the generic OS package installation. Account observation, storage and managed directories, canonical Caddy handling and Composer verification still run. The canonical lower's output does not claim complete role runtime, publication or footprint success.
