# Human Renderer: `orbit ca:trust`

[Back to `ca:trust` technical contract.](1_ca-trust.md)

This page describes the human-rendered terminal output for `ca:trust`.

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. `ca:trust` does not prompt for
missing gateway input; invalid or missing input is rendered as prose when
`--json` is absent.

## Progress Tree

`ca:trust` performs network and local OS trust-store work, so the human renderer
must show an in-progress tree after input resolution and before side effects
begin.

```text
┌ Trust Gateway CA
○ Resolve gateway
○ Fetch trust material
○ Install local trust
○ Store trust metadata
└ Orbit root CA trusted for https://10.6.0.2
```

When the selected CA is already trusted and local metadata matches:

```text
┌ Trust Gateway CA
○ Resolve gateway
○ Check local trust
└ Orbit root CA already trusted for https://10.6.0.2
```

The final tree must make the failed step visible when the command exits with
failure.

## Success Output

On successful trust installation:

```text
Orbit root CA trusted for https://10.6.0.2.
```

On already-trusted convergence:

```text
Orbit root CA already trusted for https://10.6.0.2.
```

Success output must not imply that local node identity, gateway access policy,
app routes, or runtime readiness were verified.

## Failure Output

Human-rendered failures must show:

- the failed phase or field;
- a clear prose error;
- next-step guidance only when the operator can act on it;
- no JSON envelope.

Missing gateway:

```text
Gateway is required. Run orbit gateway:add first or pass --gateway.
```

Invalid gateway:

```text
Gateway must be a valid URL, hostname, or IP address.
```

Gateway unavailable:

```text
Could not fetch the Orbit root CA from https://10.6.0.2.
```

Invalid trust material:

```text
Gateway returned invalid root CA material.
```

Unsupported platform:

```text
This platform does not support automatic Orbit root CA trust installation.
```

Trust-store failure:

```text
Failed to install the Orbit root CA into the local trust store.
```
