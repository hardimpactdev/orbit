title: "orbit process:stop"

---

```bash
orbit process:stop <process> [--idempotency-key=KEY] [--json]
```

On a container Instance, a Process whose definition the Project removed answers `process.removing` (409). The next deployment of the default removes it.

### Proposed executor path

On the Gateway engine, the stop is the same desired-state primitive as the start. A stop that waits for a drain, such as the Gateway's Horizon, stays on Swamp. This design awaits implementation and runtime proof. When the Gateway engine does not admit the whole Operation, it runs the Swamp flow above.
