**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`app:root` performs Agent-push application that may take longer than one
second, so the renderer emits a progress tree. The tree is rendered for both
the configuration-changing path and the converged no-op path so the operator can see
that artifacts were re-applied either way.

```text
┌ Updating App Root
○ Apply and verify root change
○ Apply runtime container configuration
○ Apply proxy routes
└ Working...
```

The runtime container step covers both writing the container configuration and the reload required
to pick up the new document root; both are part of the runtime container artifact step and
do not have separate progress lines.

## Human Strings

### Success — configuration changed

```text
SUCCESS: Document root for app 'docs' updated to 'public'.
Artifacts successfully re-applied on node 'app-01'.
```

### Success — converged no-op (configuration unchanged, artifacts re-applied)

```text
SUCCESS: Document root for app 'docs' is already 'public'.
Artifacts successfully re-applied on node 'app-01'.
```

If re-application found no observable change on the node, the second line
remains the same: a clean idempotent re-apply is still success.

### Success with Drift Warning

If gateway configuration was written but artifact re-application failed, the command
still succeeds (configuration was persisted) and reports the drift as a warning.

```text
SUCCESS: Document root for app 'docs' updated to 'public'.
WARNING: runtime container configuration could not be re-applied on node 'app-01'.
  Code:  process.runtime_unit_mismatch
  Next:  orbit doctor --family=process --restore
```

The warning code is the same `process.*` doctor code reported by
`doctor --family=process`; `app:root` does not invent its own drift vocabulary.

### Error: Invalid Root

```text
ERROR: The root path 'path/to/outside' resolves outside the application path.
  Resolved: /home/docs/app/../outside
  App path: /home/docs/app
```

### Error: App Not Found

```text
ERROR: Application 'missing-app' not found.
```

### Error: Authorization failed

```text
This node is not authorized for 'app:root' on 'app-1'.
```
