# JSON Renderer: `orbit workspace:env`

[Back to `workspace:env` technical contract.](1_workspace-env.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Successful commands return a top-level `success` object. Failures return a
top-level `error` object with `code`, `message`, and `meta`.

## Success Shape

```json
{
  "success": {
    "data": {
      "scope": "workspace",
      "app": "billing",
      "instance": "development",
      "workspace": "feature-mail",
      "path": "/home/orbit/apps/billing/.worktrees/feature-mail/.env",
      "stored": true,
      "applied": true,
      "runtime_restarted": true,
      "variable": {
        "key": "MAIL_MAILER",
        "value": "smtp",
        "secret": false
      }
    }
  }
}
```

`list` returns explicit rows under `variables`. `render` returns the effective
keyed map under `variables`. Secret database-derived values use `value=null`
and `secret=true`.

## Error Shape

```json
{
  "error": {
    "code": "workspace.env_apply_failed",
    "message": "Saved 'MAIL_MAILER' for workspace 'feature-mail', but applying it failed.",
    "meta": {
      "workspace": "feature-mail",
      "key": "MAIL_MAILER"
    }
  }
}
```

Command-specific error codes are `workspace.not_found`,
`workspace.env_apply_failed`, and `validation_failed`. Shared authorization and
gateway transport failures use the shared JSON envelope contract.
