# Human Renderer: `orbit app:analytics show`

[Back to `app:analytics show` technical contract.](1_app-analytics-show.md)

**Renderer:** Human renderer.

## Primitive

None. Output is emitted as prose lines.

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered. This command is a fast gateway database read.

## Success Render

```text
analytics:
  app: docs
  enabled: true
  internal_host: analytics.orbit
  dashboard_url: https://analytics.orbit
  public_hosts:
    - analytics.docs.example.com
```

## Error Render

Errors are rendered as concise prose messages.
