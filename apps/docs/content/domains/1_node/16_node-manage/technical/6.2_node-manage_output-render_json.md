# JSON Renderer: `orbit node:manage`

[Back to `node:manage` technical contract.](1_node-manage.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Envelope

```json
{
  "success": {
    "data": {
      "management": {
        "node": "operator-1",
        "user": "nicky",
        "platform": "macos_15-5",
        "ssh_host": "10.44.0.24",
        "authorized_key_installed": true,
        "host_key_pinned": true,
        "ssh_verified": true
      }
    },
    "meta": {}
  }
}
```

## Failure Envelope

Command-specific failures use the canonical error envelope. Local
`authorized_keys` failures include `error.meta.path`.
