---
title: "orbit analytics:credentials"
sidebarTitle: "analytics:credentials"
description: "Show whether the Gateway has a Plausible Stats API key, store one, or clear it."
---

```bash
orbit analytics:credentials [--set] [--api-key=KEY] [--unset] [--json]
```

| Option | Meaning |
| --- | --- |
| `--set` | Store a key. In a terminal the command asks for it when `--api-key` is absent. |
| `--api-key` | The key to store. Use it with `--set`. |
| `--unset` | Clear the stored key. |

```bash
orbit analytics:credentials
orbit analytics:credentials --set
orbit analytics:credentials --set --api-key=plausible-read-only-key
orbit analytics:credentials --unset --json
```

The command never prints the key. Human output says whether a key is stored and names the driver `plausible_ce`. JSON returns `configured`, `driver`, and the request ID.

Create the key in Plausible at `https://analytics.orbit`, then store it here. The Gateway sends it only to the fleet Plausible Stats API. `--set` and `--unset` together are refused.

The Gateway stores the key even while no analytics role is assigned. The next stats read uses it.

## Errors

| Error code | Meaning |
| --- | --- |
| `analytics.credentials_conflict` | `--set` and `--unset` were both given. |
| `analytics.api_key_invalid` | The key is missing, shorter than 8 or longer than 512 characters, or holds control characters. The CLI refuses it before any request. |
