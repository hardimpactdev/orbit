# JSON Renderer: `orbit node role:add`

[Back to `node role:add` technical contract.](1_node-role-add.md)

## Primitive

None. JSON renderer emits the standard envelope only.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Top-level envelopes:
- Success: `{ "success": { ... } }`
- Error: `{ "error": { ... } }`

## Success Shape

`success.data.node` and `success.data.assignment` are always present. The
response does not include Orbit Agent pull-job metadata; app-dev convergence
over Orbit Agent must use a direct gateway-pushed command envelope when that
slice exists.

```json
{
  "success": {
    "data": {
      "node": "NMBP",
      "assignment": {
        "role": "app-dev",
        "status": "active",
        "settings": {},
        "last_error": null,
        "converged_at": "2026-07-02T12:00:00Z"
      }
    },
    "meta": []
  }
}
```

`settings` contains only role-local desired state. Adding a role never creates,
changes, or echoes the node-owned `tld`; node TLD changes use `node:update`.

## Error Codes

- `validation_failed`
- `node.not_found`
- `gateway_unavailable`
- `authorization_failed`
