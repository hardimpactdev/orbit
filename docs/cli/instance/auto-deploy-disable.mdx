---
title: "orbit instance:auto-deploy:disable"
sidebarTitle: "instance:auto-deploy:disable"
description: "Stop deploying new commits of the branch automatically. The deployment branch, the current release, and the deployment history stay."
---

```bash
orbit instance:auto-deploy:disable <instance> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `instance` | yes | Numeric Instance ID. |
