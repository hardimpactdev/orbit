# Human Renderer: `orbit tool-credentials`

[Back to `tool-credentials` technical contract.](1_tool-credentials.md)

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`tool-credentials` is a read-only detail command. Execution is expected to
complete below one second and does not perform slow external work. No progress
tree is rendered.

## Success Output

Human output presents grouped credential fields for the selected tool and node.
For example:

```text
PostgreSQL credentials on app-1
Host      orbit.test
Port      5432
Database  orbit
Username  orbit
Password  <generated-password>
```

Credential labels and values are owned by the selected tool catalog file.

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose error, and actionable recovery guidance when the operator can resolve the issue.
