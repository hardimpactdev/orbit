# JSON Renderer: `orbit process:start [name]`

[Back to `process:start` technical contract.](1_process-start.md)

This page describes the JSON-rendered output for `process:start`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces non-interactive input mode.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the selected runtime contexts, runtime units, resulting runtime states, and durable events. The `runtimes` array contains exactly one item when `[name]` is supplied and every selected process in process order when `[name]` is omitted.

## Success Example

```json
{
  "success": {
    "data": {
      "runtimes": [
        {
          "process": "vite",
          "app": "docs",
          "workspace": "feature-docs",
          "runtime_unit": "orbit_docs_feature-docs_vite",
          "state": "running",
          "event": {
            "type": "started"
          }
        }
      ]
    },
    "meta": {}
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "process.runtime_action_failed",
    "message": "The runtime unit could not be started.",
    "data": {
      "runtimes": [
        {
          "process": "vite",
          "app": "docs",
          "workspace": "feature-docs",
          "runtime_unit": "orbit_docs_feature-docs_vite",
          "state": "failed",
          "event": null,
          "message": "The process manager reported a start failure."
        }
      ]
    },
    "meta": {
      "process": "vite",
      "partial_state": "none_started"
    }
  }
}
```

## Authorization Error

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'process:start' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "process:start",
      "serving_node": "app-1"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: node/app/workspace context is missing, invalid, or ambiguous in non-interactive input mode.
- `authorization_failed`: caller lacks `process:start` on the resolved owning node.
- `process.not_found`: `[name]` is supplied and the named process does not exist for the resolved context.
- `process.none_configured`: `[name]` is omitted and the resolved context has no process definitions.
- `process.runtime_action_failed`: the gateway cannot start the runtime unit on the owning node.
