# Human Renderer: `orbit tool-show`

[Back to `tool-show` technical contract.](1_tool-show.md)

**Renderer:** Human renderer.

## Primitive

None. Renderer prints concise prose or detail lines via `$this->line(...)` and does not render a table, prompt, spinner, or progress tree.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`tool-show` is a read-only detail command. Execution is expected to complete
below one second and does not perform slow external work. No progress tree is
rendered.

## Success Output

Human output presents the selected tool state using Orbit product vocabulary:
tool, node, expected lifecycle state, observed state when available, managed
flag, version/config metadata, and service endpoint metadata that is not secret when
tracked by the tool definition. Credential secrets are never rendered by
`tool-show`.

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose error, and actionable recovery guidance when the operator can resolve the issue.
