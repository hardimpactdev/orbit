# JSON Renderer: `orbit app:prune`

[Back to technical contract](1_app-prune.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

This file owns the JSON output contract for `app:prune`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Envelope

```json
{
  "success": {
    "data": {
      "app": "my-app",
      "stale_workspaces": [
        {
          "name": "feature-docs",
          "removed": true
        },
        {
          "name": "old-experiment",
          "removed": true
        }
      ],
      "dry_run": false
    },
    "meta": {}
  }
}
```

`app:prune` does not embed the canonical app JSON entity defined in
[`5_app/README.md`](../../README.md#app-json-entity). `success.data.app`
carries the app's identity slug as a string. Callers that need the owning
node, runtime kind, worker mode, or any other canonical entity field should
run a follow-up `app:show` against the returned slug.

### Fields

| Field | Type | Meaning |
| --- | --- | --- |
| `app` | string | App identity slug. |
| `stale_workspaces[]` | array | Workspaces that no longer back any agent IDE source on the owning node. |
| `stale_workspaces[].name` | string | Workspace identity slug. |
| `stale_workspaces[].removed` | boolean | `true` when the workspace was actually removed during this run; `false` for dry runs or when removal failed and surfaced under `success.meta.warnings[]`. |
| `dry_run` | boolean | `true` when `--dry-run` was passed and no removals were attempted. |
| `meta.warnings[]` | array | Structured non-fatal failures from individual workspace removals. Each entry carries `code`, `family`, `message`, and `next_command`. Omitted when nothing failed. |

### Dry Run Envelope

```json
{
  "success": {
    "data": {
      "app": "my-app",
      "stale_workspaces": [
        {
          "name": "feature-docs",
          "removed": false
        },
        {
          "name": "old-experiment",
          "removed": false
        }
      ],
      "dry_run": true
    },
    "meta": {}
  }
}
```

### Partial Failure (Cleanup Failure)

If one workspace removal fails, that entry's `removed` is `false` and the
failure is captured in `success.meta.warnings[]`. Each warning carries
`code`, `family`, `message`, and `next_command`.

```json
{
  "success": {
    "data": {
      "app": "my-app",
      "stale_workspaces": [
        {
          "name": "feature-docs",
          "removed": false
        }
      ],
      "dry_run": false
    },
    "meta": {
      "warnings": [
        {
          "code": "workspace.remove_failed",
          "family": "workspace",
          "message": "Failed to remove workspace 'feature-docs': Permission denied.",
          "next_command": "workspace:remove feature-docs --app=my-app --force"
        }
      ]
    }
  }
}
```

## Error Envelope

```json
{
  "error": {
    "code": "app.no_agent_ide_adapter",
    "message": "No agent IDE adapters configured for app 'my-app'.",
    "meta": {
      "app": "my-app"
    }
  }
}
```

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'app:prune' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "app:prune",
      "serving_node": "app-1"
    }
  }
}
```

| Field | Values |
| --- | --- |
| `error.code` | `validation_failed`, `app.not_found`, `authorization_failed`, `app.no_agent_ide_adapter`, `app.agent_ide_query_failed` |

`success.meta.warnings[].code` carries one `app:prune`-owned handoff code plus
the passthrough warning codes that `RemoveWorkspace` actually emits for each
stale workspace `app:prune` processes:

| Code | Family | Owner | Meaning |
| --- | --- | --- | --- |
| `workspace.remove_failed` | `workspace` | `app:prune` | The inner `workspace:remove` action raised an unhandled exception while removing a stale workspace. `next_command` points at `workspace:remove <name> --app=<app> --force` to retry the single failed entry. |
| `workspace.artifact_extra` | `workspace` | `workspace:remove` passthrough | A workspace artifact (worktree) could not be removed and remains on the node. `next_command` is `doctor --fix --family=workspace --restore`. |
| `workspace.teardown_step_failed` | `workspace` | `workspace:remove` passthrough | A workspace teardown step exited non-zero during cleanup. The warning carries the offending `step_id` and `exit_code` alongside the standard fields. `next_command` is `doctor --fix --family=workspace --restore`. |
| `process.runtime_unit_extra` | `process` | `workspace:remove` passthrough | An inherited runtime unit could not be stopped or removed. `next_command` is `doctor --fix --family=process --restore`. |

The `error.code` and warning `code` values listed here are exhaustive for
`app:prune`. Add a new value to this renderer contract before implementing
another JSON failure or warning code. `workspace.remove_failed` and
`workspace.teardown_step_failed` are registered as command handoffs in
`config/librarian-command-docs/warning_codes.php`; the two doctor-family
passthrough codes (`workspace.artifact_extra`, `process.runtime_unit_extra`)
are documented in `workspace-doctor.md` and `process-doctor.md` respectively.
