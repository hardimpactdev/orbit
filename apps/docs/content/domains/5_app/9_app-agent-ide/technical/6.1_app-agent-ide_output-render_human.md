# Human Renderer: `orbit app:agent-ide`

[Back to `app:agent-ide` technical contract.](1_app-agent-ide.md)

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

The human renderer summarizes the configured instance override, effective resolution,
and any workspace cleanup that ran.

## Progress Tree

Execution may take longer than one second when an adapter switch triggers
workspace removal side effects through Agent push.

```text
┌ Configuring App Agent IDE
○ Validate adapter
○ Check for workspace cleanup
○ Remove stale workspace `stale-ws-1`
○ Remove stale workspace `stale-ws-2`
○ Apply and verify app agent IDE
└ Working...
```

If no cleanup is needed, the tree is shorter:

```text
┌ Configuring App Agent IDE
○ Validate adapter
○ Check for workspace cleanup
○ Apply and verify app agent IDE
└ App instance `my-app.development` agent IDE set to `opencode`
```

## Output Strings

The renderer uses the same `action` vocabulary as the JSON renderer
(`set` for changed values, `converged` for no-op). Human strings phrase the
state in plain language; the JSON renderer is authoritative for machine
consumers.

If workspace cleanup after the configuration write cannot finish, the command still renders the
success line for the configuration update and then renders warning lines from
`success.meta.warnings[]` with each warning's `next_command`.

### Success (Set, instance holds the override)
```text
App instance "my-app.development" agent IDE set to "opencode" (effective: "opencode").
```

### Success (Set with `inherit`, falls through to node default)
```text
App instance "my-app.development" agent IDE set to inherit (effective: "polyscope" from node "app-1").
```

### Success (Set with `inherit`, chain resolves to no adapter)
```text
App instance "my-app.development" agent IDE set to inherit (effective: none).
```

### Success (Set with `none`, instance explicitly disables agent IDE)
```text
App instance "my-app.development" agent IDE set to none (effective: none).
```

### Success (Converged / No Change)
```text
App instance "my-app.development" agent IDE already set to "opencode".
```

### Cleanup Summary
When workspaces are removed, they are listed:

```text
Removed 2 stale workspaces during adapter switch:
- stale-ws-1
- stale-ws-2
```

## Failure Output

### Authorization failed

```text
This node is not authorized for 'app:agent' on 'app-1'.
```
