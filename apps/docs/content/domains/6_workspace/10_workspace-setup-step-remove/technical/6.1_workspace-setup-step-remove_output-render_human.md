# Technical Contract: `orbit workspace-setup-step:remove` (Human Renderer)

**Renderer:** Human.

## Primitive

None. The human renderer prints short prose/status lines only and does not render a table, spinner, or progress tree.

[Back to the canonical contract.](1_workspace-setup-step-remove.md)

## Progress Tree

No progress tree is rendered. Policy removal and order compaction perform a
single gateway database write and are expected to complete below one
second. No SSH or owning-node calls are made.

## Output Strings

### Success

```text
✓ Removed setup step {id} from instance '{app}.{instance}'.
Remaining steps renumbered.
```

When the removed step was the only step for the instance, render a hint:

```text
✓ Removed setup step {id} from instance '{app}.{instance}'.
! Instance '{app}.{instance}' now has no workspace setup steps.
```

### Errors

Errors are rendered as prose messages drawn from the canonical
[Failure Semantics](1_workspace-setup-step-remove.md#failure-semantics).

| Scenario | Message |
| --- | --- |
| Step not found | `Setup step {id} not found for instance '{app}.{instance}'.` |
| App not found | `Could not resolve app: {app}` |
| Missing destructive consent | `This is a destructive operation. Use --force or confirm the prompt.` |
| Cancelled confirmation | `Operation cancelled.` |
| Validation (step) | `Step ID must be a positive integer.` |
| Validation (app) | `Could not resolve instance. Pass --instance=<app.instance> or run from inside a registered app or workspace path.` |
| Authorization failed | `This node is not authorized for 'workspace:write' on 'app-1'.` |
