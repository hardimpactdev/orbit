# Non-Interactive Input Mode: `orbit deploy:step-add`

[Back to `deploy:step-add` technical contract.](1_deploy-step-add.md)

**Input mode:** Non-interactive.

Applies when the command is running without a TTY or when `--json` is present.
`--json` forces non-interactive input mode.

## Resolution Rules

Non-interactive input mode never render prompts and never waits for user input.
The app and command must be supplied before side effects begin. Missing app,
missing command, invalid order, invalid timeout, or invalid retention fails with
`validation_failed`.

## JSON Interaction

When `--json` is present, validation failures use the JSON renderer. No ANSI
progress output is emitted.
