# Human Renderer: `orbit process:edit [name]`

[Back to `process:edit` technical contract.](1_process-edit.md)

This page describes the human-rendered terminal output for `process:edit`.

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render the complete progress tree after input resolution and before side effects begin. `process:edit` writes gateway configuration and may re-render runtime units over SSH.

```text
┌ Editing Process
○ Validate process
○ Apply and verify process change
○ Render runtime units
○ Restart runtime units
└ Working...
```

Omit the restart step when `--restart` is not present.

## Success Output

```text
Process 'vite' updated for app 'docs'
```

When runtime-unit apply leaves repairable drift:

```text
Process 'vite' updated for app 'docs'
  Drift detected: process.runtime_unit_mismatch
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no JSON envelope, and next-step guidance only when the operator can act on it.
