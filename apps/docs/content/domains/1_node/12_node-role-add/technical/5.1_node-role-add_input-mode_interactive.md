# Interactive Input: `orbit node role:add`

[Back to `node role:add` technical contract.](1_node-role-add.md)

**Input mode:** Interactive.

Applies only with a TTY and without `--json`.

Prompt behavior:
- No prompts render because this command currently requires explicit
  arguments/options before convergence, including `--tld` for
  `app-dev` and `--redis-node` for `websocket`. `s3` uses the
  default `/srv/orbit/s3/data` when `--s3-data-path` is omitted.
