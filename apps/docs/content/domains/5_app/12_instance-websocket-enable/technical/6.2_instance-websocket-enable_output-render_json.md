# JSON Renderer: `orbit instance:websocket enable`

[Back to `instance:websocket enable` technical contract.](1_instance-websocket-enable.md)

This page describes the JSON-rendered output for `instance:websocket enable`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The binding object is returned under `success.data.binding`.

## Success Shape

```json
{
  "success": {
    "data": {
      "app": {
        "name": "docs",
        "repository": null,
        "runtime": "php",
        "runtime_config": {"proxy_transport": "http"},
        "php_version": "8.5",
        "dependency_audit_status": "unknown",
        "dependency_warning_count": 0,
        "dependency_danger_count": 0,
        "last_dependency_audit_at": null
      },
      "instance": "production",
      "serving_node": "app-prod-1",
      "binding": {
        "internal_host": "websocket.orbit",
        "public_hosts": ["ws.docs.example.com"],
        "allowed_origins": ["https://docs.example.com"]
      }
    },
    "meta": []
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `binding` | object | Resulting WebSocket binding state after the enable operation. |
| `app` | object | Canonical app entity, returned without placement fields. |
| `instance` | string | Concrete selected instance name. |
| `serving_node` | string | Selected instance's serving node and authorization boundary. |
| `binding.internal_host` | string | WireGuard-internal WebSocket service hostname. Always `websocket.orbit`. |
| `binding.public_hosts` | array | Public WebSocket hostnames bound to this app after the enable call. |
| `binding.allowed_origins` | array | Origins permitted by Reverb for this instance. Derived from the selected instance's domain. |

## Error Shapes

### Instance not found

```json
{
  "error": {
    "code": "instance.not_found",
    "message": "Instance 'docs.production' not found.",
    "meta": {
      "instance": "docs.production"
    }
  }
}
```

A bare app with zero or multiple eligible instances returns
`validation_failed` with `error.meta.field=instance` and
`error.meta.reason=instance_required`.

### Validation failed

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Instance is required.",
    "meta": {
      "field": "instance"
    }
  }
}
```

### WebSocket prerequisite failed

```json
{
  "error": {
    "code": "websocket.prerequisite_failed",
    "message": "The websocket service route requires an active router node.",
    "meta": {
      "app": "docs"
      ,"instance": "production",
      "serving_node": "app-prod-1"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'instance:write' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "instance:write",
      "instance": "docs.production",
      "serving_node": "app-prod-1"
    }
  }
}
```
