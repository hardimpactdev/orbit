# JSON Renderer: `orbit process:stop [name]`

[Back to `process:stop` technical contract.](1_process-stop.md)

This page describes the JSON-rendered output for `process:stop`.

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present. `--json` also forces
non-interactive input mode.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the process runtime context, runtime unit, resulting
runtime state, and durable event.

## Success Example

```json
{
  "success": {
    "data": {
      "runtime": {
        "process": "vite",
        "app": "docs",
        "workspace": "feature-docs",
        "runtime_unit": "orbit_docs_feature-docs_vite.service",
        "state": "stopped",
        "event": {
          "type": "stopped"
        }
      }
    },
    "meta": {}
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "process.runtime_action_failed",
    "message": "The runtime unit could not be stopped.",
    "meta": {
      "process": "vite"
    }
  }
}
```

## Caller Role Error

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "The local Orbit caller role could not be resolved.",
    "meta": {
      "caller_role": "unknown"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: process, app, or workspace context is missing, invalid,
  or ambiguous in non-interactive input mode.
- `caller_role_not_allowed`: caller role is `unknown`.
- `authorization_failed`: caller cannot operate process runtime state for the
  target context.
- `process.not_found`: the named process does not exist for the owning app.
- `process.runtime_action_failed`: the gateway cannot stop the runtime unit on
  the owning app node.
