# JSON Renderer: `orbit php:list`

[Back to `php:list` technical contract.](1_php-list.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "php": {
        "node": "app-dev-1",
        "supported": ["8.5", "8.4", "8.3"],
        "available_images": ["8.5"],
        "app": {
          "name": "docs",
          "app_instance": "development",
          "php_version": "8.5"
        },
        "workspace": {
          "name": "feature-docs",
          "php_version": "8.4",
          "inherits": false
        }
      }
    },
    "meta": []
  }
}
```

When `--live` is supplied, `success.meta.live=true`; otherwise `success.meta`
is empty.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Required input is missing or invalid.",
    "meta": {
      "field": "node"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.php` | object | PHP runtime view defined by the family README. |
| `success.data.php.app.app_instance` | string | Concrete selected app instance. Present when app context is resolved; the adjacent `php_version` remains the logical app's shared policy. |
| `success.meta.live` | boolean | Present and `true` only when `--live` supplied live image facts. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.meta` | object | Field, target, caller, or live-inspection context for automation. |

A bare logical app selector returns `validation_failed` with
`error.meta.field=app` and `error.meta.reason=app_instance_required`; the
renderer never returns one arbitrary node as a logical app's inventory.
