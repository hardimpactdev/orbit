# Non-Interactive Input Mode: `orbit deploy:run`

[Back to `deploy:run` technical contract.](1_deploy-run.md)

**Input mode:** Non-interactive.

Applies when the command is running without a TTY or when `--json` is present.
`--json` forces non-interactive input mode.

## Resolution Rules

Non-interactive input mode never render prompts and never waits for user input.
The app must be supplied before side effects begin. Missing app input fails
with `validation_failed`.

`--detach` may be combined with `--json`. In that case the JSON renderer returns
the durable run created for gateway execution and does not wait for final step
output.

## JSON Interaction

When `--json` is present, validation failures use the JSON renderer. No ANSI
progress output is emitted.
