# Human Renderer: `orbit activity:show [id]`

[Back to `activity:show` technical contract.](1_activity-show.md)

This page describes the human-rendered terminal output for `activity:show`.

**Renderer:** Human renderer.

## Primitive

- Detail: [Show detail](../../../../ux/commands/details/show-detail.md)

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. Prompt behavior belongs to the
interactive input-mode contract.

## Progress Tree

`activity:show` is a gateway database history read. Execution is expected to
complete below one second and does not perform slow external work or live node
probes. No progress tree is rendered.

## Success Output

Human output is a detail view:

```text

┌  Activity: 42
│
├  Time          2026-05-02 08:30:00
│
├  Type          workspace.created
│
├  Effect        write
│
├  Subject       workspace feature-docs
│
├  Actor         operator-1 (operator)
│
├  Command       workspace:setup
│
├  Correlation   9f7307e8-38b2-45b8-9b94-cfc341456b85
│
├  Summary       Workspace feature-docs was created.
│
├  Details       app: docs, workspace: feature-docs
│
└  Related       41 2026-05-02 08:29:58 workspace.create_requested read, 43 2026-05-02 08:30:02 process.reloaded write

```

When no related activity is visible:

```text
└  Related   —
```

## Failure Output

Human-rendered failures must show:

- the failing field or condition;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the operator can act on it.

Missing id:

```text
Activity id is required.
```

Invalid id:

```text
Activity id must be a positive integer.
```

Activity not found:

```text
Activity 42 was not found or is not visible.
```

Gateway unavailable:

```text
Gateway connection is required to show activity.
```

Authorization failed:

```text
This node is not authorized to read gateway activity history.
```
