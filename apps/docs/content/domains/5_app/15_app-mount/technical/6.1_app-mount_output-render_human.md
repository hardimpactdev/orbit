# Human Renderer: `orbit app:mount`

[Back to `app:mount` technical contract.](1_app-mount.md)

## Primitive

None. Human output uses the shared gateway success renderer for short
key/value output.

The renderer shows the app identity, `app_instance` mount target,
configured mounts, mutation action when present, and whether workspace runtime
containers inherit the mounts.

## Progress Tree

No progress tree is rendered because `app:mount` is expected to stay below one
second. It performs a single gateway API request and does not run long-lived
work on a remote node directly.

## Output Strings

Human output is intentionally compact. The JSON renderer is authoritative for
machine consumers and exact field shapes.

### List

```text
app: {"name":"hauser","node":"beast","url":"https://hauser.test","path":"/home/nckrtl/apps/hauser","root":"public","repository":null,"runtime":"php","php_version":"8.5","adopted":false}
target: {"type":"app_instance","app":"hauser","instance":"development"}
mounts: [{"source":"/home/nckrtl/projects","target":"/projects","read_only":true}]
inherited_by_workspaces: true
```

### Add or update

```text
app: {"name":"hauser","node":"NMBP","url":"https://hauser.nmbp","path":"/Users/nckrtl/apps/hauser","root":"public","repository":null,"runtime":"php","php_version":"8.5","adopted":false}
target: {"type":"app_instance","app":"hauser","instance":"nmbp"}
mounts: [{"source":"/Users/nckrtl/projects","target":"/projects","read_only":false}]
inherited_by_workspaces: true
mount: {"source":"/Users/nckrtl/projects","target":"/projects","read_only":false}
action: updated
```

### Remove

```text
app: {"name":"hauser","node":"NMBP","url":"https://hauser.nmbp","path":"/Users/nckrtl/apps/hauser","root":"public","repository":null,"runtime":"php","php_version":"8.5","adopted":false}
target: {"type":"app_instance","app":"hauser","instance":"nmbp"}
mounts: []
inherited_by_workspaces: true
action: removed
```

## Failure Output

Human failures use the shared canonical envelope renderer and print:

```text
validation_failed: Source path must be absolute.
```

Authorization failures originate at the API permission middleware. The command
human renderer does not own that failure shape.
