---
title: "orbit websocket:app:destroy"
sidebarTitle: "websocket:app:destroy"
description: "Remove an app and close only its sockets with code `4001`. Other apps keep their connections. The change stays pending until all required processes confirm application."
---

```bash
orbit websocket:app:destroy <name> [--force] [--operation-key=<key>] [--json]
```

| Option | Meaning |
| --- | --- |
| `--operation-key` | Reuse this key to retry the same change. |
| `--force` | Confirm without prompting. Interactive confirmation defaults to No. A JSON or non-interactive call without `--force` returns `websocket.confirmation_required`. |

Decline, Ctrl-C, and EOF cancel with `input.cancelled`. The CLI sends no destroy request after cancellation.

The Gateway refuses with `websocket.app_in_use` while an Instance uses the app, and with `websocket.app_reserved` for `gateway`. Remove the app from each Instance with [`instance:websocket:remove`](/cli/instance/websocket-remove) first.
