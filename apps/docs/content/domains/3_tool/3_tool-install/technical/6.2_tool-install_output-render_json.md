# JSON Renderer: `orbit tool-install`

[Back to `tool-install` technical contract.](1_tool-install.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "tool": []
    },
    "meta": {}
  }
}
```

Command-specific result data uses the canonical tool entity from [`README.md`](../../README.md#tool-json-entity) unless the command returns logs or credentials.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Required input is missing or invalid.",
    "meta": {
      "field": "tool"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `tool.not_found`, `tool.unsupported_action`, `tool.runtime_unsupported`, `tool.runtime_platform_unsupported`, `tool.instance_required`, `tool.remote_action_failed` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.meta` | object | Field, target, caller, or remote-action context for automation. |

Unsupported status example:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Invalid --status value 'foo'. Valid values: installed, running.",
    "meta": {
      "field": "status",
      "value": "foo",
      "reason": "unsupported_value"
    }
  }
}
```

Missing target example:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A node or app target is required. Provide --node, --app, configure node:default, or select a target interactively.",
    "meta": {
      "fields": ["target"]
    }
  }
}
```

Unsupported runtime/platform example:

```json
{
  "error": {
    "code": "tool.runtime_platform_unsupported",
    "message": "The docker-swarm runtime is not supported for this tool on macos.",
    "meta": {
      "tool": "redis",
      "runtime": "docker-swarm",
      "platform": "macos"
    }
  }
}
```

Instance required example:

```json
{
  "error": {
    "code": "tool.instance_required",
    "message": "Choose the tool instance to install or update.",
    "meta": {
      "tool": "redis"
    }
  }
}
```
