# Human Renderer: `orbit schedule:run`

[Back to `schedule:run` technical contract.](1_schedule-run.md)

**Renderer:** Human terminal renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and before gateway execution
begins.

```text
┌ Running Schedule
○ Resolve schedule
○ Open gateway execution
○ Run scheduled command
○ Record run history
└ Working...
```

## Success Output

Render the schedule name, scope, target, run id, status, exit code, started and
finished timestamps, and captured command output.

## Failure Output

Validation and not-found failures render the rejected field or schedule name.
Gateway and authorization failures render the selected scope when available.
Scheduled command failures render the run id when available, scheduled process
exit code, and captured output. Run-history write failures render whether the
scheduled command already ran.
