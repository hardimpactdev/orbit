title: "orbit schedule:logs"
sidebarTitle: "schedule:logs"
description: "Return the newest complete lines of the Schedule's service journal. `schedule` is the UUID of an installed Schedule."
---

```bash
orbit schedule:logs <schedule> [--lines=COUNT] [--follow] [--json]
```

| Option | Default | Meaning |
| --- | --- | --- |
| `--lines=COUNT` | `100` | 1 through 1,000 lines. |
| `--follow` | off | Stream new lines until Ctrl-C. With `--json`, print NDJSON frames. |

Without `--follow`, Orbit returns a bounded snapshot of the service journal. `--follow` opens a viewer lease and subscribes to the private log channel. The Node agent reads the Schedule journal. Orbit renews the lease while the command runs and closes it on Ctrl-C. The same line limits, redaction, reconnect handling, and loss markers apply as for [Process logs](/cli/process/logs).

When the live path is unavailable, the shared follower uses bounded reads until streaming is available again. Both paths use UTC journal timestamps and redact the owning Instance's stored environment values. It does not poll while a stream runs. See [Live logs](/reference/live-logs).
