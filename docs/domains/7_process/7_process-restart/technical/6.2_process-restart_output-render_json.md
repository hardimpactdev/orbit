# JSON Renderer: `orbit process:restart [name]`

[Back to `process:restart` technical contract.](1_process-restart.md)

This page describes the JSON-rendered output for `process:restart`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces non-interactive input mode.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the selected runtime contexts, runtime units, resulting runtime states, and durable events. The `runtimes` array contains exactly one item when `[name]` is supplied and every selected process in process order when `[name]` is omitted.

## Success Example

```json
{
  "success": {
    "data": {
      "runtimes": [
        {
          "process": "vite",
          "app": "docs",
          "workspace": "feature-docs",
          "runtime_unit": "orbit_docs_feature-docs_vite",
          "state": "running",
          "events": [
            {
              "type": "stopped"
            },
            {
              "type": "started"
            }
          ]
        }
      ]
    },
    "meta": {}
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "process.runtime_action_failed",
    "message": "The runtime unit could not be restarted.",
    "data": {
      "runtimes": [
        {
          "process": "vite",
          "app": "docs",
          "workspace": "feature-docs",
          "runtime_unit": "orbit_docs_feature-docs_vite",
          "state": "failed",
          "events": [],
          "message": "The process manager reported a restart failure."
        }
      ]
    },
    "meta": {
      "process": "vite",
      "partial_state": "none_restarted"
    }
  }
}
```

## Caller Role Error

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "The gateway did not authorize this caller for the command.",
    "meta": {
      "caller_role": "unknown"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: app or workspace context is missing, invalid, or ambiguous in non-interactive input mode.
- `caller_role_not_allowed`: caller role is `unknown`.
- `authorization_failed`: caller cannot operate process runtime state for the target context.
- `process.not_found`: `[name]` is supplied and the named process does not exist for the owning app.
- `process.none_configured`: `[name]` is omitted and the owning app has no process definitions.
- `process.runtime_action_failed`: the gateway cannot restart the runtime unit on the owning app node.
