# Non-Interactive Input Mode: `orbit cf-ssl:disable`

[Back to `cf-ssl:disable` technical contract.](1_cf-ssl-disable.md)

**Input mode:** Non-interactive.

## Selection

Use this input mode without a TTY or when `--json` is present.
`--json` forces non-interactive input mode.

## Prompt Behavior

Never render prompts. `--force` is required for destructive consent.
Missing `--force` fails before side effects with `error.code=validation_failed`
and `error.meta.field=force`. `--json` never provides destructive consent.
