---
title: "orbit node:list"
sidebarTitle: "node:list"
description: "List every Node with its status, roles, and addresses."
---

```bash
orbit node:list [--json]
```

The `Agent` column shows each Node's agent liveness: `online`, `offline`, `not seen`, or `unknown`. [`node:show`](/cli/node/show) also shows since when an agent is offline.
