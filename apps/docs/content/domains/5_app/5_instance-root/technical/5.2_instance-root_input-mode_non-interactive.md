# Non-Interactive Input Mode: `orbit instance:root [app.instance] [root]`

[Back to `instance:root` technical contract.](1_instance-root.md)

This page describes how non-interactive input mode resolves `instance:root` input
without prompts.

**Input mode:** Non-interactive.

## Selection

Use this input mode when either condition is true:

- the command is running without a TTY;
- `--json` is present.

`--json` selects the JSON renderer and forces this input mode even when the
process has a TTY.

Authorization follows the shared gateway-owned classes. A normal caller needs
`instance:root` on the selected instance's serving node; gateway implicit authority is the named
exception. The gateway rejects unauthorized requests before side effects.

## Responsibilities

- Read supplied arguments and options.
- Apply documented defaults.
- Never render prompts.
- Fail before side effects when required input is absent after default
  resolution.
- Fail before side effects when supplied input is invalid.
- Evaluate app eligibility and root validation as soon as the fields needed for
  each rule are known.

## Default Resolution

No required field has a default in non-interactive input mode.

## Required Input Failures

| Field | Missing when | Behavior |
| --- | --- | --- |
| `instance` | `[instance]` is absent. | Fail before side effects with `error.code=validation_failed` and `error.meta.field=instance`. |
| `root` | `[root]` is absent. | Fail before side effects with `error.code=validation_failed` and `error.meta.field=root`. |

## Validation Failures

Fail before side effects when:

- `instance` is not a dotted instance selector or sole-instance app shorthand;
- the selected instance does not exist (`instance.not_found`), or a bare
  logical slug is ambiguous (`meta.reason=instance_required`);
- the caller is not authorized on the selected instance's serving node;
- `root` is empty, absolute, or resolves outside the instance path after lexical
  normalization.

The selected output renderer owns how these failures are displayed.
