# Non-Interactive Input Mode: `orbit solo:todo:delete`

[Back to the canonical contract.](1_solo-todo-delete.md)

**Input mode:** Non-interactive.

This mode applies without a TTY or when `--json` is present. No prompts are
rendered. `--force` is required for destructive consent. Missing `--force`
fails before side effects with `error.code=validation_failed`,
`error.meta.field=force`, and
`error.meta.reason=destructive_consent_required`.

`--json` forces non-interactive mode and selects the JSON renderer; it is not
destructive consent.
