# Non-Interactive Input Mode: `orbit skill:install`

[Back to `skill:install` technical contract.](1_skill-install.md)

**Input mode:** Non-interactive.

This contract applies without a TTY or when `--json` is present. `--json`
forces non-interactive input mode.

## Resolution Rules

No prompts are rendered. All required fields must be supplied by arguments or
provider defaults. Existing target replacement requires explicit `--force`;
missing `--force` fails before side effects with `validation_failed`,
`meta.field=force`, and `meta.reason=destructive_consent_required`.

Provider default installs also require `HOME`; when it is absent, the command
fails with `validation_failed` and `meta.reason=missing_home`.

`--json` selects the JSON renderer and does not imply destructive consent.
