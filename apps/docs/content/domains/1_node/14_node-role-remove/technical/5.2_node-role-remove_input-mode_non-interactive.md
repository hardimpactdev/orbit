# Non-Interactive Input: `orbit node role:remove`

[Back to `node role:remove` technical contract.](1_node-role-remove.md)

**Input mode:** Non-interactive.

Applies without a TTY or when `--json` is present.

`--json` forces non-interactive input mode without destructive consent.

`--force` is required for non-interactive destructive consent.

Missing destructive consent fails before side effects.

## Responsibilities

- Read supplied arguments and options.
- Apply documented defaults.
- Never render prompts.
- Fail before side effects when destructive consent is missing.
