Show whether Apple APNs push credentials are stored on the Gateway. The private key is never returned.

## Usage

```sh
orbit conn:push-credentials:show
orbit conn:push-credentials:show --json
```

| Option | Meaning |
| --- | --- |
| `--json` | [Machine output](/reference/cli-ux#input-and-output-modes): `{"configured": true\|false, "key_id": "..."\|null, "team_id": "..."\|null, "request_id": "..."}`. |

## How it works

<Flow name="conn/push-credentials" />

The CLI sends `GET /api/v1/conn/push-credentials` (`conn:push-credentials:show`), which requires the `conn` extension, `orbit.conn.push` enabled, and Gateway access. It returns only whether credentials are stored along with the Key ID and Team ID.

## Errors

| Code | Meaning |
| --- | --- |
| `conn.push_disabled` | `orbit.conn.push` is off on the Gateway. |
| `extension.disabled` | The Conn extension is off. |
| `node_access.required` | The caller does not have Gateway access. |
