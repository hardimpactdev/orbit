# Non-Interactive Input Mode: `orbit tool-remove`

[Back to `tool-remove` technical contract.](1_tool-remove.md)

**Input mode:** Non-interactive.

This contract applies without a TTY or when `--json` is present. `--json` forces non-interactive input mode.

## Resolution Rules

No prompts are rendered. All required fields must be supplied by arguments, options, local defaults, or gateway-resolved context. Because `--json` forces non-interactive input mode, it is not destructive consent and never grants destructive consent. Destructive removal requires `--force` whenever `--json` is present. Missing `--force` fails before side effects.
