# `process:remove` Interactive Input Mode

[Back to `process:remove` technical contract.](1_process-remove.md)

This page describes how interactive input mode resolves `process:remove` input.

**Input mode:** Interactive.

## Selection

Use this input mode only when the process is attached to a TTY and `--json` is not present.

## Prompt Behavior

Prompt for missing required input in this order:

| Field | Prompt primitive | Notes |
| --- | --- | --- |
| `app` | Datatable | Show apps the caller is authorized to manage when app context is absent or ambiguous. |
| `name` | Datatable | Select from existing processes for the resolved app. If no process exists, fail before prompting for an open value. |
| `confirm` | Confirm | Required unless `--force` is supplied. |

The confirmation prompt names the process, app, and number of derived runtime units expected to be removed. If the operator declines, fail before side effects with a cancelled operation.

## `--force` Bypass

When `--force` is supplied in interactive input mode, skip the confirmation prompt after validating the process and app.
