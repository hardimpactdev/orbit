# Human Renderer: `orbit metrics:disable`

[Back to `metrics:disable` technical contract.](1_metrics-disable.md)

**Renderer:** Human renderer.

## Primitive

None. Human output uses the shared CLI success/error renderer and no
command-specific primitive.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered in this slice. The command performs one gateway API
write to remove role intent and does not synchronously inspect process or proxy
runtime artifacts.

## Success Output

Render the gateway success message and include:

- target node name;
- role value `metrics`;
- whether data purge was requested.

## Failure Output

Render standard validation, gateway, authorization, and role-removal failures
using the shared command error renderer.

No gateway-side coverage exists for this renderer because human rendering is
CLI-only for this command.
