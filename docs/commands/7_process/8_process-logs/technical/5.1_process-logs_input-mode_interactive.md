# `process:logs` Interactive Input Mode

[Back to `process:logs` technical contract.](1_process-logs.md)

This page describes how interactive input mode resolves `process:logs` input.

**Input mode:** Interactive.

## Selection

Use this input mode only when the process is attached to a TTY and `--json` is
not present.

## Prompt Behavior

Prompt for missing required input in this order:

| Field | Prompt primitive | Notes |
| --- | --- | --- |
| `app` | Select | Show apps the caller is authorized to read when app context is absent or ambiguous. |
| `workspace` | Select | Prompt only when workspace context is ambiguous and the operator chooses a workspace-scoped log read. |
| `name` | Select or text | Prefer selecting from processes defined for the resolved app. |

Do not prompt for `lines` or `follow`; those remain explicit options with
documented defaults.
