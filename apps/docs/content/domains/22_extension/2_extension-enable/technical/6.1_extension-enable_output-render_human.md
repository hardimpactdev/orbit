# Human Renderer: `orbit extension:enable`

[Back to `extension:enable` technical contract.](1_extension-enable.md)

**Renderer:** Human renderer.

## Primitive

None. This renderer uses a confirmation prompt for input, not a renderer
primitive.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered. Enablement returns a compact success or failure
message.

## Output

Successful local or gateway enablement renders the shared success output for
the returned extension state. When gateway state is disabled after local
enablement, prompt:

```text
Enable extension [solo] on the gateway too?
```

If the caller declines, render success for local enablement with
`gateway_enabled=false`.
