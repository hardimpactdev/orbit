# JSON Renderer: `orbit deploy:history`

[Back to `deploy:history` technical contract.](1_deploy-history.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "runs": [
        {
          "id": 42,
          "app": "docs",
          "status": "completed",
          "exit_code": 0,
          "started_at": "2026-05-02T09:00:00Z",
          "finished_at": "2026-05-02T09:01:30Z",
          "context": {
            "release": "20260502_090000_42",
            "app_path": "/home/docs/app",
            "release_path": "/home/docs/app/releases/20260502_090000_42",
            "app_user": "docs"
          },
          "steps": [
            {
              "id": 12,
              "title": "Pull latest",
              "status": "completed",
              "exit_code": 0
            }
          ]
        }
      ]
    },
    "meta": {
      "pagination": {
        "total": 1,
        "limit": 50,
        "limit_capped": false
      }
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Invalid value for --limit: must be a positive integer.",
    "meta": {
      "field": "limit",
      "value": "-1"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.runs` | array | Deployment run entities sorted by `started_at` descending. |
| `success.meta.pagination.total` | integer | Total number of matching runs before the limit is applied. |
| `success.meta.pagination.limit` | integer | Effective limit used for this response. |
| `success.meta.pagination.limit_capped` | boolean | True when a caller-supplied limit exceeded `500` and was clamped. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `app.not_found`, `deploy.production_app_required` | Stable command failure code. |
| `error.meta` | object | Field, missing permission, app selector, or authorization context for automation. |
