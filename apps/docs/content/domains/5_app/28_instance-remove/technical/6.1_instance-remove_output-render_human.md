# Human Renderer: `orbit instance:remove`

[Back to `instance:remove` technical contract.](1_instance-remove.md)

**Renderer:** Human renderer.

## Primitive

None. Consent is the explicit `--force` option.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered; removal is one authorized gateway request.

## Success Render

Print `Removed instance '<name>'.` after the gateway confirms deletion.

## Error Render

Missing `--force` instructs the caller to provide explicit destructive
consent. Other failures render directly.
