# JSON Renderer: `orbit cf-cache:flush`

[Back to `cf-cache:flush` technical contract.](1_cf-cache-flush.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "cache": {
        "zone": "example.com",
        "project": "docs",
        "action": "flush",
        "status": "flushed"
      }
    },
    "meta": {
      "provider": "cloudflare"
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A Cloudflare zone is required.",
    "meta": {
      "field": "zone"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.cache.zone` | string | Resolved Cloudflare zone. |
| `success.data.cache.app` | string \| null | App name when the zone came from an app. |
| `success.data.cache.action` | `flush` | Command operation that completed. |
| `success.data.cache.status` | `flushed` | Provider cache outcome. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `cloudflare_unavailable` | Stable command failure code. |
| `error.meta` | object | Field, zone, app, gateway, authorization, token, or provider failure context. |
