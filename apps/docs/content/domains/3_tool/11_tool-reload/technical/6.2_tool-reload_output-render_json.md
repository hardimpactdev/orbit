# JSON Renderer: `orbit tool-reload`

[Back to `tool-reload` technical contract.](1_tool-reload.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a single machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

Use `--stream-json` instead of `--json` only when callers need
newline-delimited progress frames. That renderer follows the shared
[Stream JSON Frames](../../../README.md#stream-json-frames) contract.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "tool": {
        "name": "caddy",
        "node": "app-1",
        "action": "reload",
        "runtime": "tool"
      }
    },
    "meta": []
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "tool.unsupported_action",
    "message": "Tool 'dns' does not support reload.",
    "meta": {
      "tool": "dns",
      "action": "reload"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `node.agent_unreachable`, `tool.not_found`, `tool.unsupported_action`, `tool.unsupported_on_node`, `tool.runtime_missing`, `tool.runtime_ambiguous`, `tool.remote_action_failed` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.meta` | object | Field, target, caller, or runtime context for automation. |

`node.agent_unreachable` includes `error.meta.reason=agent_push_unavailable`.
