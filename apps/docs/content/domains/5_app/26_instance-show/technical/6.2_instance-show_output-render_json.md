# JSON Renderer: `orbit instance:show`

[Back to `instance:show` technical contract.](1_instance-show.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON uses the machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "instance": {
        "app": "billing",
        "name": "development",
        "driver": "orbit",
        "node": "app-dev-1",
        "url": "https://billing.test"
      },
      "cloud_compatibility": null
    },
    "meta": []
  }
}
```

## Error Shapes

Failures use `validation_failed`, `app.not_found`, `instance.not_found`,
`authorization_failed`, or gateway transport codes.
