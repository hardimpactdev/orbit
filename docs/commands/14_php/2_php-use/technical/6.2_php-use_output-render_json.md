# JSON Renderer: `orbit php:use`

[Back to `php:use` technical contract.](1_php-use.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "php": {
        "node": "app-1",
        "supported": ["8.4", "8.5"],
        "installed": ["8.5"],
        "cli": "8.5",
        "app": {
          "name": "docs",
          "php_version": "8.5"
        },
        "workspace": null
      },
      "result": {
        "target": "app",
        "node": "app-1",
        "app": "docs",
        "workspace": null,
        "previous": "8.4",
        "version": "8.5",
        "inherits": false,
        "changed": true
      }
    },
    "meta": {
      "warnings": []
    }
  }
}
```

## Success With Drift Warning

If gateway intent is written but node enactment fails, the command returns a
success envelope with a structured doctor handoff warning.

```json
{
  "success": {
    "data": {
      "php": {
        "node": "app-1",
        "supported": ["8.4", "8.5"],
        "installed": ["8.5"],
        "cli": "8.5",
        "app": {
          "name": "docs",
          "php_version": "8.5"
        },
        "workspace": null
      },
      "result": {
        "target": "app",
        "node": "app-1",
        "app": "docs",
        "workspace": null,
        "previous": "8.4",
        "version": "8.5",
        "inherits": false,
        "changed": true
      }
    },
    "meta": {
      "warnings": [
        {
          "code": "app.fpm_config_mismatch",
          "family": "app",
          "message": "PHP-FPM configuration did not converge for app 'docs'.",
          "next_command": "doctor --fix --family=app --app=docs --restore"
        }
      ]
    }
  }
}
```

Workspace enactment warnings use `workspace.fpm_config_mismatch` and
`doctor --fix --family=workspace --workspace=<workspace> --restore`. Node CLI enactment
warnings use `node.cli_php_default_mismatch` and
`doctor --fix --family=node --node=<node> --restore`. Proxy backend warnings use
`proxy.route_mismatch` and `doctor --fix --family=proxy --restore`.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Required input is missing or invalid.",
    "meta": {
      "field": "version",
      "reason": "missing_required_input"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.php` | object | PHP runtime view after the gateway intent write. |
| `success.data.result.target` | `app`, `workspace`, `node_cli` | Scope selected by the command. |
| `success.data.result.changed` | boolean | Whether gateway intent changed. |
| `success.meta.warnings[]` | array | Doctor handoff warnings for partial app, workspace, proxy, or node enactment. |
| `error.code` | `validation_failed`, `caller_role_not_allowed`, `gateway_unavailable`, `authorization_failed`, `local_context_invalid` | Stable command failure code. |
| `error.meta` | object | Field, reason, target, caller, or version context for automation. |
