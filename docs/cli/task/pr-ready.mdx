Take the published pull request of an external task group out of draft once its checks are green. In manual mode it also requests the review of the configured reviewer, so GitHub notifies the reviewer that the PR waits. This is the ready step of [stage 4 of the command development pipeline](/reference/command-development-pipeline#4-pr-and-ci). The Gateway only admits the step and mints a short-lived GitHub App token. Swamp calls GitHub. See [Ready and merge a task pull request](/reference/tasks#ready-and-merge-a-task-pull-request).

There is no `orbit` command yet. Use the API or the MCP tool `task-pr-ready`.

```bash
curl -X POST "$GATEWAY/api/v1/task-groups/42/pr-ready" \
  -H "Idempotency-Key: pr-ready-42-9f3c" \
  -d '{"head_sha": "9f3c0a1b2c3d4e5f60718293a4b5c6d7e8f90a1b", "mode": "manual"}'
```

The route needs a Node with an access grant to the Gateway and a required `Idempotency-Key`. The reply is `202` with the task; follow it with `operation:show` until it ends.

| Input | Meaning |
| --- | --- |
| `group` | The numeric ID of an open external task group with a published, open pull request. |
| `head_sha` | The full SHA of the pull request head that you saw go green. A different head refuses the step. |
| `mode` | `manual` or `automatic`. `manual` also requests the reviewer's review. `automatic` only takes the PR out of draft. |

The reviewer is the GitHub login in the Gateway setting `task_pull_requests.reviewer`.

A PR that is already out of draft is not an error: Swamp skips that step, so a rerun after a refused review request is safe.

## Errors

| Code | Status | When |
| --- | --- | --- |
| `extension.disabled` | 409 | The tasks extension is off. |
| `tasks.group_closed` | 409 | The group has ended. |
| `operation.target_busy` | 409 | Another task holds the group. |
| `tasks_pr.no_pull_request` | 409 | The group has no published PR, or its PR is not open. |
| `tasks_pr.head_moved` | 409 | The PR head is not `head_sha`. The same code ends a run whose head moved after admission. |
| `tasks_pr.checks_not_passed` | 409 | The Project's merge check is not configured, or it did not pass on the head. |
| `tasks_pr.reviewer_is_author` | 409 | Manual mode, and the PR author is the reviewer. GitHub refuses that request. |
| `tasks_pr.github_unreadable` | 502 | The Gateway could not read the PR or its checks. |
| `github.not_configured` | 409 | The GitHub App is not configured. |
| `tasks_pr.ready_refused` | run | GitHub refused to take the PR out of draft. |
| `tasks_pr.review_request_refused` | run | GitHub refused the review request. The PR is already ready; run the command again. |
