# Human Renderer: `orbit node:manage`

[Back to `node:manage` technical contract.](1_node-manage.md)

**Renderer:** Human renderer.

## Primitive

Use the shared [progress tree](../../../../ux/commands/progress/progress-tree.md)
primitive.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

```text
┌ Managing this operator node
○ Verify gateway identity
○ Install gateway SSH key
○ Send management metadata
○ Pin SSH host key
○ Verify gateway SSH reachability
└ Working...
```

## Success Output

On success, render the managed node name, SSH user, platform, and WireGuard SSH
host.

```text
Operator node is manageable by the gateway.

Node: operator-1
SSH user: nicky
Platform: macos_15-5
SSH host: 10.44.0.24
```

## Failure Output

Human failures use the canonical prose error from the gateway or local
validation layer. Local `authorized_keys` errors must name the path that could
not be written.
