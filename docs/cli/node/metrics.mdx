```bash
orbit node:metrics <node> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `node` | yes | Numeric Node ID. |

| Option | Default | Meaning |
| --- | --- | --- |
| `--json` | off | Use the [standard machine output](/reference/cli-ux#input-and-output-modes). |

```bash
orbit node:metrics 7
```

Access follows the [shared Node authority rule](/cli/node#authority).

## How it works

Orbit answers only from the latest metrics snapshot that the Node's agent reported to the Gateway. It contacts no Node or other system and does not wait for a new report, so the read stays fast even when the Node is unreachable. It changes no records or Node state. Running it again reads the latest recorded snapshot; it is not a skipped action.

| Field | Meaning |
| --- | --- |
| `node_id`, `node_name` | The Node's ID and name. |
| `observed_at` | When the agent observed the snapshot, not the time of this request. |
| `agent` | The recorded [agent state and since time](/cli/node/show), shared with `node:show` and `node:list`. |
| `possibly_outdated` | Whether the agent state is anything other than `online`. |
| `cores` | The busy ratio of each core, from 0 to 1. |
| `memory`, `swap` | Used and total bytes. |
| `load` | The 1, 5, and 15-minute load averages. |
| `uptime_seconds` | Time since boot at the observation time. |
| `pressure` | The `some` `avg10` value for CPU, memory, and I/O. `0` when the kernel has no pressure data. |
| `disks` | Mount, used bytes, and total bytes. Pseudo filesystems such as `tmpfs` and `proc` are left out. `/` comes first. |

Human output shows the Node's name and ID, `Observed at` time, `Agent` state, and readable byte and duration values. A retained snapshot with `possibly_outdated: true` still succeeds, but is labeled `possibly outdated`; an offline agent is shown as `offline since <time>`, as in `node:show`. No snapshot yet is a distinct refusal, not an all-zero snapshot.

## Errors

| Code | HTTP | Meaning |
| --- | --- | --- |
| `node.id_invalid` | n/a | The supplied Node ID is not a positive integer, or the required ID is omitted in [noninteractive or machine mode](/reference/cli-ux#input-and-output-modes). |
| `http.404` | 404 | The Node is unknown. |
| `node_access.required` | 403 | The [shared Node authority rule](/cli/node#authority) refuses the caller. |
| `node.metrics_unavailable` | 422 | No metrics snapshot has been recorded for the Node yet. |
