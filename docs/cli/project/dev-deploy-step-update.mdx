---
title: "orbit project:dev-deploy-step:update"
sidebarTitle: "project:dev-deploy-step:update"
description: "Change a named step. Omitted fields keep their stored values. A required-only update is supported. `--input=PATH`, repeated, replaces the step's inputs, and `--clear-inputs` removes them; the two cannot be combined. JSON for create, update, and remove returns `name`, `command`, `timeout_seconds`, `required`, `inputs`, and `request_id`."
---

```bash
orbit project:dev-deploy-step:update cache --project=4 --required=false [--command=COMMAND] [--timeout=SECONDS] [--input=PATH ... | --clear-inputs] [--before=NAME | --after=NAME] [--json]
orbit project:dev-deploy-step:update install --project=4 --input=composer.json --input=composer.lock
```
