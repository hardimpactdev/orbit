# `app:new` Non-Interactive Input Mode

[Back to technical contract](1_app-new.md)

**Input mode:** Non-interactive.

Non-interactive mode is used when the CLI is not attached to a TTY or when
`--json` is supplied. It fails fast if required input is missing.

## Constraints

- **Missing Name:** Fails if `name` is not supplied as a positional argument.
- **Node Resolution:** Fails if `--node` is missing and no local `node:default`
  node is configured. There are no fallback prompts.
- **Validation Errors:** Any validation failure (invalid slug, unsupported PHP
  version) results in an immediate exit with a non-zero exit code.

## Behavior

- **--json Forcing:** Providing `--json` automatically forces non-interactive
  mode even if a TTY is present.
- **No Prompts:** The command will never block on user input.

## Failure Metadata

When `--json` is used, validation and resolution failures are returned in the
`error` envelope with the failing field and reason in `error.meta`.
