# Human Renderer: `orbit database:show`

[Back to `database:show` technical contract.](1_database-show.md)

## Primitive

None. Renderer prints one database connection detail view as plain key-value
lines and does not render a table, prompt, spinner, or progress tree.

## Progress Tree

No progress tree. The command is expected to complete from gateway reads only.

## Human Strings

- Success: "Showing database connection '{slug}'."
- Failure: "Database connection '{slug}' was not found."

The detail view renders `Slug`, `Driver`, `Host`, `Port`, `Database`, `Path`,
`Username`, and `Node`. Missing values render as `—`.
