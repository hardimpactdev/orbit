# Human Renderer: `orbit solo:todo:unlock`

[Back to `solo:todo:unlock` technical contract.](1_solo-todo-unlock.md)

**Renderer:** Human renderer.

## Primitive

None. Solo command renderers print compact resource or status output from the Solo response.

## Selection

Use this renderer for ordinary operator-facing output.

## Progress Tree

No progress tree is rendered. Solo commands are gateway proxy operations with a single result.

## Output

The renderer displays the primary Solo resource, list, or mutation result returned by the gateway. Failures render the Orbit error code and message.
