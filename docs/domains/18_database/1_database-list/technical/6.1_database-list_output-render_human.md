## Human Strings

- Success: "Showing {count} database connection(s)."
- Empty: "No database connections matched this scope."
- Failure: "Failed to list database connections."

The table uses the shared `table` primitive. Columns are `SLUG`, `DRIVER`,
`NODE`, and `TARGETS`. Missing node values render as `—`.
