# JSON Renderer: `orbit manifest:remove`

[Back to `manifest:remove` technical contract.](1_manifest-remove.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "manifest": {
        "url": "https://github.com/hardimpactdev/orbit/releases/latest/download/orbit-release-manifest.json",
        "source": "default",
        "custom_url": null,
        "default_url": "https://github.com/hardimpactdev/orbit/releases/latest/download/orbit-release-manifest.json"
      }
    },
    "meta": []
  }
}
```

## Error Shapes

Gateway and authorization failures use the shared envelope:

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized to perform that action.",
    "meta": {
      "reason": "missing_gateway_admin"
    }
  }
}
```
