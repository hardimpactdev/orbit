# Interactive Input Mode: `orbit workspace-teardown-step:remove`

[Back to `workspace-teardown-step:remove` technical contract.](1_workspace-teardown-step-remove.md)

This page describes how interactive input mode resolves
`workspace-teardown-step:remove` input before command behavior starts.

**Input mode:** Interactive.

## Selection

Use this input mode only when both conditions are true:

- the command is running in a TTY;
- `--json` is not present.

When `--json` is present, use
[`5.2_workspace-teardown-step-remove_input-mode_non-interactive.md`](5.2_workspace-teardown-step-remove_input-mode_non-interactive.md).

## Responsibilities

- Read supplied arguments and options.
- Prompt for missing required fields.
- Validate field-local values immediately.
- Require destructive confirmation before side effects.
- Skip the confirmation prompt when `--force` is present.

## Prompt Order

| Step | Prompt ID | Rendered when |
| --- | --- | --- |
| 1 | `workspace_teardown_step_remove.step` | `--step` is missing. |
| 2 | `workspace_teardown_step_remove.confirm` | `--force` is absent. |

## Prompt Mapping

### `workspace_teardown_step_remove.step`

| Property | Value |
| --- | --- |
| Primitive | `text` |
| Label | `Teardown step ID to remove` |
| Source | `--step` |
| Required | yes |
| Default | none |

### `workspace_teardown_step_remove.confirm`

| Property | Value |
| --- | --- |
| Primitive | `confirm` |
| Label | `Remove teardown step {id} from app '{app}'?` |
| Source | interactive destructive consent |
| Required | yes |
| Default | `false` |

## Primitive References

- [`text`](../../../../ux/commands/inputs/text-prompt.md)
- [`confirm`](../../../../ux/commands/inputs/confirm-prompt.md)

Parent app is resolved from `--app`, `.orbit/config`, or CWD path ownership.
If no parent app can be resolved, the command fails before side effects; it
does not ask for an open app value.

## Failure Semantics

- If the user declines the confirmation prompt, fail before side effects with
  `Operation cancelled.`
- If the user aborts a prompt, exit without side effects.
