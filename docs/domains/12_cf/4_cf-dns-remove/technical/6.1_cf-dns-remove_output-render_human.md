**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../commands/ux/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`cf-dns:remove` verifies provider state and performs an external provider
delete. After input resolution and before the Cloudflare delete request begins,
render this progress tree:

```text
┌ Removing Cloudflare DNS record
○ Resolve Cloudflare zone
○ Verify DNS record
○ Delete Cloudflare DNS record
└ Working...
```

## Success Output

Render one concise success line:

```text
Cloudflare DNS record record-1 removed from example.com
```

## Failure Output

Validation, missing destructive consent, gateway, authorization, and Cloudflare
failures render one concise error line.
