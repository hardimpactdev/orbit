# Human Renderer: `orbit workspace-teardown-step:list`

[Back to `workspace-teardown-step:list` technical contract.](1_workspace-teardown-step-list.md)

This page describes the human-rendered output for
`workspace-teardown-step:list`.

**Renderer:** Human renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered because `workspace-teardown-step:list` is
expected to stay below one second. It performs a fast gateway database read
and does not perform slow external work, network probes, or remote node
application.

## Success Render

The success output is a table of teardown steps for the resolved app. Steps
are ordered by the `order` field ascending. Both renderers use this single
ordering, so callers reading either output form see the same steps in the
same relative order.

The `ID` column surfaces the durable gateway-assigned step identifier used
by the sibling write command
[`workspace-teardown-step:remove`](../../13_workspace-teardown-step-remove/workspace-teardown-step-remove.md).
This matches the resolved list-exemplar precedent (`node:list`, `app:list`,
`workspace:list`) of surfacing the identifier each sibling write command
accepts.

### Example output

```text
Teardown steps for my-app:

+----+-------+-------------------------+---------+
| ID | ORDER | COMMAND                 | TIMEOUT |
+----+-------+-------------------------+---------+
| 18 | 1     | dropdb my-app_db        | 600s    |
| 19 | 2     | rm -rf storage/logs     | 30s     |
| 20 | 3     | redis-cli FLUSHDB       | 10s     |
+----+-------+-------------------------+---------+
```

### Empty result

When no steps are defined for the resolved app:

```text
No teardown steps defined for my-app.
```

## Error Render

Errors are rendered as concise prose messages.

### Validation failure (app)

```text
Could not resolve parent app. Pass `--app=<slug>` or run from inside a registered app or workspace path.
```

### App not found

```text
App 'my-app' not found.
```

### Unauthorized app

```text
You are not authorized to read teardown-step policy for 'my-app'.
```

### Gateway unavailable

```text
Gateway connection is required to list teardown steps.
```
