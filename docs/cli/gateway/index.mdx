Every command that manages remote resources sends its request to the active Gateway. The `gateway` family manages the local profiles that name a Gateway. It also pins the Gateway root certificate authority (CA), installs it in the operating-system trust store, and shows whether the Gateway answers. [Gateway trust](/reference/gateway-trust) describes where profiles live, the trust sequence, and the profile guard.

[Instance attachment commands](/cli/instance/database-add), [environment commands](/cli/env), and [`node:role:list`](/cli/node/role-list) check required inputs before they load the active Gateway profile. A missing or invalid selector therefore reports the command family's input error even when no Gateway profile exists. Commands that need a numeric ID use the shared positive-integer check. They may add the stable error code to the human explanation without changing the JSON error envelope.

## Commands

| Command | Result |
| --- | --- |
| [`gateway:add`](/cli/gateway/add) | Add a profile and trust the Gateway root CA. |
| [`gateway:use`](/cli/gateway/use) | Select the active profile. |
| [`gateway:status`](/cli/gateway/status) | Show the status and version of the active Gateway. |
| [`gateway:trust`](/cli/gateway/trust) | Trust or check the active Gateway root CA. |
| [`gateway:remove`](/cli/gateway/remove) | Remove a profile and its pinned certificate. |
| [`gateway:release:list`](/cli/gateway/release-list) | List the Gateway's release records. |
| [`gateway:release:show`](/cli/gateway/release-show) | Show one release record. |
| [`gateway:release:deploy`](/cli/gateway/release-deploy) | Release one commit to the Gateway as one Swamp run and follow it. |
| [`gateway:release:rollback`](/cli/gateway/release-rollback) | Switch the Gateway back to a retained release and follow it. |
| [`gateway:auto-release:status`](/cli/gateway/auto-release-status) | Show the automatic release state. |
| [`gateway:auto-release:enable`](/cli/gateway/auto-release-enable) | Turn automatic releases on. |
| [`gateway:auto-release:disable`](/cli/gateway/auto-release-disable) | Turn automatic releases off. |
| [`gateway:auto-release:resume`](/cli/gateway/auto-release-resume) | Clear a pause of automatic releases. |

Every command accepts `--json`. `gateway:use` and `gateway:remove` work locally. The other commands contact the Gateway. `gateway:add` and `gateway:trust` can change the operating-system trust store, which can ask for local administrator privileges.

## Gateway releases

The `gateway:release` commands release the Gateway itself. [Update and recover a Gateway](/reference/gateway-recovery#release-as-a-swamp-run) describes the release steps, the records, and the error codes. Access to the Gateway is fleet-wide, so any Node with access may run them.
