# Human Renderer: `orbit workspace:log [target]`

[Back to `workspace:log` technical contract.](1_workspace-log.md)

This page describes the human-rendered terminal output for `workspace:log`.

**Renderer:** Human renderer.

## Primitive

None. `workspace:log` is line-oriented stream output; the log stream itself is
the command's primary output.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered. Per the
[progress tree contract](../../../../ux/commands/progress/progress-tree.md), the
tree is reserved for commands whose product output is structured data or status
reporting, not for line-oriented log or stream output. Log lines are written
directly to the terminal. In follow mode, the stream remains open until the
operator interrupts it.

## Success Output

Bounded reads print each log line and then exit. Follow mode prints log lines
until interrupted (`tail -F` semantics: wait for creation, survive rotation,
history-before-live).

When the fixed application log is missing or empty, bounded reads print no
lines and exit successfully.

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no
JSON envelope, and next-step guidance only when the operator can act on it.
