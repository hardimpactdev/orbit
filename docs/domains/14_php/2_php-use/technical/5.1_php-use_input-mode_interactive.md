# Interactive Input Mode: `orbit php:use`

[Back to `php:use` technical contract.](1_php-use.md)

**Input mode:** Interactive.

Use this input mode only when both conditions are true:

- the command is running in a TTY;
- `--json` is not present.

## Prompts

| ID | Primitive | Label | Required |
| --- | --- | --- | --- |
| `target` | `select` | PHP target | Yes, when no target scope resolves from options or cwd. |
| `version` | `select` | PHP version | Yes, unless `--inherit` is supplied. |
| `workspace` | `select` | Workspace | Yes, when workspace inheritance is requested and cwd does not resolve one. |
| `app` | `select` | App | Yes, when an app target is selected and no app is resolved. |
| `node` | `select` | Node | Yes, when CLI target is selected and no node is resolved. |

## Primitive References

- [`select`](../../../../ux/commands/inputs/select-prompt.md)

## Behavior

- Each prompt only shows targets the caller is authorized to manage.
- Version choices are restricted to Orbit-supported versions installed on the
  resolved node.
- `--inherit` skips the version prompt and requires a workspace target.
- Mutually exclusive option errors are shown before prompts.
- Validation errors re-prompt the field when the user can recover within the
  same interaction; authorization failures abort.
