# Non-Interactive Input Mode: `orbit workspace:show [name]`

[Back to `workspace:show` technical contract.](1_workspace-show.md)

This page describes how non-interactive input mode resolves `workspace:show`
input without prompts.

**Input mode:** Non-interactive.

## Selection

Use this input mode when either condition is true:

- the command is running without a TTY;
- `--json` is present.

`--json` selects the JSON renderer and forces this input mode even when the
process has a TTY. Prompts are never rendered in non-interactive input mode.

## Responsibilities

- Read supplied arguments and options.
- Apply documented defaults.
- Never render prompts.
- Fail before side effects when required input is absent after default
  resolution.
- Fail before side effects when the resolved `name` is ambiguous across
  multiple projects and `--instance` is not supplied.
- Fail before side effects when supplied input is invalid.
- Evaluate path eligibility as soon as the fields needed for the rule are
  known.

## Default Resolution

When `[name]` is missing, non-interactive input mode resolves the workspace in
this order:

1. **CWD resolution.** If the current working directory is inside a known
   workspace path, use that workspace.
2. **Fail.** If CWD resolution fails, fail before side effects with
   `error.code=validation_failed` and `error.meta.field=name`.

## Required Input Failures

| Field | Missing when | Behavior |
| --- | --- | --- |
| `name` | `[name]` is absent and CWD resolution cannot produce a target. | Fail before side effects. |
| `instance` | The resolved `name` matches more than one workspace record and `--instance` is absent. | Fail before side effects with `error.code=workspace.ambiguous_name`. |

## Failures

| Code | Message |
| --- | --- |
| `validation_failed` | Workspace name is required. |
| `workspace.ambiguous_name` | Workspace name '...' is ambiguous. Specify parent project with --instance. |

## Validation Failures

Fail before side effects when:

- `name` does not match an existing workspace record visible to the caller;
- `instance` does not match an existing instance visible to the caller;
- the caller is not authorized to inspect the resolved workspace.

The selected output renderer owns how these failures are displayed.

| Path | Coverage |
