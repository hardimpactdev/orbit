# JSON Renderer: `orbit workspace:history`

[Back to technical contract.](1_workspace-history.md)

This page describes the JSON-rendered output for `workspace:history`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The run array is rendered as a flat array under `success.data.runs`, sorted by
`started_at` descending (newest first). This matches the order shown in human
output.

## Success Shape

```json
{
  "success": {
    "data": {
      "runs": [
        {
          "id": 12,
          "workspace": "feature-docs",
          "app": "ohdear",
          "action": "setup",
          "status": "completed",
          "triggered_by": "nckrtl",
          "started_at": "2026-04-30T19:00:00Z",
          "finished_at": "2026-04-30T19:00:45Z",
          "lifecycle_phase": "setup",
          "error_summary": null
        }
      ]
    },
    "meta": {
      "pagination": {
        "total": 42,
        "limit": 50,
        "since": null,
        "until": null,
        "limit_capped": false
      }
    }
  }
}
```

## Run Object Fields

| Field | Type | Description |
| --- | --- | --- |
| `id` | `int\|string` | Unique identifier for the run or event. |
| `workspace` | `string` | Workspace name. |
| `app` | `string` | Parent app slug. |
| `action` | `string` | Lifecycle action slug (see [Technical Contract](1_workspace-history.md#lifecycle-actions)). |
| `status` | `string` | Status slug (see [Technical Contract](1_workspace-history.md#status-taxonomy)). |
| `triggered_by` | `string` | Actor who initiated the action. |
| `started_at` | `datetime` | ISO 8601 start time. |
| `finished_at` | `datetime\|null` | ISO 8601 finish time; null if running. |
| `lifecycle_phase` | `string` | Broad phase (setup/teardown/meta). |
| `error_summary` | `string\|null` | Short error snippet for failed runs. |

## Pagination Metadata

| Field | Type | Description |
| --- | --- | --- |
| `total` | `int` | Total number of runs that match the applied filters before the limit is applied. |
| `limit` | `int` | Effective limit used for this response (already clamped to the `500` ceiling when applicable). |
| `since` | `datetime\|null` | The `--since` filter value, echoed back. |
| `until` | `datetime\|null` | The `--until` filter value, echoed back. It is an exclusive upper bound; use the oldest `started_at` returned as the next `--until` to walk further back through the timeline without duplicating the boundary row. |
| `limit_capped` | `boolean` | `true` when the caller-supplied `--limit` exceeded the gateway hard cap of `500` and was clamped; `false` otherwise. |

The `success.meta.pagination` slot is reserved for a future opaque cursor field
without breaking the contract; the slot is purely additive.

## Error Shapes

### Workspace not found

```json
{
  "error": {
    "code": "workspace.not_found",
    "message": "Workspace not found: feature-docs",
    "meta": {
      "name": "feature-docs"
    }
  }
}
```

### Ambiguous workspace

```json
{
  "error": {
    "code": "workspace.ambiguous_name",
    "message": "Ambiguous workspace: feature-docs. Specify --app.",
    "meta": {
      "name": "feature-docs",
      "apps": ["ohdear", "flare"]
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized to read workspace history.",
    "meta": {
      "workspace": "feature-docs",
      "app": "ohdear"
    }
  }
}
```

### Validation failed

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Invalid value for --limit: must be a positive integer.",
    "meta": {
      "field": "limit",
      "value": "-1"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to read workspace history.",
    "meta": []
  }
}
```
