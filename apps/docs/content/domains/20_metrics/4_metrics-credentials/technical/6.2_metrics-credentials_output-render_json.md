# JSON Renderer: `orbit metrics:credentials`

[Back to `metrics:credentials` technical contract.](1_metrics-credentials.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "credentials": {
        "node": "metrics-1",
        "url": "https://metrics.orbit",
        "admin_user": "admin",
        "admin_password": "<generated-password>"
      }
    },
    "meta": {
      "process": "grafana"
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "metrics.credentials_missing",
    "message": "Grafana credentials are missing for 'metrics-1'.",
    "meta": {
      "node": "metrics-1",
      "process": "grafana",
      "next_command": "doctor --family=process --restore --node [--node-transport=<transport>]=metrics-1"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.credentials.node` | string | Selected active metrics node. |
| `success.data.credentials.url` | string | Private Grafana endpoint, normally `https://metrics.orbit`. |
| `success.data.credentials.admin_user` | string | Grafana admin user. |
| `success.data.credentials.admin_password` | string | Grafana admin password. |
| `success.meta.process` | string | Source process definition, always `grafana`. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `metrics.credentials_missing` | Stable command failure code. |
