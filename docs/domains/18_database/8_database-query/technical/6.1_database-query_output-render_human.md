## Progress Tree

```text
┌ Running Database Query
○ Resolve target and connection
○ Classify statement
○ Execute query
└ Working...
```

## Human Strings

- Success: "Query returned {row_count} row(s)."
- Success for non-row statements: "Query completed. {affected_count} row(s) affected."
- Failure: "Database query failed."

Human output may truncate wide values unless `--full` is supplied.
