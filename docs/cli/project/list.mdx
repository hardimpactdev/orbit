---
title: "orbit project:list"
sidebarTitle: "project:list"
description: "List the Projects you can reach with their slug, type, repository, default branch, and root. JSON output also includes the source access and the Project summary."
---

```bash
orbit project:list [--json]
```

The list holds the Projects with an Instance on a Node you have access to; from the Gateway, every Project. With `--json`, each entry also carries the [Project summary](/reference/projects#project-summary): `repository`, `node_name`, `icon`, `color`, and `instance_count`. Conn clients read the same fields to tag a General thread to a Project.
