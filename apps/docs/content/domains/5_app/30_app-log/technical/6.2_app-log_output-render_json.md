# JSON Renderer: `orbit app:log [target]`

[Back to `app:log` technical contract.](1_app-log.md)

This page describes the JSON-rendered output for `app:log`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces non-interactive
input mode. JSON output is bounded and cannot be combined with `--follow`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data matches the Instance or Workspace application-log envelope for the
resolved proxy target: fixed logical path, file existence, requested lines, and
bounded log lines.

## Success Example

```json
{
  "success": {
    "data": {
      "target": {
        "type": "instance",
        "app": "docs",
        "instance": "development",
        "workspace": null,
        "selector": "docs.development"
      },
      "node": "app-dev-1",
      "path": "storage/logs/laravel.log",
      "lines_requested": 100,
      "file_exists": false,
      "lines": []
    },
    "meta": []
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "validation_failed",
    "message": "app:log accepts only a URL or hostname. Use instance:log for app.instance selectors.",
    "meta": {
      "field": "target",
      "value": "docs.development"
    }
  }
}
```

## Authorization Error

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'instance:read' on 'app-dev-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "instance:read",
      "serving_node": "app-dev-1"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: target is missing, not a strict URL/hostname, is a dotted
  `app.instance` or bare workspace name, does not match a registered proxy
  route; `--lines` is invalid; `--json` is combined with `--follow`; or
  `--node` does not match the serving node. Target failures use
  `error.meta.field=target`.
- `authorization_failed`: caller lacks `instance:read` or `workspace:read` for
  the resolved target type.
- `application_log.read_failed`: the gateway cannot read the fixed application
  log from the serving node.
- `gateway_unavailable`: the CLI cannot reach the Orbit gateway.
