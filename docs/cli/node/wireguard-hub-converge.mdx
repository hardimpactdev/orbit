description: "Set the current peer list on the active VPN hub in one native Operation. The hub keeps its own key and interface; this changes no peer key or address. Swamp reaches the hub over SSH from Node 209."
---

```bash
orbit node:wireguard-hub:converge 1 --idempotency-key=hub-reconcile-once
```

The command accepts a `node` ID or name, `--idempotency-key=KEY`, and `--json`. It follows the recorded Operation and returns a nonzero exit status for a failed or cancelled run. A failed run stops and leaves the hub as it is; a rerun sets the same list again. See [WireGuard hub convergence](/reference/wireguard-endpoints#converge-the-hub).
