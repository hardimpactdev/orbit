# Orbit operations in Swamp

Read the binding [Swamp shape guide](docs/swamp-shape.md), its linked
[Swamp manual](https://swamp-club.com/manual) pages and
[repository guidance](AGENTS.md) before writing, porting or reviewing an
operation. The guide overrides older contracts and conflicting Recall atoms.
Port and review kinds with the
[swamp-port skill](../.claude/skills/swamp-port/SKILL.md).

Existing grandfathered code is not a template. Pause conversions until the
native pilot settles the guide's open points; keep live-breakage fixes minimal.
