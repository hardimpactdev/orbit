# JSON Renderer: `orbit cf-dns:remove`

[Back to `cf-dns:remove` technical contract.](1_cf-dns-remove.md)

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "record": {
        "id": "record-1",
        "zone": "example.com",
        "type": "A",
        "name": "docs.example.com",
        "content": "203.0.113.10",
        "proxied": true,
        "status": "removed"
      }
    },
    "meta": {
      "action": "remove"
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Removing a Cloudflare DNS record requires --force in non-interactive mode.",
    "meta": {
      "field": "force",
      "reason": "destructive_consent_required"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.record` | object | Removed DNS record entity when metadata is available. |
| `success.meta.action` | `remove` | Command operation that completed. |
| `error.code` | `validation_failed`, `caller_role_not_allowed`, `gateway_unavailable`, `authorization_failed`, `cloudflare_unavailable` | Stable command failure code. |
| `error.meta` | object | Field, zone, record, consent, gateway, authorization, token, or provider failure context. |
