# Human Renderer: `orbit deploy:history`

[Back to `deploy:history` technical contract.](1_deploy-history.md)

**Renderer:** Human terminal renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered because execution is a gateway-local database read
expected to stay below one second and performs no slow external work.

## Run List

The human renderer outputs a table sorted by `started_at` descending.

```text
Deployment History: docs

ID  STATUS     EXIT  STARTED
44  failed     1     2026-05-07T10:20:00Z
43  completed  0     2026-05-07T09:00:00Z
```

Empty or missing cells render as `—` (em dash). Empty history renders a
concise empty-state line naming the app:

```text
No deployment history found for <app>.
```

## Failure Output

Validation and not-found failures render the rejected field or app selector.
Gateway and authorization failures render the selected app when available.
Eligibility failures for non-production apps name the resolved app.
