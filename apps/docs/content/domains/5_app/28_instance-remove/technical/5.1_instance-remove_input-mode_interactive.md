# Interactive Input: `orbit instance:remove`

[Back to `instance:remove` technical contract.](1_instance-remove.md)

**Input mode:** Interactive.

Use this mode only with a TTY and without `--json`. `--force` bypasses the
confirmation prompt and supplies destructive consent for the exact instance.

## Prompt Order

| Step | Prompt ID | Rendered when |
| --- | --- | --- |
| 1 | `instance_remove.confirm` | The dotted instance resolves and `--force` is absent. |

## Prompt Mapping

The `confirm` prompt names the dotted instance and states that its app and
sibling instances remain. The default is `false`. Declining returns
`validation_failed` with `meta.field=force` and `meta.reason=cancelled` before
side effects.
