# Human Renderer: `orbit activity:list`

[Back to `activity:list` technical contract.](1_activity-list.md)

This page describes the human-rendered terminal output for `activity:list`.

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. `activity:list` does not prompt
because all filters are optional.

## Progress Tree

`activity:list` is a gateway database history read. Execution is expected to
complete below one second and does not perform slow external work or live node
probes. No progress tree is rendered.

## Success Output

Human output is a table ordered newest first:

```text
TIME                  ID   EFFECT        TYPE                SUBJECT        ACTOR       COMMAND
2026-05-02 08:31:12   43   destructive   node.removed        app-2          control-1   node:remove
2026-05-02 08:30:00   42   write         workspace.created   feature-docs   control-1   workspace:setup
2026-05-02 08:29:58   41   read          node.list           nodes          control-1   node:list
```

When entries share a correlation id and are adjacent in the result set, the
renderer may visually repeat or group the correlation id, but it must not hide
individual rows.

When no visible activity matches the filters:

```text
No activity found.
```

## Failure Output

Human-rendered failures must show:

- the failing field or condition;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the operator can act on it.

Invalid limit:

```text
Invalid value for --limit. Use a number from 1 through 200.
```

Invalid correlation:

```text
Invalid value for --correlation. Use a UUID.
```

Invalid effect:

```text
Invalid value for --effect. Use one of: read, write, destructive.
```

Gateway unavailable:

```text
Gateway connection is required to list activity.
```

Authorization failed:

```text
This node is not authorized to read gateway activity history.
```

Local context invalid:

```text
Local node role setting is invalid.
```
