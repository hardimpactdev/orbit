# Human Renderer: `orbit instance:mount`

[Back to `instance:mount` technical contract.](1_instance-mount.md)

## Primitive

None. Human output uses the shared gateway success renderer for short
key/value output.

The renderer shows the app and concrete instance separately,
then configured mounts, mutation action when present, and workspace
inheritance. Placement and `adopted` are rendered only on the instance.

## Progress Tree

No progress tree is rendered because `instance:mount` is expected to stay below one
second. It performs a single gateway API request and does not run long-lived
work on a remote node directly.

## Output Strings

Human output is intentionally compact. The JSON renderer is authoritative for
machine consumers and exact field shapes.

## Failure Output

Human failures use the shared canonical envelope renderer and print:

```text
validation_failed: Source path must be absolute.
```

Authorization failures identify the selected dotted instance and its
serving node. The command never authorizes against an app owner.
