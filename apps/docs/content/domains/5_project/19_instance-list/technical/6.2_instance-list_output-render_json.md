# JSON Renderer: `orbit instance:list`

[Back to `instance:list` technical contract.](1_instance-list.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON uses the machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "instances": [
        {
          "project": "billing",
          "name": "development",
          "driver": "orbit",
          "node": "app-dev-1",
          "url": "https://billing.test"
        }
      ]
    },
    "meta": {"count": 1}
  }
}
```

## Error Shapes

The top-level `error` envelope carries failures such as `project.not_found`,
`authorization_failed`, or gateway transport codes.
