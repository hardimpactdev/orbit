# JSON Renderer: `orbit node:default`

[Back to `node:default` technical contract.](1_node-default.md)

This page describes the JSON-rendered output for `node:default`.

**Renderer:** JSON renderer.

## Primitive

None. JSON renderer emits the standard envelope only.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](5.2_node-default_input-mode_non-interactive.md), even
when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Input mode failures, domain validation failures, authorization failures,
and network failures must all use this envelope.

The structured contract separates the command result (`action`) from the
entity (`default_node`) to align with the shared envelope invariant.
`action` is a top-level sibling under `success.data` and is present on every
sub-action; it is never embedded inside the `default_node` object.

## Success Shape

### Show sub-action with default set

```json
{
  "success": {
    "data": {
      "action": "show",
      "default_node": {
        "name": "app-1",
        "role": null
      }
    }
  }
}
```

### Show sub-action with no default

```json
{
  "success": {
    "data": {
      "action": "show",
      "default_node": null
    }
  }
}
```

### Set sub-action

```json
{
  "success": {
    "data": {
      "action": "set",
      "default_node": {
        "name": "app-1",
        "role": "app-dev"
      }
    }
  }
}
```

### Clear sub-action with existing default

```json
{
  "success": {
    "data": {
      "action": "clear",
      "default_node": null
    },
    "meta": {
      "was_set": true
    }
  }
}
```

### Clear sub-action with no existing default

```json
{
  "success": {
    "data": {
      "action": "clear",
      "default_node": null
    },
    "meta": {
      "was_set": false
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `action` | string | The sub-action performed: `show`, `set`, or `clear`. |
| `default_node` | object \| null | The current or affected default node. `null` when no default is set or after clear. |
| `default_node.name` | string | Node name in the gateway registry. |
| `default_node.role` | string \| null | Node role from gateway validation. `null` when showing a locally stored name without gateway lookup. |
| `was_set` | boolean | Present in `clear` sub-action only. `true` when a default existed before clear, `false` when no default existed. |

## Error Shapes

### Mutually exclusive input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Provide only one node target.",
    "meta": {
      "fields": ["name", "clear"]
    }
  }
}
```

### Node not found

```json
{
  "error": {
    "code": "node.not_found",
    "message": "Node 'app-1' not found or not visible.",
    "meta": {
      "name": "app-1"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'node:read' on 'gateway-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "node:read",
      "serving_node": "gateway-1"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to set a default node.",
    "meta": []
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `action` | `show`, `set`, `clear` |
| `default_node.role` | Gateway-provided role string, or `null` when unknown. |
| `error.code` | `validation_failed`, `node.not_found`, `authorization_failed`, `gateway_unavailable` |

The `error.code` values listed here are exhaustive for `node:default`. Add a new
value to this renderer contract before implementing another JSON failure code.
Gateway JSON errors that include a structured `error.code` are preserved. In
particular, `authorization_failed` from node-list validation must not be
collapsed into `gateway_unavailable`. Only transport failures, runtime
failures, or gateway failures without a structured JSON error code render as
`gateway_unavailable`.
