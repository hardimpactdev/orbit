# 12_cf — Cloudflare Workstream

Detail file for the Cloudflare command family. Top-level command status lives
in [`PORTING.md`](PORTING.md). Doc authority: `docs/commands/12_cf/`.

## Status

Ported for the documented command surface with local fake-provider feature
coverage. Live Cloudflare E2E remains pending until a valid
`CLOUDFLARE_API_TOKEN` and safe test zone/record fixtures are available.

Gateway provider credentials are read from `CLOUDFLARE_API_TOKEN`; optional
global-key compatibility uses `CLOUDFLARE_API_EMAIL` plus
`CLOUDFLARE_API_TOKEN`.

## Commands

- [x] `cf-zone:list` — lists zones visible to the gateway token.
- [x] `cf-dns:list` — lists provider DNS records for a resolved zone.
- [x] `cf-dns:add` — creates or converges A/AAAA provider records.
- [x] `cf-dns:remove` — removes A/AAAA provider records with destructive consent.
- [x] `cf-cache:flush` — purges all cached files for a resolved zone or app domain.
- [x] `cf-cache-rule:add` — creates or converges the respect-origin cache rule for an app domain.
- [x] `cf-cache-rule:remove` — removes the app cache rule with destructive consent.
- [x] `cf-ssl:enable` — sets `strict` or explicit `full` SSL mode.
- [x] `cf-ssl:disable` — sets SSL mode `off` with destructive consent.
