# JSON Renderer: `orbit app:list`

[Back to `app:list` technical contract.](1_app-list.md)

This page describes the JSON-rendered output for `app:list`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The app array is rendered as a flat array under `success.data.apps`. Apps are
sorted by app name (ascending, case-insensitive). Each logical app appears at
most once as a compact summary. Counts are fields on that same row. The payload
has no parallel `inventory` array and exposes no concrete placement details.

`app:list` does not include `success.data.context` because it has no resolved
node or execution context.

`app:show` uses the canonical app entity for a concrete placement; `app:list`
does not use that shape.

## Success Shape

```json
{
  "success": {
    "data": {
      "apps": [
        {
          "name": "docs",
          "repository": "git@github.com:example/docs.git",
          "dependency_audit_status": "findings",
          "dependency_warning_count": 3,
          "dependency_danger_count": 1,
          "last_dependency_audit_at": "2026-07-02T08:15:00+00:00",
          "instance_count": 1,
          "workspace_count": 1
        }
      ]
    },
    "meta": []
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `apps` | array | Ordered list of visible logical apps, with every app included at most once. |
| `apps[]` | object | Compact logical-app summary. It is not the placement-shaped `app:show` entity. |
| `apps[].name` | string | Globally unique logical app name. |
| `apps[].repository` | string \| null | Recorded source repository, or `null`. |
| `apps[].dependency_audit_status` | string | Aggregate dependency-audit posture across recorded package-manager summaries. |
| `apps[].dependency_warning_count` | integer | Aggregate warning findings count. |
| `apps[].dependency_danger_count` | integer | Aggregate danger findings count. |
| `apps[].last_dependency_audit_at` | string \| null | Latest audit/failure timestamp, or `null` when no summary exists. |
| `apps[].instance_count` | integer | Number of placement-visible app instances. |
| `apps[].workspace_count` | integer | Number of placement-visible workspaces on `app-dev` instances. |

The row must not include `node`, `url`, `path`, `root`, `runtime`,
`runtime_config`, `php_version`, worker settings, `instances`, or `workspaces`.
Use `app:show` for those details.

## Enum and identifier values

| Field | Values |
| --- | --- |
| `apps[].dependency_audit_status` | `unknown`, `clean`, `findings`, `failed`, `unsupported`, `not_applicable` |

## Error Shapes

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to list apps.",
    "meta": []
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized to read the app registry.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "app:read"
    }
  }
}
```
