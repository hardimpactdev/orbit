# Interactive Input Mode: `orbit app:agent-ide`

[Back to `app:agent-ide` technical contract.](1_app-agent-ide.md)

**Input mode:** Interactive.

This command uses interactive input mode when run in a TTY without required
arguments.

Use this input mode only when both conditions are true:

- the command is running in a TTY;
- `--json` is not present.

When `--json` is present, use
[`5.2_app-agent-ide_input-mode_non-interactive.md`](5.2_app-agent-ide_input-mode_non-interactive.md)
even if the process has a TTY.

App-role callers are rejected by the gateway before this input mode renders any
prompt. Authorization is gateway-side; the CLI surfaces the rejection.

## Prompts

### `app`
- **Condition:** `[app]` argument is missing.
- **Primitive:** `datatable`
- **Prompt:** `Select an app`
- **Rows:** Visible registered apps.
- **Validation:** The selected row resolves an existing app record in gateway
  configuration. Supplied arguments may still be app names or hostnames; name
  match wins and hostname match is consulted only when no name match exists.

### `agent_ide`
- **Condition:** `[agent_ide]` argument is missing.
- **Prompt:** `Select agent IDE adapter`
- **Type:** Choice.
- **Options:** `inherit`, `none`, and every adapter registered with the
  gateway-owned adapter registry (core values include `opencode` and
  `polyscope`; adapters registered by installed Orbit extensions appear in
  the same list). The CLI queries the gateway for choices over HTTPS through
  WireGuard before rendering the prompt. The CLI does not maintain a local
  adapter manifest, scan installed extensions on the CLI host, or fall back
  to a hard-coded core list. `inherit` and `none` are reserved input values
  prepended to the choices list and are not registry entries.
- **Validation:** Must be `inherit`, `none`, or appear in the gateway-owned
  adapter registry. Validation uses the same registry that backs the
  choices list.

If the gateway is unreachable while gathering choices, the command collapses
to the `gateway_unavailable` failure defined in
[`1_app-agent-ide.md`](1_app-agent-ide.md#failure-semantics) before prompts
complete.

### Destructive Consent (Adapter Switch)
- **Condition:** The selected adapter differs from the previous effective
  adapter AND workspaces would be removed.
- **Prompt:** `This change will remove N workspaces that no longer exist for the app under the new adapter. Continue?`
- **Type:** Confirm (Yes/No).
- **Default:** No.
- **Bypass:** Passing `--force` on the command line bypasses this
  confirmation prompt and proceeds with the destructive workspace cleanup.
  `--force` is the only confirmation bypass; declining the prompt without
  `--force` aborts the command before side effects.
