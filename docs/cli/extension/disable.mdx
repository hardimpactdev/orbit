---
title: "orbit extension:disable"
sidebarTitle: "extension:disable"
description: "Disable one extension for every client."
---

```bash
orbit extension:disable <extension> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `extension` | yes | `tasks`, `ai-router`, or `documents`. |

JSON returns `name` and `enabled`. Disabling a disabled extension succeeds and changes nothing. Disabling an extension that an enabled extension depends on fails with `extension.required`. Disabling `ai-router` does not stop its collector. Run [`ai-router:destroy`](/cli/ai-router/destroy) for that.

`tasks` depends on `ai-router`. Enable `ai-router` and run [`ai-router:setup`](/cli/ai-router/setup) before you enable `tasks`; until then, enabling `tasks` fails with `ai_router.disabled`. Disable `tasks` before `ai-router`.
