# Non-Interactive Input Mode: `orbit doctor`

[Back to `doctor` technical contract.](1_doctor.md)

**Input mode:** Non-interactive.

Use this mode when the process has no TTY, when `--json` or `--stream-json` is
present, or when `--restore` or `--adopt` is supplied. `--json` and
`--stream-json` always force non-interactive input mode. `--fix` selects
interactive mode and is rejected without a TTY when no other resolution mode
flag is present.

## Required Direction

Bulk resolution in non-interactive mode must select an explicit direction:

```bash
orbit doctor --restore
orbit doctor --adopt
```

`--fix`, `--restore`, and `--adopt` are mutually exclusive. When `--json` or
`--stream-json` is present and a resolution mode is requested, the resolution
mode must be `--restore` or `--adopt`; pairing either machine-readable renderer
with `--fix` is rejected with `error.code=validation_failed` because the
interactive driver cannot prompt in non-interactive mode.

`--json` and `--stream-json` are mutually exclusive. `--json` emits one final
terminal frame; `--stream-json` emits every gateway progress frame as
newline-delimited JSON.

`--dry-run` is valid only with `--restore` or `--adopt`. It returns the same scoped diagnostic plus `actions[]` entries with `status=planned`, but it does not invoke family fixers or adopters and keeps the command effect as `read`.

## Behavior

- Run probes for the resolved scope.
- In `restore` mode, select every finding declared restorable by its family and apply the restore action.
- In `adopt` mode, select every finding declared adoptable by its family and apply the adopt action.
- In verify mode (no resolution flag), report findings without acting on them.
- When `--key=<issue-key>` is present, filter findings to that exact issue key before selecting restore/adopt actions.
- When `--dry-run` is present, plan supported actions and unsupported skips without applying either.
- Skip unsupported findings and include them in the final diagnostic.
- Fail when no selected finding supports the requested direction.
- Never render prompts.
