# Technical Contract: `orbit app:register` (Human Renderer)

This contract defines the **human renderer** for `app:register`.

[Back to the canonical contract.](1_app-register.md)

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Progress Tree

The human renderer uses a step tree to visualize the registration and
apply process.

```text
┌ Registering App
○ Resolve app configuration
○ Register app record or adopt app path
○ Apply and verify app runtime
○ Apply and verify app routing
○ Verify application
└ Working...
```

## Human Strings

The success line varies by `result.action` so the operator can see what this
run did:

- **Success (`registered`)**: "App '{name}' successfully registered on node '{node}'."
- **Success (`adopted`)**: "App '{name}' successfully adopted from path '{path}' on node '{node}'."
- **Success (`converged`)**: "App '{name}' is already converged on node '{node}'. No changes were needed."
- **Success (`partial`)**: "App '{name}' is registered on node '{node}', but proxy enactment is incomplete." The following warning names the failed layer, node, and operation.
- **Success with warning**: The success line above is rendered, followed by a
  `Warning:` block summarizing each entry from `success.meta.warnings[]` with
  its message and the suggested `next_command`. For example, when production
  activation is pending: "Warning: Production domain '{domain}' is not yet
  active. Retry with `orbit app:register {name} --domain={domain}` once DNS
  has propagated."
- **Failure (path collision)**: "Path '{path}' on node '{node}' is already owned by app '{existing_app}'. Pick a different path or remove the existing app first."
- **Failure (other)**: "Failed to register app '{name}'."
