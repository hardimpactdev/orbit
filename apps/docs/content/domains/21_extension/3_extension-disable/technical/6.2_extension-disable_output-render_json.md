# JSON Renderer: `orbit extension:disable`

[Back to `extension:disable` technical contract.](1_extension-disable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Local Success

```json
{
  "success": {
    "data": {
      "extension": {
        "slug": "solo",
        "local_enabled": false
      }
    },
    "meta": []
  }
}
```

## Gateway Success

```json
{
  "success": {
    "data": {
      "extension": {
        "slug": "solo",
        "enabled": false,
        "enabled_at": null
      }
    },
    "meta": []
  }
}
```

## Error

Hard failures use the shared error envelope:

```json
{
  "error": {
    "code": "extension_unknown",
    "message": "Unknown Orbit extension [missing].",
    "meta": {
      "extension": "missing"
    }
  }
}
```
