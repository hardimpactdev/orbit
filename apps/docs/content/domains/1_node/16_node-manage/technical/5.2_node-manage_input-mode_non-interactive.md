# Non-Interactive Input Mode: `orbit node:manage`

[Back to `node:manage` technical contract.](1_node-manage.md)

**Input mode:** Non-interactive.

## Selection

Use this input mode when `--json` is present or when the command is running
without a TTY. `--json` always forces non-interactive input mode.

## Responsibilities

Prompts are never rendered in non-interactive mode.

- If `--user` is omitted, use the current local user.
- Fail with `validation_failed` when the local Agent user cannot be resolved.
- Emit only the canonical JSON envelope in `--json` mode.

The command verifies the authenticated gateway identity before requesting the
managed Agent opt-in.
