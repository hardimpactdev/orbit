# JSON Renderer: `orbit profile [target]`

[Back to `profile` technical contract.](1_profile.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also selects
[non-interactive input mode](5.2_profile_input-mode_non-interactive.md).

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Baseline-Only Success

When Toolbar data is absent or disabled, the command still returns a successful
baseline profile result.

```json
{
  "success": {
    "data": {
      "source": "baseline",
      "instrumented": false,
      "auth_mode": "guest",
      "request_id": "2f91f44f-6575-4f15-b50f-479ac36ff06f",
      "origin": "gateway",
      "target": {
        "app": "docs",
        "workspace": null,
        "node": "app-1",
        "domain": "docs.test"
      },
      "request": {
        "method": "GET",
        "url": "https://docs.test/",
        "uri": "/",
        "status": 404,
        "bytes": 1200,
        "completed": true
      },
      "timings": {
        "dns_ms": 1.0,
        "connect_ms": 3.0,
        "tls_ms": 7.0,
        "ttfb_ms": 50.0,
        "download_ms": 2.0,
        "total_ms": 52.0
      },
      "response_headers": {
        "content-type": "text/html"
      }
    },
    "meta": {
      "warnings": []
    }
  }
}
```

Completed non-2xx responses are success when `request.completed=true`.

## Error Shape

Request failures may include partial request and timing diagnostics under
`error.data`.

```json
{
  "error": {
    "code": "profile_request_failed",
    "message": "Failed to complete profile request.",
    "data": {
      "request": {
        "method": "GET",
        "url": "https://docs.test/",
        "uri": "/",
        "status": null,
        "bytes": 0,
        "completed": false
      },
      "timings": {
        "dns_ms": 0.0,
        "connect_ms": 0.0,
        "tls_ms": 0.0,
        "ttfb_ms": 0.0,
        "download_ms": 0.0,
        "total_ms": 3000.0
      },
      "profile_error": {
        "message": "Operation timed out"
      }
    },
    "meta": {
      "origin": "caller",
      "url": "https://docs.test/"
    }
  }
}
```

## Field Contract

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.source` | `baseline`, `baseline+toolbar` | Whether the result includes Toolbar enrichment. |
| `success.data.instrumented` | boolean | Whether Toolbar data was attached. |
| `success.data.auth_mode` | `guest`, `first-user`, `user` | Auth mode sent through explicit Toolbar headers. |
| `success.data.request_id` | string | Per-run UUID sent as `X-REQUEST-ID`. |
| `success.data.origin` | `caller`, `gateway` | Where the timed request was performed. |
| `success.data.target` | object | Resolved Orbit app/workspace target. |
| `success.data.request.completed` | boolean | Whether the timed request completed. Success responses always have `true`. |
| `success.data.timings` | object | Baseline measured timing values in milliseconds. |
| `success.data.toolbar` | object | Present only when Toolbar data is available. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `target_not_found`, `profile_request_failed` | Stable command failure code. |
| `error.data` | object | Present for `profile_request_failed` diagnostics. |
| `error.meta` | object | Field, reason, origin, URL, target, or authorization context. |
