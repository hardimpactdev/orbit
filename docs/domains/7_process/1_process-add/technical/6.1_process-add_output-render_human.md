# Human Renderer: `orbit process:add [name] [command]`

[Back to `process:add` technical contract.](1_process-add.md)

This page describes the human-rendered terminal output for `process:add`.

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render the complete progress tree after input resolution and before side effects begin. `process:add` writes gateway configuration and may render runtime units over SSH, so it must not leave the operator without progress feedback.

```text
┌ Adding Process
○ Validate process
○ Create process configuration
○ Render runtime units
○ Start runtime units
└ Working...
```

Omit the start step when `--start` is not present.

## Success Output

```text
Process 'vite' added for app 'docs'
```

When runtime-unit apply leaves repairable drift:

```text
Process 'vite' added for app 'docs'
  Drift detected: process.runtime_unit_missing
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no JSON envelope, and next-step guidance only when the operator can act on it.
