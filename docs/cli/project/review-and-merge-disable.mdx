---
title: "orbit project:review-and-merge:disable"
sidebarTitle: "project:review-and-merge:disable"
description: "Turn off the review-and-merge flow. The merge check stays. Open tasks follow at the next tick."
---

```bash
orbit project:review-and-merge:disable <project> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `project` | yes | Numeric Project ID. |
