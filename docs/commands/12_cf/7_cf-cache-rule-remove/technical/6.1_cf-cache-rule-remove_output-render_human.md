## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`cf-cache-rule:remove` resolves app/provider state and performs an external
provider delete. After input resolution and before the Cloudflare delete request
begins, render this progress tree:

```text
┌ Removing Cloudflare cache rule
○ Resolve app domain
○ Resolve Cloudflare zone
○ Delete cache rule
└ Working...
```

## Success Output

Render one concise success line:

```text
Cloudflare cache rule removed for docs
```

## Failure Output

Validation, missing destructive consent, gateway, authorization, and Cloudflare
failures render one concise error line.
