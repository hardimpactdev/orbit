# Human Renderer: `orbit tool:stop`

[Back to `tool-stop` technical contract.](1_tool-stop.md)

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and before lifecycle side
effects.

```text
┌ Stopping Tool
○ Resolve target
○ Read gateway tool configuration
○ Run command action
└ Working...
```

## Success Output

Human output finishes with `Tool stopped` and may include the selected tool,
node, and action from the gateway result.

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose
error, and actionable recovery guidance when the operator can resolve the issue.
