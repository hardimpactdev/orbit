Run the [smoke tests](/reference/gateway-recovery#smoke) of the current release against the live Gateway. Smoke changes nothing and writes no release record.

```bash
orbit gateway:release:smoke [<commit>] [--since=<time>] [--json]
```

| Argument or option | Meaning |
| --- | --- |
| `commit` | The hex SHA, 7 to 40 characters, that the live Gateway must serve. Without it, smoke expects the commit of the current release. |
| `--since` | The runtime handoff time, ISO 8601 with a zone, such as `2026-10-07T06:00:00Z`. The scheduler and agent view must have restarted after it. Smoke does not wait for a tick; [`orbit gateway:release:auto:status`](/cli/gateway/release-auto-status) shows whether the current release's scheduler has ticked. |

The Gateway runs `bin/gateway-smoke` of the current release inside the request and answers when smoke ends, after about a minute by default. Meanwhile the CLI shows one running step. The detail tree shows the commit, the outcome, the check counts, the duration, and the start time. A failed run adds the smoke message and the next step. A table lists each check with its status, error, message, and duration. JSON returns `release`, `sha`, `outcome`, the smoke `report`, and `request_id`. The command exits 0 only when the outcome is `passed`.

Interrupting the CLI stops waiting, not smoke. Smoke ends on the Gateway within its own limit.

## Errors

| Error code | Meaning |
| --- | --- |
| `gateway.release_commit_invalid` | The commit is not a hex SHA of 7 to 40 characters, or the current release reports no commit. |
| `gateway.release_since_invalid` | `--since` is not an ISO 8601 time with a zone. |
| `gateway.release_smoke_failed` | Smoke printed no report, or a report that is not a check failure, such as `terminated`. Checks that did not pass are the `failed` outcome, not this error. |
| `gateway.release_smoke_timeout` | Smoke ran past its limit and was stopped. |
| `gateway.release_smoke_killed` | Something else, such as the out-of-memory killer, killed smoke before its limit. |
| `gateway.release_smoke_missing` | The current release has no `bin/gateway-smoke`. |
| `gateway.release_smoke_in_progress` | Another smoke run is in progress. Only one runs at a time. |
