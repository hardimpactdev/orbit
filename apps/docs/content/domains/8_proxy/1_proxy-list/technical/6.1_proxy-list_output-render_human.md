# Human Renderer: `orbit proxy:list`

[Back to `proxy:list` technical contract.](1_proxy-list.md)

**Renderer:** Human terminal renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`proxy:list` is a read-only gateway registry query. Execution is expected to complete below one second and does not perform slow external work. No progress tree is rendered.

## Success Output

Render a table with one row per route.

| Column | Meaning |
| --- | --- |
| Domain | Route hostname or host/path identity. |
| Kind | `app`, `instance`, `workspace`, `internal`, `proxy`, or `redirect`. |
| Owner | Owner type and owner name, or `custom`. |
| Node | Serving node. |
| Target | Upstream, redirect URL, or owner-specific target. |
| TLS | `orbit`, `external`, or `none` as recorded in configuration. |
| Status | Gateway configuration status. |

Empty or missing cells render as `—` (em dash).

When no routes match, render the empty state that names the selected filter and
node scope:

```text
No proxy routes found.
No <filter> proxy routes found.
No proxy routes found on node <node>.
```

## Failure Output

Validation, gateway, and authorization failures render one concise error line with the rejected field or selected scope when available.
