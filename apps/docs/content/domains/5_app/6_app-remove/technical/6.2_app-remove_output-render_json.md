# JSON Renderer: `orbit app:remove`

[Back to `app:remove` technical contract.](1_app-remove.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. JSON forces non-interactive input
but never supplies destructive consent; `--force` remains required.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

`app` is the canonical logical-app entity captured before removal.
`instances[]` contains the canonical app-instance entities captured by the
frozen cascade inventory. Placement, including `adopted`, remains on each
instance. Cleanup is reported both in aggregate and per instance.

## Error Shapes

### Missing destructive consent

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Pass --force to remove the logical app and every instance.",
    "meta": {
      "field": "force",
      "reason": "destructive_consent_required"
    }
  }
}
```

### Invalid instance or hostname selector

```json
{
  "error": {
    "code": "validation_failed",
    "message": "app:remove requires an exact logical app slug.",
    "meta": {
      "field": "app",
      "reason": "logical_slug_required",
      "value": "my-app.production",
      "next_command": "app:instance remove my-app --instance=production --force"
    }
  }
}
```

### Multi-node authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "Removal is not authorized across every affected serving node.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "app:remove",
      "app": "my-app",
      "instances": ["my-app.development", "my-app.production"],
      "serving_nodes": ["app-dev-1", "app-prod-1"],
      "authorized_nodes": ["app-dev-1"],
      "unauthorized_nodes": ["app-prod-1"]
    }
  }
}
```

Authorization failure occurs before confirmation or effects. App-not-found and
gateway-removal failures use `app.not_found` and `app.removal_failed` under the
same canonical error envelope.

## Fields

| Field | Meaning |
| --- | --- |
| `app` | Canonical logical app captured before removal; never placement-shaped. |
| `instances[]` | Complete canonical instance inventory captured before removal. |
| `cleanup.aggregate` | Totals across the full cascade. |
| `cleanup.instances[]` | Per-instance dependent and node-artifact outcomes. |
| `meta.authorization` | Complete multi-node permission set checked before consent. |
| `meta.warnings[]` | Post-removal drift, scoped to family, instance, and serving node. |
