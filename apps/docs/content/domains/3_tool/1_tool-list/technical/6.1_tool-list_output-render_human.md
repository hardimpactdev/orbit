# Human Renderer: `orbit tool-list`

[Back to `tool-list` technical contract.](1_tool-list.md)

**Renderer:** Human renderer.

## Primitive

- Output data list: [`data-list`](../../../../ux/commands/lists/data-list.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`tool-list` is a read-only gateway registry query. Execution is expected to complete below one second and does not perform slow external work. No progress tree is rendered.

## Success Output

Human output presents the selected registry state grouped by node. Each tool
entry renders the tool name, expected capability state, managed flag, and
version/config metadata when tracked by the tool definition.

`tool:list` is non-live and reads gateway registry state only. It must not probe
nodes or imply observed freshness; observed and liveness reporting belongs to
`doctor --family=tool` and commands with explicit live inspection contracts.

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose error, and actionable recovery guidance when the operator can resolve the issue.
