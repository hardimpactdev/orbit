title: "orbit schedule:run"
sidebarTitle: "schedule:run"
description: "Run the Schedule once now, as a task, and follow it until it ends. The calendar does not change. A native setup, transport or command failure returns `schedule.run_failed`. Admission refuses a missing target or command copy with `schedule.target_unavailable`."
---

```bash
orbit schedule:run <uuid> [--idempotency-key=KEY] [--json]
```

During checkout migration, a Node-timer Schedule run returns a waiting Operation. [Schedule migration](/reference/schedules#checkout-migration) describes its release after cutover or rollback.
