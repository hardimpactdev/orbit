# Human Renderer: `orbit cf-dns:list`

**Renderer:** Human terminal renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)
- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`cf-dns:list` resolves a provider zone and performs an external provider
request. After input resolution and before the Cloudflare request begins,
render this progress tree:

```text
┌ Listing Cloudflare DNS records
○ Resolve Cloudflare zone
○ Query DNS records
└ Working...
```

## Success Output

Render a table with one row per DNS record.

| Column | Meaning |
| --- | --- |
| Record ID | Cloudflare DNS record identifier. |
| Type | Provider record type. |
| Name | DNS record name. |
| Content | DNS record target value. |
| Proxied | `yes` or `no`. |

Empty results render `No Cloudflare DNS records found for <zone>.`

## Failure Output

Validation, gateway, authorization, and Cloudflare failures render one concise
error line with the rejected zone when available.
