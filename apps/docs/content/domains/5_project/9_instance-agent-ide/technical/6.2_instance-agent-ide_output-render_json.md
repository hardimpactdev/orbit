# JSON Renderer: `orbit instance:agent-ide`

[Back to `instance:agent-ide` technical contract.](1_instance-agent-ide.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

The JSON renderer returns the selected instance target, resulting adapter
configuration, and any cleanup results under the standard envelope.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](5.2_instance-agent-ide_input-mode_non-interactive.md),
even when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shapes

### Instance override set with post-configuration cleanup warnings

Cleanup failures after the instance configuration write are successful command outcomes.
The warnings use the same structured warning shape and warning vocabulary as
`instance:prune` and `workspace:remove`.

```json
{
  "success": {
    "data": {
      "target": {
        "project": "my-app",
        "instance": "my-app.development",
        "serving_node": "app-1"
      },
      "agent_ide": {
        "adapter": "opencode",
        "source": "instance",
        "effective_adapter": "opencode"
      },
      "cleanup": {
        "workspaces_removed": ["stale-ws-1"],
        "workspaces_failed": ["stale-ws-2"]
      },
      "action": "set"
    },
    "meta": {
      "warnings": [
        {
          "code": "workspace.artifact_extra",
          "family": "workspace",
          "message": "Workspace cleanup for 'stale-ws-2' could not remove all node-side artifacts.",
          "next_command": "doctor --family=workspace --restore"
        }
      ]
    }
  }
}
```

### Fields

| Field | Type | Meaning |
| --- | --- | --- |
| `target.project` | string | Project identity slug. |
| `target.instance` | string | Selected dotted instance selector. |
| `target.serving_node` | string | Selected instance's serving node. |
| `agent_ide.adapter` | string \| null | The explicit instance-level value: an adapter name, the literal `"none"`, or `null` when the instance override was cleared with `inherit`. |
| `agent_ide.source` | string | Where the effective adapter resolves from. See source values below. |
| `agent_ide.effective_adapter` | string \| null | The adapter used after resolution. `null` when the effective state is "agent IDE disabled" (`agent_ide.adapter` is `"none"`) or when the chain resolves to no adapter. |
| `cleanup.workspaces_removed` | array of strings | List of workspace names removed during the switch. Empty list when no cleanup ran. |
| `cleanup.workspaces_failed` | array of strings | List of workspace names whose cleanup could not finish after the configuration write. Empty or omitted when every cleanup target completed. |
| `action` | string | `"set"` when the value changed; `"converged"` when the value already matched. |

`agent_ide.source` resolves to `"instance"` when the selected instance holds an
explicit override, `"node"` when it cleared with `inherit` and its serving node
holds a default, and `"default"` when the chain resolves to no
adapter.

`success.meta.warnings` is omitted when cleanup has no warnings. When present,
each entry carries `code`, `family`, `message`, and `next_command`.

## Error Shapes

### Missing required input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Instance is required.",
    "meta": {
      "field": "instance"
    }
  }
}
```

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Agent IDE adapter is required.",
    "meta": {
      "field": "agent_ide"
    }
  }
}
```

### Instance not found

```json
{
  "error": {
    "code": "instance.not_found",
    "message": "Instance 'my-app.missing' not found.",
    "meta": {
      "instance": "my-app.missing"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'instance:agent' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "instance:agent",
      "serving_node": "app-1"
    }
  }
}
```

### Unsupported adapter

```json
{
  "error": {
    "code": "instance.unsupported_adapter",
    "message": "The adapter \"invalid-adapter\" is not supported.",
    "meta": {
      "adapter": "invalid-adapter",
      "supported": ["inherit", "none", "opencode", "polyscope"]
    }
  }
}
```

`error.meta.supported` lists the reserved input values (`inherit`, `none`)
followed by every adapter currently registered with the gateway-owned
adapter registry. Extension-supplied adapters appear in the list once
registered.

### Missing destructive consent

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Workspaces would be removed during the adapter switch. Pass --force to proceed.",
    "meta": {
      "field": "force",
      "instance": "my-app.development",
      "previous_adapter": "polyscope",
      "next_adapter": "opencode",
      "workspaces_at_risk": ["stale-ws-1", "stale-ws-2"]
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to validate the adapter or list registered adapters.",
    "meta": []
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `action` | `set`, `converged` |
| `agent_ide.source` | `instance`, `node`, `default` |
| `error.code` | `validation_failed`, `instance.not_found`, `authorization_failed`, `workspace.unsupported_for_production`, `instance.unsupported_adapter`, `gateway_unavailable` |

The `error.code` values listed here are exhaustive for `instance:agent-ide`. Add a
new value to this renderer contract before implementing another JSON failure
code.
