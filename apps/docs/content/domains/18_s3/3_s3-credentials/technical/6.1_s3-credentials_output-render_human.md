# Human Renderer: `orbit s3:credentials`

[Back to `s3:credentials` technical contract.](1_s3-credentials.md)

**Renderer:** Human terminal renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`s3:credentials` is a read-only gateway registry query. Execution is expected
to complete below one second and does not perform slow external work. No
progress tree is rendered.

## Success Output

Render a concise table containing node, private endpoint, public endpoints,
region, access key id, secret access key, and endpoint style.

## Failure Output

Validation failures name the missing or invalid role prerequisite. Missing
credentials explain that `doctor --family=tool --restore` owns SeaweedFS
credential repair.
