# Human Renderer: `orbit app:analytics disable`

[Back to `app:analytics disable` technical contract.](1_app-analytics-disable.md)

**Renderer:** Human renderer.

## Primitive

None. Output is emitted as prose lines.

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered. The disable operation is a fast gateway write and
route sync; no slow external work is performed from the CLI side.

## Success Render

```text
analytics:
  app: docs
  enabled: false
  internal_host: analytics.orbit
  public_hosts: []
```

## Error Render

Errors are rendered as concise prose messages.
