# Human Renderer: `orbit s3:publish`

[Back to `s3:publish` technical contract.](1_s3-publish.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render a progress tree after input resolution and before route convergence
begins.

```text
Publishing S3 Host
- Resolve S3 node
- Check router and ingress
- Ensure SeaweedFS credentials
- Ensure private s3.orbit route
- Ensure S3 backend pool
- Publish ingress host
- Verify route intent
```

## Success Output

Render the host, selected S3 node, private endpoint `https://s3.orbit`, public
endpoint, action (`published` or `updated`), and whether the host was already
published.

## Failure Output

Validation failures name the missing or invalid role prerequisite. Apply
failures render the next doctor command for route recovery.
