# Non-Interactive Input Mode: `orbit vpn-web-ui:change-password`

[Back to `vpn-web-ui:change-password` technical contract.](1_vpn-web-ui-change-password.md)

**Input mode:** Non-interactive.

## Selection

Use this input mode when the command is not attached to a TTY or when `--json`
is present. `--json` forces non-interactive input mode and never grants
destructive consent.

## Input Resolution

Non-interactive input mode resolves all inputs from arguments and options
without prompts. It must never render prompts, never wait for user input, and
never fall back to interactive confirmation.

## Missing Input Or Consent

- If `password` is missing, fail before side effects with
  `error.code=validation_failed`, `error.meta.field=password`, and no secret
  value in output.
- If `--force` is absent, fail before side effects with
  `error.code=validation_failed`, `error.meta.field=force`, and
  `error.meta.reason=destructive_consent_required`.
