# JSON Renderer: `orbit app:env`

[Back to `app:env` technical contract.](1_app-env.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shapes

### List

```json
{
  "success": {
    "data": {
      "variables": [
        {
          "key": "APP_DEBUG",
          "value": "false",
          "secret": false
        }
      ]
    }
  }
}
```

### Set

```json
{
  "success": {
    "data": {
      "variable": {
        "key": "APP_DEBUG",
        "value": "false",
        "secret": false
      }
    }
  }
}
```

### Render

```json
{
  "success": {
    "data": {
      "variables": {
        "APP_DEBUG": {
          "value": "false",
          "secret": false
        },
        "DB_PASSWORD": {
          "value": null,
          "secret": true
        }
      }
    }
  }
}
```

## Error Shapes

Command-specific errors use the standard error envelope. Common validation,
authorization, and gateway failures follow the shared command contract.
