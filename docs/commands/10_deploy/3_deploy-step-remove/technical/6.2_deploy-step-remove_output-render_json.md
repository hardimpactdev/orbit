# JSON Renderer: `orbit deploy:step-remove`

[Back to `deploy:step-remove` technical contract.](1_deploy-step-remove.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "step": {
        "id": 12,
        "app": "docs",
        "title": "Pull latest",
        "command": "git pull origin main",
        "order": 1,
        "timeout_seconds": 600,
        "retention": null
      }
    },
    "meta": {
      "action": "removed",
      "history_preserved": true
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "deploy.step_not_found",
    "message": "Deployment step 'Pull latest' was not found for app 'docs'.",
    "meta": {
      "app": "docs",
      "step": "Pull latest"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.step` | object | Removed deploy step entity. |
| `success.meta.action` | string | `removed`. |
| `success.meta.history_preserved` | boolean | Confirms deployment run history was not deleted. |
| `error.code` | `validation_failed`, `caller_role_not_allowed`, `gateway_unavailable`, `authorization_failed`, `app.not_found`, `deploy.production_app_required`, `deploy.step_not_found`, `destructive_consent_required` | Stable command failure code. |
| `error.meta` | object | Field, caller role, app selector, step selector, or authorization context for automation. |
