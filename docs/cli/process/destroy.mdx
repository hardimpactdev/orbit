---
title: "orbit process:destroy"
sidebarTitle: "process:destroy"
description: "Stop and remove the unit or container of one Process, then delete its record. With `--project`, destroy one definition by name."
---

```bash
orbit process:destroy <process> [--project=ID] [--yes] [--idempotency-key=KEY] [--json]
```

| Option | Meaning |
| --- | --- |
| `--project=ID` | Select a definition by name. |
| `--yes` | Confirm without a prompt. A JSON or non-interactive call without `--yes` returns `input.confirmation_required`. A declined prompt, Ctrl-C, or EOF returns `input.cancelled`. |

```bash
orbit process:destroy 41 --yes
orbit process:destroy queue --project=1 --yes
```

Destroying a definition leaves every existing Instance copy in place.

For a systemd Process, Orbit clears a retained failure only after the unit file and boot link are absent and no running process, cgroup or pending job remains. It checks the state again before deleting the record. Destroy preserves the source environment file.
