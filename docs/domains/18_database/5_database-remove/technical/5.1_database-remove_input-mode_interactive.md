# Technical Contract: `orbit database:remove` (Interactive Input)

This contract defines behavior for **interactive input mode**.

[Back to the canonical contract.](1_database-remove.md)

**Input mode:** Interactive.

Use this input mode only when both conditions are true:

- the command is running in a TTY;
- `--json` is not present.

When `--json` is present, use
[`5.2_database-remove_input-mode_non-interactive.md`](5.2_database-remove_input-mode_non-interactive.md)
even if the process has a TTY.

## Prompts

| ID | Primitive | Label | Required |
| --- | --- | --- | --- |
| `force` | `confirm` | Remove database connection and all target mappings? | Yes when `--force` is absent. |

## Primitive References

- [`confirm`](../../../../ux/commands/inputs/confirm-prompt.md)

## Behavior

- Orbit prompts once for explicit destructive confirmation after resolving the selected connection.
- A declined confirmation exits without side effects and returns `error.code=validation_failed`.
