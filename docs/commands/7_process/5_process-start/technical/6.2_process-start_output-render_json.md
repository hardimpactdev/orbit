# JSON Renderer: `orbit process:start [name]`

[Back to `process:start` technical contract.](1_process-start.md)

This page describes the JSON-rendered output for `process:start`.

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present. `--json` also forces
non-interactive input mode.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the selected runtime contexts, runtime units, resulting
runtime states, and durable events. The `runtimes` array contains exactly one
item when `[name]` is supplied and every selected process in process order when
`[name]` is omitted.

## Success Example

```json
{
  "success": {
    "data": {
      "runtimes": [
        {
          "process": "vite",
          "app": "docs",
          "workspace": "feature-docs",
          "runtime_unit": "orbit_docs_feature-docs_vite.service",
          "state": "running",
          "event": {
            "type": "started"
          }
        }
      ]
    },
    "meta": {}
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "process.runtime_action_failed",
    "message": "The runtime unit could not be started.",
    "data": {
      "runtimes": [
        {
          "process": "vite",
          "app": "docs",
          "workspace": "feature-docs",
          "runtime_unit": "orbit_docs_feature-docs_vite.service",
          "state": "failed",
          "event": null,
          "message": "systemd reported a start failure."
        }
      ]
    },
    "meta": {
      "process": "vite",
      "partial_state": "none_started"
    }
  }
}
```

## Caller Role Error

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "The local Orbit caller role could not be resolved.",
    "meta": {
      "caller_role": "unknown"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: app or workspace context is missing, invalid, or
  ambiguous in non-interactive input mode.
- `caller_role_not_allowed`: caller role is `unknown`.
- `authorization_failed`: caller cannot operate process runtime state for the
  target context.
- `process.not_found`: `[name]` is supplied and the named process does not
  exist for the owning app.
- `process.none_configured`: `[name]` is omitted and the owning app has no
  process definitions.
- `process.runtime_action_failed`: the gateway cannot start the runtime unit on
  the owning app node.
