# Human Renderer: `orbit process:restart [name]`

[Back to `process:restart` technical contract.](1_process-restart.md)

This page describes the human-rendered terminal output for `process:restart`.

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render the complete progress tree after input resolution and before side effects begin. `process:restart` performs remote runtime actions.

```text
┌ Restarting Processes
○ Resolve runtime units
○ Restart runtime units
○ Record process events
└ Working...
```

## Success Output

For a named process:

```text
Process 'vite' restarted for instance 'docs.production'
```

For a workspace context:

```text
Process 'vite' restarted for workspace 'feature-docs' on instance 'docs.development'
```

When `[name]` is omitted:

```text
2 processes restarted for workspace 'feature-docs' on instance 'docs.development'
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no JSON envelope, and next-step guidance only when the operator can act on it. Bulk failures must identify the failed process names and leave successful processes visible in the summary.
