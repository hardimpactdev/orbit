List the Nodes visible to the calling Node, using Orbit's recorded state.

## Usage

```bash
orbit node:list [--json]
```

There are no arguments or filters. See the [node family overview](/cli/node) for shared conventions.

| Option | Default | Meaning |
| --- | --- | --- |
| `--json` | off | Follows the shared [CLI standard](/reference/cli-ux). |

## How it works

<div className="flow-at" data-chart="node/list"></div>

The command reads Gateway state without contacting the Nodes, so an unreachable Node remains visible. It creates no Operation and changes nothing. Running it again reads the current records; it is not a skipped action and has no skip reason code. A failed read leaves no partial change to repair.

The active Gateway Node, the host serving the Gateway, and a caller with an access grant to the active Gateway Node see every Node. Other callers see only the Nodes they have access grants to; there is no implicit grant to their own Node. Nodes are sorted by name, then ID.

The result contains these columns.

| Column | Meaning |
| --- | --- |
| `ID`, `NAME` | The Node's ID and name. |
| `STATUS` | The Node's recorded status. A Node whose add or removal failed keeps `failed_step` and `error_code` in its JSON record. |
| `AGENT` | The Node agent's liveness: `online`, `offline`, `not seen`, or `unknown`. [`node:show`](/cli/node/show) explains these states and shows since when an agent is offline. A Node without an observing agent has `agent: null`. |
| `ROLES` | Requires the Node's active roles, comma-separated. The current response includes all recorded role assignments. |
| `PLATFORM`, `TLD`, `USER` | The Node's platform, development TLD with a leading dot, and managed user. |
| `CLUSTER` | Requires the Cluster name in the table and beside `cluster_id` in JSON. The current response supplies only the ID. |
| `WIREGUARD`, `LAN` | The Node's WireGuard and LAN addresses. |

An empty result says `No nodes.`. The machine result has a `nodes` array and a `request_id`. [Verification cases](https://github.com/hardimpactdev/orbit/blob/main/swamp/proof/node/list.cases.yaml) list the checks and the runner capabilities still needed, including active-role filtering and Cluster-name display.

## Errors

| Code | Meaning |
| --- | --- |
| `node_access.required` | The calling Node has neither Gateway authority nor an access grant to any Node. Nothing is listed or changed. |
