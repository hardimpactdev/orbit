# Human Renderer: `orbit cf-ssl:enable`

[Back to `cf-ssl:enable` technical contract.](1_cf-ssl-enable.md)

**Renderer:** Human terminal renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`cf-ssl:enable` resolves provider state and performs an external provider
write. After input resolution and before the Cloudflare SSL request begins,
render this progress tree:

```text
┌ Enabling Cloudflare SSL
○ Resolve Cloudflare zone
○ Validate SSL mode
○ Update Cloudflare SSL mode
└ Working...
```

## Success Output

Render one concise success line:

```text
Cloudflare SSL mode for example.com set to strict
```

## Failure Output

Validation, gateway, authorization, and Cloudflare failures render one concise
error line with the rejected zone or mode when available.
