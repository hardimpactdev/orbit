# JSON Renderer: `orbit tool-restart`

[Back to `tool-restart` technical contract.](1_tool-restart.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "tool": []
    },
    "meta": {}
  }
}
```

Command-specific result data uses the canonical tool entity from [`README.md`](../../README.md#tool-json-entity) unless the command returns logs or credentials.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Required input is missing or invalid.",
    "meta": {
      "field": "tool"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `tool.not_found`, `tool.unsupported_action`, `tool.remote_action_failed` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.meta` | object | Field, target, caller, or remote-action context for automation. |

`tool.remote_action_failed` preserves immediate apply diagnostics:

```json
{
  "error": {
    "code": "tool.remote_action_failed",
    "message": "Tool 'caddy' restart failed on node 'app-1'.",
    "meta": {
      "tool": "caddy",
      "node": "app-1",
      "action": "restart",
      "exit_code": 7,
      "stderr": "docker restart orbit-caddy failed"
    }
  }
}
```

When `--json` is present, the command uses non-interactive input mode and
renders no prompts. Missing target input fails before side effects:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A node or app target is required. Provide --node, --app, configure node:default, or select a target interactively.",
    "meta": {
      "fields": ["target"]
    }
  }
}
```

When both `--app` and `--node` are supplied but resolve to different nodes, the
shape is:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Invalid value for --app: 'docs'. App is not owned by the selected node.",
    "meta": {
      "field": "app",
      "value": "docs",
      "node": "app-2",
      "resolved_node": "app-1",
      "reason": "target_mismatch"
    }
  }
}
```
