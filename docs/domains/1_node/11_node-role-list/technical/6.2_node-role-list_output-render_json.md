```json
{
  "success": {
    "data": {
      "node": "client-1",
      "roles": [
        {
          "role": "app-development",
          "status": "active",
          "settings": {
            "tld": "test"
          },
          "last_error": null,
          "converged_at": "2026-05-17T12:00:00+00:00"
        }
      ]
    }
  }
}
```

## Error Codes

- `validation_failed`
- `node.not_found`
- `gateway_unavailable`
- `authorization_failed`
