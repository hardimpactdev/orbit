# Human Renderer: `orbit node:default`

[Back to `node:default` technical contract.](1_node-default.md)

This page describes the human-rendered terminal output for `node:default`.

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. Prompt behavior belongs to
[`interactive input mode`](5.1_node-default_input-mode_interactive.md).
Non-interactive validation failures are rendered here as prose errors when
`--json` is absent.

## Progress Tree

`node:default` renders a progress tree for the interactive `choose` sub-action
because it queries the gateway before side effects:

```text
┌ Setting Default Node
○ Load visible development nodes
○ Store local default
└ Working...
```

Direct set through `[name]` also renders the same tree. The local
`show` and `clear` sub-actions do not render a progress tree because execution
is expected to complete below one second and performs no slow external work.

## Success Output

### Show sub-action with default set

```text
Default development node: app-1
```

### Show sub-action with no default

```text
No default development node is set.
Run `orbit node:default <name>` to set one.
```

### Set sub-action

```text
Default development node set to app-1.
```

### Choose sub-action

Uses the same success output as `set` after the selected node is stored.

### Clear sub-action with existing default

```text
Default development node cleared.
```

### Clear sub-action with no existing default

```text
No default development node was set.
```

## Failure Output

Human-rendered failures must show:

- the failing field or condition;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the operator can act on it.

### Mutually exclusive input

```text
Cannot provide both a node name and --clear.
```

### Node not found

```text
Node 'app-1' not found or not visible.
```

### Not a development node

```text
Node 'gateway-1' is not a development node.
Only development nodes may be set as the local default.
```

### Gateway unavailable

```text
Gateway connection is required to set a default node.
```

### Caller role not allowed

```text
This command may only be run from a client.
```
