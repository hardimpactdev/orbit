title: "orbit tasks:egress"
sidebarTitle: "tasks:egress"
description: "List the outside hosts a task group's VM connected to: names and addresses, ports, and how the host saw them."
---

```bash
orbit tasks:egress [group] [--json]
```

The optional `group` argument is the numeric task group ID. Omitting it uses the standard selector. The table shows one row for each destination, port and protocol: the host, the port with its protocol, the sources that saw it, the flags, the first address with a count of the others, and the first-seen time in UTC. JSON output adds the kind, all addresses and the VM.

A name that nothing connected to has a blank port and protocol. JSON output holds the rows under `hosts`, with `null` for that port and protocol. The [egress log](/reference/task-vm-egress-log) defines the sources `conn` and `dns` and the flags `dot`, `dns` and `doh`. The list is empty until the host's agent reports the VM, and it stays after the VM is deleted.
