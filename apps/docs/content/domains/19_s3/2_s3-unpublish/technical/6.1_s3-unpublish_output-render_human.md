# Human Renderer: `orbit s3:unpublish`

[Back to `s3:unpublish` technical contract.](1_s3-unpublish.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render a progress tree after input resolution and destructive confirmation,
before route cleanup begins.

```text
Unpublishing S3 Host
- Confirm destructive removal
- Resolve S3 node
- Check router
- Remove ingress host
- Remove SeaweedFS public host config
- Apply route cleanup
```

## Success Output

Render the host, selected S3 node, action `unpublished`, and whether the host
was already absent.

## Failure Output

Validation failures name the missing or invalid prerequisite. Missing
destructive consent renders a direct message that `--force` is required in
non-interactive mode. Cleanup failures render the next doctor command for route
recovery.
