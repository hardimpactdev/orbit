# JSON Renderer: `orbit agent-ide:message [message]`

[Back to `agent-ide:message` technical contract.](1_agent-ide-message.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also selects
[non-interactive input mode](5.2_agent-ide-message_input-mode_non-interactive.md).

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "agent_ide": {
        "adapter": "opencode",
        "source": "app",
        "target": {
          "app": "docs",
          "workspace": null,
          "node": "app-1"
        },
        "session": {
          "id": "sess_123",
          "status": "active"
        },
        "delivery": {
          "status": "sent",
          "message_bytes": 45,
          "input": "argument"
        }
      }
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "no_active_session",
    "message": "No active Agent IDE session found for docs.",
    "meta": {
      "app": "docs",
      "workspace": null,
      "adapter": "opencode"
    }
  }
}
```

Adapter delivery failures include adapter-provided diagnostics under
`error.data` when a stable diagnostic is available.

```json
{
  "error": {
    "code": "adapter_delivery_failed",
    "message": "Agent IDE adapter opencode could not deliver the message.",
    "data": {
      "adapter_error": {
        "message": "Request timed out"
      }
    },
    "meta": {
      "app": "docs",
      "workspace": null,
      "adapter": "opencode"
    }
  }
}
```

## Field Contract

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.agent_ide.adapter` | string | Effective adapter used for delivery. |
| `success.data.agent_ide.source` | `workspace`, `app`, `node` | Scope that supplied the effective adapter. `workspace` is reserved for a future workspace override. |
| `success.data.agent_ide.target.app` | string | Target app. |
| `success.data.agent_ide.target.workspace` | string \| null | Target workspace, or `null` for app main context. |
| `success.data.agent_ide.target.node` | string | Owning node. |
| `success.data.agent_ide.session.id` | string \| null | Adapter session identifier when the adapter exposes one. |
| `success.data.agent_ide.delivery.status` | `sent` | Adapter accepted the message for the active session. |
| `success.data.agent_ide.delivery.message_bytes` | integer | Byte length of the delivered message. |
| `success.data.agent_ide.delivery.input` | `argument`, `stdin` | Source of the delivered message body. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `target_not_found`, `no_effective_adapter`, `no_active_session`, `adapter_delivery_failed` | Stable command failure code. |
| `error.meta` | object | Field, reason, app, workspace, node, adapter, or authorization context. |
| `error.data` | object | Present only for adapter delivery diagnostics. |

The renderer must not echo the full message body in JSON output.
