# Human Renderer: `orbit process:stop [name]`

[Back to `process:stop` technical contract.](1_process-stop.md)

This page describes the human-rendered terminal output for `process:stop`.

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render the complete progress tree after input resolution and before side
effects begin. `process:stop` performs a remote runtime action.

```text
┌ Stopping Process
○ Resolve runtime unit
○ Stop runtime unit
○ Record process event
└ Working...
```

## Success Output

```text
Process 'vite' stopped for app 'docs'
```

For a workspace context:

```text
Process 'vite' stopped for workspace 'feature-docs'
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no
JSON envelope, and next-step guidance only when the operator can act on it.
