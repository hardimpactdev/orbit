# Human Renderer: `orbit app:instance`

[Back to `app:instance` technical contract.](1_app-instance.md)

## Primitive

None. The renderer uses plain terminal text and tables without a specialized
prompt or progress primitive.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered. The command performs a single gateway API request
and is expected to complete in under one second after input is resolved.

## Success Output

For `list`, show a table of instances with app, name, driver, runtime mode, PHP
version, required extensions, and latest deployment status when present.

For `show`, print one instance summary with driver config and runtime metadata.

For `add`, print the created or updated instance name, driver, and any required
extensions recorded.

For `remove`, print the removed instance name.

## Failure Output

Failures render the gateway or validation message directly. When destructive
consent is missing for `remove`, tell the caller to pass `--force`.
