# JSON Renderer: `orbit schedule:list`

[Back to `schedule:list` technical contract.](1_schedule-list.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "schedules": [
        {
          "name": "laravel-scheduler",
          "scope": "app",
          "target": {
            "type": "app",
            "name": "docs",
            "node": "app-1"
          },
          "interval": "every minute",
          "timezone": "Europe/Amsterdam",
          "execution": {
            "type": "command",
            "value": "php artisan schedule:run"
          },
          "enabled": true,
          "status": "expected",
          "last_run": {
            "id": 12,
            "status": "completed",
            "exit_code": 0,
            "started_at": "2026-05-02T08:00:00Z",
            "finished_at": "2026-05-02T08:00:03Z"
          }
        }
      ]
    },
    "meta": {
      "app": null,
      "node": null,
      "count": 1
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The schedule filters are mutually exclusive.",
    "meta": {
      "fields": ["app", "node"]
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.schedules[]` | array | Schedule entities visible under the selected scope. |
| `success.meta.app` | string \| null | Applied app filter. |
| `success.meta.node` | string \| null | Applied node filter. |
| `success.meta.count` | integer | Number of returned schedules. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed` | Stable command failure code. |
| `error.meta` | object | Field, scope, caller, or authorization context for automation. |
