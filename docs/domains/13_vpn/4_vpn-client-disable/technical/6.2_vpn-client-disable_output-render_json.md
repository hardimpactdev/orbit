# JSON Renderer: `orbit vpn-client:disable <name>`

[Back to `vpn-client:disable` technical contract.](1_vpn-client-disable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "client": {
        "name": "laptop",
        "enabled": false,
        "action": "disabled",
        "already_disabled": false
      }
    },
    "meta": {}
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "VPN client is an active Orbit node peer.",
    "meta": {
      "field": "name",
      "reason": "node_peer_protected"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.client.name` | string | Disabled client name. |
| `success.data.client.enabled` | boolean | Always `false` on success. |
| `success.data.client.action` | `disabled` | Command action. |
| `success.data.client.already_disabled` | boolean | Whether the backend was already in the desired state. |
| `error.code` | `caller_role_not_allowed`, `validation_failed`, `vpn_runtime_unavailable`, `vpn_runtime_ssh_unavailable`, `authorization_failed`, `vpn_backend_unavailable`, `vpn_backend_auth_failed` | Stable command failure code. |
| `error.meta` | object | Caller, validation, gateway SSH, authorization, backend, or authentication failure context. |
