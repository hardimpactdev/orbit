## Primitive

- Progress tree: [`progress-tree`](../../../../ux/commands/progress/progress-tree.md)

Skipped setup renders one concise success result.

## Progress Tree

The progress tree contains a root labeled `Setting Up Instance`. It includes instance
resolution and setup-step execution when steps exist.

## Human Strings

- Success: `Instance ready and available at: {url}`
- Skipped: `Instance setup already completed for current steps.`
- Failure: `instance.setup_failed: Instance setup failed.`
