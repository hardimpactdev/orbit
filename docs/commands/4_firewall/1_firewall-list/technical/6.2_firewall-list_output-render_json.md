# JSON Renderer: `orbit firewall:list`

[Back to `firewall-list` technical contract.](1_firewall-list.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "rules": []
    },
    "meta": {
      "node": null
    }
  }
}
```

`success.data.rules[]` uses the canonical firewall rule entity from
[`README.md`](../../README.md#firewall-rule-json-entity).

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The selected node is not a firewall target.",
    "meta": {
      "field": "node",
      "node": "macbook"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.meta` | object | Field, node, caller, or gateway context for automation. |
