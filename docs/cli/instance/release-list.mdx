---
title: "orbit instance:release:list"
sidebarTitle: "instance:release:list"
---

List retained release names and the current selection. A production home keeps at most 3 releases, as [Retained releases](/reference/deployments#retained-releases) describes. See [`instance:deployment:list`](/cli/instance/deployment-list) for the recorded run history behind those releases.

```bash
orbit instance:release:list <instance> [--json]
```
