# JSON Renderer: `orbit node role:add`

[Back to `node role:add` technical contract.](1_node-role-add.md)

## Primitive

None. JSON renderer emits the standard envelope only.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Top-level envelopes:
- Success: `{ "success": { ... } }`
- Error: `{ "error": { ... } }`

## Success Shape

`success.data.node` and `success.data.assignment` are always present. The
response also includes `success.data.agent_job` when the target is opted into
Orbit Agent convergence for macOS/Darwin `app-dev`.

```json
{
  "success": {
    "data": {
      "node": "NMBP",
      "assignment": {
        "role": "app-dev",
        "status": "active",
        "settings": {
          "tld": "test"
        },
        "last_error": null,
        "converged_at": "2026-07-02T12:00:00Z"
      },
      "agent_job": {
        "id": "018f7b7c-6b32-7000-9f63-2cc8b2c91234",
        "type": "app-dev-convergence",
        "status": "queued"
      }
    }
  }
}
```

## Error Codes

- `validation_failed`
- `node.not_found`
- `gateway_unavailable`
- `authorization_failed`
