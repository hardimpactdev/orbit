# Interactive Input Mode: `orbit cf-cache:flush`

[Back to `cf-cache:flush` technical contract.](1_cf-cache-flush.md)

**Input mode:** Interactive.

## Selection

Use this input mode only when the process has a TTY and `--json` is not
present.

## Prompt Behavior

When `--zone` is absent, render this prompt before provider side effects:

| Prompt ID | Primitive | Label | Placeholder |
| --- | --- | --- | --- |
| `cf_cache_flush_zone` | `search` | `Select Cloudflare zone` | `Type to search zones` |

The searchable option labels include the Cloudflare zone name, provider status,
and up to two Orbit app domains that reference the zone. If Cloudflare returns
no zones, fail before side effects.
