# JSON Renderer: `orbit cf-dns:add`

[Back to `cf-dns:add` technical contract.](1_cf-dns-add.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "record": {
        "id": "record-1",
        "zone": "example.com",
        "type": "A",
        "name": "docs.example.com",
        "content": "203.0.113.10",
        "proxied": true,
        "status": "created"
      }
    },
    "meta": {
      "action": "create",
      "already_present": false
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A conflicting Cloudflare DNS record already exists.",
    "meta": {
      "field": "name",
      "zone": "example.com",
      "record_id": "record-2",
      "conflict": "different_content"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.record` | object | Created or existing DNS record entity. |
| `success.meta.action` | `create` | Command operation that completed. |
| `success.meta.already_present` | boolean | Whether the provider record already existed unchanged. |
| `error.code` | `validation_failed`, `caller_role_not_allowed`, `gateway_unavailable`, `authorization_failed`, `cloudflare_unavailable` | Stable command failure code. |
| `error.meta` | object | Field, zone, conflict, gateway, authorization, token, or provider failure context. |
