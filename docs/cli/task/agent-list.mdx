---
title: "orbit task:agent:list"
sidebarTitle: "task:agent:list"
description: "List a task's agent threads: each subtask's reviewer and implementer, including finished threads."
---

```bash
orbit task:agent:list [task] [--json]
```

The table shows the thread ID, role, subtask ID, driver, model, state, tokens, uncached input, cached input, output, model calls, peak context, line diff, and observation time. An unknown token field is a blank cell. JSON output includes `input_tokens`, `cached_input_tokens`, `output_tokens`, `model_calls`, and `peak_context_tokens`, each null when the driver did not report it. The [thread token metrics](/reference/tasks#thread-token-metrics) define the fields. The latest error of each thread follows the table. A thread whose last turn in a [task copy](/cli/task/turn#a-task-that-runs-in-a-copy) asked a question then shows that question and its options; JSON output gives `questions`, each with its `request_id`, `id`, `header`, `question`, `options` and flags, and an empty list when the thread asked nothing. The thread's next turn answers it. The web task board shows the cumulative total. [`task:agent:show`](/cli/task/agent-show) reads one thread's conversation.
