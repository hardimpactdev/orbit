# `process:restart` Interactive Input Mode

[Back to `process:restart` technical contract.](1_process-restart.md)

This page describes how interactive input mode resolves `process:restart` input.

**Input mode:** Interactive.

## Selection

Use this input mode only when the process is attached to a TTY and `--json` is not present.

## Prompt Behavior

Prompt for missing required input in this order:

| Field | Prompt primitive | Notes |
| --- | --- | --- |
| `app` | Select | Show apps the caller is authorized to operate when app context is absent or ambiguous. |
| `workspace` | Select | Prompt only when workspace context is ambiguous and the operator chooses a workspace-scoped runtime action. |

`name` is optional. When `[name]` is omitted, interactive mode restarts all process definitions for the resolved app or workspace context; it does not prompt for a process by default.

Prompt validation runs as soon as the field needed for a decision is known.
