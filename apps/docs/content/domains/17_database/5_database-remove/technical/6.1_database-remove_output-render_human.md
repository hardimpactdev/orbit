# Human Renderer: `orbit database:remove`

[Back to `database:remove` technical contract.](1_database-remove.md)

## Primitive

None. Renderer prints one concise success or failure line and does not render a
table, prompt, spinner, or progress tree.

## Progress Tree

No progress tree. The command validates destructive consent before side effects
and then performs one local registry mutation or typed gateway request that is
expected to complete below one second. If slow external work is added later,
add a typed progress stream before rendering a progress tree.

## Human Strings

- Success: "Database connection '{slug}' removed."
- Failure: "Failed to remove database connection '{slug}'."
