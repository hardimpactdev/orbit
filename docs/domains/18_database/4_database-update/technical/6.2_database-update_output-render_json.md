# JSON Renderer: `orbit database:update`

[Back to `database:update` technical contract.](1_database-update.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

`success.data.connection` uses the database JSON entity defined in
[`../../README.md`](../../README.md#database-json-entity).

## Error Shape

The top-level envelope is either `success` or `error`.
