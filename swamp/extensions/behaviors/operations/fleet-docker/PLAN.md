# Native Docker migration

Every effect runs through official SSH package 2026.10.23.1 (model 2026.10.20.1), on 209 with the admitted target's pinned host key. The package's 300-second command default remains unchanged. Core workflow dependencies, fan-out, guards and explicit native resume own control flow. The cfgmgmt container schema does not cover migration of arbitrary existing Docker Config, HostConfig, networks, writable layers and metadata roots. Those existing validation and artifact rules remain in shipped Python. Managed Processes use the canonical native Process child.

Only the commit and archive fan-outs use concurrency 1. Both update the same protected inventory: two actions that load the same snapshot would otherwise overwrite each other's committed-image or archive map. Other steps inherit native concurrency defaults. This limit applies within a run. Per the Orchestrator's Boundary decisions item 1, admission uses the existing generic Operation lock_key hold, docker_migrate:node:<id>. Terminal projection releases it. No host lock or custom locking is added.

The protected inventory contains private unmanaged-container configuration. It stays on the admitted host; native outputs contain only names, IDs, versions and health. Gateway Process environment copies use the existing process-parent namespace and canonical Process installer. No new credential source, token, transport, supervisor, timeout or reader is added.

Readiness and health are single observations. Separate native start and stop steps probe one originally-running unmanaged layer; an approved fallback can follow a start refusal. A failure leaves the captured workload for inspection. Resume the original run from its failed action with the same input and source; do not treat a lost result as no effect or submit overlapping migrations. The native fixture covers lost package acknowledgement and recovery; disposable filesystem tests cover inventory privacy, package refusals, metadata, fallback and volume preservation. No real engine, Incus or fleet canary is claimed.
