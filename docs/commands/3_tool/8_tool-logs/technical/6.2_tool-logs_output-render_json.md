# JSON Renderer: `orbit tool-logs`

[Back to `tool-logs` technical contract.](1_tool-logs.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "logs": {
        "tool": "redis",
        "node": "app-1",
        "lines": [
          { "message": "..." }
        ]
      }
    },
    "meta": {}
  }
}
```

`success.data.logs.lines` is always an array of objects, not bare strings.
Finite reads use `success.meta={}`.

`--follow --json` is forbidden until Orbit defines a stable streaming JSON
frame contract. When both flags are present, the command fails before opening a
stream with `error.code=validation_failed` and `error.meta.field=json`.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Required input is missing or invalid.",
    "meta": {
      "field": "tool"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `tool.not_found`, `tool.unsupported_action`, `tool.remote_action_failed` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.meta` | object | Field, target, caller, or remote-action context for automation. |

Missing target in JSON mode returns:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A node or app target is required. Provide --node, --app, or configure node:default.",
    "meta": {
      "fields": ["target"]
    }
  }
}
```

When `--app` and `--node` are both supplied but resolve to different app nodes,
the command returns:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Invalid value for --app: 'docs'. App is not owned by the selected node.",
    "meta": {
      "field": "app",
      "value": "docs",
      "node": "app-2",
      "resolved_node": "app-1",
      "reason": "target_mismatch"
    }
  }
}
```
