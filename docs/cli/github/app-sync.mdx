---

```bash
orbit github:app:sync [--idempotency-key=KEY] [--json]
orbit operation:show OPERATION_ID
```

Reuse the same key after an uncertain admission. Swamp reads installations using a short-lived App JWT minted by the Gateway; the private signing key stays on the Gateway.
