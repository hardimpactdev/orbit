## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

Render before gateway and public network reads begin.

```text
┌ Verifying Instance Analytics
○ Read analytics binding and route intent
○ Resolve public DNS
○ Verify TLS and tracking script
○ Verify dashboard remains private
└ Working...
```

## Result Render

```text
verification:
  project: docs
  instance: production
  serving_node: app-prod-1
  ready: true
  hosts:
    - host: analytics.docs.example.com
      route_intent: registered
      dns: ready
      tls: ready
      script: ready (200)
      dashboard: not_exposed (404)
      event: not_run
      plausible_site: unchecked
      ready: true
```

Incomplete readiness renders the same facts, explains that no state was
changed, and exits `1`.
