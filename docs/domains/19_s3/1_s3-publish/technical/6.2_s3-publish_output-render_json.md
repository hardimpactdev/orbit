# JSON Renderer: `orbit s3:publish`

[Back to `s3:publish` technical contract.](1_s3-publish.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "s3": {
        "node": "storage-1",
        "private_endpoint": "https://s3.orbit",
        "public_endpoints": ["https://s3.example.com"],
        "backend_pool": ["http://storage-1.s3.orbit:9000"],
        "credentials_ref": {
          "tool": "rustfs",
          "node": "storage-1"
        }
      }
    },
    "meta": {
      "host": "s3.example.com",
      "action": "published",
      "already_published": false
    }
  }
}
```

`success.meta.action` is `published` or `updated`. Idempotent no-op
publication returns `success.meta.action=published` and
`success.meta.already_published=true`.

## Error Shapes

### Active S3 node required

```json
{
  "error": {
    "code": "validation_failed",
    "message": "An active s3 role node is required to publish an S3 host.",
    "meta": {
      "field": "node",
      "required_role": "s3"
    }
  }
}
```

### Active ingress required

```json
{
  "error": {
    "code": "validation_failed",
    "message": "An active ingress role is required to publish an S3 host.",
    "meta": {
      "field": "ingress",
      "required_role": "ingress"
    }
  }
}
```

### Active router required

```json
{
  "error": {
    "code": "validation_failed",
    "message": "An active router role is required for S3 routing.",
    "meta": {
      "field": "router",
      "required_role": "router"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.s3.node` | string | Selected active s3 node. |
| `success.data.s3.private_endpoint` | string | Stable private endpoint, always `https://s3.orbit`. |
| `success.data.s3.public_endpoints` | string[] | Public S3 HTTPS endpoints after publication. |
| `success.data.s3.backend_pool` | string[] | Router-owned RustFS backend URLs. |
| `success.data.s3.credentials_ref` | object | Tool row that owns service-level credentials. |
| `success.meta.host` | string | Published host. |
| `success.meta.action` | `published`, `updated` | Command outcome. |
| `success.meta.already_published` | boolean | Whether the host was already published before the command ran. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `proxy.domain_conflict`, `s3.publish_failed` | Stable command failure code. |
