# Non-Interactive Input Mode: `orbit cf-cache:flush`

[Back to `cf-cache:flush` technical contract.](1_cf-cache-flush.md)

**Input mode:** Non-interactive.

## Selection

Use this input mode without a TTY or when `--json` is present.
`--json` forces non-interactive input mode.

## Prompt Behavior

Never render prompts. Missing `--zone` fails before side effects with
`error.code=validation_failed` and `error.meta.field=zone`.
