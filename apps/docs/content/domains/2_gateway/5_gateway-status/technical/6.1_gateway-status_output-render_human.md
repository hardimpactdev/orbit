# Human Renderer: `orbit gateway:status`

[Back to `gateway:status` technical contract.](1_gateway-status.md)

This page describes the human-rendered terminal output for `gateway:status`.

**Renderer:** Human renderer.

## Primitive

None. The command renders a key-value table of the gateway status fields using
the standard table output. No progress tree is required because the command
issues a single synchronous HTTP request that completes in under one second
under normal network conditions.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered. The command issues a single synchronous HTTP
request and renders the result inline.

## Success Output

Human output renders the `gateway` field from the `/api/status` response as a
key-value table. Fields such as `status` and `version` are displayed. Any
top-level fields in the API response outside `gateway` are not shown in human
output.

When `gateway` is absent from the API response, the full response is rendered.

## Failure Output

Human-rendered failures show:

- the error code;
- a human-readable message;
- no JSON envelope.

Gateway WireGuard unreachable:

```text
gateway_unreachable_wireguard: WireGuard route to the gateway is not established.
```

Gateway unavailable (HTTP error):

```text
gateway_unavailable: Gateway request failed (HTTP 503) Body: <excerpt>
```
