# JSON Renderer: `orbit app:websocket disable`

[Back to `app:websocket disable` technical contract.](1_app-websocket-disable.md)

This page describes the JSON-rendered output for `app:websocket disable`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` selects non-interactive JSON output only; it does not select an app
instance or imply consent.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The binding object is returned under `success.data.binding`.

## Success Shape

```json
{
  "success": {
    "data": {
      "app": {
        "name": "docs",
        "repository": null,
        "runtime": "php",
        "runtime_config": {"proxy_transport": "http"},
        "php_version": "8.5",
        "dependency_audit_status": "unknown",
        "dependency_warning_count": 0,
        "dependency_danger_count": 0,
        "last_dependency_audit_at": null
      },
      "app_instance": "production",
      "serving_node": "app-prod-1",
      "binding": {
        "internal_host": "websocket.orbit",
        "public_hosts": [],
        "allowed_origins": ["https://docs.example.com"]
      }
    },
    "meta": []
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `binding` | object | Resulting WebSocket binding state after the disable operation. |
| `app` | object | Canonical logical app entity without placement fields. |
| `app_instance` | string | Concrete selected instance name. |
| `serving_node` | string | Selected instance's serving node and authorization boundary. |
| `binding.internal_host` | string | WireGuard-internal WebSocket service hostname. Always `websocket.orbit`. |
| `binding.public_hosts` | array | Always `[]` after a successful disable. |
| `binding.allowed_origins` | array | Preserved origins from the binding; not cleared by disable. |

## Error Shapes

### App not found

```json
{
  "error": {
    "code": "app.not_found",
    "message": "App instance 'docs.production' not found.",
    "meta": {
      "app_instance": "docs.production"
    }
  }
}
```

A bare selector with zero or multiple eligible instances returns
`validation_failed` with `error.meta.reason=app_instance_required`.

### Validation failed

```json
{
  "error": {
    "code": "validation_failed",
    "message": "App is required.",
    "meta": {
      "field": "app"
    }
  }
}
```

### WebSocket binding missing

```json
{
  "error": {
    "code": "websocket.binding_missing",
    "message": "App instance 'docs.production' does not have a websocket binding.",
    "meta": {
      "app": "docs",
      "app_instance": "production",
      "serving_node": "app-prod-1"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'app:write' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "app:write",
      "app_instance": "docs.production",
      "serving_node": "app-prod-1"
    }
  }
}
```
