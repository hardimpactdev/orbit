The `github` family manages the Gateway's own GitHub App. Orbit uses the App to read private `github.com` repositories and to publish task pull requests. The [GitHub App reference](/reference/github-app) explains registration, installations, and the short-lived tokens.

## Commands

| Command | Result |
| --- | --- |
| [`github:app:install`](#orbit-githubappinstall) | Register the App when the Gateway has none, then install it on a GitHub account or organization. |
| [`github:app:sync`](#orbit-githubappsync) | Admit a native refresh of App installation observations. |
| [`github:app:show`](#orbit-githubappshow) | Show the App and the accounts that installed it. |
| [`github:app:destroy`](#orbit-githubappdestroy) | Delete the App's stored credentials from the Gateway. |

Every command accepts `--json`.

## orbit github:app:install

Open GitHub in a browser to register the App, install it, or both.

```bash
orbit github:app:install [--name=NAME] [--owner=ORGANIZATION] [--json]
```

| Option | Default | Meaning |
| --- | --- | --- |
| `--name=NAME` | prompt, `orbit` | Proposed App name for a first registration. GitHub asks for another name in the browser when the name is taken. |
| `--owner=ORGANIZATION` | your personal account | GitHub organization that owns the App registration. It applies to a first registration only. |

```bash
orbit github:app:install
orbit github:app:install --name=orbit-acme --owner=acme
```

The CLI prints each URL and opens it in a browser when it can. The browser must reach the Gateway's private HTTPS address, because GitHub redirects to it after registration. On a machine without a browser, open the printed URL on a machine that is on the Orbit VPN.

On a Gateway without an App, confirm registration on GitHub. The callback returns the native registration Operation with HTTP 202. After that Operation succeeds, run `github:app:install` again to open the installation page. Choose the account and repositories in the browser. The CLI returns `pending` without polling or claiming that installation has completed.

## orbit github:app:sync

Refresh installation observations in one native Swamp workflow. The command returns its queued Operation without waiting.

```bash
orbit github:app:sync [--idempotency-key=KEY] [--json]
orbit operation:show OPERATION_ID
```

Reuse the same key after an uncertain admission. Swamp reads installations using a short-lived App JWT minted by the Gateway; the private signing key stays on the Gateway.

## orbit github:app:show

Show the App name, slug, App ID, owner, GitHub URL, and one row for each installation.

```bash
orbit github:app:show [--json]
```

| Installation field | Meaning |
| --- | --- |
| `account` | GitHub account or organization that installed the App. |
| `type` | `user` or `organization`. |
| `repositories` | `all` or `selected`. |
| `suspended` | Whether the account suspended the installation. |

The Gateway returns stored public state. `status` distinguishes registered, pending, failed and cancelled registration. `installations_status` is unknown, current, or stale, and `observed_at` preserves the native observation time. Run `github:app:sync` to refresh it. The result never contains the private key or a token.

| Error code | Meaning |
| --- | --- |
| `github.app_missing` | The Gateway has no GitHub App. |
| `github.unavailable` | The Gateway could not reach `api.github.com`, or GitHub refused the App credential. |

## orbit github:app:destroy

Delete the App ID, slug, and private key from the Gateway. Orbit then reads every repository without a credential and cannot publish task pull requests.

```bash
orbit github:app:destroy [--yes] [--json]
```

| Option | Meaning |
| --- | --- |
| `--yes` | Confirm without a prompt. Required for noninteractive and JSON calls. |

The command prints the GitHub page where you delete the App registration. GitHub offers no API for that step.

| Error code | Meaning |
| --- | --- |
| `github.app_missing` | The Gateway has no GitHub App. |
| `input.confirmation_required` | `--yes` is missing with `--json` or without a terminal. |
| `input.cancelled` | The prompt was declined. |
