# Non-Interactive Input Mode: `orbit tool-restart`

[Back to `tool-restart` technical contract.](1_tool-restart.md)

**Input mode:** Non-interactive.

This contract applies without a TTY or when `--json` is present. `--json`
forces non-interactive input mode.

## Resolution Rules

No prompts are rendered. All required fields must be supplied by arguments,
options, local defaults, or fallback to self known by the gateway.

When `tool` is missing, the command fails before side effects with
`validation_failed` and `meta.field=tool`.

When no `--node`, `--app`, local `node:default`, or fallback to self known by the gateway
resolves a target, the command fails before side effects with
`validation_failed` and `meta.fields=["target"]`.
