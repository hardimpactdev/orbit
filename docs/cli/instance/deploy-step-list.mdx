---
title: "orbit instance:deploy-step:list"
sidebarTitle: "instance:deploy-step:list"
description: "List the deploy steps of a production Instance in phase and placement order."
---

```bash
orbit instance:deploy-step:list <instance> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `instance` | yes | Numeric Instance ID of a production Instance. |

| Option | Default | Meaning |
| --- | --- | --- |
| `--json` | off | Print the steps as JSON. |

```bash
orbit instance:deploy-step:list 15
```

In a terminal, an omitted Instance is chosen from an interactive list. A noninteractive or `--json` call without it is refused with `instance.id_invalid` and sends no request, and so is a value that is not a positive integer.

The list shows what the Gateway stored for the Instance. It does not contact any Node, so it works while a Node is unreachable. Each production Instance stores its own steps. They run during [`instance:deploy`](/cli/instance/deploy), the `before_activation` steps first, in the order shown. The Instance must be a production Instance that is source-resolved or active, with a valid deployment branch; otherwise the command is refused with `deployment_config.unavailable`.

| Column | Meaning |
| --- | --- |
| `NAME` | The step name. |
| `PHASE` | `before_activation` or `after_activation`. |
| `COMMAND` | The shell command. A long command wraps and is never cut, and the lines of a multiline command are kept. |
| `TIMEOUT (SECONDS)` | The step's timeout in seconds. |

An empty list says `No deploy steps found.`. The human output ends with the request ID. With `--json`, stdout holds `{ steps, request_id }`: the steps in the same order, each with `name`, `phase`, `command` and `timeout_seconds`, and an empty `steps` list when there are none. See [Production deploy steps](/reference/deployments#production-deploy-steps) for the limits and the execution contract.

## Errors

| Code | Meaning |
| --- | --- |
| `instance.id_invalid` | The Instance is missing in a call that cannot prompt, or is not a positive integer. |
| `input.cancelled` | You cancelled the Instance list. |
| `deployment_config.unavailable` | The Instance is not a production Instance that is source-resolved or active with a valid branch. |
| `http.404` | The Instance is unknown. |
| `node_access.required` | The caller has no access grant to the Instance's Node. |
