# `process:add` Interactive Input Mode

[Back to `process:add` technical contract.](1_process-add.md)

This page describes how interactive input mode resolves `process:add` input.

**Input mode:** Interactive.

## Selection

Use this input mode only when the process is attached to a TTY and `--json` is not present.

## Prompt Behavior

Prompt for missing required input in this order:

| Field | Prompt primitive | Notes |
| --- | --- | --- |
| `app` | Datatable | Show apps the caller is authorized to manage when app context is absent or ambiguous. |
| `name` | Text | Validate slug syntax and uniqueness before asking for later fields. |
| `command` | Text | Require a non-empty command string. |
| `restart_policy` | Select | Default to `never`. |
| `crash_notification` | Select | Default to `none`. |

Prompt validation runs as soon as the field needed for a decision is known. After a blocker is shown, the operator can change the current prompt value or cancel the flow.
