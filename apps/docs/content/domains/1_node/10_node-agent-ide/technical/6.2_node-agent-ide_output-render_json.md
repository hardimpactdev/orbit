# JSON Renderer: `orbit node:agent-ide [name] [agent_ide]`

[Back to `node:agent-ide` technical contract.](1_node-agent-ide.md)

This page describes the JSON-rendered output for `node:agent-ide`.

**Renderer:** JSON renderer.

## Primitive

None. JSON renderer emits the standard envelope only.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](5.2_node-agent-ide_input-mode_non-interactive.md), even
when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

### Adapter set to a new value

```json
{
  "success": {
    "data": {
      "name": "app-1",
      "agent_ide": {
        "adapter": "opencode",
        "source": "node"
      },
      "action": "set"
    }
  }
}
```

### Adapter cleared with `none`

```json
{
  "success": {
    "data": {
      "name": "app-1",
      "agent_ide": {
        "adapter": null,
        "source": "default"
      },
      "action": "set"
    }
  }
}
```

### No-op convergence (already matching)

```json
{
  "success": {
    "data": {
      "name": "app-1",
      "agent_ide": {
        "adapter": "opencode",
        "source": "node"
      },
      "action": "converged"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `name` | string | The target node name. |
| `agent_ide.adapter` | string \| null | The configured adapter name, or `null` when cleared with `none`. |
| `agent_ide.source` | string | `"node"` when an explicit non-`none` adapter is set; `"default"` when cleared with `none`. |
| `action` | string | `"set"` when the value changed; `"converged"` when the value already matched. |

## Error Shapes

Structured gateway failures keep the gateway's original `error.code`,
`error.message`, and `error.meta`. The CLI preserves
`authorization_failed`, `node.not_found`, and `node.unsupported_adapter` from
the gateway response; it uses `gateway_unavailable` only for unstructured
transport failures such as an unreachable gateway or an HTTP failure without a
structured Orbit error envelope.

### Missing required input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Node name is required.",
    "meta": {
      "field": "name"
    }
  }
}
```

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Agent IDE adapter is required.",
    "meta": {
      "field": "agent_ide"
    }
  }
}
```

### Node not found

```json
{
  "error": {
    "code": "node.not_found",
    "message": "Node 'app-1' not found.",
    "meta": {
      "name": "app-1"
    }
  }
}
```

### Unsupported adapter

```json
{
  "error": {
    "code": "node.unsupported_adapter",
    "message": "Adapter 'unknown-ide' is not supported.",
    "meta": {
      "adapter": "unknown-ide"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to update node configuration.",
    "meta": []
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'node:agent' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "node:agent",
      "serving_node": "app-1"
    }
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `action` | `set`, `converged` |
| `agent_ide.source` | `node`, `default` |
| `error.code` | `validation_failed`, `node.not_found`, `node.unsupported_adapter`, `gateway_unavailable`, `authorization_failed` |

| Error code | Metadata |
| --- | --- |
| `validation_failed` | `field` |
| `node.not_found` | `name` |
| `node.unsupported_adapter` | `adapter` |
| `gateway_unavailable` | none required |
| `authorization_failed` | Gateway-provided authorization context, usually `reason`, `missing_permission`, and `serving_node`. |

The `error.code` values listed here are exhaustive for `node:agent-ide`. Add a
new value to this renderer contract before implementing another JSON failure
code.
