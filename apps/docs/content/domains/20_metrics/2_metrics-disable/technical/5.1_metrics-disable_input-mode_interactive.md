# Interactive Input Mode: `orbit metrics:disable`

[Back to `metrics:disable` technical contract.](1_metrics-disable.md)

**Input mode:** Interactive.

## Mode Selection

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Flow

Prompts render after `--node` resolves and before any gateway role-removal
request.

| Prompt ID | Primitive | Rendered when | Validation |
| --- | --- | --- | --- |
| `metrics.disable_confirm` | `confirm` | `--force` is absent. | Explicit destructive consent. |

`--force` bypasses the confirmation prompt after the target node is resolved.
Rejected confirmation fails before side effects with
`error.code=validation_failed`, `error.meta.field=force`, and
`error.meta.reason=destructive_consent_required`.

Invalid prompt answers re-prompt until the value is valid or the operator
aborts. Abort fails before side effects.
