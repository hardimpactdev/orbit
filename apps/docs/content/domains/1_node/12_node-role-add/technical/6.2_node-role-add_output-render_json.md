# JSON Renderer: `orbit node role:add`

[Back to `node role:add` technical contract.](1_node-role-add.md)

## Primitive

None. JSON renderer emits the standard envelope only.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Top-level envelopes:
- Success: `{ "success": { ... } }`
- Error: `{ "error": { ... } }`

## Success Shape

`success.data.node` and `success.data.assignment`.

## Error Codes

- `validation_failed`
- `node.not_found`
- `gateway_unavailable`
- `authorization_failed`
