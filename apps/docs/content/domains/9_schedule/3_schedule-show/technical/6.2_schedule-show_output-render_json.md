# JSON Renderer: `orbit schedule:show`

[Back to `schedule:show` technical contract.](1_schedule-show.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
  "success": {
    "data": {
      "schedule": {
        "name": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs",
          "node": "app-1"
        },
        "interval": "every minute",
        "timezone": "Europe/Amsterdam",
        "execution": {
          "type": "command",
          "value": "php artisan schedule:run"
        },
        "enabled": true,
        "status": "expected",
        "last_run": {
          "id": 12,
          "status": "completed",
          "exit_code": 0,
          "started_at": "2026-05-02T08:00:00Z",

```

## Error Shape

```json
{
  "error": {
    "code": "schedule.not_found",
    "message": "Schedule 'laravel-scheduler' was not found.",
    "meta": {
      "name": "laravel-scheduler",
      "app": "docs",
      "node": null
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.schedule` | object | Schedule entity defined in [`9_schedule/README.md`](../../README.md#schedule-json-entity). |
| `success.meta.app` | string \| null | Applied app filter. |
| `success.meta.node` | string \| null | Applied node filter. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `schedule.not_found` | Stable command failure code. |
| `error.meta` | object | Schedule name, field, scope, caller, or authorization context for automation. |
