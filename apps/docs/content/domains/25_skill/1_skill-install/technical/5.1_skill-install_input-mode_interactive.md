# Interactive Input Mode: `orbit skill:install`

[Back to `skill:install` technical contract.](1_skill-install.md)

**Input mode:** Interactive.

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Behavior

No prompt is rendered for target replacement. Existing target replacement
requires explicit `--force`; if the target exists and `--force` is absent, the
command exits before side effects with `validation_failed`,
`meta.field=target`, and `meta.reason=target_exists`.

The command never prompts to infer a provider, choose a target path, or confirm
provider defaults.

## Primitive References

None. `skill:install` has no interactive prompt primitive.
