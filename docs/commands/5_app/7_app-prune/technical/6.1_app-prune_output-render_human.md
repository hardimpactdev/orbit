This file owns the human output contract for `app:prune`.

## Progress Tree

The human renderer uses a step tree grouped by workspace.

```text
Pruning workspaces for 'my-app' (control node)
|
+- [Discovery] Querying agent IDE adapters... done.
|  Found 2 stale workspaces.
|
+- [Workspace] feature-docs
|  +- [Processes] Stopping artifacts... done.
|  +- [Proxy] Removing route feature-docs.my-app.orbit.test... done.
|  +- [Filesystem] Removing path /home/orbit/apps/my-app/workspaces/feature-docs... done.
|  +- [Database] Skipped (manual cleanup; ownership not tracked).
|  +- [Registry] Removing record... done.
|
+- [Workspace] old-experiment
   +- [Processes] Stopping artifacts... done.
   +- [Proxy] Removing route old-experiment.my-app.orbit.test... done.
   +- [Filesystem] Removing path /home/orbit/apps/my-app/workspaces/old-experiment... done.
   +- [Database] Skipped (manual cleanup; ownership not tracked).
   +- [Registry] Removing record... done.

Pruning complete. 2 workspaces removed.
```

If `--dry-run` is present:

```text
Pruning workspaces for 'my-app' (control node) [DRY RUN]
|
+- [Discovery] Querying agent IDE adapters... done.
|  Found 2 stale workspaces.
|
+- [Workspace] feature-docs (would remove)
|  +- [Database] Skipped (manual cleanup; ownership not tracked).
|
+- [Workspace] old-experiment (would remove)
   +- [Database] Skipped (manual cleanup; ownership not tracked).

Dry run complete. No side effects performed.
```

## Failure Reporting

- **Validation Errors:** Rendered as standard Laravel Prompts error messages.
- **Partial Success:**
  ```text
  ! [Workspace] feature-docs: Partial removal.
    - [Filesystem] Error: Permission denied.
  ```
