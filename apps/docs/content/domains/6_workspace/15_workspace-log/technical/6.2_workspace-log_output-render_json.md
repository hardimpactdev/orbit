# JSON Renderer: `orbit workspace:log [target]`

[Back to `workspace:log` technical contract.](1_workspace-log.md)

This page describes the JSON-rendered output for `workspace:log`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces non-interactive
input mode. JSON output is bounded and cannot be combined with `--follow`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the resolved workspace target, serving node, fixed logical
path, requested line count, file existence, and bounded log lines.

## Success Example

```json
{
  "success": {
    "data": {
      "target": {
        "type": "workspace",
        "app": "docs",
        "instance": "development",
        "workspace": "feature-docs",
        "selector": "feature-docs"
      },
      "node": "app-dev-1",
      "path": "storage/logs/laravel.log",
      "lines_requested": 100,
      "file_exists": true,
      "lines": [
        "[2026-04-30 12:00:00] local.INFO: Workspace ready"
      ]
    },
    "meta": []
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "validation_failed",
    "message": "--json cannot be combined with --follow.",
    "meta": {
      "field": "json"
    }
  }
}
```

## Authorization Error

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'workspace:read' on 'app-dev-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "workspace:read",
      "serving_node": "app-dev-1"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: target is missing, invalid, or ambiguous in non-interactive
  input mode; `--instance` is required and missing; `--lines` is invalid;
  `--json` is combined with `--follow`; or `--node` does not match the serving
  node. Target failures use `error.meta.field=target`.
- `authorization_failed`: caller lacks `workspace:read` on the resolved serving node.
- `workspace.not_found`: the resolved workspace does not exist or is not visible.
- `application_log.read_failed`: the gateway cannot read the fixed application
  log from the serving node.
- `gateway_unavailable`: the CLI cannot reach the Orbit gateway.
