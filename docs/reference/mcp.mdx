# MCP server

The Gateway serves a Model Context Protocol (MCP) server so AI agents can operate Orbit directly without shelling out to the CLI. Every tool call dispatches through Laravel's HTTP kernel as the matching API request, enforcing the same WireGuard identity, access grants, validation, redaction, and [Activity](/cli/activity) logging.

## Endpoints

Both endpoints speak streamable HTTP and expose the same operator catalogue, protected by [Browser access to the Gateway](/reference/browser-access):

| Endpoint | Listed tools | Use when |
| --- | --- | --- |
| `https://gateway.orbit/mcp` | Full operator catalogue on one page (limit 500) | Client loads tool definitions on demand or has room for the full list |
| `https://gateway.orbit/mcp/search` | `search_tools` and `execute_tools` | Client loads every listed tool into context |

JSON-RPC request envelopes are limited to 15 MiB (`15,728,640` bytes), checked after active-peer authorization (HTTP 413 on overflow) so full 10 MiB [Project Document uploads](/reference/project-documents#content-and-versions) fit.

`search_tools` returns matching tool names and input schemas (an empty query browses the catalogue). `execute_tools` runs up to 25 calls in order (`{"calls": [{"name": "...", "arguments": {...}}]}`), preserves empty JSON objects (`{}`), stops on the first error, and caps combined output at 65,536 bytes.

Each MCP HTTP request shares one 570-second command deadline (under the 600-second PHP-FPM limit) with a 20-second cleanup reserve. Any `execute_tools` call starting after the forward deadline expires returns `command.deadline_exceeded` (status 504) and stops the batch.

## Identity and access

Callers are identified by their WireGuard IP address with no token or OAuth login:

- Unknown or inactive peers receive HTTP `403 peer.identity_unknown` before listing tools.
- `gateway-desired-fleet-state` is open to any active WireGuard peer without an access grant.
- All other tools enforce standard [Node access grants](/cli/node/access-add) (`403 node_access.required`).
- Clients must trust the Orbit root CA (via `orbit gateway:trust` or `NODE_EXTRA_CA_CERTS` for Node.js clients).

## Tool list changes

The server declares `tools.listChanged: false` and never pushes list-change notifications or kills sessions when a release or extension toggle changes the catalogue:

- Calls to active tools continue working normally.
- Calls to removed or renamed tools return HTTP 400 with JSON-RPC error `-32602` (`Tool [name] not found`), prompting the client to reconnect or re-list tools.
- Calls to tools belonging to a disabled extension return `isError: true` with `status: 409` and `error.code: extension.disabled` (both directly and inside `execute_tools`).

`/mcp/search` always searches the live catalogue without reconnecting.

## Tools

Tool names match the [API reference](/api/overview) operation IDs (`<family>-<verb>`, such as `node-list`, `instance-show`, `process-restart`). Path, query, header (including `Idempotency-Key`), and JSON body parameters flatten into one input object. For example, `instance-rename` maps `POST /api/v1/instances/{instance}/rename`: Send `instance` and at least one of `branch` or `domain`. `GET` tools are marked read-only, and `x-orbit-destructive` operations (`DELETE` routes plus `instance-unregister`) are marked destructive.

Successful calls return the API JSON as text. API errors return a normal MCP response with `isError: true` and the error envelope plus HTTP status:

```json
{"isError": true, "content": [{"type": "text", "text": "{\"status\":422,\"error\":{\"code\":\"validation.failed\",\"message\":\"...\"}}"}]}
```

Machine callbacks, streaming endpoints, browser pages, direct Swamp internal endpoints (`operation-direct-*`), Conn launch HTTP endpoints, and internal WebSocket registry hooks are excluded from the catalogue in `bin/mcp-tools`. Log tools (`instance-logs`, `process-logs`, `schedule-logs`) and `task-swamp-runs` return bounded snapshots rather than streams.

### Operations

Operation-starting tools (`x-orbit-operation: start`, such as `instance-deploy` and `instance-rollback`) return immediately without streaming:

```json
{
  "operation": { "id": 42, "kind": "instance.deploy", "status": "queued", "sequence": 1 },
  "poll": { "tool": "operation-show", "after_seconds": 2 },
  "meta": { "request_id": "..." }
}
```

Poll `operation-show` after `poll.after_seconds` (then `poll_after_seconds` on each reply) until `status` is terminal (`succeeded`, `failed`, or `cancelled`). Use `operation-list` (with cursor pagination) to recover open Operations after a context reset, and `operation-cancel` to stop one.

## Connect a client

Add the HTTP MCP server in Claude Code from any WireGuard peer that trusts the Orbit CA:

```bash
claude mcp add --transport http orbit https://gateway.orbit/mcp
```

For clients configured via JSON that prefer the compact search endpoint:

```json
{"mcpServers": {"orbit": {"type": "http", "url": "https://gateway.orbit/mcp/search"}}}
```

## Keep the catalogue current

`bin/build-api` runs `bin/docs-openapi` and `bin/mcp-tools` to regenerate `docs/openapi.json` and `apps/gateway/resources/mcp/tools.json` (preserving `oneOf`/`anyOf` input variants, `x-orbit-extension`, `x-orbit-bodyless`, `x-orbit-destructive`, and empty object schemas `{}`).

```bash
bin/build-api
```

CI runs `bin/mcp-tools --check` and verifies every public API route has a matching tool.

## Why it works this way

Generating tools from `docs/openapi.json` keeps over a hundred endpoints in sync with validation and descriptions automatically. Dispatching through Laravel's HTTP kernel reuses WireGuard identity, grants, redaction, and Activity without duplicating security logic, while keeping the server stateless avoids tying up PHP-FPM workers with long-lived SSE notification streams.
