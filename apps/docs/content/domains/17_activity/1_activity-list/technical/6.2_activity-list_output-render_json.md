# JSON Renderer: `orbit activity:list`

[Back to `activity:list` technical contract.](1_activity-list.md)

This page describes the JSON-rendered output for `activity:list`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](../../../README.md#invocation-model), even when
the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Validation failures, gateway reachability failures, and authorization failures
must all use this envelope.

## Success Shape

```json
{
  "success": {
    "data": {
      "activities": [
        {
          "id": 42,
          "occurred_at": "2026-05-02T08:30:00+00:00",
          "correlation_id": "9f7307e8-38b2-45b8-9b94-cfc341456b85",
          "type": "workspace.created",
          "effect": "write",
          "subject": {
            "type": "workspace",
            "name": "feature-docs"
          },
          "actor": {
            "node": "client-1"
          },
          "command": "workspace:setup",
          "summary": "Workspace feature-docs was created."
        }
      ]
    },
    "meta": {
      "filters": {
        "app": null,
        "node": null,
        "effect": null,
        "correlation": null
      },
      "limit": 25,
      "count": 1,
      "has_more": false
    }
  }
}
```

Empty results use the same shape with `activities: []`, `count: 0`, and
`has_more: false`.

| Field | Type | Meaning |
| --- | --- | --- |
| `activities[]` | array | Activity entries visible to the caller, newest first. |
| `activities[].id` | integer | Stable gateway activity id. |
| `activities[].occurred_at` | string | ISO-8601 timestamp recorded by the gateway. |
| `activities[].correlation_id` | string | UUID shared by records from the same operation. |
| `activities[].type` | string | Stable activity type, such as `workspace.created`. |
| `activities[].effect` | string | Recorded effect of the activity entry. |
| `activities[].subject` | object | Recorded subject reference for the activity entry. |
| `activities[].actor` | object | Gateway-known node identity that caused the activity when available. |
| `activities[].command` | string \| null | CLI command name when the entry came from a command. |
| `activities[].summary` | string | Human-readable summary. Automation must not parse it. |
| `filters` | object | Normalized filter values used for the query. |
| `limit` | integer | Maximum number of requested rows. |
| `count` | integer | Number of returned rows. |
| `has_more` | boolean | Whether more visible rows match the filters beyond the limit. |

## Error Shapes

### Validation failed

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Invalid activity filter.",
    "meta": {
      "field": "limit",
      "reason": "out_of_range"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to list activity.",
    "meta": {}
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized to read gateway activity history.",
    "meta": {}
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `activities[].effect` | `read`, `write`, `destructive` |
| `has_more` | `true`, `false` |
| `error.meta.reason` | `missing`, `invalid`, `out_of_range` |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed` |

The `error.code` values listed here are exhaustive for `activity:list`. Add a
new value to this renderer contract before implementing another JSON failure
code.
