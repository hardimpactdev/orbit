# JSON Renderer: `orbit app:websocket disable`

[Back to `app:websocket disable` technical contract.](1_app-websocket-disable.md)

This page describes the JSON-rendered output for `app:websocket disable`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The binding object is returned under `success.data.binding`.

## Success Shape

```json
{
  "success": {
    "data": {
      "binding": {
        "app": "docs",
        "internal_host": "websocket.orbit",
        "public_hosts": [],
        "allowed_origins": ["https://docs.example.com"]
      }
    },
    "meta": []
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `binding` | object | Resulting WebSocket binding state after the disable operation. |
| `binding.app` | string | App identity slug. |
| `binding.internal_host` | string | WireGuard-internal WebSocket service hostname. Always `websocket.orbit`. |
| `binding.public_hosts` | array | Always `[]` after a successful disable. |
| `binding.allowed_origins` | array | Preserved origins from the binding; not cleared by disable. |

## Error Shapes

### App not found

```json
{
  "error": {
    "code": "app.not_found",
    "message": "App 'docs' not found.",
    "meta": {
      "app": "docs"
    }
  }
}
```

### Validation failed

```json
{
  "error": {
    "code": "validation_failed",
    "message": "App is required.",
    "meta": {
      "field": "app"
    }
  }
}
```

### WebSocket binding missing

```json
{
  "error": {
    "code": "websocket.binding_missing",
    "message": "App 'docs' does not have a websocket binding.",
    "meta": {
      "app": "docs"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'app:write' on 'app-1'.",
    "meta": {
      "missing_permission": "app:write",
      "serving_node": "app-1"
    }
  }
}
```
