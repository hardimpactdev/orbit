# Human Renderer: `orbit node role:list [node]`

[Back to `node role:list` technical contract.](1_node-role-list.md)

## Primitive

None. The human renderer uses a table because this is a fast read command.

## Progress Tree

No progress tree. This command is a local or gateway-forwarded read.

## Success Output

- Render a table with `ROLE`, `STATUS`, `SETTINGS`, `LAST ERROR`, and `CONVERGED AT`. Empty or missing cells render as `—` (em dash).
- If the node has no roles, render the empty state naming the node:

  ```text
  No role assignments found for node <node>.
  ```

## Failure Output

- Validation and lookup failures render plain prose errors.
