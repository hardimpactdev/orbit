# Human Renderer: `orbit process:restart [name]`

[Back to `process:restart` technical contract.](1_process-restart.md)

This page describes the human-rendered terminal output for `process:restart`.

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render the complete progress tree after input resolution and before side
effects begin. `process:restart` performs a remote runtime action.

```text
┌ Restarting Process
○ Resolve runtime unit
○ Stop runtime unit
○ Start runtime unit
○ Record process events
└ Working...
```

## Success Output

```text
Process 'vite' restarted for app 'docs'
```

For a workspace context:

```text
Process 'vite' restarted for workspace 'feature-docs'
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no
JSON envelope, and next-step guidance only when the operator can act on it.
