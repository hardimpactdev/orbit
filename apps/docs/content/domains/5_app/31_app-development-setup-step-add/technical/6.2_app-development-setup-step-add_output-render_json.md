# JSON output: `app-development-setup-step:add`

Success returns `success.data.step` with `id`, `app`, `order`,
`command`, and `timeout_seconds`. Failure returns the shared `error` envelope.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Primitive

None. JSON output is emitted as one machine-readable envelope.
