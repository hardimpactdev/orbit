# Human Renderer: `orbit tool-show`

[Back to `tool-show` technical contract.](1_tool-show.md)

**Renderer:** Human renderer.

## Primitive

- Detail: [Show detail](../../../../ux/commands/details/show-detail.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`tool-show` is a read-only detail command. Execution is expected to complete
below one second and does not perform slow external work. No progress tree is
rendered.

## Success Output

Human output presents the selected tool state using the show-detail primitive:

```text

┌  Tool: composer
│
├  Node       app-1
│
├  Expected   installed
│
├  Version    2.9.2
│
├  Managed    yes
│
└  Endpoints  —

```

Credential secrets are never rendered by `tool-show`.

The observed/live section renders only when `--live` was requested or the
gateway response includes a real observed value. Registry-only reads must not
print `Observed: (not observed)`.

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose error, and actionable recovery guidance when the operator can resolve the issue.
