# Technical Contract: `orbit app:register` (JSON Renderer)

This contract defines the **JSON renderer** for `app:register`.

[Back to the canonical contract.](1_app-register.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Envelope

```json
{
  "success": {
    "data": {
      "result": {
        "action": "registered"
      },
      "app": {
        "name": "docs",
        "node": "app-1",
        "environment": "development",
        "url": "https://docs.test",
        "path": "/home/orbit/apps/docs",
        "root": "public",
        "repository": null,
        "php_version": "8.5",
        "adopted": false
      }
    },
    "meta": {
      "node": "app-1",
      "warnings": []
    }
  }
}
```

### Fields

- `result.action`: One of `registered`, `adopted`, `converged`. Describes what
  this run did.
  - `registered` — first-time registration of a previously-known path that
    was not yet managed by Orbit.
  - `adopted` — first-time registration where the path existed on the node
    but was unmanaged. `app.adopted` is set to `true` for this run.
  - `converged` — idempotent re-application where no observable artifact change
    was needed. The durable `app.adopted` value is preserved across
    converged re-runs.
- `app`: The canonical app JSON entity defined in
  [`5_app/README.md`](../../README.md#app-json-entity). `app.adopted` is
  `true` once the path was adopted via registration and stays `true` on
  subsequent converged re-runs.
- `meta.warnings`: Structured non-fatal drift and retry handoffs. Each entry
  carries `code`, `family`, `message`, and `next_command`.

### Success with `proxy.domain_inactive` warning

```json
{
  "success": {
    "data": {
      "result": {
        "action": "registered"
      },
      "app": {
        "name": "docs",
        "node": "app-1",
        "environment": "production",
        "url": "https://docs.example.com",
        "path": "/home/docs/app",
        "root": "public",
        "repository": null,
        "php_version": "8.5",
        "adopted": false
      }
    },
    "meta": {
      "node": "app-1",
      "warnings": [
        {
          "code": "proxy.domain_inactive",
          "family": "proxy",
          "message": "Production domain 'docs.example.com' is not yet active. Retry with 'orbit app:register docs --domain=docs.example.com' once DNS has propagated.",
          "next_command": "app:register docs --domain=docs.example.com"
        }
      ]
    }
  }
}
```

## Error Envelope

### Path collision

Returned when the supplied `--path` on the resolved node is already owned by a
different registered app. Fails before any side effects.

```json
{
  "error": {
    "code": "app.path_collision",
    "message": "Path '/home/orbit/apps/docs' on node 'app-1' is already owned by app 'docs-legacy'.",
    "meta": {
      "path": "/home/orbit/apps/docs",
      "existing_app": "docs-legacy",
      "node": "app-1"
    }
  }
}
```

### Apply failure

```json
{
  "error": {
    "code": "app.enactment_failed",
    "message": "Failed to complete non-retryable app application on node 'app-1'.",
    "meta": {
      "step": "enact_runtime_artifacts",
      "node": "app-1",
      "reason": "Permission denied"
    }
  }
}
```

### Common Error Codes

| Code | Meaning |
| --- | --- |
| `validation_failed` | A supplied input failed gateway-side static validation (e.g. malformed `--domain`, unsupported `--php-version`, missing required field). `error.meta.field` names the offending input. |
| `app.path_collision` | The supplied `--path` on the resolved node is already owned by a different registered app. `error.meta.path`, `error.meta.existing_app`, `error.meta.node`. |
| `app.ineligible_node` | The caller may run `app:register`, but the resolved target node is not an active app node. |
| `app.ssh_failure` | The gateway could not connect to the target app node. |
| `app.enactment_failed` | Registry write succeeded but node-side execution failed in a way that cannot be retried through convergence. Retryable PHP-FPM or runtime artifact drift is reported as `success.meta.warnings[]` with singular `app.*` product codes and `family: "app"` instead. `error.meta.step`, `error.meta.node`, `error.meta.reason`. |
| `caller_role_not_allowed` | The gateway-identified caller role is not permitted to invoke `app:register` (e.g. an app-node peer). |
| `authorization_failed` | The caller is not authorized to inspect or manage the target app or app node. |

### Common Warning Codes

Non-fatal drift is reported in `success.meta.warnings[]`. Each warning carries
`code`, `family`, `message`, and `next_command`.

| Code | Family | Meaning |
| --- | --- | --- |
| `proxy.domain_inactive` | `proxy` | The production domain is not yet active because DNS or TLS prerequisites are pending. Retry with `app:register [name] --domain=<host>`. |
| `app.php_version_unavailable` | `app` | The requested PHP version is supported by Orbit but not yet installed on the owning app node. Operator installs the runtime, then `doctor --fix --family=app --restore` converges. |
| `app.fpm_config_missing` | `app` | App PHP-FPM configuration could not be installed during application. `doctor --fix --family=app --restore` will repair it. |

## Enum And Identifier Values

| Field | Values |
| --- | --- |
| `result.action` | `registered`, `adopted`, `converged` |
| `error.code` | `validation_failed`, `app.path_collision`, `app.ineligible_node`, `app.ssh_failure`, `app.enactment_failed`, `caller_role_not_allowed`, `authorization_failed` |

The `error.code` values listed here are exhaustive for `app:register`. Add a
new value to this renderer contract before implementing another JSON failure
code.
