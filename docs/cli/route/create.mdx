---
title: "orbit route:create"
sidebarTitle: "route:create"
description: "Create an explicit app Route targeting an Instance, or create a custom proxy Route for a Node-local service."
---

```bash
orbit route:create <instance> <domain> [--publication=private|public] [--web-root=PATH] [--idempotency-key=KEY]
orbit route:create <domain> --node=NODE --upstream=URL [--idempotency-key=KEY]
orbit route:create <domain> --node=NODE --process=PROCESS [--idempotency-key=KEY]
orbit route:create <domain> --process=PROCESS [--ingress=NODE] --publication=public [--idempotency-key=KEY]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `instance` | App form | Numeric Instance ID. Its Project owns the Route; its Node or active Cluster determines the scope. |
| `domain` | yes | The Route domain. The Gateway normalizes it. |

| Option | Default | Meaning |
| --- | --- | --- |
| `--publication=INTENT` | `private` | `private` or `public` for the app form. Public custom proxies require a Process and accept an Ingress. |
| `--node=NODE` | none | Serving Node ID or name for a private custom proxy. |
| `--ingress=NODE` | derived | Public Process Route Ingress Node name or ID; defaults to the Process Cluster Ingress or the single Ingress serving existing public app Routes. |
| `--upstream=URL` | none | Loopback HTTP URL for a custom proxy Route, such as `http://127.0.0.1:4788`. |
| `--process=PROCESS` | none | Name or ID of a Node Process on the serving Node, for a custom proxy Route. |
| `--web-root=PATH` | none | A web root inside the Instance's checkout or release, such as `apps/docs/public`. The Route becomes another site of the Instance. A production Instance needs a deployed release. |

```bash
orbit route:create 12 shop.example.test
orbit route:create 12 shop.example.com --publication=public
orbit route:create 12 docs.shop.test --web-root=apps/docs/public
orbit route:create executor.orbit --node=beast --upstream=http://127.0.0.1:4788
orbit route:create executor.orbit --node=beast --process=executor
```

In a terminal, Orbit lists available Instances for an omitted Instance ID and prompts for an omitted domain. If no Instances are available or selection is cancelled, it creates nothing. In noninteractive or JSON mode, provide both arguments for the app form.

The app form creates and activates a Route for the Instance. The Instance implies the Project and scope. An inactive Instance returns `route.target_inactive`; an Instance already targeted by another Route returns `route.target_conflict`. An identical retry for an existing active Route returns that Route. With `--web-root`, the Instance keeps its own Route and gets another site. See [Create and change targets](/reference/routes#create-and-change-targets) and [Serve several web roots](/reference/routes#serve-several-web-roots).

`--upstream` or `--process` selects the custom proxy form. Its first argument is the domain. Private publication requires `--node`. Public publication requires a numeric `--process`, with optional `--ingress`, without `--node` or `--upstream`. The Process can run on another Node outside the Cluster. See [public Process hostnames](/reference/routes#public-process-hostnames) for listener and firewall requirements.

## Errors

| Error code | Meaning |
| --- | --- |
| `route.domain_invalid` | The domain is not a valid domain. |
| `route.domain_conflict` | Another Route owns the domain, or it is a reserved name: `gateway.orbit`, `metrics.orbit`, `reverb.orbit`, `analytics.orbit`, or `collector.ai-router.orbit`. |
| `route.retry_conflict` | A Route with this domain exists with a different Instance, publication, or custom proxy configuration. |
| `route.scope_required` | A private custom proxy needs a Node; a public custom proxy needs a numeric Process ID and optional Ingress. |
| `route.target_inactive` | The Instance is not active. |
| `route.target_web_root_unsupported` | The target Instance has no supported relative web root, such as a package rooted at `.`. |
| `route.target_conflict` | The target Instance already has a Route without a web root. |
| `route.web_root_release_missing` | The production Instance has no selected release. Deploy it first. |
| `route.web_root_unsafe` | The production web root would serve an application `.env`, or sits in the default directory without being the Instance root. |
| `app-prod.web_root_invalid` | The selected production release lacks the web root or its application directory, or the web root holds a link. |
| `route.web_root_unsupported` | A custom proxy Route got a web root. |
| `route.router_required` | The Cluster has no active Router. |
| `route.node_inactive`, `route.cluster_inactive` | The Instance's Node or Cluster, or the custom proxy's Node, is not active. |
| `route.upstream_invalid` | The upstream is not a loopback HTTP URL. |
| `route.upstream_unresolved` | The Process has no single Node-local listener. |
| `route.process_conflict` | The Process is not a Node Process on the serving Node. |
| `process.runtime_lock_failed` | Process Route creation could not acquire the Process runtime lock within its bounded wait. No Route was reserved. |
