## Progress Tree

Render a progress tree for mutations before any side effect:

```text
┌ Updating Node Permissions
○ Validate request
○ Apply permission change
└ Working...
```

Read mode does not render a tree; it prints the current permission set
directly.

## Success Output

- Print the consuming node, serving node, the new normalized permission set,
  whether the grant was `created` or `updated`, and any redundant-permission
  warnings.
- For read mode, print the consuming node, serving node, and the current
  normalized permission set.
