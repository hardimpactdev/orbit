# Human Renderer: `orbit schedule:remove`

[Back to `schedule:remove` technical contract.](1_schedule-remove.md)

**Renderer:** Human terminal renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and destructive consent, and
before gateway removal intent or backend cleanup begins.

```text
┌ Remove Schedule
○ Resolve schedule
○ Record gateway removal intent
○ Disable timer
○ Remove timer and service artifacts
○ Finalize schedule removal
└ Schedule `laravel-scheduler` removed from app `docs`
```

## Success Output

Render the schedule name, scope, target, removed timer/service artifact summary,
and cleanup result.

## Failure Output

Validation and not-found failures render the rejected field or schedule name.
Destructive-consent failures render no progress tree and state that no schedule
was removed. Cleanup failures render the schedule status, target node, and next
doctor command: `doctor --family=schedule --fix`.
