# JSON Renderer: `orbit database:list`

[Back to `database:list` technical contract.](1_database-list.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "connections": [
        {
          "slug": "acme",
          "driver": "pgsql",
          "host": "postgres.internal",
          "port": 5432,
          "database": "acme",
          "path": null,
          "username": "orbit",
          "node": "gateway",
          "targets": [
            {
              "type": "app_instance",
              "app": "acme",
              "instance": "development",
              "env_prefix": "DB"
            }
          ]
        }
      ]
    },
    "meta": {
      "count": 1
    }
  }
}
```

## Error Shape

`validation_failed`, `gateway_unavailable`, and `authorization_failed` use the
shared JSON envelope with field or scope details in `error.meta`.
