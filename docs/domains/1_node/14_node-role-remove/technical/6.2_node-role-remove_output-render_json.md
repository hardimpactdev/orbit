# JSON Renderer: `orbit node role:remove`

[Back to `node role:remove` technical contract.](1_node-role-remove.md)

## Primitive

None. JSON renderer emits the standard envelope only.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Top-level envelopes:
- Success: `{ "success": { ... } }`
- Error: `{ "error": { ... } }`

## Success Shape

`success.data.node`, `success.data.role`, and `success.data.purged_data`.

## Error Codes

- `validation_failed`
- `node.not_found`
- `node_role.remove_blocked`
- `node_role.remove_failed`
- `gateway_unavailable`
- `authorization_failed`
