# JSON Output Renderer: `orbit workspace-teardown-step:remove`

[Back to `workspace-teardown-step:remove` technical contract.](1_workspace-teardown-step-remove.md)

This page describes the JSON output for `workspace-teardown-step:remove`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces
non-interactive input mode and never grants destructive consent.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Envelope

```json
{
  "success": {
    "data": {
      "result": {
        "action": "removed"
      },
      "step": {
        "id": 18,
        "app": "hauser",
        "instance": "nmbp",
        "phase": "teardown",
        "command": "php artisan db:wipe",
        "order": 1,
        "timeout_seconds": 600
      }
    },
    "meta": {
      "new_step_count": 0
    }
  }
}
```

## Success Payload

| Field | Type | Description |
| --- | --- | --- |
| `success.data.result.action` | string | Always `removed`. |
| `success.data.step` | object | The step definition that was removed. |
| `success.data.step.id` | integer | Original step ID. |
| `success.data.step.app` | string | App slug. |
| `success.data.step.instance` | string | Required instance that owned the removed step. |
| `success.data.step.phase` | string | Always `teardown`. |
| `success.data.step.command` | string | The command that was removed. |
| `success.data.step.order` | integer | The original order position of the step. |
| `success.data.step.timeout_seconds` | integer | The original timeout. |
| `success.meta.new_step_count` | integer | Number of teardown steps remaining for the instance after compaction. |

## Error Envelope

```json
{
  "error": {
    "code": "workspace.step_not_found",
    "message": "Teardown step 18 not found for app 'docs'.",
    "meta": {
      "step_id": 18,
      "app": "docs",
      "phase": "teardown"
    }
  }
}
```

## Error Codes

| Code | Description |
| --- | --- |
| `validation_failed` | Required input is missing or invalid, including missing destructive consent or a cancelled confirmation prompt. `error.meta.field` names the offending input (`instance`, `step`, or `force`) when applicable. |
| `instance.not_found` | The app slug could not be resolved. |
| `workspace.unsupported_for_production` | The selected instance is served by an `app-prod` node, where workspace policy is disabled. |
| `workspace.step_not_found` | The step ID does not exist for the resolved app and `phase=teardown`. |
| `authorization_failed` | The caller lacks `workspace:write` on the resolved instance's serving node. `error.meta.reason=missing_permission`, `error.meta.missing_permission=workspace:write`, and `error.meta.serving_node` names that node. |
| `gateway_unavailable` | The gateway cannot be reached. |
