---
title: "orbit extension:enable"
sidebarTitle: "extension:enable"
description: "Enable one extension for every client."
---

```bash
orbit extension:enable <extension> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `extension` | yes | `tasks`, `ai-router`, or `documents`. |

JSON returns `name` and `enabled`. Enabling an enabled extension succeeds and leaves it enabled. An extension can depend on another one; enabling it while a dependency is off fails with `extension.dependency_disabled`. Enabling runs the extension's enable hook, which only does quick, repeatable setup, and then turns the switch on. When the hook fails, the switch stays off and the command reports the hook's error. An extension that needs fleet resources has its own setup command, such as [`ai-router:setup`](/cli/ai-router/setup).
