# Technical Contract: `orbit instance:register` (JSON Renderer)

This contract defines the **JSON renderer** for `instance:register`.

[Back to the canonical contract.](1_instance-register.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

### Fields

- `result.action`: One of `registered`, `adopted`, `moved`, `partial`, or
  `converged`. Describes what
  this run did.
  - `registered` — first-time registration of a known path that is not yet
    managed by Orbit.
  - `adopted` — first-time registration where the path existed on the node
    but was unmanaged. `instance.adopted` is set to `true` for this run.
  - `converged` — idempotent re-application where no observable artifact change
    was needed. The durable `instance.adopted` value is preserved across
    converged re-runs.
  - `partial` — a re-application persisted route intent but proxy enactment
    failed. `meta.warnings[]` identifies the failed layer, node, and operation.
- `project`: The canonical project JSON entity defined in
  [`5_project/README.md`](../../README.md#project-json-entity). It has no placement or
  adoption fields.
- `instance`: The canonical concrete instance registered or converged by this
  run. Placement lives in `instance.driver_config`, and `instance.adopted`
  persists path-derived adoption state.
- `meta.warnings`: Structured non-fatal drift and retry handoffs. Each entry
  carries `code`, `family`, `message`, and `next_command`.

## Error Envelope

### Path collision

Returned when the supplied `--path` on the resolved node is already owned by a
different registered instance. Fails before any side effects.

```json
{
  "error": {
    "code": "project.path_collision",
    "message": "Path '/home/orbit/apps/docs' on node 'app-1' is already owned by instance 'docs-archive.development'.",
    "meta": {
      "path": "/home/orbit/apps/docs",
      "existing_instance": "docs-archive.development",
      "serving_node": "app-1"
    }
  }
}
```

### Apply failure

```json
{
  "error": {
    "code": "project.creation_failed",
    "message": "Failed to complete non-retryable app application on node 'app-1'.",
    "meta": {
      "step": "enact_runtime_artifacts",
      "node": "app-1",
      "reason": "Permission denied"
    }
  }
}
```

### Common Error Codes

| Code | Meaning |
| --- | --- |
| `validation_failed` | A supplied input failed gateway-side static validation. Ambiguous bare logical selection uses `error.meta.reason=instance_required`; `error.meta.field` names other offending input. |
| `project.path_collision` | The supplied `--path` on the resolved node is already owned by a different registered instance. `error.meta.path`, `error.meta.existing_instance`, `error.meta.serving_node`. |
| `project.ineligible_node` | The caller may run `instance:register`, but the resolved target node does not have the active app role required for the requested registration mode. `error.meta.required_role` is `app-dev` when `--domain` is absent and `app-prod` when `--domain` is supplied. |
| `project.creation_failed` | Registry write succeeded but node-side execution failed in a way that cannot be retried through convergence. Fields: `error.meta.step`, `error.meta.node`, `error.meta.reason`. |
| `authorization_failed` | The caller lacks `instance:register` on the selected or proposed instance serving node. |

Retryable runtime or configuration drift is reported as
`success.meta.warnings[]` instead of `project.creation_failed`. Managed app
configuration uses `app.*` codes; concrete runtime containers use
`process.runtime_unit_*` with `family: "process"`.

### Common Warning Codes

Non-fatal drift is reported in `success.meta.warnings[]`. Each warning carries
`code`, `family`, `message`, and `next_command`.

| Code | Family | Meaning |
| --- | --- | --- |
| `proxy.domain_inactive` | `proxy` | The selected production instance domain is not yet active because DNS or TLS prerequisites are pending. Retry with `instance:register <project.instance> --domain=<host>`. |
| `instance.php_version_unavailable` | `instance` | The requested PHP version is supported by Orbit but the matching image is not yet available on the selected instance's serving node. `doctor --family=instance --instance=<project.instance> --restore` converges. |
| `process.runtime_unit_missing` | `process` | The concrete instance runtime container could not be rendered or started. `doctor --family=process --restore` will repair it. |

## Enum and identifier values

| Field | Values |
| --- | --- |
| `result.action` | `registered`, `adopted`, `moved`, `partial`, `converged` |
| `error.code` | `validation_failed`, `project.path_collision`, `project.ineligible_node`, `project.creation_failed`, `authorization_failed` |

The `error.code` values listed here are exhaustive for `instance:register`. Add a
new value to this renderer contract before implementing another JSON failure
code.
