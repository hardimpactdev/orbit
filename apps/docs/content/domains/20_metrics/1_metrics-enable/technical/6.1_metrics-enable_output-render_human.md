# Human Renderer: `orbit metrics:enable`

[Back to `metrics:enable` technical contract.](1_metrics-enable.md)

**Renderer:** Human renderer.

## Primitive

None. Human output uses the shared CLI success/error renderer and no
command-specific primitive.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered in this slice. The command performs one gateway API
write that records role and baseline intent and asks the gateway to converge the
owned metrics runtimes.

## Success Output

Render the gateway success message for the role assignment or reconvergence and
include:

- target node name;
- role value `metrics`;
- assignment status.

## Failure Output

Render standard validation, gateway, and authorization failures using the shared
command error renderer.

## Test Mapping

No gateway-side coverage exists for this renderer because human rendering is
CLI-only for this command.
