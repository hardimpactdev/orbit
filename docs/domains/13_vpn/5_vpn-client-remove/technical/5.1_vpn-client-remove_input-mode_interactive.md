# Interactive Input Mode: `orbit vpn-client:remove`

[Back to `vpn-client:remove` technical contract.](1_vpn-client-remove.md)

**Input mode:** Interactive.

## Selection

Use this input mode when the command is attached to a TTY and `--json` is not
present.

## Prompt Contract

Interactive input mode does not prompt for `name`; `name` is a required command
argument. After the target client is resolved and verified as a non-node client,
prompt for destructive confirmation unless `--force` is supplied.

| Field | Prompt ID | Primitive | Label | Default |
| --- | --- | --- | --- | --- |
| `force` | `vpn_client_remove.confirm` | `confirm` | `Remove VPN client {name}?` | `false` |

If the operator declines confirmation, fail before side effects.

`--force` bypasses the confirmation prompt and counts as destructive consent.

## Primitive References

- [`confirm`](../../../../commands/ux/inputs/confirm-prompt.md)

## Validation Timing

- Caller-role eligibility is checked before prompts.
- Client existence and active-node protection are checked before confirmation.
- Backend deletion begins only after destructive consent.
