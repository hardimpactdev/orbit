# Human Renderer: `orbit app:env`

[Back to `app:env` technical contract.](1_app-env.md)

## Primitive

None. The renderer uses plain terminal text and tables without a specialized
prompt or progress primitive.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered. The command performs a single gateway API request
and is expected to complete in under one second after input is resolved.

## Success Output

For `list`, show a table of explicit non-secret env variables for the instance.

For `set`, print the saved key and instance.

For `render`, show the effective env map. Secret values must be redacted.

## Failure Output

Failures render the gateway or validation message directly. If `--secret` is
supplied, explain that explicit secret env storage is not available in this
slice.
