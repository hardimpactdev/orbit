# JSON Renderer: `orbit node:show [name]`

[Back to `node:show` technical contract.](1_node-show.md)

This page describes the JSON-rendered output for `node:show`.

**Renderer:** JSON renderer.

## Primitive

None. JSON renderer emits the standard envelope only.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](5.2_node-show_input-mode_non-interactive.md), even
when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "node": {
        "name": "app-1",
        "role": "app-dev",
        "status": "active",
        "platform": "ubuntu_24-04",
        "roles": [
          {
            "role": "app-dev",
            "status": "active",
            "settings": {
              "tld": "orbit.test"
            },
            "last_error": null,
            "converged_at": "2026-05-17T12:00:00+00:00"
          },
          {
            "role": "database",
            "status": "error",
            "settings": {},
            "last_error": "Provisioning failed.",
            "converged_at": null
          }
        ],
        "addresses": {
          "wireguard": "10.6.0.7"
        },
        "agent_ide": {
          "adapter": "opencode",
          "source": "node"
        },
        "grants": {
          "consuming_nodes": ["operator-1"],
          "serving_nodes": []
        }
      }
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `node.name` | string | The node name. |
| `node.role` | string | Primary role value: `gateway`, `vpn`, `router`, `app-dev`, `app-prod`, `database`, `agent`, `ingress`, `websocket`, or `s3`. |
| `node.status` | string | Durable registry lifecycle: `provisioning` or `active`. |
| `node.environment` | string \| null | App-role environment. `null` for non-app roles. |
| `node.platform` | string | Never `null`. Platform-version identifier such as `ubuntu_24-04` or `macos_15-4`; `unknown` when not detectable yet. See [`node:new` JSON renderer](../../1_node-new/technical/6.2_node-new_output-render_json.md#node-fields) for platform field semantics. |
| `node.roles` | array | Composable role assignments for the node, ordered by role. Empty when no role assignments exist. |
| `node.roles[].role` | string | Role assignment name: `gateway`, `vpn`, `router`, `app-dev`, `app-prod`, `database`, `agent`, `ingress`, `websocket`, or `s3`. |
| `node.roles[].status` | string | Role assignment convergence status: `pending`, `active`, `error`, or `removing`. |
| `node.roles[].settings` | object | Role-local desired settings for that assignment. Empty object when the role has no stored settings. |
| `node.roles[].last_error` | string \| null | Last convergence error recorded for that assignment. `null` when no error is recorded. |
| `node.roles[].converged_at` | string \| null | ISO 8601 timestamp of the most recent successful convergence for that assignment. `null` when the assignment has not converged successfully. |
| `node.addresses.wireguard` | string | Orbit WireGuard address assigned to the node. |
| `node.agent_ide.adapter` | string \| null | Agent IDE adapter name configured on the node. `null` when the node has no node-level adapter set and uses the system default. Mirrors the [`node:agent-ide` JSON renderer](../../10_node-agent-ide/technical/6.2_node-agent-ide_output-render_json.md) payload. |
| `node.agent_ide.source` | string | Resolution source for the rendered adapter: `node` when explicit; `default` when no node-level adapter is set. The `app` and `workspace` overrides apply at runtime, not at node-level reporting. |
| `node.grants.consuming_nodes` | string[] | Nodes granted access to operate on this node. |
| `node.grants.serving_nodes` | string[] | Nodes this node is granted access to operate on. |

`node:show` is a registry read. It does not return live checks, SSH
reachability, WireGuard probe results, or drift warnings. Use
`doctor --family=node --json` for node readiness and drift output.

## Error Shapes

### Missing required input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Node name is required.",
    "meta": {
      "field": "name"
    }
  }
}
```

### Node not found

```json
{
  "error": {
    "code": "node.not_found",
    "message": "Node 'app-1' not found or not visible.",
    "meta": {
      "name": "app-1"
    }
  }
}
```

### Not authorized

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized to inspect 'app-1'.",
    "meta": {
      "name": "app-1",
      "missing_permission": "node:read"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to show node details.",
    "meta": {}
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `node.role` | `gateway`, `vpn`, `router`, `app-dev`, `app-prod`, `database`, `agent`, `ingress`, `websocket`, `s3`, `app`, `operator` |
| `node.status` | `provisioning`, `active` |
| `node.environment` | `development`, `production`, `null` |
| `node.platform` | Platform-version identifier such as `ubuntu_24-04` or `macos_15-4`; `unknown` when not detectable yet. Never `null`. |
| `node.roles[].role` | `gateway`, `vpn`, `router`, `app-dev`, `app-prod`, `database`, `agent`, `ingress`, `websocket`, `s3` |
| `node.roles[].status` | `pending`, `active`, `error`, `removing` |
| `node.agent_ide.source` | `node`, `default` |
| `error.code` | `validation_failed`, `node.not_found`, `authorization_failed`, `gateway_unavailable` |

The `error.code` values listed here are exhaustive for `node:show`. Add a new
value to this renderer contract before implementing another JSON failure code.
Live check outcomes never appear here: the registry read either succeeds or the
read itself fails with one of the codes above.
