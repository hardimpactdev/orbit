# `app:new` Interactive Input Mode

[Back to technical contract](1_app-new.md)

**Input mode:** Interactive.

Interactive mode is used when the CLI is attached to a TTY and `--json` is not
supplied. It prioritizes helpful prompts to resolve missing input.

## Prompt Flow

### 1. Node Resolution
If `--node` is missing, Orbit first asks the operator to choose the target app
node:
- **Primitive:** `datatable`
- **Prompt:** "Select target app node:"
- **Rows:** Visible active nodes with the `app` role.
- **Validation:** Selected node must be an active app node.

When a valid local `node:default` development app node is configured, it is
preselected as the first row in the table. The operator can press Enter to keep
it or move to another visible app node before continuing.

### 2. App Name
After the target app node is resolved, Orbit prompts for the app name when
`name` is missing from the command line.
- **Prompt:** "App name (slug):"
- **Validation:** Must match `^[a-z0-9](?:[a-z0-9-]*[a-z0-9])?$`, be 40
  characters or fewer, and be globally available in the gateway app registry.
  App names are globally unique; they are not scoped to the selected app node.

### 3. Repository (Optional)
If `--repo` is missing, Orbit may prompt if the user wants to clone a repo.
- **Prompt:** "Clone from a git repository? (y/n)"
- **If Yes:** "Repository URL (or GitHub owner/repo):"
- Orbit does not prompt for git credentials, SSH keys, or personal access
  tokens. GitHub inputs are cloned with `gh repo clone` on the target app
  node; non-GitHub inputs are cloned with `git clone`. Both paths use the
  credentials that node already has provisioned. If those credentials are
  missing or wrong, source creation fails with `app.source_creation_failed`
  and the operator addresses node-side credentials directly.

## Behavior

- **Validation Errors:** If input fails validation, the user is re-prompted
  until valid input is provided or the command is cancelled (Ctrl+C).
- **Default Values:** Optional flags like `--php-version` and `--root` use their
  defaults unless explicitly overridden; they are not typically prompted for
  unless part of an "advanced" flow.
