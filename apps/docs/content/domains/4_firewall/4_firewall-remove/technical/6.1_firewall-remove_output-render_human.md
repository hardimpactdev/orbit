# Human Renderer: `orbit firewall:remove`

[Back to `firewall-remove` technical contract.](1_firewall-remove.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and destructive confirmation, before backend cleanup or gateway configuration removal begins.

```text
┌ Removing Firewall Rule
○ Confirm destructive removal
○ Resolve firewall rule
○ Remove backend firewall rule
○ Apply and verify firewall removal
└ Working...
```

## Success Output

Render the removed rule name and node. If the rule was already absent from gateway configuration, render a concise idempotent absence message.

## Failure Output

Validation failures render the rejected field. Missing destructive consent
renders a direct message that `--force` is required in non-interactive mode.
Cleanup failures render the next doctor command for recovery.
