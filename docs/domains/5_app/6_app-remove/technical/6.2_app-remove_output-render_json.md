# `app:remove` JSON Renderer

[Back to `app:remove` technical contract.](1_app-remove.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

This file owns the JSON schema and envelope for `app:remove`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[non-interactive input mode](5.2_app-remove_input-mode_non-interactive.md), even
when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "app": {
        "name": "my-app",
        "node": "app-1",
        "environment": "development",
        "url": "https://my-app.test",
        "path": "/home/my-app/app",
        "root": "public",
        "repository": null,
        "php_version": "8.5",
        "adopted": false
      },
      "result": {
        "action": "removed"
      },
      "cleanup": {
        "proxy_routes_removed": 1,
        "workspaces_removed": 0,
        "schedules_removed": 0,
        "processes_removed": 0,
        "fpm_config_removed": true,
        "runtime_config_removed": true
      }
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `app` | object | Canonical app JSON entity defined in [`5_app/README.md`](../../README.md#app-json-entity), captured before gateway configuration removal. |
| `result.action` | string | Always `removed`. |
| `cleanup.proxy_routes_removed` | integer | Count of app-owned proxy routes deleted from gateway configuration. |
| `cleanup.workspaces_removed` | integer | Count of app-owned workspace records deleted from gateway configuration. |
| `cleanup.schedules_removed` | integer | Count of app-owned schedules deleted from gateway configuration. |
| `cleanup.processes_removed` | integer | Count of app-owned process units stopped and deleted. |
| `cleanup.fpm_config_removed` | boolean | `true` when the app PHP-FPM configuration was removed on the app node. `false` when it was already absent or could not be removed (with a warning under `success.meta.warnings`). |
| `cleanup.runtime_config_removed` | boolean | `true` when managed runtime configuration was removed on the app node. `false` when it was already absent or could not be removed (with a warning under `success.meta.warnings`). |

`success.meta.warnings` is omitted when there are no warnings. When dependent
configuration or node-side artifact cleanup leaves residue behind, the result remains
successful and the recovery warnings are reported under `success.meta.warnings`.

`app:remove` does not duplicate drift item shapes for each family in its own output.
Detailed item-level drift belongs to the affected family doctor; the warning's
`next_command` points operators at that doctor.

Warning fields:

| Field | Type | Meaning |
| --- | --- | --- |
| `code` | string | Stable warning code keyed to the relevant family doctor. |
| `family` | string | Doctor family that owns the remaining drift. |
| `message` | string | Human-readable warning message. Automation must not parse it. |
| `next_command` | string | Suggested repair command, typically `doctor --fix --family=<family> --restore`. |

## Error Shapes

### Missing required input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "App name is required.",
    "meta": {
      "field": "app"
    }
  }
}
```

### Missing destructive consent

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Use --force to remove this app.",
    "meta": {
      "field": "force"
    }
  }
}
```

### App not found

Already-absent removal returns this error shape. `app:remove` is an imperative
command against an existing gateway-owned app record, not an idempotent
absent-state convergence command.

```json
{
  "error": {
    "code": "app.not_found",
    "message": "App 'my-app' not found.",
    "meta": {
      "name": "my-app"
    }
  }
}
```

### Caller role not allowed

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "This command may only be run from an operator or gateway node.",
    "meta": {
      "caller_role": "app"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to remove an app.",
    "meta": {}
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This operator node is not authorized to remove this app.",
    "meta": {
      "name": "my-app",
      "caller_role": "control"
    }
  }
}
```

### Gateway configuration removal failure

Returned only when Step 1 (deletion of the gateway app record) itself fails. No
dependent gateway configuration or node-side artifacts have been touched.

```json
{
  "error": {
    "code": "app.removal_failed",
    "message": "Failed to remove the gateway app record for 'my-app'.",
    "meta": {
      "name": "my-app",
      "reason": "gateway_database_write_failed"
    }
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `result.action` | `removed` |
| `error.code` | `validation_failed`, `app.not_found`, `caller_role_not_allowed`, `gateway_unavailable`, `authorization_failed`, `app.removal_failed` |

The `error.code` values listed here are exhaustive for `app:remove`. Add a new
value to this renderer contract before implementing another JSON failure code.

## Common Warning Codes

Non-fatal drift after Step 1 is reported in `success.meta.warnings[]`. Each
warning carries `code`, `family`, `message`, and `next_command`.

| Code | Family | Meaning |
| --- | --- | --- |
| `app.fpm_config_extra` | `app` | The app PHP-FPM configuration could not be removed and remains on the app node without matching active app configuration. `doctor --fix --family=app --restore` will reconcile it. |
| `app.runtime_config_extra` | `app` | Managed runtime configuration could not be removed and remains on the app node without matching active app configuration. `doctor --fix --family=app --restore` will reconcile it. |
| `proxy.route_extra` | `proxy` | An app-owned proxy route could not be removed. `doctor --fix --family=proxy --restore` will reconcile it. |
| `workspace.artifact_extra` | `workspace` | A workspace artifact for a removed workspace record could not be cleaned up. `doctor --fix --family=workspace --restore` will reconcile it. |
| `process.runtime_unit_extra` | `process` | An app-owned process unit could not be stopped or removed. `doctor --fix --family=process --restore` will reconcile it. |
| `schedule.unit_extra` | `schedule` | An app-owned schedule unit could not be removed. `doctor --fix --family=schedule --restore` will reconcile it. |
