---
title: "orbit metrics:credentials"
sidebarTitle: "metrics:credentials"
description: "Read the stored Grafana administrator credential, or admit a native reset."
---

```bash
orbit metrics:credentials [--reset] [--json]
```

| Option | Meaning |
| --- | --- |
| `--reset` | Admit a native reset and follow its Operation. Human output then reads the active credential; JSON returns the Operation. |

Human output prints the URL, the user `admin`, the stored active password and the request ID. Reads execute no host action. A failed reset retains the pending password; a fresh reset checks it before another write. The Gateway has no execution-lifetime credential lock.
