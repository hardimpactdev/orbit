# `process:list` Interactive Input Mode

[Back to `process:list` technical contract.](1_process-list.md)

This page describes how interactive input mode resolves `process:list` input.

**Input mode:** Interactive.

## Selection

Use this input mode only when the process is attached to a TTY and `--json` is not present.

## Prompt Behavior

Prompt only when node, instance, or workspace context cannot be resolved from supplied options or local context. A supplied ambiguous bare app slug fails with `validation_failed`, `field=instance`, and `reason=instance_required` instead of prompting.

| Field | Prompt primitive | Notes |
| --- | --- | --- |
| `instance` | Select | Show concrete instances the caller is authorized to read. |
| `workspace` | Select | Prompt only when the local context is ambiguous and the operator chooses a workspace-scoped list. |

The command does not prompt for live inspection. Runtime artifact checks belong to `doctor --family=process`.
