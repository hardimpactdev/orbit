# JSON Renderer: `orbit process:edit [name]`

[Back to `process:edit` technical contract.](1_process-edit.md)

This page describes the JSON-rendered output for `process:edit`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces non-interactive input mode.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the updated process definition, changed fields, and derived runtime units. Partial post-configuration drift is reported under `success.meta.warnings[]`.

Warning objects contain:

| Field | Meaning |
| --- | --- |
| `code` | Singular product warning code, such as `process.runtime_unit_missing`, with the owning family recorded separately. |
| `family` | State family that owns the warning. |
| `message` | Human-readable warning summary. |
| `next_command` | Suggested command to inspect or repair the warning. |

## Success Example

```json
{
  "success": {
    "data": {
      "process": {
        "name": "vite",
        "app": "docs",
        "command": "npm run dev",
        "restart_policy": "never",
        "crash_notification": "agent_ide",
        "runtime": "systemd"
      },
      "changed": [
        "command"
      ],
      "runtime_units": [
        {
          "name": "orbit_docs_main_vite",
          "context": "main"
        }
      ]
    },
    "meta": {
      "warnings": []
    }
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "validation_failed",
    "message": "At least one editable field is required.",
    "meta": {
      "field": "editable_fields"
    }
  }
}
```

## Authorization Error

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'process:edit' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "process:edit",
      "serving_node": "app-1"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: missing `name` or node/app/workspace context, invalid enum value (`restart_policy`, `crash_notification`, `runtime`), empty `command`, invalid runtime scope, or no editable fields supplied.
- `authorization_failed`: caller lacks `process:edit` on the resolved owning node.
- `process.not_found`: the named process does not exist for the resolved owner scope.
- `gateway_unavailable`: the CLI cannot reach the gateway API before configuration is changed.
