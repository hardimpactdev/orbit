# Human Renderer: `orbit database:update`

[Back to `database:update` technical contract.](1_database-update.md)

## Primitive

None. Renderer prints one concise success or failure line and does not render a
table, prompt, spinner, or progress tree.

## Progress Tree

No progress tree. The command validates input before side effects and then
performs one local registry mutation or typed gateway request that is expected
to complete below one second. If slow external work is added later, add a typed
progress stream before rendering a progress tree.

## Human Strings

- Success: "Database connection '{slug}' updated."
- Failure: "Failed to update database connection '{slug}'."
