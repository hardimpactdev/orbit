# JSON Renderer: `orbit deploy:log`

[Back to `deploy:log` technical contract.](1_deploy-log.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "run": {
        "id": 42,
        "app": "docs",
        "status": "failed",
        "exit_code": 1,
        "started_at": "2026-05-02T09:00:00Z",
        "finished_at": "2026-05-02T09:01:30Z",
        "steps": [
          {
            "id": 13,
            "title": "Run migrations",
            "status": "failed",
            "exit_code": 1
          }
        ]
      },
      "steps": [
        {
          "id": 13,
          "title": "Run migrations",
          "status": "failed",
          "exit_code": 1,
          "started_at": "2026-05-02T09:01:00Z",
          "finished_at": "2026-05-02T09:01:30Z",
          "output": {
            "stdout": "",
            "stderr": "Migration table is locked.\n"
          }
        }
      ]
    },
    "meta": {
      "lines": 500,
      "truncated_by_filter": false
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "deploy.run_not_found",
    "message": "Deployment run 999 was not found for app 'docs'.",
    "meta": {
      "app": "docs",
      "run": 999
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.run` | object | Deployment run entity. |
| `success.data.steps` | array | Captured per-step output records after optional step filtering. |
| `success.meta.lines` | integer | Effective per-stream line limit. |
| `success.meta.truncated_by_filter` | boolean | True when any stream was shortened by `--lines`. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `app.not_found`, `deploy.production_app_required`, `deploy.run_not_found`, `deploy.step_not_found`, `deploy.log_read_failed` | Stable command failure code. |
| `error.meta` | object | Field, app selector, run id, step id, line limit, or authorization context for automation. |
