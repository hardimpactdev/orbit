description: "Install one package on a Node."
---

```bash
orbit tool:install [package] --node=ID [--manager=MANAGER] [--constraint=CONSTRAINT] [--repository=JSON] [--idempotency-key=KEY] [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `package` | when the command cannot prompt | The package name in the manager's own form, at most 255 characters. In a terminal, the command asks for it. Otherwise it fails with `tool.package_required`. |

| Option | Meaning |
| --- | --- |
| `--node=ID` | Numeric Node ID. |
| `--manager=MANAGER` | `apt`, `vp`, `composer`, `brew`, or `brew-cask`, limited to those the Node supports. In a terminal, the command offers the Node's `active` and `uninstalled` managers. Otherwise it fails with `tool.manager_required`. |
| `--constraint=CONSTRAINT` | Optional SemVer range. It only stops an unsafe version. |

```bash
orbit tool:install @openai/codex --node=12 --manager=vp --constraint='^0.150'
orbit tool:install laravel/installer --node=12 --manager=composer
orbit tool:install ripgrep --node=12 --manager=brew
```

Use `vp` for npm packages such as Codex and Claude Code, `composer` for `vendor/package` tools, `apt` for Ubuntu packages, and `brew` for a Homebrew Core formula with a compatible verified bottle. `brew-cask` manages supported official Homebrew casks on macOS.

The result is `applied` for a new install. It is `unchanged` when the Tool already exists and its package is installed, such as on a retry or a repeated install. A failed package phase retains the Tool for retry or removal. List Tools to find that record; the Operation holds the failure code and steps.
