# Interactive Input Mode: `orbit deploy:run`

[Back to `deploy:run` technical contract.](1_deploy-run.md)

**Input mode:** Interactive.

Applies when the command is attached to a TTY and `--json` is not present.

## Prompt Behavior

Interactive input mode prompts only for missing required fields after caller
role, gateway reachability, and provided options are resolved.

| Prompt ID | Primitive | Field | Shown when | Validation |
| --- | --- | --- | --- | --- |
| `deploy.run.app` | `search` | `app` | No app argument was supplied. | Visible production app the caller may deploy. |

`--detach` is never prompted. It must be supplied explicitly when the operator
wants an asynchronous run.

## Abort Behavior

Prompt aborts exit with the shared Orbit command failure status and perform no
gateway writes, run-history creation, or node-side execution.
