## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`cf-cache-rule:add` resolves app/provider state and performs an external
provider write. After input resolution and before the Cloudflare rule request
begins, render this progress tree:

```text
┌ Adding Cloudflare cache rule
○ Resolve app domain
○ Resolve Cloudflare zone
○ Write cache rule
└ Working...
```

## Success Output

Render one concise success line:

```text
Cloudflare cache rule ready for docs: respect origin Cache-Control
```

## Failure Output

Validation, gateway, authorization, and Cloudflare failures render one concise
error line with the project name when available.
