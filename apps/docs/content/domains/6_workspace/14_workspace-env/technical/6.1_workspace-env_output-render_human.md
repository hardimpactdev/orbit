# Human Renderer: `orbit workspace:env`

[Back to `workspace:env` technical contract.](1_workspace-env.md)

## Primitive

- List output: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

`render` prints the effective `KEY=value` map as plain terminal text.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered. Each action is one bounded gateway request, and
the terminal result reports whether state was stored, applied, and followed by
a runtime reapply.

## Success Output

Output identifies the workspace scope, app, concrete instance,
workspace, `.env` path, and stored/applied/runtime-restarted outcomes.

## Failure Output

Failures render gateway or validation messages directly and name the workspace
target when known.
