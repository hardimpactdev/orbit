# Analytics

## Purpose

This domain owns the command contracts and product vocabulary for Orbit's
analytics command family. See [Analytics command contracts](README.md).

## Responsibilities

These responsibilities define what this domain's documentation must keep
aligned and own.

- Keep the `analytics:*` command contracts aligned with Orbit's current
  behavior.
- Define the analytics role, Plausible CE process boundary, private dashboard
  route, and public app tracking route vocabulary used by other domains.

## Boundaries

This landing page is an index for Librarian's domain spine. It does not change
Orbit behavior; detailed contracts remain in the linked command and technical
documents.
