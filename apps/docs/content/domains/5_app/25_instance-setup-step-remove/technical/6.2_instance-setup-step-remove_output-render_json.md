# JSON Renderer: `orbit instance-setup-step:remove`

[Back to `instance-setup-step:remove` technical contract.](1_instance-setup-step-remove.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

`success.data.step` contains the removed instance-owned setup step, including
`project` and `instance`. `success.meta.action` contains `removed`.

## Error Shape

The top-level envelope is either `success` or `error`.

Exhaustive command-specific codes:

- `instance.not_found`
- `instance.setup_step_not_found`
- `validation_failed`
- `authorization_failed`
