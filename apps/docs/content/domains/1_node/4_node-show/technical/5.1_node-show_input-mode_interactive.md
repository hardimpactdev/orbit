# Interactive Input Mode: `orbit node:show [name]`

[Back to `node:show` technical contract.](1_node-show.md)

This page describes how interactive input mode resolves `node:show` input before
command behavior starts.

**Input mode:** Interactive.

## Selection

Use this input mode only when both conditions are true:

- the command is running in a TTY;
- `--json` is not present.

When `--json` is present, use
[`5.2_node-show_input-mode_non-interactive.md`](5.2_node-show_input-mode_non-interactive.md) even if the process has a TTY.

## Responsibilities

- Read any supplied arguments and options.
- Prompt for `name` with a finite node data table when `[name]` is missing.
- Validate field-local values immediately when a supplied value is read or a
prompt is submitted.
- Re-prompt after invalid field-local values.
- Stop before side effects when a resolved value violates a domain rule that
cannot be corrected by re-prompting.

## Missing Name Resolution

When `[name]` is missing, interactive input mode must ask for the target node
with a `datatable`. It must not silently use the local default node or the
calling node because the visible node choices are finite and reviewable.

The prompt primitive is `datatable` with label `Select a node`. Rows are visible
active node records, including primary role, role assignments, host, and status.

## Prompt Mapping

### `node_show.name`

| Property | Value |
| --- | --- |
| Primitive | `datatable` |
| Label | `Select a node` |
| Source | `[name]` |
| Required | yes (when `[name]` is missing) |
| Choices | Visible active nodes. |
| Default | none |
| Validation timing | When `[name]` is read or when the selected row is submitted. |
| Invalid terminal behavior | Supplied invalid values fail before side effects; prompted rows are already valid choices. |

- [`datatable`](../../../../ux/commands/lists/data-table-prompt.md)

## Failure Semantics

- Missing required input is collected by a data table prompt before side effects.
- Invalid supplied field-local input fails before side effects. Prompted values
  are selected from visible active nodes.
- Path eligibility is evaluated as soon as the prompt result makes the selected
  path knowable. If the target node does not exist or is not visible, fail
  before side effects after the name is resolved.
- If the user aborts a prompt, exit with the standard command failure status
  and do not start side effects.
