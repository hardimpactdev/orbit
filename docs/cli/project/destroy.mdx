---
title: "orbit project:destroy"
sidebarTitle: "project:destroy"
description: "Remove a Project that has no Instances and no Routes. Its definitions, setup steps, and update records go with it. Task groups must all be `cancelled` or `completed`; they and their dependent records are deleted with the Project. Any other group status returns HTTP 409 and `project.has_task_groups` without deleting anything. Every associated task VM row must be `destroyed`. A VM in any other state, including `failed`, returns HTTP 409 and `project.task_vm_not_destroyed`; the message names the VM and its state. Nothing is deleted. Wait for destruction to finish before retrying."
---

Project deletion also deletes the old workspace lease rows of its groups and their operations. See [Remove a Project](/reference/projects#remove-a-project).

```bash
orbit project:destroy <project> [--yes] [--json]
```

The CLI shows the Project and asks for confirmation, with No selected. `--yes` confirms without a prompt and is required for JSON and noninteractive calls.
