# JSON Renderer: `orbit app:analytics verify`

[Back to `app:analytics verify` technical contract.](1_app-analytics-verify.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Ready Shape

```json
{
  "success": {
    "data": {
      "verification": {
        "app": "docs",
        "ready": true,
        "hosts": [
          {
            "host": "analytics.docs.example.com",
            "route_intent": {"status": "registered"},
            "dns": {"status": "ready", "routing": "direct", "answers": [{"type": "A", "value": "93.184.216.34"}], "expected_targets": [{"type": "A", "value": "93.184.216.34"}], "matches_ingress": true},
            "tls": {"status": "ready", "verified": true},
            "script": {"status": "ready", "url": "https://analytics.docs.example.com/js/script.js", "http_status": 200},
            "dashboard": {"status": "not_exposed", "url": "https://analytics.docs.example.com/", "http_status": 404},
            "event": {"status": "not_run"},
            "plausible_site": {"status": "unchecked", "reason": "Plausible credentials are not managed by Orbit."},
            "ready": true
          }
        ]
      }
    },
    "meta": []
  }
}
```

`dns.status=unsafe` means the stored host was not a multi-label DNS hostname or
resolution returned only private/reserved addresses. Orbit does not perform an
HTTPS request in that state.

## Not-ready Shape

```json
{
  "error": {
    "code": "analytics.public_not_ready",
    "message": "App analytics public readiness is incomplete.",
    "meta": {"app": "docs"},
    "data": {"verification": {"app": "docs", "ready": false, "hosts": []}}
  }
}
```
