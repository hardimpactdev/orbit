# Human Renderer: `orbit app:setup`

[Back to `app:setup` technical contract.](1_app-setup.md)

## Primitive

- Progress tree: [`progress-tree`](../../../../ux/commands/progress/progress-tree.md)

Skipped setup renders one concise success result.

## Progress Tree

The progress tree contains a root labeled `Setting Up App`. It includes app
resolution and setup-step execution when steps exist.

## Human Strings

- Success: `App ready and available at: {url}`
- Skipped: `App setup already completed for current steps.`
- Failure: `app.setup_failed: App setup failed.`
