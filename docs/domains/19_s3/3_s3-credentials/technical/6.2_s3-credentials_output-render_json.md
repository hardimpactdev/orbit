# JSON Renderer: `orbit s3:credentials`

[Back to `s3:credentials` technical contract.](1_s3-credentials.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "credentials": {
        "node": "storage-1",
        "private_endpoint": "https://s3.orbit",
        "public_endpoints": ["https://s3.example.com"],
        "region": "orbit",
        "access_key_id": "<generated-access-key>",
        "secret_access_key": "<generated-secret-key>",
        "bucket_endpoint_style": "path",
        "backend_pool": ["http://storage-1.s3.orbit:9000"]
      }
    },
    "meta": {
      "tool": "rustfs"
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "s3.credentials_missing",
    "message": "RustFS service credentials are missing for 'storage-1'.",
    "meta": {
      "node": "storage-1",
      "tool": "rustfs",
      "next_command": "doctor --fix --family=tool --restore --node=storage-1"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.credentials.node` | string | Selected active s3 node. |
| `success.data.credentials.private_endpoint` | string | Stable private endpoint, always `https://s3.orbit`. |
| `success.data.credentials.public_endpoints` | string[] | Public S3 HTTPS endpoints published for the selected node. |
| `success.data.credentials.region` | string | S3 region value for client configuration. |
| `success.data.credentials.access_key_id` | string | RustFS service access key id. |
| `success.data.credentials.secret_access_key` | string | RustFS service secret access key. |
| `success.data.credentials.bucket_endpoint_style` | string | Endpoint style. V1 returns `path`. |
| `success.data.credentials.backend_pool` | string[] | Router-owned RustFS backend URLs. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `s3.credentials_missing` | Stable command failure code. |
