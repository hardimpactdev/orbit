# Human Renderer: `orbit extension:disable`

[Back to `extension:disable` technical contract.](1_extension-disable.md)

**Renderer:** Human renderer.

## Primitive

None. The current renderer prints the shared success or failure output.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered. Disablement returns a compact success or failure
message.

## Output

Successful local or gateway disablement renders the shared success output for
the returned extension state. There is no confirmation prompt in this slice.
