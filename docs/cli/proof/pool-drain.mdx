```bash
orbit proof:pool:drain
```

Use it before a maintenance window that needs every copy of the proof Project's default gone. It is the one command for that.

The command does three things:

- It records the drain. The drain lasts until [`orbit proof:pool:resume`](/cli/proof/pool-resume), also across Gateway restarts.
- It destroys each idle [warm copy](/cli/proof/run#warm-copies). A warm copy whose create still runs is destroyed when the create ends.
- It stops every refill. No new warm copy is made while the pool is drained.

Running proofs are not touched. Their copies, also those taken from the pool, are destroyed at the end of each run, as always. A proof that starts while the pool is drained finds no warm copy and creates its copies.

The answer lists the warm copies whose destroy started and the proof copies that still run. Run the command again to see both lists. The window can start when both are empty. A second drain changes nothing else.

The caller needs Gateway access, as for [`orbit proof:run`](/cli/proof/run).

## How it works

The Gateway records the drain and cancels the task group of each idle warm copy with discard. Each cancel destroys its copy and drops the copy's hold on its Node's places. The destroy of the last copy on a Node starts that Node's stopped runners again.

## Errors

The command has no error of its own. A caller without Gateway access is refused as on every Gateway route.
