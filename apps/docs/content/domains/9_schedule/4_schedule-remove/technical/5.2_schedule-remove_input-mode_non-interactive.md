# Non-Interactive Input Mode: `orbit schedule:remove`

[Back to `schedule:remove` technical contract.](1_schedule-remove.md)

**Input mode:** Non-interactive.

## Mode Selection

This contract applies without a TTY or when `--json` is present. `--json` forces non-interactive input mode.

## Behavior

No prompts are rendered. `name` must resolve from arguments, optional filters must disambiguate duplicate visible names, and `--force` is required before side effects. Missing `name` fails before side effects with `error.code=validation_failed`. Ambiguous scope fails with `error.code=validation_failed`. Missing `--force` fails before side effects with `error.code=validation_failed`, `error.meta.field=force`, and `error.meta.reason=destructive_consent_required`.

`--json` selects the JSON renderer only. It does not change validation, does not grant authorization, and does not imply destructive consent.
