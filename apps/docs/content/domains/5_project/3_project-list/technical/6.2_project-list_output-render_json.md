# JSON Renderer: `orbit project:list`

[Back to `project:list` technical contract.](1_project-list.md)

This page describes the JSON-rendered output for `project:list`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The app array is rendered as a flat array under `success.data.projects`. Apps are
sorted by project name (ascending, case-insensitive). Each project appears at
most once as a compact summary. Counts are fields on that same row. The payload
has no parallel `inventory` array and exposes no concrete placement details.

`project:list` does not include `success.data.context` because it has no resolved
node or execution context.

`project:show` returns the canonical project entity. It also returns concrete
instances visible to the caller and their nested workspaces. It does not use a
singular placement-shaped project entity, and `project:list` does not use that shape.

## Success Shape

```json
{
  "success": {
    "data": {
      "projects": [
        {
          "name": "docs",
          "repository": "git@github.com:example/docs.git",
          "dependency_audit_status": "findings",
          "dependency_warning_count": 3,
          "dependency_danger_count": 1,
          "last_dependency_audit_at": "2026-07-02T08:15:00+00:00",
          "instance_count": 1,
          "workspace_count": 1
        }
      ]
    },
    "meta": []
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `projects` | array | Ordered list of visible projects, with every app included at most once. |
| `projects[]` | object | Compact project summary. It is not the placement-shaped `project:show` entity. |
| `projects[].name` | string | Globally unique project name. |
| `projects[].repository` | string \| null | Recorded source repository, or `null`. |
| `projects[].dependency_audit_status` | string | Aggregate dependency-audit posture across recorded package-manager summaries. |
| `projects[].dependency_warning_count` | integer | Aggregate warning findings count. |
| `projects[].dependency_danger_count` | integer | Aggregate danger findings count. |
| `projects[].last_dependency_audit_at` | string \| null | Latest audit/failure timestamp, or `null` when no summary exists. |
| `projects[].instance_count` | integer | Number of placement-visible instances. |
| `projects[].workspace_count` | integer | Number of placement-visible workspaces on `app-dev` instances. |

The row must not include `node`, `url`, `path`, `root`, `runtime`,
`runtime_config`, `php_version`, worker settings, `instances`, or `workspaces`.
Use `project:show` for those details.

## Enum and identifier values

| Field | Values |
| --- | --- |
| `projects[].dependency_audit_status` | `unknown`, `clean`, `findings`, `failed`, `unsupported`, `not_applicable` |

## Error Shapes

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to list projects.",
    "meta": []
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized to read the project registry.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "project:read"
    }
  }
}
```
