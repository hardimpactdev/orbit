# JSON Renderer: `orbit activity:show [id]`

[Back to `activity:show` technical contract.](1_activity-show.md)

This page describes the JSON-rendered output for `activity:show`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](../../../README.md#invocation-model), even when
the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Validation failures, not-found failures, gateway reachability failures, and
authorization failures must all use this envelope.

## Success Shape

```json
{
  "success": {
    "data": {
      "activity": {
        "id": 42,
        "occurred_at": "2026-05-02T08:30:00+00:00",
        "correlation_id": "9f7307e8-38b2-45b8-9b94-cfc341456b85",
        "type": "workspace.created",
        "effect": "write",
        "subject": {
          "type": "workspace",
          "name": "feature-docs"
        },
        "actor": {
          "node": "client-1"
        },
        "command": "workspace:setup",
        "description": "Workspace feature-docs was created.",
        "properties": {
          "app": "docs",
          "workspace": "feature-docs"
        },
        "channel": "api"
      },
      "related": [
        {
          "id": 41,
          "occurred_at": "2026-05-02T08:29:58+00:00",
          "correlation_id": "9f7307e8-38b2-45b8-9b94-cfc341456b85",
          "type": "workspace.create_requested",
          "effect": "read",
          "subject": {
            "type": "workspace",
            "name": "feature-docs"
          },
          "actor": {
            "node": "client-1"
          },
          "command": "workspace:setup",
          "description": "Workspace feature-docs setup was requested.",
          "properties": {
            "app": "docs",
            "workspace": "feature-docs"
          },
          "channel": "api"
        }
      ]
    },
    "meta": {
      "related_count": 1
    }
  }
}
```

When no related activity is visible, `related` is an empty array and
`related_count` is `0`.

| Field | Type | Meaning |
| --- | --- | --- |
| `activity` | object | Selected activity entry. |
| `activity.id` | integer | Stable gateway activity id. |
| `activity.occurred_at` | string | ISO-8601 timestamp recorded by the gateway. |
| `activity.correlation_id` | string \| null | UUID shared by records from the same operation. |
| `activity.type` | string | Stable activity type, such as `workspace.created`. |
| `activity.effect` | string | Recorded effect of the activity entry. |
| `activity.subject` | object \| null | Recorded subject reference for the activity entry. |
| `activity.actor` | object \| null | Gateway-known node identity that caused the activity when available. |
| `activity.command` | string \| null | CLI command name when the entry came from a command. |
| `activity.description` | string \| null | Human-readable description. Automation must not parse it. |
| `activity.properties` | object | Type-specific structured audit data. Canonical fields such as `effect` remain top-level. |
| `activity.channel` | string | Canonical origin channel (`cli` or `api`). Internal rows use `api` plus lane and transport properties. |
| `related[]` | array | Other visible entries from the same correlation id, ordered oldest first. Every item uses the same complete Activity DTO as `activity`. |
| `related_count` | integer | Count of returned related entries. |

## Error Shapes

### Validation failed

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Activity id must be a positive integer.",
    "meta": {
      "field": "id",
      "reason": "invalid"
    }
  }
}
```

### Activity not found

```json
{
  "error": {
    "code": "activity_not_found",
    "message": "Activity 42 was not found or is not visible.",
    "meta": {
      "id": 42
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to show activity.",
    "meta": []
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized to read gateway activity history.",
    "meta": []
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `activity.effect` | `read`, `write`, `destructive` |
| `related[].effect` | `read`, `write`, `destructive` |
| `activity.channel`, `related[].channel` | `cli`, `api` |
| `error.meta.reason` | `missing`, `invalid` |
| `error.code` | `validation_failed`, `activity_not_found`, `gateway_unavailable`, `authorization_failed` |

The `error.code` values listed here are exhaustive for `activity:show`. Add a
new value to this renderer contract before implementing another JSON failure
code.
