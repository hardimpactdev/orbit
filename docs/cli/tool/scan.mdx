---
title: "orbit tool:scan"
sidebarTitle: "tool:scan"
---

List installed apt packages, Homebrew formulae, casks, and Vite+ global packages for one Node from the Node agent's latest reports. It reads nothing on the Node. The result distinguishes registered ownership, dependencies, adoption support, and each manager's scan state. It changes no packages or Tool records. A manager the agent has not reported is explicit, not an empty inventory. The HTTP shape, scan states, and error codes are in [Discover installed packages](/reference/tools#discover-installed-packages).

Human output shows the Node, the time of the oldest report it used, and one row for each manager's scan state. It then shows one row for each package from a `complete` manager: manager, package, kind, version, dependency, Tool ID when the package is registered, and adoption. An unsupported package includes its block token. A null version, including a non-SemVer formula revision, is an em dash. A manager that is `unsupported` or not observed yet is named separately, because its empty package list is not an inventory. JSON output is that inventory plus `request_id`.

```bash
orbit tool:scan --node=ID [--json]
```
