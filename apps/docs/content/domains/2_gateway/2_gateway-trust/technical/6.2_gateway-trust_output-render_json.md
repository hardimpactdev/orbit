# JSON Renderer: `orbit gateway:trust`

[Back to `gateway:trust` technical contract.](1_gateway-trust.md)

This page describes the JSON-rendered output for `gateway:trust`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](../../../README.md#invocation-model), even when
the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Input validation failures, local-context failures, gateway reachability
failures, invalid trust material, unsupported platform failures, trust-store
failures, and local metadata failures must all use this envelope.

## Success Shape

```json
{
  "success": {
    "data": {
      "gateway_trust": {
        "gateway_url": "https://10.6.0.2",
        "trusted": true,
        "status": "trusted",
        "ca_sha256": "5f2c2f4c7b6f0d4b3e8e27af2a84392c6f0b9a7b4e78a9b1c9d2e3f4a5b6c7d8"
      }
    },
    "meta": {
      "trusted_at": "2026-05-02T08:30:00+00:00"
    }
  }
}
```

Already-trusted convergence uses the same shape with
`gateway_trust.status` set to `already_trusted`.

| Field | Type | Meaning |
| --- | --- | --- |
| `gateway_trust.gateway_url` | string | Normalized configured gateway URL. |
| `gateway_trust.trusted` | boolean | `true` after the local trust check or installation succeeds. |
| `gateway_trust.status` | string | `trusted` when installed or refreshed; `already_trusted` when no trust-store write was needed. |
| `gateway_trust.ca_sha256` | string | SHA-256 hex fingerprint of the installed PEM certificate bytes. |
| `trusted_at` | string | ISO-8601 timestamp recorded after local trust succeeds. |

## Error Shapes

### Gateway missing

```json
{
  "error": {
    "code": "validation_failed",
    "message": "No gateway is configured. Run orbit gateway:add first.",
    "meta": {
      "field": "gateway",
      "reason": "missing"
    }
  }
}
```

### Local config read failed

```json
{
  "error": {
    "code": "node.local_config_read_failed",
    "message": "Local Orbit database is locked. Another Orbit process may be writing; try again.",
    "meta": {
      "field": "gateway",
      "reason": "local_database_locked"
    }
  }
}
```

The same error code is used for the other actionable local settings read
failures:

```json
{
  "error": {
    "code": "node.local_config_read_failed",
    "message": "Local Orbit database is unavailable. Check the database file path and permissions.",
    "meta": {
      "field": "gateway",
      "reason": "local_database_unavailable"
    }
  }
}
```

```json
{
  "error": {
    "code": "node.local_config_read_failed",
    "message": "Local Orbit database is read-only. Check the database file permissions.",
    "meta": {
      "field": "gateway",
      "reason": "local_database_read_only"
    }
  }
}
```

```json
{
  "error": {
    "code": "node.local_config_read_failed",
    "message": "Local Orbit database file is corrupt or unreadable.",
    "meta": {
      "field": "gateway",
      "reason": "local_database_corrupt"
    }
  }
}
```

```json
{
  "error": {
    "code": "node.local_config_read_failed",
    "message": "Local gateway settings table is missing. Run database migrations.",
    "meta": {
      "field": "gateway",
      "reason": "settings_table_missing"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Could not fetch the gateway CA from https://10.6.0.2.",
    "meta": {
      "gateway_url": "https://10.6.0.2",
      "endpoint": "/api/ca/root"
    }
  }
}
```

### Invalid trust material

```json
{
  "error": {
    "code": "node.gateway_api_error",
    "message": "Gateway returned invalid CA material.",
    "meta": {
      "gateway_url": "https://10.6.0.2",
      "endpoint": "/api/ca/root",
      "reason": "invalid_trust_material"
    }
  }
}
```

### Unsupported platform

```json
{
  "error": {
    "code": "node.unsupported_platform",
    "message": "This platform does not support automatic gateway CA trust installation.",
    "meta": {
      "platform": "linux-unknown",
      "reason": "unsupported_trust_store"
    }
  }
}
```

### Local trust failed

```json
{
  "error": {
    "code": "node.local_config_write_failed",
    "message": "Failed to install the gateway CA into the local trust store.",
    "meta": {
      "gateway_url": "https://10.6.0.2",
      "reason": "trust_store_failed"
    }
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `gateway_trust.trusted` | `true` |
| `gateway_trust.status` | `trusted`, `already_trusted` |
| `error.meta.reason` | `missing`, `invalid`, `local_database_unavailable`, `local_database_locked`, `local_database_read_only`, `local_database_corrupt`, `settings_table_missing`, `invalid_trust_material`, `unsupported_trust_store`, `trust_store_failed`, `metadata_write_failed` |
| `error.code` | `validation_failed`, `node.local_config_read_failed`, `gateway_unavailable`, `node.gateway_api_error`, `node.unsupported_platform`, `node.local_config_write_failed` |

The `error.code` values listed here are exhaustive for `gateway:trust`. Add a
new value to this renderer contract before implementing another JSON failure
code.
