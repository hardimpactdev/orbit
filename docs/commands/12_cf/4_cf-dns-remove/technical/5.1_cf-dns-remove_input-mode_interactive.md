# Interactive Input Mode: `orbit cf-dns:remove`

[Back to `cf-dns:remove` technical contract.](1_cf-dns-remove.md)

**Input mode:** Interactive.

## Selection

Use this input mode only when the process has a TTY and `--json` is not
present.

## Prompt Behavior

When `--force` is absent, render a confirmation prompt after `record-id` and
`zone` resolve and before side effects:

| Prompt ID | Primitive | Label | Default |
| --- | --- | --- | --- |
| `cf_dns_remove_confirm` | `confirm` | `Remove Cloudflare DNS record <record-id> from <zone>?` | `false` |

Supplying `--force` is explicit destructive consent and skips the confirmation
prompt. Declining the prompt fails before side effects.
