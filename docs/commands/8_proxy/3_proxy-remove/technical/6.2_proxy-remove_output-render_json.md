# JSON Renderer: `orbit proxy:remove`

[Back to `proxy:remove` technical contract.](1_proxy-remove.md)

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "route": {
        "domain": "old.test",
        "kind": "redirect",
        "owner": {
          "type": "custom",
          "name": null
        },
        "node": "app-1",
        "target": {
          "type": "redirect",
          "value": "https://docs.test"
        },
        "redirect_code": 302,
        "tls": {
          "managed_by": "orbit",
          "trusted_by_gateway_ca": true
        },
        "status": "removed"
      }
    },
    "meta": {
      "backend_removed": true,
      "tls_removed": true
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "proxy.cleanup_failed",
    "message": "The proxy route was removed from gateway intent, but backend cleanup failed.",
    "data": {
      "route": {
        "domain": "old.test",
        "kind": "redirect",
        "owner": {
          "type": "custom",
          "name": null
        },
        "node": "app-1",
        "target": {
          "type": "redirect",
          "value": "https://docs.test"
        },
        "redirect_code": 302,
        "tls": {
          "managed_by": "orbit",
          "trusted_by_gateway_ca": true
        },
        "status": "removed_with_drift"
      }
    },
    "meta": {
      "next_command": "doctor --family=proxy --fix --node=app-1"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.route` | object | Removed custom proxy route. |
| `success.meta.backend_removed` | boolean | Whether backend route cleanup completed. |
| `success.meta.tls_removed` | boolean | Whether route-scoped TLS cleanup completed. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `proxy.not_found`, `proxy.owned_route_denied`, `destructive_consent_required`, `proxy.cleanup_failed` | Stable command failure code. |
| `error.data.route` | object | Removed route when cleanup failed after gateway intent removal. |
| `error.meta` | object | Field, node, owner, caller, or recovery context for automation. |
