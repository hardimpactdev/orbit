# JSON Renderer: `orbit tool:logs`

[Back to `tool-logs` technical contract.](1_tool-logs.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a single machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "logs": {
        "tool": "dns",
        "node": "gateway",
        "runtime": "tool",
        "lines": [
          {
            "message": "dns ready"
          }
        ]
      }
    },
    "meta": {
      "line_count": 1
    }
  }
}
```

A process-backed result also includes process runtime metadata from the exact
resolved process row.

## Error Shape

```json
{
  "error": {
    "code": "tool.runtime_ambiguous",
    "message": "More than one runtime matches this tool action.",
    "meta": {
      "tool": "caddy",
      "action": "logs"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `node.agent_unreachable`, `tool.not_found`, `tool.unsupported_action`, `tool.unsupported_on_node`, `tool.runtime_missing`, `tool.runtime_ambiguous`, `tool.remote_action_failed` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.meta` | object | Field, target, caller, or runtime context for automation. |

`node.agent_unreachable` includes `error.meta.reason=agent_push_unavailable`.
