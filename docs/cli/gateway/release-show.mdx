---
title: "orbit gateway:release:show"
sidebarTitle: "gateway:release:show"
description: "Show one release record."
---

```bash
orbit gateway:release:show [<release>] [--json]
```

| Argument | Meaning |
| --- | --- |
| `release` | A record id of one to six digits, or a hex SHA of 7 to 40 characters for the newest record of that commit. In a terminal, an omitted value opens a list of the records. |

JSON returns the record. `gateway.release_not_found` means no record matches, and `gateway.release_id_invalid` means the selector has another form.

For a verified release, `phases.fleet.status` is `current` when every eligible Node has applied the agent pin and its selected role inputs. With `--json`, `phases.fleet.nodes` shows each Node, its Operation IDs and role outcomes. See [Fleet rollout](/reference/gateway-recovery#fleet-rollout). A [follow-up phase](/reference/gateway-recovery#follow-up-phases), such as `phases.ai_router_guard`, has its own `status`, `error_code` and Operation ID.
