# JSON Renderer: `orbit deploy:step-add`

[Back to `deploy:step-add` technical contract.](1_deploy-step-add.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "step": {
        "id": 12,
        "project": "docs",
        "instance": "production",
        "title": "Pull latest",
        "command": "git pull origin main",
        "order": 1,
        "timeout_seconds": 600,
        "retention": null
      }
    },
    "meta": {
      "action": "created"
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "deploy.production_project_required",
    "message": "App 'docs' is not a production project.",
    "meta": {
      "project": "docs",
      "environment": "development"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.step` | object | Deploy step entity defined in [`10_deploy/README.md`](../../README.md#deploy-step-json-entity). |
| `success.meta.action` | string | `created`. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `instance.not_found`, `deploy.production_project_required` | Stable command failure code. `validation_failed` with `error.meta.reason=instance_required` reports an ambiguous bare project selector. |
| `error.meta` | object | Field, missing permission, app selector, app environment, or authorization context for automation. |
