# Human Renderer: `orbit deploy:log`

[Back to `deploy:log` technical contract.](1_deploy-log.md)

**Renderer:** Human terminal renderer.

## Primitive

None. Renderer prints a run detail view with grouped captured output, not a list or progress primitive.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered because execution is a gateway-local database read
expected to stay below one second and performs no slow external work.

## Log Output

The human renderer shows a run header, step summaries, and captured output
grouped by deployment step.

```text
Deployment Log: docs run #42

✔ Pull latest (exit 0)
STDOUT:
Already up to date.

✘ Run migrations (exit 1)
STDERR:
Migration table is locked.
```

When `--step` is present, only the selected step is shown. When `--lines` trims
captured output, the renderer indicates that the stream was truncated by the
display filter.

## Failure Output

Validation and not-found failures render the rejected field, app selector, run
id, or step id. Gateway and authorization failures render the selected app when
available. Log read failures render the run id when available.
