# Interactive Input: `orbit node role:remove`

[Back to `node role:remove` technical contract.](1_node-role-remove.md)

**Input mode:** Interactive.

Applies only with a TTY and without `--json`.

## Prompt Behavior

Prompt behavior:
- When `--force` is absent, request a no-side-effect gateway preview after
  node and role validation.
- Render the returned dependent-resource summaries as `Dependent resources:`
  list items when the list is non-empty.
- Render a destructive confirmation prompt before side effects even when the
  returned dependent list is empty.
- `--force` bypasses the confirmation prompt.
- Rejected confirmation fails with `error.code=validation_failed`,
  `error.meta.field=force`, and
  `error.meta.reason=destructive_consent_required`.

Confirmation prompt:
- `Remove role '<role>' from '<node>'?`
