# Human Renderer: `orbit instance:add`

[Back to `instance:add` technical contract.](1_instance-add.md)

**Renderer:** Human renderer.

## Primitive

None. The command writes a compact confirmation.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered; creation is one gateway request.

## Success Render

Print the created instance name, app, driver, and required extensions when
present.

## Error Render

Render driver validation, authorization, and gateway failures directly.
