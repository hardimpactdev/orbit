# Interactive Input Mode: `orbit s3:credentials`

[Back to `s3:credentials` technical contract.](1_s3-credentials.md)

**Input mode:** Interactive.

## Mode Selection

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Flow

Prompts render after gateway reachability is known and before the gateway reads
credential material.

| Prompt ID | Primitive | Rendered when | Validation |
| --- | --- | --- | --- |
| `s3.node` | `datatable` | `--node` is absent and more than one visible active s3 node exists. | Visible active node with the `s3` role. |

Invalid prompt answers re-prompt until the value is valid or the operator
aborts. Abort fails before credential material is read.
