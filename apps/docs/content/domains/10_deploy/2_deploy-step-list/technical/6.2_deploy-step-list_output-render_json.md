# JSON Renderer: `orbit deploy:step-list`

[Back to `deploy:step-list` technical contract.](1_deploy-step-list.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "steps": [
        {
          "id": 12,
          "app": "docs",
          "app_instance": "production",
          "title": "Pull latest",
          "command": "git pull origin main",
          "order": 1,
          "timeout_seconds": 600,
          "retention": null
        }
      ]
    },
    "meta": {
      "app": "docs",
      "app_instance": "production",
      "count": 1
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "app.not_found",
    "message": "App 'docs' was not found.",
    "meta": {
      "app": "docs"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.steps[]` | array | Deploy step entities visible for the selected app instance. |
| `success.meta.app` | string | Selected production app. |
| `success.meta.app_instance` | string | Selected concrete app instance. |
| `success.meta.count` | integer | Number of returned steps. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `app.not_found`, `deploy.production_app_required` | Stable command failure code. `validation_failed` with `error.meta.reason=app_instance_required` reports an ambiguous bare app selector. |
| `error.meta` | object | Field, app selector, app environment, missing permission, or authorization context for automation. |
