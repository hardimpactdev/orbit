# Non-Interactive Input Mode: `orbit tool:remove`

[Back to `tool-remove` technical contract.](1_tool-remove.md)

**Input mode:** Non-interactive.

This contract applies without a TTY or when `--json` is present. `--json` forces non-interactive input mode.

## Resolution Rules

No prompts are rendered. All required fields must be supplied by arguments,
options, or local defaults. Every removal in non-interactive mode requires
`--force`, including JSON mode. Missing `--force` fails before side effects with `validation_failed`,
`meta.field=force`, and `meta.reason=destructive_consent_required`.

`--json` forces non-interactive input mode and selects the JSON renderer. It
never grants destructive consent. Ordinary tool, target, authorization, and
existence validation still apply before side effects.
