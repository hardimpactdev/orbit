# JSON Renderer: `orbit metrics:disable`

[Back to `metrics:disable` technical contract.](1_metrics-disable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "node": "metrics-1",
      "role": "metrics",
      "purged_data": false
    },
    "meta": []
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Use --force to disable metrics.",
    "meta": {
      "field": "force",
      "reason": "destructive_consent_required"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.node` | string | Target node. |
| `success.data.role` | string | Always `metrics`. |
| `success.data.purged_data` | boolean | Whether purge cleanup was requested. |
| `success.meta` | array | Always present; empty for this command. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `node_role.remove_blocked`, `node_role.remove_failed` | Stable command failure code. |
| `error.meta.field` | string | `force` when destructive consent is missing. |
| `error.meta.reason` | string | `destructive_consent_required` when destructive consent is missing. |
