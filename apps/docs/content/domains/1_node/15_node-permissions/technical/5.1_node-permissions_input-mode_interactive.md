# Interactive Input: `orbit node:permissions`

[Back to `node:permissions` technical contract.](1_node-permissions.md)

**Input mode:** Interactive.

Applies only with a TTY and without `--json`.

## Prompt behavior

- Prompt for the consuming node when `[consuming_node]` is omitted, using a
  searchable selector that lists the active node records the caller may
  administer.
- Prompt for the serving node when `[serving_node]` is omitted, using the
  same selector source.
- Prompt for the permission set with a multiselect. Preselect the current
  grant permissions when an edge exists; preselect nothing when the edge is
  missing.
- Submitting the multiselect against an existing grant updates the
  permission set to exactly the selected normalized permissions.
- Submitting a non-empty multiselect against a missing grant creates the
  grant edge with that normalized set.

## Authorization

- All prompts are gated by the `node:permissions` authorization check. Callers
  without `node:permissions` or `*` on a grant to the gateway receive
  `authorization_failed` before the first prompt renders.
