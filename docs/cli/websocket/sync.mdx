---
title: "orbit websocket:sync"
sidebarTitle: "websocket:sync"
description: "Record a sync Operation and wait for confirmation without restarting the serving processes."
---

```bash
orbit websocket:sync [--wait=60] [--operation-key=<key>] [--json]
```

| Option | Meaning |
| --- | --- |
| `--wait` | Maximum wait in seconds, from 0 to 3600. Default: 60. The CLI polls operation status until the wait ends. |
| `--operation-key` | Reuse this key to retry the same sync. |
| `--json` | Return machine-readable JSON. |

The command exits unsuccessfully if the deadline passes while application is pending. It does not undo the saved change.
