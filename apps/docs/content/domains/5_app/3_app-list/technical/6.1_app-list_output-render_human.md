# Human Renderer: `orbit app:list`

[Back to `app:list` technical contract.](1_app-list.md)

This page describes the human-rendered output for `app:list`.

**Renderer:** Human renderer.

## Primitive

- Data list: [`Laravel\Prompts\datatable`](../../../../ux/commands/lists/data-list.md)

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered because `app:list` is expected to stay below one
second. It performs a fast gateway database read and does not perform slow
external work, network probes, or remote node application.

## Success Render

The success output starts with one Laravel Prompts data list. Logical apps are
ordered alphabetically by app name (case-insensitive), keyed by app name, and
rendered with these exact columns:

- `Name`
- `Repository`
- `Instances`
- `Workspaces`

The prompt label is `Select an app` and its hint is `Press / to search`.
Selecting a row immediately renders the selected app through `app:show`, where
instance and nested workspace placement rows appear.

This renderer requires an interactive terminal. Non-interactive callers use
`app:list --json`; otherwise the command returns `validation_failed` before
gateway I/O.

### Example output

```text
 ┌ Select an app ─────────────────────────────────────────────────────┐
 │ / Search                                                           │
 ├──────┬─────────────────────────────────────┬───────────┬────────────┤

 │ docs │ git@github.com:example/docs.git     │ 1         │ 3          │
 └──────┴─────────────────────────────────────┴───────────┴────────────┘

 App: blog
 ...
```

### Empty result

When no apps are visible:

```text
No apps found.
```

## Error Render

Errors are rendered as concise prose messages.

### Gateway unavailable

```text
Gateway connection is required to list apps.
```

Authorization failures originate at the API permission middleware and are
documented as part of the JSON renderer contract (see
[`6.2_app-list_output-render_json.md`](6.2_app-list_output-render_json.md)).
The command's human renderer does not own that failure shape, so it is not
covered here.

### Selection cancelled

```text
validation_failed: Operation cancelled.
```

### Non-interactive human output

```text
validation_failed: Interactive app selection requires a terminal. Use --json for non-interactive output.
```
