# JSON Renderer: `orbit skill:install`

[Back to `skill:install` technical contract.](1_skill-install.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "action": "installed",
      "provider": "codex",
      "target": "/Users/example/.agents/skills/orbit",
      "source": "/Users/example/orbit/.agents/skills/orbit"
    },
    "meta": []
  }
}
```

`success.data.provider` is `null` when the caller provides a raw explicit path
without a known provider slug.

## Error Shape

Missing target input:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Provide a provider slug or an explicit target path.",
    "meta": {
      "fields": ["provider", "path"],
      "reason": "missing_target"
    }
  }
}
```

Existing target without `--force`:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Use --force to overwrite the existing skill target.",
    "meta": {
      "field": "target",
      "reason": "target_exists",
      "target": "/Users/example/.agents/skills/orbit"
    }
  }
}
```

Missing `HOME` for a provider default:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "HOME environment variable is required for provider default installs.",
    "meta": {
      "field": "home",
      "reason": "missing_home",
      "provider": "codex"
    }
  }
}
```

Documented `error.code` values named for coverage tracking:
`validation_failed`, `skill.install_failed`.
