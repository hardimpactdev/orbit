# Human Renderer: `orbit gateway:use <name>`

[Back to `gateway:use` technical contract.](1_gateway-use.md)

This page describes the human-rendered output for `gateway:use`.

**Renderer:** Human renderer.

## Primitive

None. Output is printed as plain text lines.

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered because `gateway:use` is a local-only write
command that does not contact the gateway API or perform external network work.

## Success Render

Human output reports the selected gateway name and endpoint.

## Error Render

Errors are rendered as concise prose messages.

### Unknown gateway

```text
No gateway named '<name>' is configured.
```
