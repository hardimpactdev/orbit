# Native artifact candidates

Gateway admission owns the ordered artifact URLs for Tool Manager SHA-256 artifacts, role PHP packages and native Caddy. The retained agent Caddy contract is unchanged.

The pinned `@swamp/cfgmgmt` 2026.11.01.1 fetch accepts one URL and discards curl/wget exit codes when it writes failed state. Its `Download failed:` text cannot distinguish transport errors from local I/O. The shared `node-artifact-fetch` workflow uses its read-only checksum check to retain valid cache files, then official `@swamp/ssh.exec` with `okExitCodes: any` to download into a run-specific staging path. The pure decoder allows only curl transport exit codes; it never reads error text or previous-run state. curl is a managed Node prerequisite.

A native assertion requires a successful transfer. Native SHA-256 verification fails the step on a mismatch before permission changes and atomic publication. A failed integrity check never tries upstream. A terminal native assertion requires verified publication or a repaired valid cache file. Step lookups tolerate absent guarded-step entries. Dependencies explicitly accept guarded skips, so a mirror hit still reaches verification and publication. Cleanup removes the staged file after success, failure or a guarded skip. curl uses HTTPS, a 512 MiB limit, a 15s connect timeout and a 600s total timeout. Each transfer has a 630s outer bound; checksum, publication and cleanup commands have 30s bounds. No custom transport or shipped script is added.

The Swamp references used are `references/workflow/reference.md` (Guard, Assert and dependency conditions), `references/workflow/references/direct-execution.md`, and the installed official SSH `models/_lib/schemas.ts` and `operations.ts` (`okExitCodes`, structured `exitCode`, argv and stdin). `node.role_add.missing-mirror` removes cached Caddy and admits an absent mirror in the disposable Gateway, proving upstream recovery through the production child workflow.
