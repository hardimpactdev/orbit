# Interactive Input Mode: `orbit schedule:add`

[Back to `schedule:add` technical contract.](1_schedule-add.md)

**Input mode:** Interactive.

Applies when the command is attached to a TTY and `--json` is not present.

## Prompt Behavior

Interactive input mode prompts only for missing required fields after applying
provided arguments, options, and local defaults.

| Prompt ID | Primitive | Field | Shown when | Validation |
| --- | --- | --- | --- | --- |
| `schedule.add.name` | `text` | `name` | No name argument was supplied. | Unique schedule slug within the selected scope. |
| `schedule.add.target_type` | `select` | target selector | Neither `--app` nor `--node` resolved a target. | `app` or `node`. |
| `schedule.add.app` | `datatable` | `app` | The target type is app and no app was supplied. | Visible active app the caller may manage. |
| `schedule.add.node` | `datatable` | `node` | The target type is node and no node was supplied or defaulted. | Visible active gateway or app node with schedule capability. |
| `schedule.add.execution_type` | `select` | execution selector | Neither `--command` nor `--script` was supplied. | `command` or `script`. |
| `schedule.add.command` | `text` | `command` | The execution type is command and no command was supplied. | Non-empty command accepted by policy. |
| `schedule.add.script` | `text` | `script` | The execution type is script and no script was supplied. | Managed readable script path. |
| `schedule.add.interval` | `text` | `interval` | No interval was supplied. | Portable Orbit interval expression. |
| `schedule.add.timezone` | `text` | `timezone` | The target has no default timezone. | Valid IANA timezone. |

Prompts are skipped for fields already resolved by arguments, options, or local defaults. Mutually exclusive target or execution-source options fail as soon as the conflict is known; the command does not ask unrelated later prompts.

## Abort Behavior

Prompt aborts exit with the shared Orbit command failure status and perform no gateway writes or scheduler pickup.
