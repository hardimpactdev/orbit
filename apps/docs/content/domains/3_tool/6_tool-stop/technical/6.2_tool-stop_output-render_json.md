# JSON Renderer: `orbit tool:stop`

[Back to `tool-stop` technical contract.](1_tool-stop.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a single machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

Use `--stream-json` instead of `--json` only when callers need
newline-delimited progress frames. That renderer follows the shared
[Stream JSON Frames](../../../README.md#stream-json-frames) contract.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "tool": {
        "name": "orbstack",
        "node": "mac-1",
        "action": "stop"
      }
    },
    "meta": []
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "tool.unsupported_action",
    "message": "Tool 'composer' does not support stop.",
    "meta": {
      "tool": "composer",
      "action": "stop"
    }
  }
}
```
