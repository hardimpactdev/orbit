# JSON Renderer: `orbit update`

[Back to `update` technical contract.](1_update.md)

This page describes the JSON-rendered output for `update`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](../../../README.md#invocation-model), even
when the process has a TTY.

## Relationship to human progress

The JSON renderer does not emit ANSI progress trees or live step events. It
reports the terminal state of the same steps the human renderer animates:
`check`, then — only when an update is applied — `download`, `replace`, and
`doctor`. Consumers that need machine-readable progress should use the stable
`steps[]` identifiers and statuses from the final JSON envelope.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Completed updates and both skip outcomes (already installed, gateway behind) are
success envelopes (exit 0). Check failures, download/replace failures, and
checkout-unavailable are error envelopes (exit 1).

## Success Shape

A completed update carries the version transition, the resolved versions, the
doctor issue count after the update, and the ordered steps:

```json
{
  "success": {
    "data": {
      "update": {
        "scope": "local",
        "target": "local",
        "status": "completed",
        "from_version": "0.1.129",
        "to_version": "0.1.131",
        "latest_version": "0.1.131",
        "doctor_issues": 0,
        "steps": [
          { "name": "check", "status": "completed" },
          { "name": "download", "status": "completed" },
          { "name": "replace", "status": "completed" },
          { "name": "doctor", "status": "completed" }
        ]
      }
    }
  }
}
```

When the version is already installed, the skip carries only the check step and
no version transition:

```json
{
  "success": {
    "data": {
      "update": {
        "scope": "local",
        "target": "local",
        "status": "skipped_already",
        "from_version": "0.1.131",
        "to_version": null,
        "latest_version": "0.1.131",
        "doctor_issues": null,
        "steps": [{ "name": "check", "status": "skipped" }]
      }
    }
  }
}
```

A gateway-behind skip uses status `skipped_gateway_behind` with the `check` step
`completed` (a newer release was found, but the gateway has not taken it yet).

| Field | Type | Meaning |
| --- | --- | --- |
| `update.scope` | string | Always `local` for `orbit update`. |
| `update.target` | string | Always `local` for the caller-machine checkout. |
| `update.status` | string | `completed`, `skipped_already`, or `skipped_gateway_behind`. |
| `update.from_version` | string\|null | Installed version before the update. |
| `update.to_version` | string\|null | Version updated to; `null` for skips. |
| `update.latest_version` | string\|null | Latest release resolved by the check. |
| `update.doctor_issues` | int\|null | Post-update doctor issue count; `null` when doctor did not run (skips) or could not be parsed. |
| `update.steps[]` | array | Ordered steps that ran. |
| `update.steps[].name` | string | Stable step identifier. |
| `update.steps[].status` | string | Step status. |

## Error Shapes

### Update check failed

```json
{
  "error": {
    "code": "local_update_check_failed",
    "message": "Failed to update local Orbit checkout.",
    "data": { "output": "Could not resolve the latest Orbit release version." },
    "meta": { "failed_step": "check" }
  }
}
```

### Local update failed

```json
{
  "error": {
    "code": "local_update_failed",
    "message": "Failed to update local Orbit checkout.",
    "data": { "output": "curl: (22) The requested URL returned error: 404" },
    "meta": { "failed_step": "download" }
  }
}
```

### Local checkout unavailable

```json
{
  "error": {
    "code": "local_checkout_unavailable",
    "message": "Local Orbit checkout cannot be updated.",
    "meta": { "path": "/home/orbit/orbit" }
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `update.scope` | `local` |
| `update.target` | `local` |
| `update.status` | `completed`, `skipped_already`, `skipped_gateway_behind` |
| `update.steps[].name` | `check`, `download`, `replace`, `doctor` |
| `update.steps[].status` | `completed`, `skipped`, `failed` |
| `error.code` | `local_update_check_failed`, `local_update_failed`, `local_checkout_unavailable` |
| `error.meta.failed_step` | `check`, `download`, `replace` |

The `error.code` values listed here are exhaustive for `update`. Add a new
value to this renderer contract before implementing another JSON failure code.
Captured command output is diagnostic data and belongs under `error.data.output`,
not `error.meta`.

runner.
