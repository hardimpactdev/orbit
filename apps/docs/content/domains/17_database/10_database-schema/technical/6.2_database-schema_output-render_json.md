# JSON Renderer: `orbit database:schema`

[Back to `database:schema` technical contract.](1_database-schema.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

The gateway returns the generic query-runner result shape: `data` holds the
driver-reported `columns` and `rows`, and the resolved connection identity
lives in `meta` (`connection`, `driver`) alongside the read-query metadata.

```json
{
  "success": {
    "data": {
      "columns": ["table_name", "table_type"],
      "rows": [
        { "table_name": "users", "table_type": "BASE TABLE" },
        { "table_name": "reports", "table_type": "VIEW" }
      ]
    },
    "meta": {
      "connection": "acme",
      "driver": "pgsql",
      "mode": "read",
      "limit": 10000,
      "total_rows": 2,
      "returned_rows": 2,
      "truncated": false,
      "truncated_by": [],
      "max_json_bytes": 1048576,
      "duration_ms": 4
    }
  }
}
```

## Error Shape

The top-level envelope is either `success` or `error`.
