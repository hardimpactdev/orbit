# JSON Renderer: `orbit instance:analytics enable`

[Back to `instance:analytics enable` technical contract.](1_instance-analytics-enable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Error Shapes

### Public domain required

```json
{
  "error": {
    "code": "analytics.domain_required",
    "message": "Instance 'docs.production' requires a configured public domain before analytics can be enabled.",
    "meta": {
      "app": "docs", "instance": "production", "serving_node": "app-prod-1"
    }
  }
}
```

Ambiguous bare selectors fail with `validation_failed` and
`error.meta.reason=instance_required`. Authorization failures include
`reason=missing_permission`, `missing_permission=instance:write`, `instance`,
and `serving_node`.

### Analytics prerequisite failed

```json
{
  "error": {
    "code": "analytics.prerequisite_failed",
    "message": "The analytics service route requires an active analytics node.",
    "meta": {
      "app": "docs"
    }
  }
}
```
