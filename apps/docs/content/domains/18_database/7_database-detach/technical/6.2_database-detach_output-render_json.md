# JSON Renderer: `orbit database:detach`

[Back to `database:detach` technical contract.](1_database-detach.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "result": {
        "action": "detached",
        "connection": "acme",
        "target_type": "app",
        "target": "acme",
        "env_prefix": "DB"
      }
    },
    "meta": {}
  }
}
```

## Error Shape

The top-level envelope is either `success` or `error`.
