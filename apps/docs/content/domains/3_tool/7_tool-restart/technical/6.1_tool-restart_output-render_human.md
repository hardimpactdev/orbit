# Human Renderer: `orbit tool-restart`

[Back to `tool-restart` technical contract.](1_tool-restart.md)

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and before gateway reads, node inspection, or node apply begins.

```text
┌ Restarting Tool
○ Resolve target
○ Read gateway tool configuration
○ Run command action
└ Working...
```

## Success Output

Human output reports only the lifecycle action result:

```text
Restarted <tool> on <node>.
```

Do not append expected capability state, observed state, managed flag, version,
or configuration metadata after lifecycle actions. Detailed inspection belongs
to `tool:show`, JSON output, doctor, or logs.

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose error, and actionable recovery guidance when the operator can resolve the issue.

For `tool.remote_action_failed`, human output includes:

- The immediate apply diagnostic: exit code when known and a brief stderr
  summary when present.
- `orbit tool:logs <tool> [--node=<node>]` when the tool declares a log source.
- `orbit doctor --family=tool --restore` for convergence repair.
- A retry hint using `orbit tool:restart <tool> [--node=<node>]`.
