# Non-Interactive Input Mode: `orbit codex:app`

[Back to `codex:app` technical contract.](1_codex-app.md)

**Input mode:** Non-interactive.

## Selection

Use this input mode when `--json` is present or when the command is running
without a TTY. `--json` always forces non-interactive input mode.

Non-interactive input mode must never render prompts.

## Responsibilities

Prompts are never rendered in non-interactive mode; prompts are never rendered.

- `action` is required.
- `--node` is required.
- `app` is required for `add` and `remove`.
- `app` is rejected for `list`.
- Never render prompts.
- No values are prompted or inferred from `node:default`.

Validation failures happen before gateway side effects.
