# Human Renderer: `orbit schedule:remove`

[Back to `schedule:remove` technical contract.](1_schedule-remove.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and destructive consent, and before gateway removal is written.

```text
┌ Removing Schedule
○ Resolve schedule
○ Delete gateway schedule row
└ Working...
```

## Success Output

Render the deleted schedule snapshot: name, scope, and target. Do not render a
scheduler notification, heartbeat, remote-cleanup, or pickup result.

## Failure Output

Validation and not-found failures render the rejected field or schedule name.
Destructive-consent failures render no progress tree and state that no schedule
was removed. Gateway write failures do not claim any target-node side effect.
