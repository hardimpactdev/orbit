# Human Renderer: `orbit dns:resolve-tld [tld] [target]`

[Back to `dns:resolve-tld` technical contract.](1_dns-resolve-tld.md)

This page describes the human-rendered terminal output for `dns:resolve-tld`.

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. Prompt behavior and destructive
confirmation belong to the input-mode contracts.

## Progress Tree

`dns:resolve-tld` performs local resolver writes and may refresh a platform
resolver backend, so the human renderer must show an in-progress tree after
input resolution and before side effects begin.

Resolve path:

```text
┌ Configuring Local DNS
○ Validate .test
○ Write resolver override
○ Refresh resolver
└ Working...
```

Reset path:

```text
┌ Resetting Local DNS
○ Validate .test
○ Remove resolver override
○ Refresh resolver
└ .test resolver override removed
```

Already-converged resolve path:

```text
┌ Configuring Local DNS
○ Validate .test
○ Check resolver override
└ .test already resolves to 10.6.0.7
```

Already-absent reset path:

```text
┌ Resetting Local DNS
○ Validate .test
○ Check resolver override
└ .test resolver override already absent
```

The final tree must make the failed step visible when the command exits with
failure.

## Success Output

Resolved:

```text
.test resolves to 10.6.0.7.
```

Already resolved:

```text
.test already resolves to 10.6.0.7.
```

Reset:

```text
.test resolver override removed.
```

Already absent:

```text
.test resolver override already absent.
```

Success output must not imply that gateway development DNS, app routes,
Cloudflare, or public DNS were changed.

## Failure Output

Human-rendered failures must show:

- the failing phase or field;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the operator can act on it.

Caller role not allowed:

```text
This command may only be run from a client.
```

Invalid TLD:

```text
Development TLD must be a single lowercase DNS label without a leading dot.
```

Invalid target:

```text
Target must be an IPv4 or IPv6 address.
```

Destructive consent missing:

```text
Reset cancelled. No local resolver changes were made.
```

Unsupported platform:

```text
This platform does not support automatic local DNS resolver configuration.
```

Resolver write failed:

```text
Failed to update local DNS resolver configuration.
```

Resolver refresh failed:

```text
Local DNS resolver configuration changed, but the resolver could not be refreshed.
```
