# Human Renderer: `orbit process:start [name]`

[Back to `process:start` technical contract.](1_process-start.md)

This page describes the human-rendered terminal output for `process:start`.

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render the complete progress tree after input resolution and before side
effects begin. `process:start` performs a remote runtime action.

```text
┌ Start Process
○ Resolve runtime unit
○ Start runtime unit
○ Record process event
└ Process `vite` started
```

## Success Output

```text
Process 'vite' started for app 'docs'
```

For a workspace context:

```text
Process 'vite' started for workspace 'feature-docs'
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no
JSON envelope, and next-step guidance only when the operator can act on it.
