title: "orbit node:converge"
sidebarTitle: "node:converge"
description: "Re-apply the Gateway-rendered Orbit footprint of a Node: its agent files, Caddyfile, PHP runtime policy, temporary-file cleanup and applicable network artifacts. Only an active VPN owner receives the private DNS listener; a Gateway-only Node is a resolver client. It never changes an Instance or a role, so it works on a Node that owns Instances, unlike `node:add`."
---

```bash
orbit node:converge <node> [--force] [--idempotency-key=KEY] [--json]
```

| Option | Meaning |
| --- | --- |
| `--force` | Re-apply every artifact, not only the ones whose digest changed. Each artifact still leaves a matching live copy alone |
| `--idempotency-key=KEY` | Reuse the same key to repeat admission safely |

The Gateway returns HTTP 202 with an Operation for every admitted target. The CLI follows its steps and prints the final Operation with `--json`. One native Swamp run on Node 209 reaches the target and VPN hub through pinned SSH. The network part runs last, after the other required parts succeed. Unsupported applicable artifacts refuse before native Node effects; a matching digest does not prove an unsupported action. A Node that is not an active, managed Linux Node fails with `node.converge_unsupported`. [Converge the Orbit footprint](/reference/node-provisioning#converge-the-orbit-footprint) lists the artifacts and error codes.

The network part has its own desired-state digest. Each run also reads public WireGuard state on the target and hub, resolves a peer endpoint and checks its DNS policy. When the digest and live state match, it writes no WireGuard file and runs no tunnel apply, reload or restart. Drift reuses the native network child and ends with a bounded tunnel probe and a recent handshake check. A VPN hub publishes the full recorded peer list. Admission holds the Node and shared hub against another converge.

This command replaces the separate network and hub converge commands. It changes no role assignment, Tool or package recipe.

```bash
orbit node:converge beast
```
