# JSON Renderer: `orbit tool:credentials`

[Back to `tool-credentials` technical contract.](1_tool-credentials.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "credentials": {
        "tool": "hermes",
        "node": "agent-1",
        "fields": {
          "url": "https://hermes.agent",
          "username": "admin",
          "password": "<generated-password>"
        }
      }
    },
    "meta": []
  }
}
```

Credential field names and value types are owned by the selected tool catalog
file.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Required input is missing or invalid.",
    "meta": {
      "field": "tool"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `tool.not_found`, `tool.unsupported_action` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.meta` | object | Field, target, or caller context for automation. |
