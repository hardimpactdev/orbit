# JSON Renderer: `orbit extension:list`

[Back to `extension:list` technical contract.](1_extension-list.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success

```json
{
  "success": {
    "data": {
      "extensions": [
        {
          "slug": "solo",
          "label": "Solo",
          "description": "Solo API command family through the Orbit gateway.",
          "commands": [
            "solo:project:list",
            "solo:process:list",
            "solo:scratchpad:list",
            "solo:todo:list"
          ],
          "permissions": [
            "solo:*",
            "solo:project:list",
            "solo:process:read",
            "solo:scratchpad:write",
            "solo:todo:comment"
          ],
          "local_enabled": true,
          "gateway_enabled": false
        }
      ]
    },
    "meta": []
  }
}
```

When gateway state cannot be read, `gateway_enabled` is `null` and the success
metadata carries the gateway warning.

The `solo` extension appears with its registered command catalog and permission
families. Disabled local Solo still hides `solo:*` commands from normal command
discovery, and direct invocation of a registered Solo command fails with
`extension_disabled` and `meta.scope=local`. Gateway Solo proxy routes are
controlled separately by gateway extension state. Read-only Solo routes require
`solo:*` on the resolved Solo target node; mutating Solo routes require the
operation-specific Solo permission on that same target. When local `solo` is
enabled, implemented Solo commands call
the gateway Solo proxy and return the same shared JSON envelope. Registered
commands that are not implemented yet fail with `solo_command_deferred`.

## Error

Hard failures use the shared error envelope:

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway is unavailable.",
    "meta": []
  }
}
```
