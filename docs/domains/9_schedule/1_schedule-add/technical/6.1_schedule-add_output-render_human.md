# Human Renderer: `orbit schedule:add`

[Back to `schedule:add` technical contract.](1_schedule-add.md)

**Renderer:** Human terminal renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and before gateway writes or scheduler pickup begins.

```text
┌ Adding Schedule
○ Validate schedule target
○ Validate execution source
○ Apply and verify schedule
○ Notify Orbit Scheduler
└ Working...
```

## Success Output

Render the schedule name, scope, target, interval, timezone, execution source, enabled state, and the Orbit Scheduler pickup result.

## Failure Output

Validation failures render the rejected field. Gateway and authorization failures render the selected scope when available. Application failures render the created schedule name, drift status, and next doctor command: `doctor --fix --family=schedule --restore`.
