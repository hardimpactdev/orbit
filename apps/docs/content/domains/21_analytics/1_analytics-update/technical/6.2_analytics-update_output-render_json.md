# JSON Renderer: `orbit analytics:update`

[Back to `analytics:update` technical contract.](1_analytics-update.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "analytics": {
        "node": "analytics-1",
        "process": "plausible",
        "previous_version": "3.2.1",
        "version": "3.2.2",
        "status": "active"
      }
    },
    "meta": []
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.analytics.node` | string | Selected active analytics node. |
| `success.data.analytics.process` | string | Process identity, always `plausible` for v1. |
| `success.data.analytics.previous_version` | string \| null | Plausible CE version stored before this request. |
| `success.data.analytics.version` | string | Requested Plausible CE version after update. |
| `success.data.analytics.status` | string | Process row status after update. |

## Error Shapes

### Version required

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The Plausible CE version is required.",
    "meta": {
      "field": "version"
    }
  }
}
```

### Active analytics node required

```json
{
  "error": {
    "code": "validation_failed",
    "message": "An active analytics role node is required.",
    "meta": {
      "field": "node",
      "required_role": "analytics"
    }
  }
}
```

### Process missing

```json
{
  "error": {
    "code": "process.not_found",
    "message": "The Plausible CE process was not found on analytics-1.",
    "meta": {
      "node": "analytics-1",
      "process": "plausible"
    }
  }
}
```
