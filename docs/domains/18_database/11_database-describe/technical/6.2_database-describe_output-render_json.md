# JSON Renderer: `orbit database:describe`

[Back to `database:describe` technical contract.](1_database-describe.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

`success.data` contains `connection`, `table`, `columns[]`, and `indexes[]`.

## Error Shape

The top-level envelope is either `success` or `error`.
