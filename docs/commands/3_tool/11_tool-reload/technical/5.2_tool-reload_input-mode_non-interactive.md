# Non-Interactive Input Mode: `orbit tool-reload`

[Back to `tool-reload` technical contract.](1_tool-reload.md)

**Input mode:** Non-interactive.

This contract applies without a TTY or when `--json` is present. `--json` forces non-interactive input mode.

## Resolution Rules

No prompts are rendered. All required fields must be supplied by arguments, options, local defaults, or gateway-resolved context. Missing optional interactive selections fail as validation errors instead of rendering fallback prompts.
