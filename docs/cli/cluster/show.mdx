---
title: "orbit cluster:show"
sidebarTitle: "cluster:show"
description: "Show one Cluster with its state, TLD, Router, and member Nodes."
---

```bash
orbit cluster:show <cluster> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `cluster` | yes | Numeric Cluster ID. |

| Option | Default | Meaning |
| --- | --- | --- |
| `--json` | off | Print the Cluster as JSON. |

```bash
orbit cluster:show 3
```

In a terminal, an omitted Cluster is chosen from an interactive list. A noninteractive or `--json` call without it is refused with `cluster.id_invalid` and sends no request, and so is a value that is not a positive integer.

The command shows what Orbit has recorded. It does not contact the Nodes, so it works while a Node is unreachable. The detail is titled `Cluster: <name>` and has the fields ID, State, TLD, Router, Nodes and Request ID. The TLD has a leading dot, the Router and each member Node show as name and ID, and a missing value shows `—`, including a Cluster without members. Member Nodes are sorted by name, then ID, in human and JSON output.

## Errors

| Code | Meaning |
| --- | --- |
| `cluster.id_invalid` | The Cluster is missing or is not a positive integer, and the CLI cannot prompt. |
| `http.404` | The Cluster is unknown. |
| `node_access.required` | The caller has no access grant to any member Node of the Cluster, or, for a Cluster without members, to the Gateway Node. |
