# Human Renderer: `orbit instance:list`

[Back to `instance:list` technical contract.](1_instance-list.md)

**Renderer:** Human renderer.

## Primitive

- Table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md).

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered; this is a fast gateway registry read.

## Success Render

Render one row per visible instance with `PROJECT`, `NAME`, `DRIVER`, `MODE`,
`PHP`, `EXTENSIONS`, and `DEPLOYMENT` columns. An empty result prints
`No instances found.`

## Error Render

Render gateway validation and authorization messages directly.
