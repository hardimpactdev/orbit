# JSON Renderer: `orbit database:add-user`

[Back to `database:add-user` technical contract.](1_database-add-user.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via
`$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

`success.data.connection` uses the database JSON entity defined in
[`../../README.md`](../../README.md#database-json-entity). Credential secrets
are omitted.

## Error Shape

The top-level envelope is either `success` or `error`.

Exhaustive command-specific codes:

- `validation_failed`
- `authorization_failed`
