# `database:query-local`

[Back to Database commands.](../../README.md)

Hidden internal command used by the gateway to execute SQLite queries on the
node that owns the SQLite file.

This command is not part of Orbit's public command surface.

## Usage

```bash
orbit database:query-local
```
