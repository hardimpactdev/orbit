# Interactive Input Mode: `orbit vpn-web-ui:change-password`

[Back to `vpn-web-ui:change-password` technical contract.](1_vpn-web-ui-change-password.md)

**Input mode:** Interactive.

## Selection

Use this input mode when the command is attached to a TTY and `--json` is not
present.

## Prompt Contract

Interactive input mode prompts for a missing password, validates it locally, and
then asks for destructive confirmation unless `--force` is supplied.

| Field | Prompt ID | Primitive | Label | Default |
| --- | --- | --- | --- | --- |
| `password` | `vpn_web_ui_change_password.password` | `password` | `New VPN web UI password` | None |
| `force` | `vpn_web_ui_change_password.confirm` | `confirm` | `Rotate the VPN web UI password?` | `false` |

If the operator declines confirmation, fail before side effects.

`--force` bypasses only the confirmation prompt. It does not bypass password
validation.

## Primitive References

- [`confirm`](../../../../ux/commands/inputs/confirm-prompt.md)

## Validation Timing

- Caller-role eligibility is checked before prompts.
- Password validation runs as soon as the password is supplied.
- Credential rotation begins only after destructive consent.
- The password value must not be echoed in validation errors or progress output.
