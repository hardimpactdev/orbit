# Human Renderer: `orbit deploy:run`

[Back to `deploy:run` technical contract.](1_deploy-run.md)

**Renderer:** Human terminal renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and before run-history
creation or node-side execution begins.

```text
┌ Running Deployment
○ Resolve production app
○ Create deployment run
○ Execute deployment steps
○ Record deployment result
└ Working...
```

Detached runs render only through the run-creation step and then exit with a
summary that includes the run id.

## Success Output

Foreground success output shows the app, run id, final status, duration, each
executed step, per-step exit code, and captured output.

Detached success output shows the app, run id, `status=running`, and the command
to inspect history or logs later.

## Failure Output

Validation and not-found failures render the rejected field or app selector.
Gateway and authorization failures render the selected app when available.
Step failures render the run id, failing step title, exit code, and captured
stdout/stderr. History-write failures render whether any deployment step already
ran.
