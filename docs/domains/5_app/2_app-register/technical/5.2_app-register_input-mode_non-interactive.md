# Technical Contract: `orbit app:register` (Non-Interactive Input)

This contract defines behavior for **non-interactive input mode** (e.g., CI, scripts, or when `--json` is present).

[Back to the canonical contract.](1_app-register.md)

**Input mode:** Non-interactive.

Use this input mode when either condition is true:

- the command is running without a TTY;
- `--json` is present.

`--json` selects the JSON renderer and forces this input mode even when the
process has a TTY.

## Behavior

- **Validation**: All required inputs must be supplied via arguments or options. Missing required input causes an immediate failure.
- **No Prompts**: The command will never wait for user input.
- **Adoption Rules**: To adopt an unmanaged path, `--path` and `--node` must be explicitly provided.

## Failure Semantics

- Missing required input fails before side effects with
  `error.code=validation_failed`.
- `error.meta.field` names the missing input.
- `error.meta.reason` may describe the missing-input rule that failed.
