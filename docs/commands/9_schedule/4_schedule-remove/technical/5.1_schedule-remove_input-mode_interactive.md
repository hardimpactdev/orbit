# Interactive Input Mode: `orbit schedule:remove`

[Back to `schedule:remove` technical contract.](1_schedule-remove.md)

**Input mode:** Interactive.

## Mode Selection

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Flow

Prompts render after caller role and gateway reachability are known and before
any gateway removal intent or backend cleanup.

| Prompt ID | Primitive | Rendered when | Validation |
| --- | --- | --- | --- |
| `schedule.remove.name` | `text` | `name` argument omitted. | Existing visible schedule slug. |
| `schedule.remove.scope` | `select` | The schedule name matches multiple visible scopes and no filter disambiguates it. | One matching app or node scope. |
| `schedule.remove.confirm` | `confirm` | Always after the schedule is resolved unless `--force` is present. | Explicit destructive consent. |

The confirmation text names the schedule, scope, target, interval, and artifacts
that will be removed.

Rejected confirmation fails before side effects with
`error.code=destructive_consent_required`.
