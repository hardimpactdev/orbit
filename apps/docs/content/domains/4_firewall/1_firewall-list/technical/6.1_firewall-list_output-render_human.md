# Human Renderer: `orbit firewall:list`

[Back to `firewall-list` technical contract.](1_firewall-list.md)

**Renderer:** Human terminal renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`firewall:list` is a read-only gateway registry query. Execution is expected to complete below one second and does not perform slow external work. No progress tree is rendered.

## Success Output

Render firewall rules grouped by node. Empty or missing cells render as `—`
(em dash).

When no rules match, render the empty state that names the selected scope:

```text
No firewall rules found.
No firewall rules found on node <node>.
```

## Failure Output

Validation, gateway, and authorization failures render one concise error line with the rejected field or selected scope when available.
