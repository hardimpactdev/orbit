# JSON Renderer: `orbit codex:app`

[Back to `codex:app` technical contract.](1_codex-app.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Add Success

```json
{
  "success": {
    "data": {
      "codex_project": {
        "app": "docs",
        "node": "mini",
        "label": "docs",
        "remote_path": "/home/orbit/apps/docs",
        "ssh_alias": "app-node",
        "added": true
      }
    },
    "meta": []
  }
}
```

## Remove Success

```json
{
  "success": {
    "data": {
      "codex_project": {
        "app": "docs",
        "node": "mini",
        "removed": true
      }
    },
    "meta": []
  }
}
```

## List Success

```json
{
  "success": {
    "data": {
      "codex_projects": [
        {
          "app": "docs",
          "label": "docs",
          "remote_path": "/home/orbit/apps/docs",
          "ssh_alias": "app-node"
        }
      ]
    },
    "meta": []
  }
}
```

## Warnings

When the config file is written but the Codex App callback fails, include:

```json
{
  "code": "codex_app.apply_failed",
  "message": "Codex App config was written, but Codex App did not acknowledge the apply callback."
}
```

## Error Shape

Command-specific errors use the standard error envelope. Common validation,
authorization, and gateway failures follow the shared command contract.
