# JSON Renderer: `orbit ca:trust`

[Back to `ca:trust` technical contract.](1_ca-trust.md)

This page describes the JSON-rendered output for `ca:trust`.

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](../../../README.md#invocation-model), even when
the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Input validation failures, gateway reachability failures, invalid trust material,
unsupported platform failures, trust-store failures, and local metadata failures
must all use this envelope.

## Success Shape

```json
{
  "success": {
    "data": {
      "ca": {
        "gateway": "https://10.6.0.2",
        "trusted": true,
        "status": "trusted",
        "ca_sha256": "5f2c2f4c7b6f0d4b3e8e27af2a84392c6f0b9a7b4e78a9b1c9d2e3f4a5b6c7d8"
      }
    },
    "meta": {
      "trusted_at": "2026-05-02T08:30:00+00:00"
    }
  }
}
```

Already-trusted convergence uses the same shape with `ca.status` set to
`already_trusted`.

| Field | Type | Meaning |
| --- | --- | --- |
| `ca.gateway` | string | Normalized trusted gateway URL. |
| `ca.trusted` | boolean | `true` after the local trust check or installation succeeds. |
| `ca.status` | string | `trusted` when installed or refreshed; `already_trusted` when no trust-store write was needed. |
| `ca.ca_sha256` | string | SHA-256 hex fingerprint of the installed PEM certificate bytes. |
| `trusted_at` | string | ISO-8601 timestamp recorded after local trust succeeds. |

## Error Shapes

### Gateway missing

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Gateway is required. Run orbit gateway:add first or pass --gateway.",
    "meta": {
      "field": "gateway",
      "reason": "missing"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Could not fetch the Orbit root CA from https://10.6.0.2.",
    "meta": {
      "gateway": "https://10.6.0.2",
      "endpoint": "/api/ca/root"
    }
  }
}
```

### Invalid trust material

```json
{
  "error": {
    "code": "trust_material_invalid",
    "message": "Gateway returned invalid root CA material.",
    "meta": {
      "gateway": "https://10.6.0.2",
      "endpoint": "/api/ca/root"
    }
  }
}
```

### Local trust failed

```json
{
  "error": {
    "code": "local_trust_failed",
    "message": "Failed to install the Orbit root CA into the local trust store.",
    "meta": {
      "gateway": "https://10.6.0.2",
      "reason": "trust_store_failed"
    }
  }
}
```

## Enum And Identifier Values

| Field | Values |
| --- | --- |
| `ca.trusted` | `true` |
| `ca.status` | `trusted`, `already_trusted` |
| `error.meta.reason` | `missing`, `invalid`, `unsupported_trust_store`, `trust_store_failed`, `metadata_write_failed` |
| `error.code` | `validation_failed`, `gateway_unavailable`, `trust_material_invalid`, `local_trust_failed` |

The `error.code` values listed here are exhaustive for `ca:trust`. Add a new
value to this renderer contract before implementing another JSON failure code.
