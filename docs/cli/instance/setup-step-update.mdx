sidebarTitle: "instance:setup-step:update"

```bash
orbit instance:setup-step:update <name> --project=<id> [--command=<command>] [--timeout=<seconds>] [--before=<name>|--after=<name>] [--rebalance=<name>=<seconds>]... [--json]
```
