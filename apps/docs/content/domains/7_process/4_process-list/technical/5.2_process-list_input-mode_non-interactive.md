# `process:list` Non-Interactive Input Mode

[Back to `process:list` technical contract.](1_process-list.md)

This page describes how non-interactive input mode resolves `process:list` input without prompts.

**Input mode:** Non-interactive.

## Selection

Use this input mode when either condition is true:

- the command is running without a TTY;
- `--json` is present.

`--json` selects the JSON renderer and forces non-interactive input mode even when the process has a TTY.

## Responsibilities

- Read supplied options and local context.
- Apply documented defaults.
- Never render prompts.
- Fail before gateway query when required context is absent or ambiguous.
- Fail before gateway query when supplied input is forbidden or invalid.

## Required Input Failures

| Field | Missing when | Behavior |
| --- | --- | --- |
| `app` | Neither `--app` nor local context resolves exactly one app, and `--workspace` does not resolve an app. | Fail before gateway query with `error.code=validation_failed` and `error.meta.field=app`. |
