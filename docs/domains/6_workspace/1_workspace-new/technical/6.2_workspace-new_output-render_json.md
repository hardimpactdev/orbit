# Technical Contract: `orbit workspace:new` (JSON Renderer)

[Back to the canonical technical contract.](1_workspace-new.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Envelope

```json
{
  "success": {
    "data": {
      "result": {
        "action": "created"
      },
      "workspace": {
        "name": "feature-a",
        "app": "my-app",
        "node": "app-1",
        "path": "/home/orbit/apps/my-app/.worktrees/feature-a",
        "url": "https://feature-a.my-app.test",
        "php_version": "8.5",
        "php_inherited": true,
        "agent_ide": {
          "adapter": null,
          "workspace_id": null
        },
        "adopted": false,
        "lifecycle_status": "expected"
      }
    },
    "meta": {
      "node": "app-1",
      "base": "main",
      "http_probe": {
        "url": "https://feature-a.my-app.test",
        "result": "healthy",
        "status_code": 200,
        "duration_ms": 240
      },
      "warnings": []
    }
  }
}
```

### Fields

- `result.action`: Always `created` for `workspace:new`. The command does not
  adopt existing paths; adoption belongs to `doctor --fix --family=workspace --adopt`
  and `workspace:setup` where explicitly documented.
- `workspace.name`: The workspace identity slug. Unique within the parent
  app, not globally.
- `workspace.app`: The parent app slug.
- `workspace.node`: The resolved app node slug (inherited from the parent
  app).
- `workspace.path`: The absolute workspace path on the app node.
  Generic worktrees use `<app path>/.worktrees/<workspace>`. Agent IDE source
  drivers such as OpenCode and Polyscope may return their own physical path.
- `workspace.url`: The primary workspace URL.
- `workspace.php_version`, `workspace.php_inherited`, `workspace.adopted`,
  and `workspace.lifecycle_status`: canonical workspace entity fields defined
  in [`6_workspace/README.md`](../../README.md#workspace-json-entity).
- `workspace.agent_ide`: Adapter metadata captured for the workspace source.
  `workspace.agent_ide.adapter` is `null` for generic worktrees.
  `workspace.agent_ide.workspace_id` stores the adapter-side id when available;
  for Polyscope this is the workspace id returned by the SDK, and for OpenCode
  this is the best-effort session id created in the worktree.
- `meta.base`: The source ref/branch passed to the selected workspace source
  driver. Echoes `--base` (default `main`). This is command-result metadata,
  not a durable workspace entity field.
- `meta.http_probe`: HTTP probe result from setup time. This is command metadata,
  not durable workspace state and not the registry lifecycle status rendered
  by `workspace:list`.
- `meta.http_probe.url`: URL probed by the command.
- `meta.http_probe.result`: `healthy` or `unhealthy`.
- `meta.http_probe.status_code`: HTTP status code when a response was
  received; `null` when the probe timed out before a response.
- `meta.http_probe.duration_ms`: Probe duration in milliseconds.
- `meta.warnings`: Structured non-fatal drift and retry handoffs. Each
  entry carries `code`, `family`, `message`, and `next_command`.

## Success with Drift Warning

If the gateway workspace row is written but downstream node application
fails in a retryable way, the command still exits `0` and reports drift
under `success.meta.warnings[]` using the canonical structured warning
shape:

```json
{
  "success": {
    "data": {
      "result": {
        "action": "created"
      },
      "workspace": {
        "name": "feature-a",
        "app": "my-app",
        "node": "app-1",
        "path": "/home/orbit/apps/my-app/.worktrees/feature-a",
        "url": "https://feature-a.my-app.test",
        "php_version": "8.5",
        "php_inherited": true,
        "agent_ide": {
          "adapter": null,
          "workspace_id": null
        },
        "adopted": false,
        "lifecycle_status": "expected"
      }
    },
    "meta": {
      "node": "app-1",
      "base": "main",
      "http_probe": {
        "url": "https://feature-a.my-app.test",
        "result": "healthy",
        "status_code": 200,
        "duration_ms": 240
      },
      "warnings": [
        {
          "code": "workspace.path_missing",
          "family": "workspace",
          "message": "Workspace path '/home/orbit/apps/my-app/.worktrees/feature-a' is missing on node 'app-1'. SSH application failed after gateway configuration was written.",
          "next_command": "doctor --fix --family=workspace --restore"
        }
      ]
    }
  }
}
```

## Error Envelope

### Per-app workspace-name collision

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The workspace name 'feature-a' is already used for app 'my-app'.",
    "meta": {
      "field": "name",
      "reason": "workspace_name_collision",
      "app": "my-app",
      "workspace": "feature-a"
    }
  }
}
```

### Reserved name `main`

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The name 'main' is reserved and cannot be used as a workspace name.",
    "meta": {
      "field": "name",
      "reason": "reserved_name"
    }
  }
}
```

### Hard apply failure

```json
{
  "error": {
    "code": "workspace.enactment_failed",
    "message": "Workspace application on node 'app-1' stopped before Orbit could classify remaining drift.",
    "meta": {
      "step": "classify_artifacts",
      "node": "app-1",
      "reason": "SSH stream closed before artifact probe completed"
    }
  }
}
```

### Common Error Codes

| Code | Meaning |
| --- | --- |
| `validation_failed` | A supplied input failed gateway-side static validation. `error.meta.field` names the offending input (`name`, `app`, `php_version`); `error.meta.reason` may name the rule (`reserved_name`, `workspace_name_collision`, `slug_regex`, `combined_length_exceeded`, `unsupported_php_version`). |
| `caller_role_not_allowed` | The gateway denied the caller's WireGuard peer identity for `workspace:new` (e.g. an app-node peer). |
| `authorization_failed` | The caller is not authorized to manage the parent app or its node. |
| `workspace.parent_app_invalid` | The resolved parent app is missing, unauthorized, or unable to own workspaces. |
| `workspace.ssh_failure` | The gateway could not reach the parent app's owning app node before gateway configuration was written. |
| `workspace.enactment_failed` | Gateway workspace row was written, but downstream execution failed before Orbit could classify the result as repairable drift or a command-owned setup failure. Retryable PHP-FPM, runtime, or proxy drift is reported under `success.meta.warnings[]` instead. `error.meta.step`, `error.meta.node`, `error.meta.reason`. |

### Common Warning Codes

Non-fatal drift is reported in `success.meta.warnings[]`. Each warning
carries `code`, `family`, `message`, and `next_command`. Codes are drawn
from the `workspace` family in
[`workspace-doctor.md`](../../workspace-doctor.md) and from the
`proxy` family for workspace-owned route handoffs.

| Code | Family | Meaning |
| --- | --- | --- |
| `workspace.path_missing` | `workspace` | The workspace path was not created on the app node. `doctor --fix --family=workspace --restore` will repair it when gateway configuration has enough source information. |
| `workspace.fpm_config_missing` | `workspace` | Workspace PHP-FPM configuration could not be installed during application. `doctor --fix --family=workspace --restore` will repair it. |
| `workspace.fpm_config_mismatch` | `workspace` | Installed FPM configuration differs from gateway workspace configuration. `doctor --fix --family=workspace --restore` will rewrite it. |
| `workspace.runtime_config_missing` | `workspace` | Managed workspace runtime configuration is absent. `doctor --fix --family=workspace --restore` will reinstall it. |
| `workspace.runtime_config_mismatch` | `workspace` | Managed workspace runtime configuration differs from gateway workspace configuration. `doctor --fix --family=workspace --restore` will rewrite it. |
| `proxy.domain_inactive` | `proxy` | The workspace-owned proxy route is not yet active because DNS or TLS prerequisites are pending. Retry through the relevant `proxy` family command. |
| `workspace.http_probe_unhealthy` | `null` | The setup-time HTTP probe returned `>= 500` or timed out. The warning is not a `workspace` doctor issue code; inspect the app or rerun `workspace:setup` after fixing application health. |

## Enum and identifier values

| Field | Values |
| --- | --- |
| `result.action` | `created` |
| `workspace.php_inherited` | `true`, `false` |
| `workspace.adopted` | `true`, `false` |
| `workspace.lifecycle_status` | `expected`, `setup-pending` |
| `error.code` | `validation_failed`, `caller_role_not_allowed`, `authorization_failed`, `workspace.parent_app_invalid`, `workspace.ssh_failure`, `workspace.enactment_failed` |

The `error.code` values listed here are exhaustive for `workspace:new`. Add
a new value to this renderer contract before implementing another JSON
failure code.
