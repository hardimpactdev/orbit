# JSON Renderer: `orbit firewall:allow`

[Back to `firewall-allow` technical contract.](1_firewall-allow.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "rule": {
        "name": "local-vite",
        "node": "app-1",
        "direction": "incoming",
        "action": "allow",
        "source": "10.6.0.0/24",
        "destination": null,
        "port": 5173,
        "protocol": "tcp",
        "reason": "local development server",
        "status": "enacted"
      }
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "firewall_rule.enactment_failed",
    "message": "The firewall rule was saved, but the backend apply failed.",
    "data": {
      "rule": {
        "name": "local-vite",
        "node": "app-1",
        "direction": "incoming",
        "action": "allow",
        "source": "10.6.0.0/24",
        "destination": null,
        "port": 5173,
        "protocol": "tcp",
        "reason": "local development server",
        "status": "expected"
      }
    },
    "meta": {
      "next_command": "doctor --family=firewall_rule --restore --node=app-1"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `firewall_rule.name_collision`, `firewall_rule.baseline_conflict`, `firewall_rule.enactment_failed` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.data.rule` | object | Firewall rule configuration when a post-write apply failure occurred. |
| `error.meta` | object | Field, node, caller, conflicts, or recovery context for automation. |
