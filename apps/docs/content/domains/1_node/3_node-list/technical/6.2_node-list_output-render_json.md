# JSON Renderer: `orbit node:list`

[Back to `node:list` technical contract.](1_node-list.md)

This page describes the JSON-rendered output for `node:list`.

**Renderer:** JSON renderer.

## Primitive

None. JSON renderer emits the standard envelope only.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](../../../README.md#invocation-model), even
when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Input mode failures, domain validation failures, authorization failures,
and network failures must all use this envelope.

The node array is rendered as a flat array under `success.data.nodes` rather
than wrapped in a `success.data.list.items` object. When pagination is
introduced in the future, pagination metadata attaches to
`success.meta.pagination` per the shared envelope rules in
[`docs/domains/README.md`](../../../README.md#json-envelope), so the
`success.data.nodes` array contract remains stable.

## Success Shape

```json
{
  "success": {
    "data": {
      "nodes": [
        {
          "name": "app-1",
          "role": "app-dev",
          "environment": null,
          "host": "203.0.113.10",
          "platform": "ubuntu_24-04",
          "status": "active",
          "addresses": {
            "wireguard": "10.6.0.7"
          },
          "roles": [
            {
              "role": "app-dev",
              "status": "active",
              "settings": {
                "tld": "orbit.test"
              },
              "last_error": null,
              "converged_at": "2026-05-17T12:00:00+00:00"
            },
            {
              "role": "database",
              "status": "error",
              "settings": {},
              "last_error": "Provisioning failed.",
              "converged_at": null
            }
          ]
        }
      ]
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `node` | array | Ordered list of visible nodes matching the applied filters. |
| `nodes[].name` | string | Node name in the gateway registry. |
| `nodes[].host` | string | Bootstrap or public endpoint metadata. This is not the peer IP and must not be rendered as one. |
| `nodes[].addresses.wireguard` | string \| null | Orbit WireGuard peer address assigned to the node. `null` when no peer address is recorded. |
| `nodes[].platform` | string | Structural platform-version identifier such as `ubuntu_24-04` or `macos_15-4`. `unknown` when the gateway has not yet detected the platform. Never `null`. |
| `nodes[].status` | string | Durable registry lifecycle: `provisioning` or `active`. |
| `nodes[].roles` | array | Composable role assignments for the node, ordered by role. Empty when no role assignments exist. |
| `nodes[].roles[].role` | string | Role assignment name: `gateway`, `vpn`, `router`, `app-dev`, `app-prod`, `database`, `agent`, `ingress`, `websocket`, `s3`, `metrics`, or `analytics`. |
| `nodes[].roles[].status` | string | Role assignment convergence status: `pending`, `active`, `error`, or `removing`. |
| `nodes[].roles[].settings` | object | Role-local desired settings for that assignment. Empty object when the role has no stored settings. |
| `nodes[].roles[].last_error` | string \| null | Last convergence error recorded for that assignment. `null` when no error is recorded. |
| `nodes[].roles[].converged_at` | string \| null | ISO 8601 timestamp of the most recent successful convergence for that assignment. `null` when the assignment has not converged successfully. |

Nodes that are not visible to the authenticated caller are omitted from the
array. `node:list` does not return placeholder rows for hidden nodes and does
not include a per-node `visible` field. Callers whose identity is not
authorized to read the registry at all receive `error.code=authorization_failed`
instead of an empty array.

### Empty result

When no nodes match the filters:

```json
{
  "success": {
    "data": {
      "nodes": []
    }
  }
}
```

## Error Shapes

### Invalid filter value

`--role` accepts a single enum value. Comma-separated input is not supported
and fails with the same `validation_failed` shape because the supplied string
is not one of the allowed values.

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Invalid value for --role: 'invalid'. Allowed values: gateway, vpn, router, app-dev, app-prod, database, agent, ingress, websocket, s3, metrics.",
    "meta": {
      "field": "role",
      "value": "invalid",
      "allowed": ["gateway", "vpn", "router", "app-dev", "app-prod", "database", "agent", "ingress", "websocket", "s3", "metrics"]
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to list nodes.",
    "meta": []
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized to read the node registry.",
    "meta": {
      "missing_permission": "node:read"
    }
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `nodes[].addresses.wireguard` | Orbit WireGuard peer address, or `null` when not recorded. Never falls back to `host`. |
| `nodes[].platform` | Platform-version identifier such as `ubuntu_24-04` or `macos_15-4`; `unknown` when not detectable yet. Never `null`. |
| `nodes[].status` | `provisioning`, `active` |
| `nodes[].roles[].role` | `gateway`, `vpn`, `router`, `app-dev`, `app-prod`, `database`, `agent`, `ingress`, `websocket`, `s3`, `metrics`, `analytics` |
| `nodes[].roles[].status` | `pending`, `active`, `error`, `removing` |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed` |

The `error.code` values listed here are exhaustive for `node:list`. Add a new
value to this renderer contract before implementing another JSON failure code.
