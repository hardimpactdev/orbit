# Non-Interactive Input Mode: `orbit s3:publish`

[Back to `s3:publish` technical contract.](1_s3-publish.md)

**Input mode:** Non-interactive.

## Mode Selection

This contract applies without a TTY or when `--json` is present. `--json`
forces non-interactive input mode.

## Behavior

No prompts are rendered. `host` and the serving S3 node must resolve from
arguments, options, or gateway-visible state. Missing required input fails
before side effects with `error.code=validation_failed`.

`--json` selects the JSON renderer only. It does not change validation and does
not grant authorization.

## Required Inputs

| Field | Missing behavior |
| --- | --- |
| `host` | Fail before side effects with `validation_failed` and `error.meta.field=host`. |
| `node` | Optional only when exactly one visible active s3 node exists. Otherwise fail before side effects with `validation_failed` and `error.meta.field=node`. |
