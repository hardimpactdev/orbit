# JSON Renderer: `orbit process:list`

[Back to `process:list` technical contract.](1_process-list.md)

This page describes the JSON-rendered output for `process:list`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces non-interactive input mode.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Success data contains the resolved context and process definitions with latest durable lifecycle event data when present.

`success.data.context` is present because `process:list` must resolve one node,
instance, or workspace execution scope before it can list process definitions. This
does not imply a context block for registry list commands whose inputs are only
filters.

## Success Example

```json
{
  "success": {
    "data": {
      "context": {
        "project": "docs",
        "instance": "development",
        "workspace": "feature-docs"
      },
      "processes": [
        {
          "name": "vite",
          "project": "docs",
          "instance": "development",
          "workspace": "feature-docs",
          "command": "npm run dev",
          "restart_policy": "never",
          "crash_notification": "agent_ide",
          "runtime_unit": "orbit_docs_development_feature-docs_vite",
          "last_event": {
            "id": 123,
            "type": "started"
          }
        }
      ]
    },
    "meta": []
  }
}
```

## Error Example

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A node, instance, or workspace context is required.",
    "meta": {
      "field": "instance"
    }
  }
}
```

## Authorization Error

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized to read process intent.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "process:read"
    }
  }
}
```

## Error Code Vocabulary

- `validation_failed`: node/instance/workspace context is missing, invalid, or ambiguous in non-interactive input mode. An ambiguous bare project selector uses `error.meta.field=instance` and `error.meta.reason=instance_required`.
- `authorization_failed`: caller lacks `process:read` on the resolved node or instance serving node.
- `gateway_unavailable`: the CLI cannot reach the gateway API.
