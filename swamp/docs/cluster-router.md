# Native Cluster Router transitions

`cluster.router_set` and `cluster.router_unset` run one native DAG. The Gateway captures the candidate, obsolete assignments, workload and publication participants from database state. It admits the configured Node username without account lookup or a guessed home.

The Router worker uses the canonical Node role account reader before prerequisite installation and old-certificate retirement. It passes the resolved account to the existing fixed local programs. A missing account or a supplied home that differs stops the stage before effects. The public Router inventory accepts optional home for existing supplied input; newly admitted inventories omit it. No account discovery result is stored on the Gateway.

The DAG prepares a candidate before selection, publishes private DNS, waits for the DNS grace period and then withdraws old Caddy sites, certificate scopes and firewall rules. An unchanged selection performs no host or DNS effects. All host effects run in Swamp; the agent remains frozen. Certificate issuance uses the canonical control209 signer and its existing approved custody configuration.
