# Human Renderer: `orbit instance-setup-step:add`

[Back to `instance-setup-step:add` technical contract.](1_instance-setup-step-add.md)

## Primitive

None. The renderer prints one concise success or failure line.

## Progress Tree

No progress tree. The command writes one gateway setup-step record and does not
run remote work.

## Human Strings

- Success: `App setup step '{title}' added.`
- Failure: `validation_failed: {message}`
