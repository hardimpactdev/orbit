# JSON Renderer: `orbit cf-dns:list`

[Back to `cf-dns:list` technical contract.](1_cf-dns-list.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "records": [
        {
          "id": "record-1",
          "zone": "example.com",
          "type": "A",
          "name": "docs.example.com",
          "content": "203.0.113.10",
          "proxied": true,
          "status": "observed"
        }
      ]
    },
    "meta": {
      "zone": "example.com",
      "count": 1
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The selected Cloudflare zone was not found.",
    "meta": {
      "field": "zone",
      "zone": "missing.example"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.records[]` | array | DNS record entities returned by Cloudflare. |
| `success.meta.zone` | string | Requested zone value. |
| `success.meta.count` | integer | Number of records returned. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `cloudflare_unavailable` | Stable command failure code. |
| `error.meta` | object | Field, zone, gateway, authorization, token, or provider failure context. |
