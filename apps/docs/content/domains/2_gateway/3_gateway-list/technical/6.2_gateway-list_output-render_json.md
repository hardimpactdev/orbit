# JSON Renderer: `orbit gateway:list`

[Back to `gateway:list` technical contract.](1_gateway-list.md)

This page describes the JSON-rendered output for `gateway:list`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "active_gateway": "default",
      "gateways": [
        {
          "name": "default",
          "active": true,
          "url": "https://10.6.0.2",
          "wireguard_ip": "10.6.0.2",
          "ca_fingerprint": "sha256:abc123"
        }
      ]
    }
  }
}
```

`active_gateway` is `null` when no gateway is active.

## Error Shapes

### No gateways configured

```json
{
  "error": {
    "code": "validation_failed",
    "message": "No gateways configured. Run orbit gateway:add first.",
    "meta": {
      "reason": "missing"
    }
  }
}
```
