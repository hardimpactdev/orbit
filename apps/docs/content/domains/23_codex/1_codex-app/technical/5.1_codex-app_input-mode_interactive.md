# Interactive Input Mode: `orbit codex:app`

[Back to `codex:app` technical contract.](1_codex-app.md)

**Input mode:** Interactive.

## Selection

Use this input mode only when both conditions are true:

- the command is running in a TTY;
- `--json` is not present.

When `--json` is present, use
[`5.2_codex-app_input-mode_non-interactive.md`](5.2_codex-app_input-mode_non-interactive.md)
even if the process has a TTY.

## Prompt Behavior

Interactive mode may prompt for missing action, concrete Orbit app instance,
or target node.

- Action choices are `add`, `remove`, and `list`.
- `add` and `remove` prompt for a concrete `orbit` app instance when
  `[app.instance]` is
  missing. The choices show the dotted selector and serving node; logical apps
  and external-driver instances are not source-placement choices.
- Every action prompts for a target node when `--node` is missing.
- Target node prompts show active visible non-gateway nodes supported by the
  `codex-app` tool definition.

Prompted values are still revalidated by the gateway before side effects. A
supplied bare logical app fails with `app_instance_required` instead of being
silently expanded, and a supplied external-driver instance fails with the
shared `unsupported` validation reason.
