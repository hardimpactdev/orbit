---
title: "orbit node:metrics"
sidebarTitle: "node:metrics"
description: "Show one metrics snapshot of an active Node: CPU per core, memory, swap, load, uptime, pressure, and disks."
---

```bash
orbit node:metrics <node> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `node` | yes | Numeric Node ID. |

| Option | Default | Meaning |
| --- | --- | --- |
| `--json` | off | Print the snapshot as JSON. |

```bash
orbit node:metrics 7
```

In a terminal, an omitted Node is chosen from an interactive list. A noninteractive or `--json` call without it is refused with `node.id_invalid` and sends no request, and so is an ID that is not a positive integer.

Orbit reads the snapshot from the [Metrics role](/reference/metrics#read-node-metrics) through Grafana. It runs four queries for the Node's exporter: one for memory, swap, load, and uptime, and one each for cores, pressure, and disks. Only the first decides whether the Node has metrics. The command starts no run, changes no Node and stores no sample.

| Field | Meaning |
| --- | --- |
| `cores` | The busy ratio of each core, from 0 to 1. |
| `memory`, `swap` | Used and total bytes. |
| `load` | The 1, 5, and 15-minute load averages. |
| `uptime_seconds` | Time since boot. |
| `pressure` | The `some` `avg10` value for CPU, memory, and I/O. `0` when the kernel has no pressure data or its query failed. |
| `disks` | Mount, used bytes, and total bytes. Pseudo filesystems such as `tmpfs` and `proc` are left out. `/` comes first. |

Human output shows bytes and durations in readable units, with the Node's name and ID and the request ID. JSON keeps the raw numbers. A missing value shows `—`. If the query for cores, pressure or disks fails, that field is empty and pressure is `0`, and the command still succeeds.

## Errors

| Code | HTTP | Meaning |
| --- | --- | --- |
| `node.id_invalid` | n/a | The Node is missing or is not a positive integer, and the CLI cannot prompt. |
| `node.metrics_unavailable` | 422 | The Node is not active or has no WireGuard address. |
| `metrics.assignment_missing` | 409 | No Node has the Metrics role. |
| `metrics.assignment_drift` | 409 | More than one Node has the Metrics role. |
| `metrics.node_inactive` | 409 | The Metrics Node is not active. |
| `metrics.credentials_missing` | 422 | The Metrics role has no stored credentials. |
| `http.404` | 404 | The Node is unknown. |
| `node.metrics_unreachable` | 502 | Grafana could not answer, or Prometheus has no samples for the Node yet. |
| `node_access.required` | 403 | The caller has no access grant to the Node. |
