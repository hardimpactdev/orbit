# JSON Renderer: `orbit schedule:add`

[Back to `schedule:add` technical contract.](1_schedule-add.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "result": {
        "action": "created",
        "scheduler_pickup": "confirmed"
      },
      "schedule": {
        "name": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs.production",
          "node": "app-1"
        },
        "interval": "every minute",
        "timezone": "Europe/Amsterdam",
        "execution": {
          "type": "command",
          "value": "php artisan schedule:run"
        },
        "enabled": true,
        "status": "expected",
        "last_run": null
      }
    },
    "meta": []
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "schedule.target_unreachable",
    "message": "Schedule 'laravel-scheduler' was recorded, but schedule dispatch through gateway node 'gateway' could not be confirmed reachable.",
    "data": {
      "schedule": {
        "name": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs.production",
          "node": "app-1"
        },
        "interval": "every minute",
        "timezone": "Europe/Amsterdam",
        "execution": {
          "type": "command",
          "value": "php artisan schedule:run"
        },
        "enabled": true,
        "status": "scheduler_unreachable",
        "last_run": null
      }
    },
    "meta": {
      "node": "gateway",
      "next_command": "doctor --family=schedule"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.result.action` | string | `created`. |
| `success.data.result.scheduler_pickup` | string | Scheduler pickup result, usually `confirmed`. |
| `success.data.schedule` | object | Schedule entity defined in [`9_schedule/README.md`](../../README.md#schedule-json-entity). |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `schedule.name_collision`, `schedule.target_unreachable` | Stable command failure code. |
| `error.data.schedule` | object | Present when gateway configuration exists after a target reachability failure. |
| `error.meta.next_command` | string | Recovery command for target reachability failures. |
