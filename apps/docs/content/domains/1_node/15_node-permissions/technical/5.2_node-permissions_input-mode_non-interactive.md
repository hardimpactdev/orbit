# Non-Interactive Input: `orbit node:permissions`

[Back to `node:permissions` technical contract.](1_node-permissions.md)

**Input mode:** Non-interactive.

Applies without a TTY or when `--json` is present.

`--json` forces non-interactive input mode.

## Responsibilities

- Read supplied arguments and options.
- Apply documented defaults.
- Reject combinations of `--preset`, `--permissions`, `--add`, and `--remove`
  before side effects.
- Reject unknown permission strings or unknown preset names before side
  effects.
- Never render prompts.
- Fail before side effects when required input is absent or invalid.
