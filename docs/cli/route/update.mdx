---
title: "orbit route:update"
sidebarTitle: "route:update"
description: "Change the domain or the publication of an explicit Project Route, or the web root of a Route. Give at least one option. Send `--web-root` on its own."
---

```bash
orbit route:update <route> [--domain=DOMAIN] [--publication=INTENT] [--web-root=PATH] [--idempotency-key=KEY]
```

| Option | Meaning |
| --- | --- |
| `--domain=DOMAIN` | The new domain. |
| `--publication=INTENT` | The new publication, `private` or `public`. |
| `--web-root=PATH` | The new web root. `--web-root=` clears it, so the Route serves the Instance's effective root. |

```bash
orbit route:update 9 --domain=shop.example.com
orbit route:update 9 --publication=public
orbit route:update 14 --web-root=apps/admin/public
```

A domain change creates a replacement Route and returns its ID. The current Route stays authoritative until cutover. A publication-only change keeps the Route ID. See [Change an explicit domain](/reference/routes#change-an-explicit-domain) and [Publish the public edge](/reference/routes#publish-the-public-edge).

<Note>
During a domain change, `route:show` shows both Routes, `replacement_step`, `failed_step`, and `error_code`. Repeat the same request to resume. A different domain or publication request changes nothing.
</Note>

## Errors

| Error code | Meaning |
| --- | --- |
| `route.update_required` | No option was given. |
| `route.kind_unsupported` | The Route is a custom proxy or analytics tracking Route. |
| `route.domain_immutable` | The Route is generated. Only an explicit domain can change. |
| `route.domain_conflict` | Another Route owns the new domain, or it is a reserved name. |
| `route.domain_change_conflict` | Another domain change is in progress. |
| `route.web_root_domain_immutable` | A Route with a web root keeps its domain. Create a new Route and remove the old one. |
| `route.web_root_update_separate` | `--web-root` was combined with another option. |
| `route.web_root_unsupported` | The Route is not an active app Route with one active target. |
| `route.web_root_conflict` | The Route is the only Route without a web root of a `laravel-app` or `symfony-app` Instance, or of a production Instance. |
| `route.target_conflict` | A cleared web root would give the Instance a second Route without a web root. |
| `route.reconciliation_required` | The Route or its targets do not allow this change, for example a public domain for development Instances. |
| `instance.source_profile_missing` | A target has no recorded source profile. Orbit does not recover missing profiles on older Instances; see the [no-legacy-support rule](/reference/projects#one-public-name-without-compatibility). |
