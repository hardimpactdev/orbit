# JSON Renderer: `orbit cf-zone:list`

[Back to `cf-zone:list` technical contract.](1_cf-zone-list.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "zones": [
        {
          "id": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
          "name": "example.com",
          "status": "active"
        }
      ]
    },
    "meta": {
      "count": 1
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "cloudflare_unavailable",
    "message": "Cloudflare is unavailable.",
    "meta": {
      "reason": "token_missing"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.zones[]` | array | Cloudflare zones visible to the provider account. |
| `success.meta.count` | integer | Number of zones returned. |
| `error.code` | `gateway_unavailable`, `authorization_failed`, `cloudflare_unavailable` | Stable command failure code. |
| `error.meta` | object | Gateway, authorization, token, or provider failure context. |
