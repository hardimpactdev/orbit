# Codex

## Purpose

This domain owns the command contracts and product vocabulary for Orbit's Codex
command family. See [Codex command contracts](README.md).

## Responsibilities

These responsibilities scope what the Codex domain owns within Orbit's
documentation.

- Keep the `codex:app` command contract aligned with Orbit's current behavior.
- Document the Codex App project registration bridge for eligible target nodes.
- Preserve the boundary between Codex App registration and app runtime
  configuration.

## Boundaries

This landing page is an index for Librarian's domain spine. It does not change
Orbit behavior; detailed contracts remain in the linked command and technical
documents.
