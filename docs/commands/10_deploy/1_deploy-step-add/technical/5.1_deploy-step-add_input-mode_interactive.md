# Interactive Input Mode: `orbit deploy:step-add`

[Back to `deploy:step-add` technical contract.](1_deploy-step-add.md)

**Input mode:** Interactive.

Applies when the command is attached to a TTY and `--json` is not present.

## Prompt Behavior

Interactive input mode prompts only for missing required fields after gateway
reachability and provided options are resolved.

| Prompt ID | Primitive | Field | Shown when | Validation |
| --- | --- | --- | --- | --- |
| `deploy.step_add.app` | `search` | `app` | No app argument was supplied. | Visible production app the caller may manage. |
| `deploy.step_add.command` | `text` | `command` | No command argument was supplied. | Non-empty shell command string. |
| `deploy.step_add.title` | `text` | `title` | The derived command title is ambiguous or too long. | Non-empty display label. |

`order`, `timeout`, and `retention` are optional flags and are not prompted by
default. Invalid supplied values fail as soon as the field is known.

## Primitive References

- [`search`](../../../ux/inputs/search-prompt.md)

## Abort Behavior

Prompt aborts exit with the shared Orbit command failure status and perform no
gateway writes.
