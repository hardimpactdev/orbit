# Human Renderer: `orbit app:prune`

[Back to technical contract](1_app-prune.md)

This file owns the human output contract for `app:prune`.

## Progress Tree

The human renderer uses a step tree grouped by workspace.

```text
┌ Pruning App Workspaces
○ Query agent IDE adapters
○ Remove workspace `feature-docs`
○ Remove workspace `old-experiment`
└ Working...
```

If `--dry-run` is present:

```text
┌ Previewing App Workspace Prune
○ Query agent IDE adapters
○ Preview workspace `feature-docs`
○ Preview workspace `old-experiment`
└ Dry run complete. No side effects performed.
```

## Failure Reporting

- **Validation Errors:** Rendered as standard Laravel Prompts error messages.
- **Partial Success:**
  ```text
  ! [Workspace] feature-docs: Partial removal.
    - [Filesystem] Error: Permission denied.
  ```
