# Human Renderer: `orbit instance:env`

[Back to `instance:env` technical contract.](1_instance-env.md)

## Primitive

None. The renderer uses plain terminal text and tables without a specialized
prompt or progress primitive.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

`list` and `render` perform a single gateway API request and stay below one
second after input is resolved.

`set --apply` renders a progress tree with these phases:

1. Save env value in gateway state
2. Update remote `.env` file
3. Clear Laravel caches
4. Reapply app runtime container

## Success Output

For `list`, show a table of explicit non-secret env variables for the instance.

For `set`, print the saved key, app, instance, and concrete `.env` path. For
`set --apply`, also state that the value was applied and whether the selected
instance runtime restarted.

For `render`, show the effective env map. Secret values must be redacted.

Human output names `scope=instance`, the project, selected instance,
`workspace=—`, concrete `.env` path, and the stored/applied/runtime-restarted
outcomes without implying that the project root was targeted.

## Failure Output

Failures render the gateway or validation message directly. If `--secret` is
supplied, explain that explicit secret env storage is not available in this
slice.
