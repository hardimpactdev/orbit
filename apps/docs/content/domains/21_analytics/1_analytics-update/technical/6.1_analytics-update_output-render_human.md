# Human Renderer: `orbit analytics:update`

[Back to `analytics:update` technical contract.](1_analytics-update.md)

**Renderer:** Human terminal renderer.

## Primitive

None. Output is emitted as concise prose lines.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered. The command performs one gateway-backed process
update request; the process family owns longer-running runtime progress.

## Success Output

Render the selected analytics node, previous version when present, requested
version, and process status.

```text
analytics:
  node: analytics-1
  previous_version: 3.2.1
  version: 3.2.2
  process: plausible
  status: active
```

## Failure Output

Validation failures name the missing or invalid field. Missing process failures
point to `doctor --family=process --restore`.
