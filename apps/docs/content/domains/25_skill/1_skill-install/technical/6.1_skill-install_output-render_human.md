# Human Renderer: `orbit skill:install`

[Back to `skill:install` technical contract.](1_skill-install.md)

**Renderer:** Human renderer.

## Primitive

None. The command emits fixed key-value lines and no shared display primitive.

## Selection

Use this renderer when `--json` is absent.

## Success Output

Human success output prints key-value lines for the same result fields used by
the JSON renderer:

```text
action: installed
provider: codex
target: /Users/example/.agents/skills/orbit
source: /Users/example/orbit/.agents/skills/orbit
```

When the target was provided as a raw explicit path, `provider` is rendered as
an empty value.

## Failure Output

Handled failures render as:

```text
validation_failed: Use --force to overwrite the existing skill target.
```

## Progress Tree

No progress tree is rendered. `skill:install` performs one local filesystem copy
and is expected to stay below one second in normal use. It performs no gateway,
network, SSH, fleet, or provider-download work.

## Test Mapping

| Path | Coverage |
| --- | --- |
| `apps/cli/tests/Feature/Commands/Skill/SkillInstallCommandTest.php` | Human success key-value lines and handled validation failure prefix. |

There is no gateway-side coverage for this renderer: human rendering is owned
by `apps/cli` for a local-only command.
