# JSON Renderer: `orbit app:analytics show`

[Back to `app:analytics show` technical contract.](1_app-analytics-show.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

```json
  "success": {
    "data": {
      "app": {"name": "docs", "repository": null, "runtime": "php", "runtime_config": {"proxy_transport": "http"}, "php_version": "8.5", "dependency_audit_status": "unknown", "dependency_warning_count": 0, "dependency_danger_count": 0, "last_dependency_audit_at": null},
      "app_instance": "production",
      "serving_node": "app-prod-1",
      "binding": {
        "enabled": true,
        "internal_host": "analytics.orbit",
        "dashboard_url": "https://analytics.orbit",
        "public_hosts": ["analytics.docs.example.com"],
        "tracking_paths": ["/js/*", "/api/event"],

          }

      }
    },

  }
}
```

## Error Shapes

### Binding missing

```json
{
  "error": {
    "code": "analytics.binding_missing",
    "message": "Analytics is not enabled for app instance 'docs.production'.",
    "meta": {
      "app": "docs", "app_instance": "production", "serving_node": "app-prod-1"
    }
  }
}
```

`app` is the canonical logical entity. Ambiguous bare selectors fail with
`app_instance_required`; authorization failures identify `app_instance`,
`serving_node`, and `missing_permission=app:read`.
