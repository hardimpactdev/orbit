# JSON Renderer: `orbit instance:websocket credentials`

[Back to `instance:websocket credentials` technical contract.](1_instance-websocket-credentials.md)

This page describes the JSON-rendered output for `instance:websocket credentials`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The credentials object is returned under `success.data.credentials`.

## Success Shape

```json
{
  "success": {
    "data": {
      "project": {
        "name": "docs",
        "repository": null,
        "runtime": "php",
        "runtime_config": {"proxy_transport": "http"},
        "php_version": "8.5",
        "dependency_audit_status": "unknown",
        "dependency_warning_count": 0,
        "dependency_danger_count": 0,
        "last_dependency_audit_at": null
      },
      "instance": "production",
      "serving_node": "app-prod-1",
      "credentials": {
        "internal_host": "websocket.orbit",
        "public_hosts": ["ws.docs.example.com"],
        "allowed_origins": ["https://docs.example.com"],
        "reverb_app_id": "docs",
        "reverb_app_key": "abcdef1234567890abcdef1234567890",
        "reverb_app_secret": "abcdef1234567890abcdef1234567890abcdef1234567890"
      }
    },
    "meta": []
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `credentials` | object | Full Reverb connection details for the app. |
| `project` | object | Canonical project entity without placement fields. |
| `instance` | string | Concrete selected instance name. |
| `serving_node` | string | Selected instance's serving node and secret-read authorization boundary. |
| `credentials.internal_host` | string | WireGuard-internal WebSocket service hostname. Always `websocket.orbit`. |
| `credentials.public_hosts` | array | Public WebSocket hostnames bound to this app. |
| `credentials.allowed_origins` | array | Origins permitted by Reverb for this app. |
| `credentials.reverb_app_id` | string | Binding-specific Reverb application identifier generated at enable time; unique per instance binding. |
| `credentials.reverb_app_key` | string | Reverb application key. 32 characters. |
| `credentials.reverb_app_secret` | string | Reverb application secret. 48 characters. Treat as a secret value. |

## Error Shapes

### Instance not found

```json
{
  "error": {
    "code": "instance.not_found",
    "message": "Instance 'docs.production' not found.",
    "meta": {
      "instance": "docs.production"
    }
  }
}
```

A bare selector with zero or multiple credential-eligible instances returns
`validation_failed` with `error.meta.reason=instance_required`.

### Validation failed

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Instance is required.",
    "meta": {
      "field": "instance"
    }
  }
}
```

### WebSocket binding missing

```json
{
  "error": {
    "code": "websocket.binding_missing",
    "message": "Instance 'docs.production' does not have an enabled websocket binding.",
    "meta": {
      "project": "docs",
      "instance": "production",
      "serving_node": "app-prod-1"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'instance:credentials' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "instance:credentials",
      "instance": "docs.production",
      "serving_node": "app-prod-1"
    }
  }
}
```
