# Human Renderer: `orbit app:show [app]`

[Back to `app:show` technical contract.](1_app-show.md)

This page describes the human-rendered terminal output for `app:show`.

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. Prompt behavior belongs to
[`interactive input mode`](5.1_app-show_input-mode_interactive.md).
Non-interactive validation failures are rendered here as prose errors when
`--json` is absent.

## Progress Tree

`app:show` is a registry read. Execution is expected to complete below one
second and does not perform slow external work or live app-node probes. No
progress tree is rendered.

## Success Output

When the app is found:

```text
App: docs
Domain: docs.test
Environment: development
Node: app-1 (1.2.3.4)

Registry:
  Repository:    git@github.com:my/repo.git
  PHP Version:   8.5
  App Path:      /home/docs/app
  Document Root: /home/docs/app/public

Agent IDE:
  Adapter:   opencode
  Source:    app
  Discovery: available

Workspaces:
  - main (branch: main)
  - feature-docs (branch: feature/docs)

Processes:
  - vite

Routes:
  - docs.test (kind: app, owner: app)
```

The Workspaces, Processes, and Routes sections list the full registry intent
the app owns. They are not truncated. Per-item content is registry-shaped (see
the JSON renderer for exact field semantics); no live status is rendered. When
no items exist for a section, the section reads `(none)`.

## Failure Output

Human-rendered failures must show:

- the failing phase or field;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the operator can act on it.

### Missing input

```text
App name is required.
```

### App not found

```text
App 'docs' not found or not visible.
```

### Not authorized

```text
This caller is not authorized to inspect 'docs'.
```

### Gateway unavailable

```text
Gateway connection is required to show app details.
```

### Local context invalid

```text
Local node role setting is invalid.
```
