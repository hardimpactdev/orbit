## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)
- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Without `--live`, `php:list` is a gateway registry read. Execution is expected
to complete below one second and does not perform slow external work. No
progress tree is rendered.

With `--live`, render this progress tree after input resolution and before live
inspection begins:

```text
┌ Inspecting PHP Runtime
○ Resolve target
○ Read gateway configuration
○ Inspect installed versions
└ Working...
```

## Success Output

Human output presents a compact runtime table with:

- supported PHP versions;
- installed PHP versions on the resolved node;
- node CLI default;
- app PHP version when an app context is resolved;
- workspace effective PHP version and inheritance state when a workspace
  context is resolved.

## Failure Output

Human-rendered failures show the unresolved or unauthorized target and a concise
recovery hint, such as passing `--app=<app>`, `--workspace=<workspace>`, or
`--node=<node>`.
