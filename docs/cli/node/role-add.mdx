Add a role's packages, files, services, ports and Metrics membership to a Node. Use `--converge` to repair an existing assignment without removing it first.

```bash
orbit node:role:add <node> <role> [--converge] [--postgres-process=ID] [--clickhouse-process=ID] [--idempotency-key=KEY] [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `node` | yes | Positive numeric Node ID. |
| `role` | yes | `app-dev`, `app-prod`, `ingress`, `database`, `websocket`, `analytics`, `ci-runner`, `metrics`, `gateway`, or `swamp`. |

| Option | Default | Meaning |
| --- | --- | --- |
| `--converge` | off | Repair an assignment that is `active`, `failed` at a `converge:` step, or `provisioning` for at least 11 minutes with no Operation holding the Node. |
| `--postgres-process=ID` | none | For `analytics`, including convergence: the storage Process for PostgreSQL 16 or managed PostgreSQL 18. See [Analytics storage requirements](/reference/analytics#prepare-the-database-processes). |
| `--clickhouse-process=ID` | none | For `analytics`, including convergence: the ClickHouse storage Process. See [Analytics storage requirements](/reference/analytics#prepare-the-database-processes). |
| `--idempotency-key=KEY` | generated | [Shared request replay rules](/reference/operations#retry-a-start-with-a-key). |
| `--json` | off | [Shared machine-output rules](/reference/cli-ux#input-and-output-modes). |

```bash
orbit node:role:add 7 database
orbit node:role:add 7 database --converge
orbit node:role:add 9 analytics --postgres-process=41 --clickhouse-process=42
```

[Shared input rules](/reference/cli-ux#input-and-output-modes) govern omitted arguments and Analytics storage options. Access follows the [Node family's shared authority rule](/cli/node#authority). [Role compatibility](/reference/node-provisioning#role-compatibility) owns conflicts, singleton roles and ingress Cluster requirements; the [CI runner reference](/reference/node-provisioning#ci-runner-role) describes that role's host boundary.

A repeat without `--converge` is refused with `validation.failed`, except for an `active` `ingress` assignment, which reapplies its configuration. A successful second convergence reports no changes when the Node already matches. To move `gateway`, `websocket` or `metrics`, use [`node:role:relocate`](/cli/node/role-relocate).

## How it works

<div className="flow-at" data-chart="node/role-add"></div>
<div className="flow-at" data-chart="node/role-converge"></div>

Orbit checks recorded preconditions before changing the Node and allows one add or convergence at a time on it. The final check must pass before a new assignment becomes `active`. Role work does not install the Node agent or Orbit CLI; [`node:converge`](/cli/node/converge) owns them.

Application roles apply the configured storage directory's owner and mode. Orbit refuses protected storage paths before changing the Node. For `swamp`, it also repairs an existing compile cache's ownership and readability, then checks it without running a compilation.

For `gateway`, [Node provisioning](/reference/node-provisioning#add-a-node) lists the runtime this role owns. Converge it only with a release whose scheduler owns the automatic tick. Adding the role grants that Node access to active `vpn` and `metrics` Nodes on other machines.

A failed first add leaves the assignment `failed`, with its failed step and error code. Finished changes remain; after correcting the cause, use `--converge`. A failed convergence of an `active` assignment leaves it active. Orbit validates Caddy configuration before reloading it. Use [`node:role:list`](/cli/node/role-list) for recorded assignment state and [`doctor`](/cli/doctor) for drift.

## Errors

| Code | Meaning |
| --- | --- |
| `node.id_invalid` | The supplied Node selector is not a positive numeric ID. |
| `http.404` | The Node is not recorded. |
| `node_access.required` | The shared Node authority rule refuses the caller. |
| `validation.failed` | Invalid role, protected `vpn` or `router`, incompatible assignment, singleton or Cluster violation, ineligible convergence, a repeat that requires convergence, or Analytics options supplied for another role. |
| `operation.kind_unavailable` | The Node is not active Linux with recorded SSH management. |
| `operation.target_busy` | Another Operation holds the Node; the refused call creates no Operation and changes no assignment. |
| `database.wireguard_ip_missing` | `database` requires the Node's recorded WireGuard address. |
| `node_role.storage_process_required`, `analytics.settings_missing` | An Analytics storage selector or setting is missing or invalid. |
| `analytics.*`, `process.wireguard_ip_missing` | A storage Process does not meet the [Analytics requirements](/reference/analytics#assign-the-role). |
| `node.settings_path_invalid`, `node.settings_path_protected`, `node.settings_path_managed` | The configured storage path is invalid, protected, or overlaps a managed checkout. |
| `role.os_unsupported` | The Node does not run an admitted Ubuntu release. |

An execution failure reports the failed step and its error code on the Operation, rather than an admission refusal.
