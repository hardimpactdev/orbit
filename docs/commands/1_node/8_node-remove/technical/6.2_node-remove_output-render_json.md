# JSON Renderer: `orbit node:remove [name]`

[Back to `node:remove` technical contract.](1_node-remove.md)

This page describes the JSON-rendered output for `node:remove`.

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](5.2_node-remove_input-mode_non-interactive.md), even
when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "name": "app-1",
      "action": "removed",
      "removed_self": false,
      "wireguard_peer_removed": true,
      "grants_removed": 2
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `name` | string | The removed node name. |
| `action` | string | Always `removed`. |
| `removed_self` | boolean | `true` when the removed node was the authenticated control caller's own node record. |
| `wireguard_peer_removed` | boolean | `true` when the WireGuard peer was removed, `false` when it was already absent. |
| `grants_removed` | integer | Count of deleted `node_access` records. |

`success.meta.warnings` is omitted when there are no warnings. When partial
WireGuard detach leaves a stale peer behind, the result remains successful and
the recovery warning is reported under `success.meta.warnings`.

### Success removing the current control caller

```json
{
  "success": {
    "data": {
      "name": "control-1",
      "action": "removed",
      "removed_self": true,
      "wireguard_peer_removed": true,
      "grants_removed": 1
    }
  }
}
```

### Success with WireGuard detach warning

```json
{
  "success": {
    "data": {
      "name": "app-1",
      "action": "removed",
      "removed_self": false,
      "wireguard_peer_removed": false,
      "grants_removed": 2
    },
    "meta": {
      "warnings": [
        {
          "code": "node.wireguard_peer_extra",
          "message": "WireGuard peer could not be removed.",
          "family": "node",
          "next_command": "doctor --family=node --fix"
        }
      ]
    }
  }
}
```

Warning fields:

| Field | Type | Meaning |
| --- | --- | --- |
| `code` | string | Stable warning code. For partial WireGuard detach, `node.wireguard_peer_extra`. |
| `message` | string | Human-readable warning message. Automation must not parse it. |
| `family` | string | Doctor family that owns the remaining drift. |
| `next_command` | string | Suggested repair command. |

## Error Shapes

### Missing required input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Node name is required.",
    "meta": {
      "field": "name"
    }
  }
}
```

### Missing destructive consent

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Use --force to remove this node.",
    "meta": {
      "field": "force"
    }
  }
}
```

### Node not found

Already-absent removal returns this error shape. `node:remove` is an imperative
command against an existing gateway-owned node record, not an idempotent
absent-state convergence command.

```json
{
  "error": {
    "code": "node.not_found",
    "message": "Node 'app-1' not found.",
    "meta": {
      "name": "app-1"
    }
  }
}
```

### Gateway node removal

Returned for any target node with role `gateway`.

```json
{
  "error": {
    "code": "node.gateway_removal_denied",
    "message": "The gateway node cannot be removed with this command.",
    "meta": {
      "name": "gateway-1",
      "role": "gateway"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to remove a node.",
    "meta": {}
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This control node is not authorized to remove nodes.",
    "meta": {
      "required_node": "gateway-1",
      "caller_role": "control"
    }
  }
}
```

### Caller role not allowed

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "This command may only be run from a control or gateway node.",
    "meta": {
      "caller_role": "app"
    }
  }
}
```

### Local context invalid

```json
{
  "error": {
    "code": "local_context_invalid",
    "message": "Local node role setting is invalid.",
    "meta": {
      "setting": "general.local_node_role",
      "reason": "unsupported_value",
      "caller_role": "unknown"
    }
  }
}
```

## Enum And Identifier Values

| Field | Values |
| --- | --- |
| `action` | `removed` |
| `error.code` | `validation_failed`, `node.not_found`, `node.gateway_removal_denied`, `gateway_unavailable`, `authorization_failed`, `caller_role_not_allowed`, `local_context_invalid` |

The `error.code` values listed here are exhaustive for `node:remove`. Add a new
value to this renderer contract before implementing another JSON failure code.
