# Technical Contract: `orbit workspace:setup` (Human Renderer)

**Renderer:** Human.

[Back to the canonical technical contract.](1_workspace-setup.md)

## Progress Tree

`workspace:setup` renders a step tree during execution. Steps are shown
sequentially and updated in real-time.

```text
Setting up workspace feature-a for app my-app...

  ✔ Resolve workspace identity
  ✔ Converge gateway intent
  ✔ Configure routing (https://feature-a.my-app.orbit.local)
  ✔ Enact runtime artifacts on app-node-1
  ◌ Run setup steps (2/3)
    ✔ composer install
    ✔ php artisan migrate
  ◌ npm install
  ✔ Start processes (web, worker)
  ✔ Run HTTP probe

Success! Workspace feature-a is set up.
URL: https://feature-a.my-app.orbit.local
```

## Conditional Steps

- **Setup steps**: Only shown if the parent app defines setup steps.
  Skipped step rows are omitted silently to keep output focused.
- **Processes**: Only shown if processes are started.
- **HTTP probe**: Final setup-time URL probe. Probe failure renders a non-fatal
  warning under the success line; it does not turn the command outcome into a
  failure or create a doctor issue code.

## Human Strings

The success line varies by `result.action` so the operator can see what
this run did:

- **Success (`set_up`)**: "Workspace '{name}' is set up under app '{app}' on node '{node}'."
- **Success (`adopted`)**: "Workspace '{name}' adopted from path '{path}' on node '{node}'."
- **Success (`converged`)**: "Workspace '{name}' is already converged on node '{node}'. No changes were needed."
- **Success with warning**: The success line above is rendered, followed by
  a `Warning:` block summarizing each entry from `success.meta.warnings[]`
  with its message and the suggested `next_command`. For example:
  "Warning: Setup completed, but the HTTP probe for '{url}' did not return a
  serving response within 10s. Rerun
  `orbit workspace:setup {name}` after fixing the app."
- **Failure (setup step)**: "Setup step '{step}' failed with exit code
  {exit_code} on node '{node}'. The workspace path is still set up; rerun
  `orbit workspace:setup {name}` after fixing the script."

## Prose Errors

Errors are rendered with clear, actionable summaries:

```text
Error: Setup step "npm install" failed with exit code 1.

The command was run in /var/www/my-app/feature-a on node app-node-1.
Workspace intent and runtime artifacts remain in place. Rerun
"orbit workspace:setup feature-a" after fixing the script,
or see "orbit workspace:log feature-a" for the full execution output.
```
