# JSON Renderer: `orbit app:prune`

[Back to technical contract](1_app-prune.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

This file owns the JSON output contract for `app:prune`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Envelope

```json
{
  "success": {
    "data": {
      "app": {
        "name": "my-app",
        "node": "app-1",
        "environment": "development",
        "url": "https://my-app.orbit.test",
        "path": "/home/my-app/app",
        "root": "public",
        "repository": null,
        "php_version": "8.5",
        "adopted": false
      },
      "stale_workspaces": [
        {
          "name": "feature-docs",
          "status": "removed",
          "database": "skipped"
        },
        {
          "name": "old-experiment",
          "status": "removed",
          "database": "skipped"
        }
      ]
    },
    "meta": {
      "dry_run": false,
      "warnings": []
    }
  }
}
```

The `database` field reports the cleanup decision for any database
encountered during the workspace removal. In this contract revision the
only valid value is `"skipped"`; database removal requires explicit Orbit
ownership tracking that does not yet exist in gateway intent (see
`technical/1_app-prune.md` §3 and `BLUEPRINT.md` §Apps). Future tracking
work may introduce additional values such as `"removed"` or
`"would-remove"`; until then automation must treat `"skipped"` as the only
valid value and must not infer database ownership from any other field.

`success.data.app` is the canonical app JSON entity defined in
[`5_app/README.md`](../../README.md#app-json-entity).

### Partial Failure (Cleanup Failure)

If one workspace removal fails, the status is `partial` and the error is
captured in `success.meta.warnings[]`. Each warning carries `code`, `family`,
`message`, and `next_command`.

```json
{
  "success": {
    "data": {
      "app": {
        "name": "my-app",
        "node": "app-1",
        "environment": "development",
        "url": "https://my-app.orbit.test",
        "path": "/home/my-app/app",
        "root": "public",
        "repository": null,
        "php_version": "8.5",
        "adopted": false
      },
      "stale_workspaces": [
        {
          "name": "feature-docs",
          "status": "partial",
          "database": "skipped"
        }
      ]
    },
    "meta": {
      "dry_run": false,
      "warnings": [
        {
          "code": "workspace.artifact_extra",
          "family": "workspace",
          "message": "Workspace 'feature-docs' worktree cleanup failed: Permission denied.",
          "next_command": "doctor --fix --family=workspace --restore"
        }
      ]
    }
  }
}
```

## Error Envelope

```json
{
  "error": {
    "code": "app.no_agent_ide_adapter",
    "message": "No agent IDE adapters configured for app 'my-app'.",
    "meta": {
      "app": "my-app"
    }
  }
}
```

```json
{
  "error": {
    "code": "caller_role_not_allowed",
    "message": "This command may only be run from a control or gateway node.",
    "meta": {
      "caller_role": "app"
    }
  }
}
```

| Field | Values |
| --- | --- |
| `error.code` | `validation_failed`, `app.not_found`, `caller_role_not_allowed`, `authorization_failed`, `app.no_agent_ide_adapter`, `app.agent_ide_query_failed` |
| `success.meta.warnings[].code` | Same warning codes surfaced by `workspace:remove`, including `workspace.artifact_extra`, `proxy.route_extra`, and `process.runtime_unit_extra`. |

The `error.code` and warning `code` values listed here are exhaustive for
`app:prune`. Add a new value to this renderer contract before implementing
another JSON failure or warning code.
