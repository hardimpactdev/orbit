# JSON Renderer: `orbit schedule:remove`

[Back to `schedule:remove` technical contract.](1_schedule-remove.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "schedule": {
        "name": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs",
          "node": "app-1"
        },
        "interval": "every minute",
        "timezone": "Europe/Amsterdam",
        "execution": {
          "type": "command",
          "value": "php artisan schedule:run"
        },
        "enabled": false,
        "status": "removed",
        "last_run": null
      }
    },
    "meta": {
      "history_retained": true
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.schedule` | object | Snapshot of the gateway row deleted by this request. |
| `success.meta.history_retained` | boolean | Whether durable run history remains available. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `schedule.not_found`, `destructive_consent_required` | Stable command failure code. |
| `error.meta` | object | Field, scope, or caller context for automation. |

`validation_failed`, `gateway_unavailable`, `authorization_failed`,
`schedule.not_found`, and `destructive_consent_required`. Linked tests cover
only the mapped assertions above; remaining renderer codes stay as coverage
gaps until focused tests land.
