# Technical Contract: `orbit workspace:new` (JSON Renderer)

[Back to the canonical technical contract.](1_workspace-new.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).
`--json` emits one final result. Use `--stream-json` instead only when callers
need newline-delimited progress frames; that renderer follows the shared
[Stream JSON Frames](../../../README.md#stream-json-frames) contract.

## Success Envelope

```json
{
  "success": {
    "data": {
      "result": {
        "action": "created"
      },
      "workspace": {
        "name": "feature-a",
        "app": "my-app",
        "instance": "development",
        "node": "app-1",
        "path": "/home/orbit/apps/my-app/.worktrees/feature-a",
        "url": "https://feature-a.my-app.test",
        "php_version": "8.5",
        "php_inherited": false,
        "adopted": false,
        "lifecycle_status": "expected"
      }
    },
    "meta": {
      "node": "app-1",
      "base": "main",
      "http_probe": {
        "url": "https://feature-a.my-app.test",
        "result": "healthy",
        "status_code": 200,
        "duration_ms": 240
      },
      "warnings": []
    }
  }
}
```

### Fields

- `result.action`: Always `created` for `workspace:new`. The command does not
  adopt existing paths; adoption belongs to `doctor --family=workspace --adopt`
  and `workspace:setup` where explicitly documented.
- `workspace.name`: The workspace identity slug. Unique within the parent
  app, not globally.
- `workspace.app`: The parent app slug.
- `workspace.instance`: The selected instance name. This structural
  field is always a non-null string because every workspace row persists a
  non-null `instance_id`.
- `workspace.node`: The effective workspace node slug.
- `workspace.path`: The absolute workspace path on the node. Worktree creation
  uses `<selected app path>/.worktrees/<workspace>`.
- `workspace.url`: The primary workspace URL.
- `workspace.php_version`, `workspace.php_inherited`, `workspace.adopted`,
  and `workspace.lifecycle_status`: canonical workspace entity fields defined
  in [`6_workspace/README.md`](../../README.md#workspace-json-entity).
- `meta.base`: The source ref/branch passed to the selected workspace source
  driver. Echoes `--base` (default `main`). This is command-result metadata,
  not a durable workspace entity field.
- `meta.http_probe`: HTTP probe result from setup time. This is command metadata,
  not durable workspace state and not the registry lifecycle status rendered
  by `workspace:list`.
- `meta.http_probe.url`: URL probed by the command.
- `meta.http_probe.result`: `healthy` or `unhealthy`.
- `meta.http_probe.status_code`: HTTP status code when a response was
  received; `null` when the probe timed out before a response.
- `meta.http_probe.duration_ms`: Probe duration in milliseconds.
- `meta.warnings`: Structured non-fatal drift and retry handoffs. Each
  entry carries `code`, `family`, `message`, and `next_command`.

## Success with Drift Warning

If the gateway workspace row is written but downstream node application
fails in a retryable way, the command still exits `0` and reports drift
under `success.meta.warnings[]` using the canonical structured warning
shape:

```json
{
  "success": {
    "data": {
      "result": {
        "action": "created"
      },
      "workspace": {
        "name": "feature-a",
        "app": "my-app",
        "instance": "development",
        "node": "app-1",
        "path": "/home/orbit/apps/my-app/.worktrees/feature-a",
        "url": "https://feature-a.my-app.test",
        "php_version": "8.5",
        "php_inherited": false,
        "adopted": false,
        "lifecycle_status": "expected"
      }
    },
    "meta": {
      "node": "app-1",
      "base": "main",
      "http_probe": {
        "url": "https://feature-a.my-app.test",
        "result": "healthy",
        "status_code": 200,
        "duration_ms": 240
      },
      "warnings": [
        {
          "code": "workspace.path_missing",
          "family": "workspace",
          "message": "Workspace path '/home/orbit/apps/my-app/.worktrees/feature-a' is missing on node 'app-1'. Agent-push application failed after gateway configuration was written.",
          "next_command": "workspace:setup"
        }
      ]
    }
  }
}
```

## Error Envelope

### Per-app workspace-name collision

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The workspace name 'feature-a' is already used for app 'my-app'.",
    "meta": {
      "field": "name",
      "reason": "workspace_name_collision",
      "app": "my-app",
      "workspace": "feature-a"
    }
  }
}
```

### Reserved name `main`

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The name 'main' is reserved and cannot be used as a workspace name.",
    "meta": {
      "field": "name",
      "reason": "reserved_name"
    }
  }
}
```

### Concrete instance required

```json
{
  "error": {
    "code": "validation_failed",
    "message": "App 'my-app' must resolve to one concrete instance.",
    "meta": {
      "field": "instance",
      "reason": "instance_required",
      "app": "my-app"
    }
  }
}
```

### Hard apply failure

```json
{
  "error": {
    "code": "workspace.enactment_failed",
    "message": "Workspace application on node 'app-1' stopped before Orbit could classify remaining drift.",
    "meta": {
      "step": "classify_artifacts",
      "node": "app-1",
      "reason": "unexpected_failure"
    }
  }
}
```

### Registration failure after source provisioning

```json
{
  "error": {
    "code": "workspace.registration_failed",
    "message": "Workspace source was created, but registration failed.",
    "meta": {
      "step": "apply_workspace_registration",
      "node": "app-1",
      "path": "/home/orbit/apps/my-app/.worktrees/feature-a",
      "partial_state": "source_retained",
      "next_command": "orbit workspace:setup 'feature-a' --instance='my-app.development' --path='/home/orbit/apps/my-app/.worktrees/feature-a'"
    }
  }
}
```

### Common Error Codes

| Code | Meaning |
| --- | --- |
| `validation_failed` | A supplied input failed gateway-side static validation. Metadata names the offending field and validation rule. |
| `authorization_failed` | The caller lacks `workspace:new` on the effective workspace node. `error.meta.reason=missing_permission`, `error.meta.missing_permission=workspace:new`, and `error.meta.serving_node` names that node when known. |
| `workspace.parent_project_invalid` | The resolved parent app is missing, unauthorized, or unable to own workspaces. |
| `workspace.node_unreachable` | The gateway could not reach the effective workspace node before gateway configuration was written. |
| `workspace.source_create_failed` | Source provisioning failed before gateway intent was written. No workspace row is retained. |
| `workspace.registration_failed` | Source provisioning succeeded, but workspace registration failed. `error.meta.partial_state` identifies whether the source alone or both source and row remain, and `error.meta.next_command` adopts or converges the retained path. |
| `workspace.enactment_failed` | Gateway workspace row was written, but downstream execution failed before Orbit could classify the result as repairable drift or a command-owned setup failure. Fields: `error.meta.step`, `error.meta.node`, and `error.meta.reason`. Setup-step failures use `setup_step_failed`, process-start failures use `process_start_failed`, and unclassified plan exceptions use `unexpected_failure`. These reason identifiers are stable and do not contain command output or exception details. Source and intent remain for retry. |

For `validation_failed`, `error.meta.field` is `name`, `instance`, or `php_version`.
The reason may be `instance_required`, `reserved_name`,
`workspace_name_collision`, `slug_regex`, `combined_length_exceeded`, or
`unsupported_php_version`. The `instance_required` reason means a bare app
selector or inferred parent app did not resolve to exactly one concrete
instance.

Retryable runtime container, runtime, or proxy drift is reported under
`success.meta.warnings[]` instead of `workspace.enactment_failed`.

### Common Warning Codes

Non-fatal drift is reported in `success.meta.warnings[]`. Each warning
carries `code`, `family`, `message`, and `next_command`. Codes are drawn
from the `workspace` family in
[`workspace-doctor.md`](../../workspace-doctor.md) and from the
`proxy` family for workspace-owned route handoffs.

| Code | Family | Meaning |
| --- | --- | --- |
| `workspace.path_missing` | `workspace` | The workspace path was not created on the node. Workspace doctor is report-only; re-run `workspace:setup` or repair the path explicitly. |
| `process.runtime_unit_missing` | `process` | The workspace's concrete runtime container could not be rendered or started. `doctor --family=process --restore` will repair it. |
| `process.runtime_unit_mismatch` | `process` | The workspace's concrete runtime container differs from its process-backed runtime definition. `doctor --family=process --restore` will rewrite it. |
| `workspace.runtime_config_missing` | `workspace` | Managed workspace runtime configuration is absent. Workspace doctor is report-only; re-run `workspace:setup` or repair configuration explicitly. |
| `workspace.runtime_config_mismatch` | `workspace` | Managed workspace runtime configuration differs from gateway workspace configuration. Workspace doctor is report-only; re-run `workspace:setup` or repair configuration explicitly. |
| `proxy.domain_inactive` | `proxy` | The workspace-owned proxy route is not yet active because DNS or TLS prerequisites are pending. Retry through the relevant `proxy` family command. |
| `workspace.http_probe_unhealthy` | `null` | The setup-time HTTP probe returned `>= 500` or timed out. The warning is not a `workspace` doctor issue code; inspect the app or rerun `workspace:setup` after fixing application health. |

## Enum and identifier values

| Field | Values |
| --- | --- |
| `result.action` | `created` |
| `workspace.php_inherited` | `true`, `false` |
| `workspace.adopted` | `true`, `false` |
| `workspace.lifecycle_status` | `expected`, `setup-pending` |
| `error.code` | `validation_failed`, `authorization_failed`, `workspace.parent_project_invalid`, `workspace.unsupported_for_production`, `workspace.node_unreachable`, `workspace.source_create_failed`, `workspace.registration_failed`, `workspace.enactment_failed` |

The `error.code` values listed here are exhaustive for `workspace:new`. Add
a new value to this renderer contract before implementing another JSON
failure code.
