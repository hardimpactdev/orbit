# Non-Interactive Input Mode: `orbit app:root [app] [root]`

[Back to `app:root` technical contract.](1_app-root.md)

This page describes how non-interactive input mode resolves `app:root` input
without prompts.

**Input mode:** Non-interactive.

## Selection

Use this input mode when either condition is true:

- the command is running without a TTY;
- `--json` is present.

`--json` selects the JSON renderer and forces this input mode even when the
process has a TTY.

Authorization is gateway-side and grants-only. When the caller's grant on the
app's owning node does not include `app:root`, the gateway rejects the request
with `authorization_failed` before side effects begin; the CLI surfaces the
rejection.

## Responsibilities

- Read supplied arguments and options.
- Apply documented defaults.
- Never render prompts.
- Fail before side effects when required input is absent after default
  resolution.
- Fail before side effects when supplied input is invalid.
- Evaluate app eligibility and root validation as soon as the fields needed for
  each rule are known.

## Default Resolution

No required field has a default in non-interactive input mode.

## Required Input Failures

| Field | Missing when | Behavior |
| --- | --- | --- |
| `app` | `[app]` is absent. | Fail before side effects with `error.code=validation_failed` and `error.meta.field=app`. |
| `root` | `[root]` is absent. | Fail before side effects with `error.code=validation_failed` and `error.meta.field=root`. |

## Validation Failures

Fail before side effects when:

- `app` does not match an existing app name or hostname visible to the caller;
- the caller is not authorized to manage the resolved app;
- `root` is empty, absolute, or resolves outside the app path after lexical
  normalization.

The selected output renderer owns how these failures are displayed.

## Test Mapping

| Path | Coverage |
| --- | --- |
| `apps/cli/tests/Feature/Commands/App/AppWriteCommandTest.php` | Missing `root` validation before gateway and `--json` forcing non-interactive mode. |
