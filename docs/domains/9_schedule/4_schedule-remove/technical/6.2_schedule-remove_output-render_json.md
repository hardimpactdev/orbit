# JSON Renderer: `orbit schedule:remove`

[Back to `schedule:remove` technical contract.](1_schedule-remove.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "schedule": {
        "name": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs",
          "node": "app-1"
        },
        "interval": "every minute",
        "timezone": "Europe/Amsterdam",
        "execution": {
          "type": "command",
          "value": "php artisan schedule:run"
        },
        "enabled": false,
        "status": "removed",
        "last_run": null
      }
    },
    "meta": {
      "scheduler_pickup": "confirmed",
      "history_retained": true
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "schedule.target_unreachable",
    "message": "Schedule 'laravel-scheduler' was removed from gateway configuration, but schedule dispatch through gateway node 'gateway' could not be confirmed reachable.",
    "data": {
      "schedule": {
        "name": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs",
          "node": "app-1"
        },
        "interval": "every minute",
        "timezone": "Europe/Amsterdam",
        "execution": {
          "type": "command",
          "value": "php artisan schedule:run"
        },
        "enabled": false,
        "status": "removed_pending_pickup",
        "last_run": null
      }
    },
    "meta": {
      "next_command": "doctor --family=schedule"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.schedule` | object | Removed schedule entity. |
| `success.meta.scheduler_pickup` | string | Orbit Scheduler pickup result, usually `confirmed`. |
| `success.meta.history_retained` | boolean | Whether durable run history remains available. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `schedule.not_found`, `destructive_consent_required`, `schedule.target_unreachable` | Stable command failure code. |
| `error.data.schedule` | object | Removed schedule when scheduler pickup could not be confirmed after gateway state changed. |
| `error.meta` | object | Field, scope, caller, or recovery context for automation. |
