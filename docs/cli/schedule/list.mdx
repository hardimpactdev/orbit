title: "orbit schedule:list"
sidebarTitle: "schedule:list"
description: "List the Schedules whose target Node you may address, without command text, or the definitions of one Project."
---

```bash
orbit schedule:list [--project=ID] [--json]
```

For a migrated container Schedule, timer state and latest execution come from bounded container inspection. A stopped container is inactive; reading it never wakes it. Stored desired state remains unchanged.
