# JSON Renderer: `orbit instance:mount`

[Back to `instance:mount` technical contract.](1_instance-mount.md)

Use this renderer when `--json` is present.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

Every action returns the canonical logical `project` and selected canonical
`instance` separately. Node, URL, path, root, domain, placement, and `adopted`
exist only inside `instance`.

```json
{
  "success": {
    "data": {
      "app": {
        "name": "hauser",
        "repository": null,
        "runtime": "php",
        "runtime_config": {
          "proxy_transport": "http"
        },
        "php_version": "8.5",
        "dependency_audit_status": "unknown",
        "dependency_warning_count": 0,
        "dependency_danger_count": 0,
        "last_dependency_audit_at": null
      },
      "instance": {
        "app": "hauser",
        "name": "nmbp",
        "driver": "orbit",
        "driver_config": {
          "environment": "development",
          "node": "NMBP",
          "url": "https://hauser.nmbp",
          "path": "/Users/nckrtl/apps/hauser",
          "root": "public",
          "domain": "hauser.nmbp"
        },
        "adopted": false,
        "runtime": {
          "runtime": "php",
          "php_version": "8.5",
          "frankenphp_image": "ghcr.io/hardimpactdev/orbit-frankenphp:2-php8.5-bookworm",
          "mode": "classic",
          "configured_mounts": [
            {
              "source": "/Users/nckrtl/apps",
              "target": "/apps",
              "read_only": true
            }
          ],
          "required_php_extensions": []
        },
        "worker_enabled": false,
        "worker_config": null,
        "deploy_warmup_paths": [],
        "latest_deployment_status": null,
        "latest_deployment_run_id": null
      },
      "mounts": [
        {
          "source": "/Users/nckrtl/apps",
          "target": "/apps",
          "read_only": true
        }
      ],
      "mount": {
        "source": "/Users/nckrtl/apps",
        "target": "/apps",
        "read_only": true
      },
      "action": "updated",
      "inherited_by_workspaces": true
    },
    "meta": []
  }
}
```

For `list`, omit `mount` and `action`. For `remove`, `mounts` is the remaining
list, `mount` is the removed row when one existed, and `action` is `removed` or
`missing`. `add` uses `created`, `updated`, or `unchanged`.

## Fields

| Field | Meaning |
| --- | --- |
| `project` | Canonical project without placement or adoption fields. |
| `instance` | Canonical selected instance; owns all placement and `adopted`. |
| `mounts[]` | Complete configured mount list for the selected instance after the action. |
| `mount` | Changed mount for mutation actions when present. |
| `action` | `created`, `updated`, `unchanged`, `removed`, or `missing`. |
| `inherited_by_workspaces` | Whether workspaces targeting this instance inherit the mounts; currently `true`. |

## Error Shapes

Bare project selectors fail before authorization:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A dotted instance selector is required.",
    "meta": {
      "field": "instance",
      "reason": "instance_required"
    }
  }
}
```

Authorization is evaluated on the selected instance's serving node:

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This client is not authorized to manage mounts for 'hauser.nmbp'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "instance:mount",
      "instance": "hauser.nmbp",
      "serving_node": "NMBP"
    }
  }
}
```

Other validation failures use `validation_failed` with the existing reasons:
`source_must_be_absolute`, `source_outside_app_dev_home`, `source_sensitive`,
`target_must_be_absolute`, `target_reserved`, `instance_runtime_not_php`, and
`instance_mounts_app_dev_only`. Missing entities use `instance.not_found` as
applicable.
