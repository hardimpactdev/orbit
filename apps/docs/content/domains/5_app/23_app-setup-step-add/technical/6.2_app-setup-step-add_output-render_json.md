# JSON Renderer: `orbit app-setup-step:add`

[Back to `app-setup-step:add` technical contract.](1_app-setup-step-add.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

`success.data.step` contains `app`, `app_instance`, the setup step id, title,
command, sort order, and timeout.

## Error Shape

The top-level envelope is either `success` or `error`.

Exhaustive command-specific codes:

- `app.not_found`
- `validation_failed`
- `authorization_failed`
