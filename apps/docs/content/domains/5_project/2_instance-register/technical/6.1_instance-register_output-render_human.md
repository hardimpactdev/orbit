# Technical Contract: `orbit instance:register` (Human Renderer)

This contract defines the **human renderer** for `instance:register`.

[Back to the canonical contract.](1_instance-register.md)

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Progress Tree

The human renderer uses a step tree to visualize the registration and
apply process.

```text
┌ Registering Instance
○ Resolve project configuration
○ Register or adopt selected instance
○ Apply and verify instance runtime
○ Apply and verify instance routing
○ Verify application
└ Working...
```

## Human Strings

The success line varies by `result.action` so the operator can see what this
run did:

- **Success (`registered`)**: "Instance '{selector}' successfully registered on node '{node}'."
- **Success (`adopted`)**: "Instance '{selector}' successfully adopted from path '{path}' on node '{node}'."
- **Success (`moved`)**: "Instance '{selector}' successfully moved to path '{path}' on node '{node}'."
- **Success (`converged`)**: "Instance '{selector}' is already converged on node '{node}'. No changes were needed."
- **Success (`partial`)**: "Instance '{selector}' is registered on node '{node}', but proxy enactment is incomplete." The following warning names the failed layer, node, and operation.
- **Success with warning**: The success line above is rendered, followed by a
  `Warning:` block summarizing each entry from `success.meta.warnings[]` with
  its message and the suggested `next_command`. For example, when production
  activation is pending: "Warning: Production domain '{domain}' is not yet
  active. Retry with `orbit instance:register {selector} --domain={domain}` once DNS
  has propagated."
- **Failure (path collision)**: "Path '{path}' on node '{node}' is already owned by instance '{existing_instance}'. Pick a different path or remove that instance first."
- **Failure (instance required)**: "Project '{project}' requires a concrete instance selector."
- **Failure (other)**: "Failed to register instance '{selector}'."
