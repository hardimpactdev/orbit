# JSON Renderer: `orbit cf-cache-rule:add`

[Back to `cf-cache-rule:add` technical contract.](1_cf-cache-rule-add.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "rule": {
        "app": "docs",
        "zone": "example.com",
        "action": "add",
        "cache": true,
        "browser_ttl": "respect_origin",
        "status": "ready"
      }
    },
    "meta": {
      "provider": "cloudflare",
      "already_present": false
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The instance has no Cloudflare-backed domain.",
    "meta": {
      "field": "app",
      "app": "docs"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.rule.project` | string | Project that owns the domain. |
| `success.data.rule.zone` | string | Resolved Cloudflare zone. |
| `success.data.rule.action` | `add` | Command operation that completed. |
| `success.data.rule.browser_ttl` | `respect_origin` | Browser TTL policy installed by the rule. |
| `success.meta.already_present` | boolean | Whether an equivalent provider rule already existed. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `cloudflare_unavailable` | Stable command failure code. |
| `error.meta` | object | Field, app, zone, gateway, authorization, token, or provider failure context. |
