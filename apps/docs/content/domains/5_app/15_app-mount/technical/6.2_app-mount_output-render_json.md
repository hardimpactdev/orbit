# JSON Renderer: `orbit app:mount`

[Back to `app:mount` technical contract.](1_app-mount.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via
`$this->line(...)`.

The JSON renderer returns mount payloads under the standard `success` or
`error` envelope.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts even when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Fields

| Field | Type | Meaning |
| --- | --- | --- |
| `app.name` | string | App identity slug. |
| `app.node` | string \| null | Owning node slug when known. |
| `app.url` | string | Primary app URL. |
| `app.path` | string | Absolute app path on the owning node. |
| `app.root` | string | Document root relative to `path`. |
| `app.repository` | string \| null | Recorded source repository. |
| `app.runtime` | string | App runtime. |
| `app.php_version` | string | PHP version recorded for the app runtime. |
| `app.worker_enabled` | boolean | Whether FrankenPHP worker mode is enabled. |
| `app.worker_config` | object \| null | Worker configuration when present. |
| `app.adopted` | boolean | Whether the app was adopted from an existing path. |
| `mounts` | array | All configured app runtime mounts after the command. |
| `mounts[].source` | string | Absolute host source path on the owning node. |
| `mounts[].target` | string | Absolute container target path. |
| `mounts[].read_only` | boolean | Whether Docker renders this bind mount read-only. |
| `mount` | object | The changed mount for `add`, and for `remove` when a mount existed. |
| `action` | string | Mutation result: `created`, `updated`, `unchanged`, `removed`, or `missing`. |
| `inherited_by_workspaces` | boolean | Always `true`; workspace runtime containers inherit parent app mounts. |

## Error Shapes

### Missing or invalid action

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Action must be one of: list, add, remove.",
    "meta": {
      "field": "action",
      "allowed": ["list", "add", "remove"]
    }
  }
}
```

### Missing app

```json
{
  "error": {
    "code": "validation_failed",
    "message": "App is required.",
    "meta": {
      "field": "app"
    }
  }
}
```

### App not found

```json
{
  "error": {
    "code": "app.not_found",
    "message": "App 'docs' not found.",
    "meta": {
      "app": "docs"
    }
  }
}
```

### Unsafe source

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Runtime mount sources must live under /home/orbit.",
    "meta": {
      "reason": "source_outside_app_dev_home",
      "source": "/srv/shared",
      "home": "/home/orbit"
    }
  }
}
```

### Reserved target

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Runtime mount target '/packages' is reserved by Orbit.",
    "meta": {
      "reason": "target_reserved",
      "target": "/packages"
    }
  }
}
```

### Unsupported app runtime

```json
{
  "error": {
    "code": "validation_failed",
    "message": "App 'docs' does not use the PHP runtime.",
    "meta": {
      "reason": "app_runtime_not_php",
      "app": "docs",
      "runtime": "static"
    }
  }
}
```

### Unsupported owning role

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Configurable app runtime mounts are currently supported for app-dev apps only.",
    "meta": {
      "reason": "app_mounts_app_dev_only",
      "app": "docs"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'app:mount' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "app:mount",
      "serving_node": "app-1"
    }
  }
}
```

## Error Codes

| Code | Meaning |
| --- | --- |
| `validation_failed` | Input is missing or violates app runtime mount policy. |
| `app.not_found` | The app selector did not match an app record. |
| `authorization_failed` | The caller lacks `app:read` or `app:mount` on the owning node. |

Validation failures for source and target policy include `error.meta.reason`.
Current reasons include `source_must_be_absolute`,
`source_outside_app_dev_home`, `source_sensitive`,
`target_must_be_absolute`, `target_reserved`, `app_runtime_not_php`, and
`app_mounts_app_dev_only`.
