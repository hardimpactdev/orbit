# JSON Renderer: `orbit database:tables`

[Back to `database:tables` technical contract.](1_database-tables.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "connection": "acme",
      "tables": [
        { "name": "users", "kind": "base_table" }
      ]
    },
    "meta": {
      "target": "acme",
      "target_type": "app"
    }
  }
}
```

## Error Shape

The top-level envelope is either `success` or `error`.
