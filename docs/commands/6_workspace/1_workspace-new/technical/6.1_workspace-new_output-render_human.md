# Technical Contract: `orbit workspace:new` (Human Renderer)

[Back to the canonical technical contract.](1_workspace-new.md)

## Progress Tree

`workspace:new` performs remote work (SSH to the parent app's node, worktree
creation, FPM, proxy route, inherited process units, and setup steps) that
typically exceeds one second. It uses the shared step-tree renderer to
visualize progress in real time.

```text
┌ Create Workspace
○ Provision worktree on app-1
○ Register proxy routes
○ Install PHP-FPM artifacts
○ Render inherited process units
○ Run setup step: composer install
○ Run setup step: npm install
○ Run setup step: php artisan migrate
└ Workspace `feature-a` ready at https://feature-a.my-app.test
```

## Completion Summary

Upon success a one-line summary is printed:

```text
Workspace 'feature-a' created on app 'my-app' (node 'app-1').
URL: https://feature-a.my-app.test
PHP: 8.5 (inherited from app)
```

## Warning Display

Non-fatal drift surfaces inline under the affected step and again in a
`Warnings:` block beneath the completion summary. Each warning entry shows
the human-readable message and a retry hint pointing at `next_command`,
mirroring the `app:new`/`app:register` shape. Examples:

- A workspace path that did not get created during enactment prints
  "Workspace path is missing on 'app-1'." with the hint
  `Resolve with: orbit doctor --family=workspace --fix`.
- A missing FPM pool prints "Workspace PHP-FPM configuration is missing."
  with the hint `Resolve with: orbit doctor --family=workspace --fix`.
- A pending workspace proxy route prints the corresponding
  `proxy_route`-family warning with its own `next_command`.

## Failure Display

Failures are rendered as prose errors with troubleshooting hints. If a
failure occurs during the progress tree, the affected step shows a red
error dot. Validation failures detected before side effects (reserved name
`main`, slug regex, per-app workspace-name collision, unsupported
`--php-version`, unresolved parent app) are rendered without a progress
tree:

```text
✗ Failed to create workspace 'feature-a'
  The workspace name 'feature-a' is already used for app 'my-app'.
```

```text
✗ Failed to create workspace 'main'
  The name 'main' is reserved and cannot be used as a workspace name.
```
