# JSON Renderer: `orbit app:setup`

[Back to `app:setup` technical contract.](1_app-setup.md)

## Primitive

- Progress stream: [`progress-tree`](../../../../ux/commands/progress/progress-tree.md)

Final JSON uses the shared machine-readable envelope.

## Selection

Use this renderer when `--json` is present. Use the stream renderer when
`--stream-json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

`success.data.app` and `success.data.app_instance` identify the selected
placement. `success.data.run` contains the instance-owned setup run status,
step-set hash, started and finished timestamps, and step results.

## Error Shape

The top-level envelope is either `success` or `error`.

Exhaustive command-specific codes:

- `app.not_found`
- `validation_failed` with `error.meta.reason=app_instance_required`
- `app.setup_failed`
- `authorization_failed`
