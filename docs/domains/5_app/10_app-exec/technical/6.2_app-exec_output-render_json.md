# JSON Renderer: `orbit app:exec`

[Back to `app:exec` technical contract.](1_app-exec.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via
`$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts even when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The wrapper exit code is `0` whenever the wrapper successfully ran the
underlying command, regardless of the underlying command's exit code. The
underlying exit code is reported in `success.data.exit_code`. Wrapper
failures (validation, app not found, unsupported runtime, container not
running, authorization, gateway unavailability) use the standard `error`
envelope and exit `1`.

## Success Shapes

### Underlying command exited 0

```json
{
  "success": {
    "data": {
      "app": "docs",
      "container": "orbit-app-docs",
      "command": ["php", "-v"],
      "exit_code": 0,
      "stdout": "PHP 8.5.0 (cli) (built: ...) (NTS)\n",
      "stderr": ""
    }
  }
}
```

### Underlying command exited non-zero

```json
{
  "success": {
    "data": {
      "app": "docs",
      "container": "orbit-app-docs",
      "command": ["php", "artisan", "migrate"],
      "exit_code": 1,
      "stdout": "",
      "stderr": "SQLSTATE[HY000]: database is locked\n"
    }
  }
}
```

The underlying exit code is reported in `success.data.exit_code`. The
wrapper exit code remains `0` because `app:exec` successfully ran the
command end-to-end; consumers branch on `success.data.exit_code` to detect
the underlying failure.

### Fields

| Field | Type | Meaning |
| --- | --- | --- |
| `app` | string | App identity slug. |
| `container` | string | Container name `app:exec` ran the command inside (`orbit-app-<slug>`). |
| `command` | array of string | The command tokens passed to `docker exec`, in order. |
| `exit_code` | integer | The underlying command's exit code. `0` means the underlying command succeeded. |
| `stdout` | string | The underlying command's captured stdout. May be empty. |
| `stderr` | string | The underlying command's captured stderr. May be empty. |

## Error Shapes

### Missing command

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A command to execute is required.",
    "meta": {
      "field": "command"
    }
  }
}
```

### Missing app

```json
{
  "error": {
    "code": "validation_failed",
    "message": "App is required.",
    "meta": {
      "field": "app"
    }
  }
}
```

### App not found

```json
{
  "error": {
    "code": "app.not_found",
    "message": "App 'missing' not found.",
    "meta": {
      "app": "missing"
    }
  }
}
```

### Unsupported runtime

```json
{
  "error": {
    "code": "app.exec_unsupported_runtime",
    "message": "App 'static-site' has runtime_kind=static; app:exec requires runtime_kind=php.",
    "meta": {
      "app": "static-site",
      "runtime_kind": "static"
    }
  }
}
```

### Container not running

```json
{
  "error": {
    "code": "app.exec_container_not_running",
    "message": "App 'docs' runtime container is not running on node 'app-1'.",
    "meta": {
      "app": "docs",
      "container": "orbit-app-docs",
      "node": "app-1"
    }
  }
}
```

### Command not executable

```json
{
  "error": {
    "code": "app.exec_command_not_executable",
    "message": "Command is not executable inside app 'docs' runtime container on node 'app-1'.",
    "meta": {
      "app": "docs",
      "container": "orbit-app-docs",
      "node": "app-1",
      "exit_code": 126,
      "stderr": "OCI runtime exec failed: ... permission denied"
    }
  }
}
```

### Command not found

```json
{
  "error": {
    "code": "app.exec_command_not_found",
    "message": "Command not found inside app 'docs' runtime container on node 'app-1'.",
    "meta": {
      "app": "docs",
      "container": "orbit-app-docs",
      "node": "app-1",
      "exit_code": 127,
      "stderr": "OCI runtime exec failed: ... executable file not found in $PATH"
    }
  }
}
```

### Docker daemon unavailable

```json
{
  "error": {
    "code": "app.exec_docker_unavailable",
    "message": "Docker daemon is unavailable on node 'app-1'.",
    "meta": {
      "app": "docs",
      "node": "app-1",
      "stderr": "Cannot connect to the Docker daemon at unix:///var/run/docker.sock"
    }
  }
}
```

### Node unreachable

```json
{
  "error": {
    "code": "app.exec_node_unreachable",
    "message": "Cannot reach node 'app-1' to run app:exec.",
    "meta": {
      "app": "docs",
      "node": "app-1",
      "exit_code": 255,
      "stderr": "ssh: connect to host 10.6.0.7 port 22: Connection refused"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'app:exec' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "app:exec",
      "serving_node": "app-1"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to run app:exec.",
    "meta": {}
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `error.code` | `validation_failed`, `app.not_found`, `app.exec_unsupported_runtime`, `app.exec_container_not_running`, `app.exec_command_not_executable`, `app.exec_command_not_found`, `app.exec_docker_unavailable`, `app.exec_node_unreachable`, `authorization_failed`, `gateway_unavailable` |

The `error.code` values listed here are exhaustive for `app:exec`. Add a
new value to this renderer contract before implementing another JSON failure
code.

## Test Mapping

| Path | Coverage |
| --- | --- |
| `tests/Feature/Commands/Apps/AppExecCommandTest.php` | JSON envelope and every documented `error.code` (see notes). |
| `tests/Feature/Http/Api/AppExecControllerTest.php` | API JSON envelope shape and HTTP status mapping (see notes). |

`AppExecCommandTest` must assert: the success envelope shape on both
zero and non-zero underlying exits (including the test that proves a
non-zero child exit is NOT misclassified as infra failure), and the
`validation_failed`, `app.not_found`, `app.exec_unsupported_runtime`,
`app.exec_container_not_running` (preflight missing-and-stopped
variants), `app.exec_command_not_executable` (docker exit 126),
`app.exec_command_not_found` (docker exit 127),
`app.exec_docker_unavailable`, `app.exec_node_unreachable`, and
`gateway_unavailable` failure codes.

`AppExecControllerTest` must assert: the API JSON envelope shape, the
success payload, and HTTP status mapping for `app.not_found` (404),
`app.exec_unsupported_runtime` / `app.exec_container_not_running` /
`app.exec_command_not_executable` / `app.exec_command_not_found` /
`validation_failed` (422), `app.exec_docker_unavailable` /
`app.exec_node_unreachable` (502), and `authorization_failed` (403)
for the `app:exec` permission.
