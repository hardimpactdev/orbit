# Human Renderer: `orbit database:query`

[Back to `database:query` technical contract.](1_database-query.md)

## Primitive

None. `database:query` is JSON-only because query results are primarily
LLM-operated and must remain strict machine-readable output. The command emits
the documented JSON envelope even when `--json` is omitted.

## Progress Tree

No progress tree. The public command must not mix progress output, prose, or
tables into query stdout because stdout is reserved for strict JSON results.
Diagnostics and audit data belong on stderr or in the activity log.

## Human Strings

- None. Success and failure responses use the JSON renderer shape.

`--full` controls JSON result truncation. It does not select a human renderer.
