# Interactive Input Mode: `orbit tool-restart`

[Back to `tool-restart` technical contract.](1_tool-restart.md)

**Input mode:** Interactive.

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Behavior

When `tool` is missing, prompt with a searchable tool catalog.

When no explicit target selector or local `node:default` resolves a target on
the gateway, prompt for a visible tool node. Invalid prompt answers re-prompt
until the value is valid or the operator aborts.

If the operator aborts a prompt, the command exits before side effects with
`validation_failed`.
