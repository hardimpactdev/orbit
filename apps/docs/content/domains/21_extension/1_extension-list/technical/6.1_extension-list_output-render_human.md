# Human Renderer: `orbit extension:list`

[Back to `extension:list` technical contract.](1_extension-list.md)

**Renderer:** Human renderer.

## Primitive

None. The current renderer prints compact status lines.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered. This is a compact read-only status command.

## Output

Each extension renders one line:

```text
cloudflare: local=enabled, gateway=disabled
codex: local=disabled, gateway=enabled
solo: local=disabled, gateway=unknown
```

When gateway state cannot be read, use `gateway=unknown` for every extension.
