```bash
orbit tasks:provision <group> [--idempotency-key=KEY] [--json]
```

Provision the numeric task `group` through the Gateway's `tasks.provision` operation. The group must use external orchestration and be `todo`. If you omit `group` in a terminal, choose a todo group from the prompt. Machine mode requires its ID. The command follows capacity waits until the workspace is ready. It starts no subtask or check. `--idempotency-key` reuses the same operation on a repeated start. Ctrl-C stops following; it leaves the operation running. Use `tasks:cancel` to end the group and stop a waiting provision. See [Provision an external group](/reference/tasks#provision-an-external-group).
