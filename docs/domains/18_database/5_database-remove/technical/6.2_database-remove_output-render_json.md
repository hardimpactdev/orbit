# JSON Renderer: `orbit database:remove`

[Back to `database:remove` technical contract.](1_database-remove.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "result": {
        "action": "removed",
        "connection": "acme"
      }
    },
    "meta": {}
  }
}
```

## Error Shape

The top-level envelope is either `success` or `error`.
