# Non-Interactive Input Mode: `orbit php:use`

[Back to `php:use` technical contract.](1_php-use.md)

**Input mode:** Non-interactive.

Use this input mode when the command is not attached to a TTY or when `--json`
is present. `--json` forces non-interactive input mode.

## Behavior

- Never render prompts.
- Missing `version` fails with `error.code=validation_failed` unless
  `--inherit` is supplied.
- Missing target scope fails with `error.code=validation_failed` when cwd and
  explicit options do not resolve a target.
- `--inherit` without a resolved workspace fails with
  `error.code=validation_failed`.
- Mutually exclusive options fail before side effects.
- A project target is fully resolved, authorized across every affected
  Orbit instance serving node, and image-preflighted before the shared policy
  is mutated; non-interactive mode never chooses one instance implicitly.
