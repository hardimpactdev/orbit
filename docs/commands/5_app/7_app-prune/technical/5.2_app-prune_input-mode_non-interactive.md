# Non-Interactive Input Mode: `orbit app:prune`

[Back to technical contract](1_app-prune.md)

**Input mode:** Non-interactive.

This file owns the non-interactive input contract for `app:prune`.

Use this input mode when either condition is true:

- the command is running without a TTY;
- `--json` is present.

`--json` selects the JSON renderer and forces this input mode even when the
process has a TTY. It never authorizes destructive pruning; `--force` must be
passed explicitly when `--dry-run` is absent. Non-interactive input mode must
never render prompts.

## Rules

### 1. Mandatory Input
- The `app` argument must be supplied on the command line.
- If `app` is missing, the command fails immediately with a validation error.

### 2. Destructive Consent
- If `--dry-run` is **not** present, the `--force` flag **must** be present.
- If `--force` is missing and `--dry-run` is false, the command fails before side effects with `error.code=validation_failed` and `error.meta.field=force`.
- If `--dry-run` is present, `--force` is optional and ignored.

## Failure Semantics

- **Missing App:** Standard non-interactive failure.
- **Missing Force:** Standard destructive non-interactive failure.
