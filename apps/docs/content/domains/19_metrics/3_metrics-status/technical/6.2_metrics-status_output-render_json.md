# JSON Renderer: `orbit metrics:status`

[Back to `metrics:status` technical contract.](1_metrics-status.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "metrics": [
        {
          "node": "metrics-1",
          "url": "https://metrics.orbit",
          "processes": [
            {"key": "grafana", "label": "Grafana", "name": "grafana", "runtime": "docker-swarm"},
            {"key": "node-exporter", "label": "Node Exporter", "name": "node-exporter", "runtime": "systemd"},
            {"key": "prometheus", "label": "Prometheus", "name": "prometheus", "runtime": "docker-swarm"}
          ]
        }
      ]
    },
    "meta": []
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'process:read' on 'metrics-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "process:read",
      "serving_node": "metrics-1"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.metrics[].node` | string | Metrics node name. |
| `success.data.metrics[].url` | string | Private Grafana endpoint. |
| `success.data.metrics[].processes[].key` | string | Stable process identity slug. |
| `success.data.metrics[].processes[].label` | string | Durable human display label. |
| `success.data.metrics[].processes[].name` | string | Deprecated compatibility alias equal to `key`; new consumers must use `key` and `label`. |
| `success.data.metrics[].processes[].runtime` | `docker-swarm` or `systemd` | Process runtime backend. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed` | Stable command failure code. |
