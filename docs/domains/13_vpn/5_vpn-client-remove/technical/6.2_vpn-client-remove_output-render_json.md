# JSON Renderer: `orbit vpn-client:remove <name>`

[Back to `vpn-client:remove` technical contract.](1_vpn-client-remove.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present. `--json` also forces
non-interactive input mode and never grants destructive consent.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "client": {
        "name": "laptop",
        "action": "removed"
      }
    },
    "meta": {}
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Use --force to remove this VPN client.",
    "meta": {
      "field": "force",
      "reason": "destructive_consent_required"
    }
  }
}
```

## Active Node Peer Error

```json
{
  "error": {
    "code": "validation_failed",
    "message": "VPN client is an active Orbit node peer.",
    "meta": {
      "field": "name",
      "reason": "node_peer_protected",
      "next_command": "node:remove app-1"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.client.name` | string | Removed client name. |
| `success.data.client.action` | `removed` | Command action. |
| `error.code` | `validation_failed`, `vpn_runtime_unavailable`, `vpn_runtime_ssh_unavailable`, `authorization_failed`, `vpn_backend_unavailable`, `vpn_backend_auth_failed` | Stable command failure code. |
| `error.meta` | object | Validation, gateway SSH, authorization, backend, or authentication failure context. |
