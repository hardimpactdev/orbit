# Interactive Input Mode: `orbit skill:install`

[Back to `skill:install` technical contract.](1_skill-install.md)

**Input mode:** Interactive.

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Behavior

No prompt is rendered when the resolved target is absent. When it already
exists and `--force` is absent, render this destructive confirmation after
source and target validation and before deleting anything:

```text
Replace existing Orbit skill target '<target>'?
```

Declining fails before side effects with `error.code=validation_failed`,
`error.meta.field=force`, and
`error.meta.reason=destructive_consent_required`. `--force` skips the prompt.

The command never prompts to infer a provider, choose a target path, or confirm
provider defaults.
