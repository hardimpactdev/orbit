---
title: "orbit task:agent:list"
sidebarTitle: "task:agent:list"
description: "List a task's agent threads: each subtask's reviewer and implementer, including finished threads."
---

```bash
orbit task:agent:list [task] [--json]
```

The table shows the thread ID, role, subtask ID, driver, model, state, tokens, uncached input, cached input, output, model calls, peak context, line diff, and observation time. An unknown token field is a blank cell. JSON output includes `input_tokens`, `cached_input_tokens`, `output_tokens`, `model_calls`, and `peak_context_tokens`, each null when the driver did not report it. The [thread token metrics](/reference/tasks#thread-token-metrics) define the fields. The latest error of each thread follows the table. The web task board shows the cumulative total. [`task:agent:show`](/cli/task/agent-show) reads one thread's conversation.
