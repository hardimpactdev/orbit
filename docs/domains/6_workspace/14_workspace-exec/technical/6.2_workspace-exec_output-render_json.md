# JSON Renderer: `orbit workspace:exec`

[Back to `workspace:exec` technical contract.](1_workspace-exec.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope via
`$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts even when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

The wrapper exit code is `0` whenever the wrapper successfully ran the
underlying command, regardless of the underlying command's exit code. The
underlying exit code is reported in `success.data.exit_code`. Wrapper
failures (validation, workspace not found, unsupported runtime, container
not running, authorization, gateway unavailability) use the standard
`error` envelope and exit `1`.

## Success Shapes

### Underlying command exited 0

```json
{
  "success": {
    "data": {
      "workspace": "docs-feature",
      "app": "docs",
      "container": "orbit-ws-docs-docs-feature",
      "command": ["php", "-v"],
      "exit_code": 0,
      "stdout": "PHP 8.5.0 (cli) (built: ...) (NTS)\n",
      "stderr": ""
    }
  }
}
```

### Underlying command exited non-zero

```json
{
  "success": {
    "data": {
      "workspace": "docs-feature",
      "app": "docs",
      "container": "orbit-ws-docs-docs-feature",
      "command": ["php", "artisan", "test"],
      "exit_code": 1,
      "stdout": "",
      "stderr": "Tests failed.\n"
    }
  }
}
```

The underlying exit code is reported in `success.data.exit_code`. The
wrapper exit code remains `0` because `workspace:exec` successfully ran the
command end-to-end; consumers branch on `success.data.exit_code` to detect
the underlying failure.

### Fields

| Field | Type | Meaning |
| --- | --- | --- |
| `workspace` | string | Workspace identity slug. |
| `app` | string | Parent app identity slug. |
| `container` | string | Container name `workspace:exec` ran the command inside (`orbit-ws-<app>-<workspace>`). |
| `command` | array of string | The command tokens passed to `docker exec`, in order. |
| `exit_code` | integer | The underlying command's exit code. `0` means the underlying command succeeded. |
| `stdout` | string | The underlying command's captured stdout. May be empty. |
| `stderr` | string | The underlying command's captured stderr. May be empty. |

## Error Shapes

### Missing command

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A command to execute is required.",
    "meta": {
      "field": "command"
    }
  }
}
```

### Missing workspace

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Workspace is required.",
    "meta": {
      "field": "workspace"
    }
  }
}
```

### Workspace not found

```json
{
  "error": {
    "code": "workspace.not_found",
    "message": "Workspace 'missing' not found.",
    "meta": {
      "workspace": "missing"
    }
  }
}
```

### Ambiguous workspace name

```json
{
  "error": {
    "code": "workspace.ambiguous_name",
    "message": "Workspace name 'shared' matches multiple apps; pass --app to disambiguate.",
    "meta": {
      "workspace": "shared",
      "apps": ["docs", "site"]
    }
  }
}
```

### Unsupported runtime

```json
{
  "error": {
    "code": "workspace.exec_unsupported_runtime",
    "message": "Workspace 'docs-feature' parent app has runtime_kind=static; workspace:exec requires runtime_kind=php.",
    "meta": {
      "workspace": "docs-feature",
      "app": "docs",
      "runtime_kind": "static"
    }
  }
}
```

### Container not running

```json
{
  "error": {
    "code": "workspace.exec_container_not_running",
    "message": "Workspace 'docs-feature' runtime container is not running on node 'app-1'.",
    "meta": {
      "workspace": "docs-feature",
      "container": "orbit-ws-docs-docs-feature",
      "node": "app-1"
    }
  }
}
```

### Command not executable

```json
{
  "error": {
    "code": "workspace.exec_command_not_executable",
    "message": "Command is not executable inside workspace 'docs-feature' runtime container on node 'app-1'.",
    "meta": {
      "workspace": "docs-feature",
      "app": "docs",
      "container": "orbit-ws-docs-docs-feature",
      "node": "app-1",
      "exit_code": 126,
      "stderr": "OCI runtime exec failed: ... permission denied"
    }
  }
}
```

### Command not found

```json
{
  "error": {
    "code": "workspace.exec_command_not_found",
    "message": "Command not found inside workspace 'docs-feature' runtime container on node 'app-1'.",
    "meta": {
      "workspace": "docs-feature",
      "app": "docs",
      "container": "orbit-ws-docs-docs-feature",
      "node": "app-1",
      "exit_code": 127,
      "stderr": "OCI runtime exec failed: ... executable file not found in $PATH"
    }
  }
}
```

### Docker daemon unavailable

```json
{
  "error": {
    "code": "workspace.exec_docker_unavailable",
    "message": "Docker daemon is unavailable on node 'app-1'.",
    "meta": {
      "workspace": "docs-feature",
      "node": "app-1",
      "stderr": "Cannot connect to the Docker daemon at unix:///var/run/docker.sock"
    }
  }
}
```

### Node unreachable

```json
{
  "error": {
    "code": "workspace.exec_node_unreachable",
    "message": "Cannot reach node 'app-1' to run workspace:exec.",
    "meta": {
      "workspace": "docs-feature",
      "node": "app-1",
      "exit_code": 255,
      "stderr": "ssh: connect to host 10.6.0.7 port 22: Connection refused"
    }
  }
}
```

### Authorization failed

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'workspace:exec' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "workspace:exec",
      "serving_node": "app-1"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to run workspace:exec.",
    "meta": {}
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `error.code` | `validation_failed`, `workspace.not_found`, `workspace.ambiguous_name`, `workspace.exec_unsupported_runtime`, `workspace.exec_container_not_running`, `workspace.exec_command_not_executable`, `workspace.exec_command_not_found`, `workspace.exec_docker_unavailable`, `workspace.exec_node_unreachable`, `authorization_failed`, `gateway_unavailable` |

The `error.code` values listed here are exhaustive for `workspace:exec`.
Add a new value to this renderer contract before implementing another JSON
failure code.

## Test Mapping

| Path | Coverage |
| --- | --- |
| `tests/Feature/Commands/Workspaces/WorkspaceExecCommandTest.php` | JSON envelope and every documented `error.code` (see notes). |
| `tests/Feature/Http/Api/WorkspaceExecControllerTest.php` | API JSON envelope shape and HTTP status mapping (see notes). |

`WorkspaceExecCommandTest` must assert: the success envelope shape on
both zero and non-zero underlying exits (including the test that proves
a non-zero child exit is NOT misclassified as infra failure), and the
`validation_failed`, `workspace.not_found`, `workspace.ambiguous_name`,
`workspace.exec_unsupported_runtime`,
`workspace.exec_container_not_running` (preflight missing-and-stopped
variants), `workspace.exec_command_not_executable` (docker exit 126),
`workspace.exec_command_not_found` (docker exit 127),
`workspace.exec_docker_unavailable`, `workspace.exec_node_unreachable`,
and `gateway_unavailable` failure codes.

`WorkspaceExecControllerTest` must assert: the API JSON envelope shape,
the success payload, and HTTP status mapping for `workspace.not_found`
(404), `workspace.ambiguous_name` (400),
`workspace.exec_unsupported_runtime` /
`workspace.exec_container_not_running` /
`workspace.exec_command_not_executable` /
`workspace.exec_command_not_found` / `validation_failed` (422),
`workspace.exec_docker_unavailable` / `workspace.exec_node_unreachable`
(502), and `authorization_failed` (403) for the `workspace:exec`
permission.
