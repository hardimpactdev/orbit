# JSON Renderer: `orbit php:use`

[Back to `php:use` technical contract.](1_php-use.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "php": {
        "supported": ["8.5", "8.4", "8.3"],
        "project": {
          "name": "docs",
          "php_version": "8.5"
        },
        "instances": [
          {"instance": "development", "driver": "orbit", "node": "app-dev-1", "available_images": ["8.5"]},
          {"instance": "production", "driver": "orbit", "node": "app-prod-1", "available_images": ["8.5"]},
          {"instance": "production-cloud", "driver": "laravel-cloud", "node": null, "available_images": null}
        ],
        "workspace": null
      },
      "result": {
        "target": "app",
        "project": "docs",
        "workspace": null,
        "previous": "8.4",
        "version": "8.5",
        "image": "ghcr.io/hardimpactdev/orbit-frankenphp:1-php8.5-bookworm",
        "inherits": false,
        "changed": true,
        "instances": [
          {"instance": "development", "driver": "orbit", "node": "app-dev-1", "status": "reconciled", "image": "ghcr.io/hardimpactdev/orbit-frankenphp:1-php8.5-bookworm"},
          {"instance": "production", "driver": "orbit", "node": "app-prod-1", "status": "reconciled", "image": "ghcr.io/hardimpactdev/orbit-frankenphp:1-php8.5-bookworm"},
          {"instance": "production-cloud", "driver": "laravel-cloud", "node": null, "status": "external", "image": null}
        ]
      }
    },
    "meta": {
      "warnings": []
    }
  }
}
```

App and workspace results include `success.data.result.image` with the approved
FrankenPHP image tag for the resolved version. Workspace results report the
image for the effective version after applying the override or inheritance.
Node CLI results omit `success.data.result.image`; host CLI selection is
governed by the `php-cli` toolchain, not FrankenPHP runtime images.

## Failed app reconciliation

If any affected Orbit instance fails after the shared policy write, the command
returns an error envelope, never partial success. Completed results and the
failed instance remain explicit for Doctor repair.

```json
{
  "error": {
    "code": "php.reconciliation_failed",
    "message": "PHP policy was updated, but one or more instances did not reconcile.",
    "meta": {
      "project": "docs",
      "version": "8.5",
      "next_command": "doctor --family=instance --instance=docs.production --restore",
      "instances": [
        {"instance": "development", "driver": "orbit", "node": "app-dev-1", "status": "reconciled"},
        {"instance": "production", "driver": "orbit", "node": "app-prod-1", "status": "failed"},
        {"instance": "production-cloud", "driver": "laravel-cloud", "node": null, "status": "external"}
      ]
    }
  }
}
```

Recovery is exposed once at `error.meta.next_command` when one runnable command
repairs the failed result. Each instance row records only result facts; recovery
commands are never nested inside it.

Workspace runtime and proxy warnings may still use the owning-family warning
contract. Every `success.meta.warnings[]` entry carries `code`, `family`,
`message`, and `next_command`. `family` is `workspace` for workspace artifact
drift and `proxy` for proxy-backend drift. `next_command` is the single
machine-runnable Doctor command for that family.
Project fan-out uses `php.reconciliation_failed`; it never places failed
instance reconciliation under `success.meta.warnings`.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Required input is missing or invalid.",
    "meta": {
      "field": "version",
      "reason": "missing_required_input"
    }
  }
}
```

When `--node` names a node that does not serve the resolved workspace,
the command fails before any gateway configuration write with this shape:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Node 'image-node' does not serve workspace 'feature-docs'.",
    "meta": {
      "field": "node",
      "reason": "target_mismatch",
      "node": "image-node",
      "project": "docs",
      "instance": "development",
      "workspace": "feature-docs",
      "serving_node": "app-dev-1"
    }
  }
}
```

For workspace targets, `meta.app` and `meta.instance` identify the parent
placement and `meta.serving_node` reports its serving node.

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.php` | object | PHP runtime view after the gateway configuration write. |
| `success.data.result.target` | `app`, `workspace`, `node_cli` | Scope selected by the command. |
| `success.data.result.image` | string or null | Approved FrankenPHP image tag for app and workspace results. Omitted for `node_cli` targets. `null` only when a workspace inheritance result has no effective version to resolve. |
| `success.data.result.changed` | boolean | Whether gateway configuration changed. |
| `success.data.result.instances[]` | array | Per-instance app-policy results with `instance`, `driver`, `node`, `status`, and `image`. |
| `success.meta.warnings[]` | array | Structured non-fatal workspace or proxy Doctor handoffs. |
| `success.meta.warnings[].code` | string | Stable owning-family warning code. |
| `success.meta.warnings[].family` | `workspace`, `proxy` | Stable state family that owns repair. |
| `success.meta.warnings[].message` | string | Human-readable warning text. |
| `success.meta.warnings[].next_command` | string | Single machine-runnable owning-family Doctor command. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `php.reconciliation_failed` | Stable command failure code. |
| `error.meta.field` | string | Input field the failure is attributed to (for example `version`, `node`). |
| `error.meta.reason` | `missing_required_input`, `mutually_exclusive_input`, `missing_target`, `unsupported`, `not_installed`, `target_mismatch` | Stable validation reason. |
| `error.meta.node` | string | Selected node name. Present on `target_mismatch` and `not_installed`. |
| `error.meta.project` | string | Resolved project name. Present on `target_mismatch` (parent project for workspace targets). |
| `error.meta.serving_node` | string | Serving node of the resolved workspace instance. Present on `target_mismatch`. |
| `error.meta.next_command` | string | Single recovery command when one command repairs the failed result. |

Every warning object has these fields:

| Warning field | Type | Meaning |
| --- | --- | --- |
| `code` | string | Stable warning code owned by the named family. |
| `family` | `workspace`, `proxy` | Stable state family that owns repair. |
| `message` | string | Human-readable warning text. |
| `next_command` | string | Single machine-runnable Doctor command for that family. |
