# JSON Renderer: `orbit tool:remove`

[Back to `tool-remove` technical contract.](1_tool-remove.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "tool": []
    },
    "meta": []
  }
}
```

Command-specific result data uses the canonical tool entity from [`README.md`](../../README.md#tool-json-entity) unless the command returns credentials.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Required input is missing or invalid.",
    "meta": {
      "field": "tool"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `tool.not_found`, `tool.unsupported_action`, `tool.remote_action_failed` | Stable command failure code. |
| `error.message` | string | Human-readable failure summary. |
| `error.meta` | object | Field, target, caller, or remote-action context for automation. |

### Missing destructive consent

Only non-JSON non-interactive mode can return this failure. `--json` itself is
destructive consent.

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Use --force or --json to remove this tool.",
    "meta": {
      "field": "force",
      "reason": "destructive_consent_required"
    }
  }
}
```

### Missing target

```json
{
  "error": {
    "code": "validation_failed",
    "message": "A node or app target is required. Provide --node, --app, configure node:default, or select a target interactively.",
    "meta": {
      "fields": [
        "target"
      ]
    }
  }
}
```
