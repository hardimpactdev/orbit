# Interactive Input Mode: `orbit app:codex`

[Back to `app:codex` technical contract.](1_app-codex.md)

**Input mode:** Interactive.

## Selection

Use this input mode only when both conditions are true:

- the command is running in a TTY;
- `--json` is not present.

When `--json` is present, use
[`5.2_app-codex_input-mode_non-interactive.md`](5.2_app-codex_input-mode_non-interactive.md)
even if the process has a TTY.

## Prompt Behavior

Interactive mode may prompt for missing action, app selector, or target node.

- Action choices are `add`, `remove`, and `list`.
- `add` and `remove` prompt for an app when `[app]` is missing.
- Every action prompts for a target node when `--node` is missing.
- Target node prompts show active visible non-gateway nodes supported by the
  `codex-app` tool definition.

Prompted values are still revalidated by the gateway before side effects.
