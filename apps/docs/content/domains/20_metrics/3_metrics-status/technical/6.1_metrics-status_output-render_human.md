# Human Renderer: `orbit metrics:status`

[Back to `metrics:status` technical contract.](1_metrics-status.md)

**Renderer:** Human renderer.

## Primitive

Use [`table`](../../../../ux/commands/lists/table.md).

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered. The command reads gateway configuration and does
not perform live node or runtime probes.

## Success Output

Render a table with these columns:

| Column | Value |
| --- | --- |
| `Node` | Metrics node name. |
| `URL` | `https://metrics.orbit`. |
| `Processes` | Comma-separated process names from gateway configuration. |

If no metrics nodes are visible, render an empty table.

## Failure Output

Render standard validation, gateway, and authorization failures using the shared
command error renderer.

## Test Mapping

No gateway-side coverage exists for this renderer because human rendering is
CLI-only for this command.
