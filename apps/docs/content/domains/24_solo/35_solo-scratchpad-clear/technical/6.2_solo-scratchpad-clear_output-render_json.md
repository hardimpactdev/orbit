# JSON Renderer: `orbit solo:scratchpad:clear`

[Back to `solo:scratchpad:clear` technical contract.](1_solo-scratchpad-clear.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer for automation. Because JSON mode is non-interactive, this
destructive command requires `--force`.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success

Success responses use a top-level `success` key:

```json
{
  "success": {
    "data": {},
    "meta": []
  }
}
```

The Solo payload is returned under `success.data`. Gateway or upstream metadata is returned under `success.meta` when present.

## Error

Error responses use a top-level `error` key:

```json
{
  "error": {
    "code": "extension_disabled",
    "message": "The Solo extension is not enabled.",
    "meta": {
      "extension": "solo"
    }
  }
}
```

Missing or declined destructive consent uses:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Use --force to run this destructive Solo command.",
    "meta": {
      "field": "force",
      "reason": "destructive_consent_required"
    }
  }
}
```

Stable error codes include `extension_disabled`, `authorization_failed`, `validation_failed`, and `solo_upstream_unavailable`.
