# JSON Renderer: `orbit app:analytics enable`

[Back to `app:analytics enable` technical contract.](1_app-analytics-enable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "binding": {
        "app": "docs",
        "enabled": true,
        "internal_host": "analytics.orbit",
        "dashboard_url": "https://analytics.orbit",
        "public_hosts": ["analytics.docs.example.com"],
        "tracking_paths": ["/js/*", "/api/event"],
        "tracking_endpoints": [
          {
            "host": "analytics.docs.example.com",
            "script_base_url": "https://analytics.docs.example.com",
            "event_endpoint": "https://analytics.docs.example.com/api/event"
          }
        ]
      }
    }
  }
}
```

## Error Shapes

### Public domain required

```json
{
  "error": {
    "code": "analytics.domain_required",
    "message": "App 'docs' requires a configured public domain before analytics can be enabled.",
    "meta": {
      "app": "docs"
    }
  }
}
```

### Analytics prerequisite failed

```json
{
  "error": {
    "code": "analytics.prerequisite_failed",
    "message": "The analytics service route requires an active analytics node.",
    "meta": {
      "app": "docs"
    }
  }
}
```
