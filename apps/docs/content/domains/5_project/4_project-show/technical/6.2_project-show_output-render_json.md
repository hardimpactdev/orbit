# JSON Renderer: `orbit project:show [project]`

[Back to `project:show` technical contract.](1_project-show.md)

This page describes the JSON-rendered output for `project:show`.

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

`--json` also disables interactive prompts and forces the
[`non-interactive input mode`](5.2_project-show_input-mode_non-interactive.md),
even when the process has a TTY.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Fields

`project:show` intentionally keeps `success.data.project` limited to the canonical project
JSON entity. Show-only registry expansion lives under the sibling
`success.data.details` object so automation can consume the project entity without
also accepting command-specific relationship fields.

| Field | Type | Meaning |
| --- | --- | --- |
| `project` | object | Canonical project JSON entity defined in [`5_project/README.md`](../../README.md#app-json-entity). |
| `details.dependency_audits` | object[] | Per-manager dependency audit summaries owned by the project. These are not instance- or workspace-specific. |
| `details.instances[]` | object[] | Placement-visible instances ordered by instance name. Gateway callers receive every instance; non-gateway callers receive only Orbit instances on authorized serving nodes. |
| `details.instances[].name` | string | Instance name unique within the app. |
| `details.instances[].driver` | string | Instance driver, currently `orbit` or `laravel-cloud`. |
| `details.instances[].node` | string \| null | Orbit serving-node slug, or `null` for an external driver-backed instance. |
| `details.instances[].url` | string \| null | Registry-derived instance URL, or `null` when the driver configuration does not provide enough URL information. |
| `details.instances[].path` | string \| null | Absolute source path for an Orbit instance, or `null` for an external driver. |
| `details.instances[].root` | string \| null | Document root relative to `path` for an Orbit instance, or `null` for an external driver. |
| `details.instances[].domain` | string \| null | Domain stored by the instance driver, or `null` when none is configured. |
| `details.instances[].agent_ide` | object | Effective IDE for this instance, resolved instance override → serving-node default → none. |
| `details.instances[].agent_ide.workspace_discovery` | string \| null | Discovery support for the effective adapter. |
| `details.instances[].workspaces` | object[] | Workspaces owned by this instance, ordered by workspace name. |
| `details.instances[].workspaces[].name` | string | Workspace slug. |
| `details.instances[].workspaces[].url` | string | Primary intended workspace URL. |
| `details.instances[].workspaces[].lifecycle_status` | string | Registry lifecycle status, not live readiness. |
| `details.instances[].processes[]` | object[] | Full registry list of process definitions owned by this instance. Runtime status belongs to the `process` family. |
| `details.instances[].processes[].name` | string | Process slug, unique only within its owning instance. |
| `details.instances[].bindings` | object | Registry bindings owned by this instance. |
| `details.instances[].bindings.routes[]` | object[] | Proxy routes derived from this instance. |
| `details.instances[].bindings.websocket` | object \| null | Instance-selected WebSocket site/binding summary, or `null`. |
| `details.instances[].bindings.analytics` | object \| null | Instance-selected analytics site/binding summary, or `null`. |

`project:show` is a registry read. It does not return live runtime container, document-root,
route, process, or node-reachability checks. Use
`doctor --family=instance --json` for app readiness and drift output.

Workspace, process, effective IDE, and binding state is exposed only below
`details.instances[]`. `project:show` has no flat project fallback for any of
those relationships.

If real-world projects grow lists large enough to require pagination, paging
metadata will be added under `success.meta` (mirroring `project:list`). The
default contract emits full lists with no truncation indicator.

`details.instances[].agent_ide` reports the effective resolved view for one
instance, not the full chain. The

`details.instances[].agent_ide.inherited_from` values:

| Value | Meaning |
| --- | --- |
| `instance` | The instance has an explicit agent IDE setting and that setting is in effect. |
| `node` | The instance inherits from its serving node. |
| `default` | Neither the instance nor its serving node has an explicit setting; no agent IDE is configured. |

`details.instances[].agent_ide.workspace_discovery` values:

| Value | Meaning |
| --- | --- |
| `available` | The resolved adapter implements workspace discovery for this app. |
| `unavailable` | Reserved for a future explicit live adapter check. `project:show` does not emit this value in its registry-only read path. |
| `unsupported` | The resolved adapter does not implement workspace discovery. |
| `null` | The instance's effective adapter is `null`; no discovery is meaningful. |

## Error Shapes

### Missing required input

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Project name is required.",
    "meta": {
      "field": "instance"
    }
  }
}
```

### Instance not found

```json
{
  "error": {
    "code": "project.not_found",
    "message": "Project 'docs' not found or not visible.",
    "meta": {
      "project": "docs"
    }
  }
}
```

### Not authorized

```json
{
  "error": {
    "code": "authorization_failed",
    "message": "This node is not authorized for 'project:read' on 'app-1'.",
    "meta": {
      "reason": "missing_permission",
      "missing_permission": "project:read",
      "serving_node": "app-1"
    }
  }
}
```

### Gateway unavailable

```json
{
  "error": {
    "code": "gateway_unavailable",
    "message": "Gateway connection is required to show app details.",
    "meta": []
  }
}
```

## Enum and identifier values

| Field | Values |
| --- | --- |
| `details.instances[].agent_ide.inherited_from` | `instance`, `node`, `default` |
| `details.instances[].agent_ide.workspace_discovery` | `available`, `unavailable`, `unsupported`, `null` |
| `error.code` | `validation_failed`, `project.not_found`, `authorization_failed`, `gateway_unavailable` |

The `error.code` values listed here are exhaustive for `project:show`. Add a new
value to this renderer contract before implementing another JSON failure code.
Live check outcomes never appear here: the registry read either succeeds or
the read itself fails with one of the codes above.
