# Human Renderer: `orbit instance:websocket credentials`

[Back to `instance:websocket credentials` technical contract.](1_instance-websocket-credentials.md)

This page describes the human-rendered output for `instance:websocket credentials`.

**Renderer:** Human renderer.

## Primitive

None. Output is emitted as prose lines via `$this->line(...)`.

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered. The credentials command is a fast gateway database
read; no slow external work is performed.

## Success Render

The success output presents the credentials payload under a `credentials:` label.
All credential fields are shown including `reverb_app_secret`.

### Example output

```text
credentials:
  app: docs
  instance: production
  serving_node: app-prod-1
  internal_host: websocket.orbit
  public_hosts:
    - ws.docs.example.com
  allowed_origins:
    - https://docs.example.com
  reverb_app_id: docs.production
  reverb_app_key: <key>
  reverb_app_secret: <secret>
```

## Error Render

Errors are rendered as concise prose messages.
