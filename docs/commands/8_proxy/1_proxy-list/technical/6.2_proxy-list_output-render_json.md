# JSON Renderer: `orbit proxy:list`

[Back to `proxy:list` technical contract.](1_proxy-list.md)

**Renderer:** JSON renderer.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "routes": [
        {
          "domain": "docs.test",
          "kind": "app",
          "owner": {
            "type": "app",
            "name": "docs"
          },
          "node": "app-1",
          "target": {
            "type": "app",
            "value": "docs"
          },
          "redirect_code": null,
          "tls": {
            "managed_by": "orbit",
            "trusted_by_gateway_ca": true
          },
          "status": "expected"
        },
        {
          "domain": "old.test",
          "kind": "redirect",
          "owner": {
            "type": "custom",
            "name": null
          },
          "node": "app-1",
          "target": {
            "type": "redirect",
            "value": "https://docs.test"
          },
          "redirect_code": 302,
          "tls": {
            "managed_by": "orbit",
            "trusted_by_gateway_ca": true
          },
          "status": "expected"
        }
      ]
    },
    "meta": {
      "filter": "all",
      "node": null,
      "count": 2
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "The selected proxy route filter is invalid.",
    "meta": {
      "field": "filter",
      "allowed": ["all", "app", "workspace", "gateway", "tool", "custom", "redirect"]
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.routes[]` | array | Proxy route entities visible under the selected scope. |
| `success.meta.filter` | string | Applied filter. |
| `success.meta.node` | string \| null | Applied serving-node filter. |
| `success.meta.count` | integer | Number of returned routes. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed` | Stable command failure code. |
| `error.meta` | object | Field, node, caller, or authorization context for automation. |
