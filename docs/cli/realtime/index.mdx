The Gateway publishes [realtime events](/reference/events) on a private WebSocket channel. `realtime:show` shows where that channel is. `realtime:logs` connects to it and prints each event as it arrives. Realtime needs an active `websocket` role, as [Realtime events with Reverb](/solutions/realtime-reverb) describes.

## Commands

| Command | Result |
| --- | --- |
| [`realtime:show`](/cli/realtime/show) | Show the Gateway's Reverb connection. |
| [`realtime:logs`](/cli/realtime/logs) | Stream realtime Gateway events as they arrive. |

Both commands accept `--json`.
