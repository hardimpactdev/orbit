# Human Renderer: `orbit node:revoke [consuming_node] [serving_node]`

[Back to `node:revoke` technical contract.](1_node-revoke.md)

This page describes the human-rendered terminal output for `node:revoke`.

**Renderer:** Human renderer.

## Primitive

- Progress: [Progress tree](../../../../ux/commands/progress/progress-tree.md)

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. Prompt behavior belongs to
[`interactive input mode`](5.1_node-revoke_input-mode_interactive.md).
Non-interactive validation failures are rendered here as prose errors when
`--json` is absent.

## Progress Tree

Render the complete progress tree after input resolution and destructive
consent, before revocation side effects begin. `node:revoke` performs
gateway-owned grant deletion, so the human renderer must not leave the operator
without progress feedback even when the happy path usually completes quickly.

Full flow:

```text
┌ Revoking Grant
○ Validate nodes
○ Verify authorization
○ Revoke access
└ Working...
```

When the grant is already absent, the revoke step completes as a successful
idempotent step and the footer reports that access was already revoked.

## Success Output

When revocation succeeds:

```text
Access from 'operator-1' to 'app-1' revoked
```

When the grant was already absent:

```text
Access from 'operator-1' to 'app-1' was already revoked
```

When the revocation locks the current caller out of the gateway:

```text
Access from 'operator-1' to 'gateway-1' revoked
  This machine no longer has Orbit gateway access.
```

## Failure Output

Human-rendered failures must show:

- the failing phase or field;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the operator can act on it.

### Missing node

```text
Node 'operator-1' not found.
```

### Gateway unavailable

```text
Gateway connection is required to revoke a grant.
```

### Authorization failed

```text
This action requires the node:revoke permission on a grant to the gateway.
```

### Missing destructive consent

Rendered for non-interactive human output when `--force` is absent.

```text
Use --force to revoke this grant.
```

### Cancelled confirmation

```text
Operation cancelled.
```
