# JSON Renderer: `orbit manifest:update <url>`

[Back to `manifest:update` technical contract.](1_manifest-update.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "manifest": {
        "url": "https://artifacts.example.com/channels/live-test/orbit-release-manifest.json",
        "source": "custom",
        "custom_url": "https://artifacts.example.com/channels/live-test/orbit-release-manifest.json",
        "default_url": "https://github.com/hardimpactdev/orbit/releases/latest/download/orbit-release-manifest.json"
      }
    }
  }
}
```

## Error Shapes

Validation failures use `error.code=validation_failed` with
`error.meta.field=url`. Gateway and authorization failures use the shared
envelope.
