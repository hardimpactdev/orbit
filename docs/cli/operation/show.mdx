---
title: "orbit operation:show"
sidebarTitle: "operation:show"
description: "Show the parent Operation, including its kind, target, status, error code, result and times."
---

```bash
orbit operation:show <operation> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `operation` | yes | Numeric operation ID. |

JSON returns the parent record, as `GET /api/v1/operations/{operation}` does. The command exits `0` for any status; read `status` for the outcome.


```bash
orbit operation:show 42
```
