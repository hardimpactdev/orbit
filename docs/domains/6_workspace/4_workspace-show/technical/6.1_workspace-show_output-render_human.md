# Human Renderer: `orbit workspace:show [name]`

[Back to `workspace:show` technical contract.](1_workspace-show.md)

This page describes the human-rendered terminal output for `workspace:show`.

**Renderer:** Human renderer.

## Primitive

- Detail: [Show detail](../../../../ux/commands/details/show-detail.md)

## Selection

Use this renderer when `--json` is not present.

The human renderer does not own input prompting. Prompt behavior belongs to
[`interactive input mode`](5.1_workspace-show_input-mode_interactive.md).
Non-interactive validation failures are rendered here as prose errors when
`--json` is absent.

## Progress Tree

`workspace:show` is a registry read. Execution is expected to complete below
one second and does not perform slow external work or live app-node probes.
No progress tree is rendered.

## Success Output

When the workspace is found:

```text

┌  Workspace: feature-docs
│
├  App            docs
│
├  Branch         feature/docs
│
├  Node           app-1 (1.2.3.4)
│
├  URL            https://feature-docs.docs.test
│
├  Path           /home/orbit/apps/docs/.worktrees/feature-docs
│
├  Agent IDE      opencode
│
├  PHP            8.5 (inherited from app)
│
├  FPM pool       orbit-docs-feature-docs
│
├  Hostname       feature-docs.docs.test
│
├  Processes      vite
│
├  Route          feature-docs.docs.test (kind: workspace, owner: workspace)
│
└  Latest setup   12345, completed, finished 2026-04-30 18:00:00

```

Inherited processes render as a comma-separated one-line summary. Missing
route and latest setup values render as `—`.

The PHP Version line shows the effective version followed by its source
(`workspace` for an explicit override or `app` for inheritance from the
parent app).

## Failure Output

Human-rendered failures must show:

- the failing phase or field;
- a clear prose error;
- no JSON envelope;
- next-step guidance only when the operator can act on it.

### Missing input

```text
Workspace name is required.
```

### Workspace not found

```text
Error: Workspace 'feature-docs' not found or not visible.
Check 'orbit workspace:list' for available workspaces.
```

### Ambiguous workspace

```text
Error: Workspace name 'feature-docs' is ambiguous.
Found in app: docs, api.
Specify the parent app with --app=<app>.
```

### Not authorized

```text
This caller is not authorized to inspect 'feature-docs'.
```

### Gateway unavailable

```text
Gateway connection is required to show workspace details.
```
