# JSON output: `app-development-setup-step:list`

Success returns `success.data.steps`, an ordered array of app-owned default
step records. Failure returns the shared `error` envelope.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Primitive

None. JSON output is emitted as one machine-readable envelope.
