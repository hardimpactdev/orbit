# Interactive Input Mode: `orbit tool:remove`

[Back to `tool-remove` technical contract.](1_tool-remove.md)

**Input mode:** Interactive.

This contract applies only when the process is attached to a TTY and `--json` is not present.

## Prompt Behavior

The destructive confirmation prompt is required unless `--force` is supplied.
The prompt is rendered after target and tool resolution prove the managed tool
row exists and supports removal, and before any cleanup side effect begins.

Target node prompts may render only after gateway visibility is known. Invalid prompt answers re-prompt until the value is valid or the operator aborts.

If the operator declines the confirmation, the command exits before side
effects with `validation_failed`, `meta.field=force`, and
`meta.reason=cancelled`.
