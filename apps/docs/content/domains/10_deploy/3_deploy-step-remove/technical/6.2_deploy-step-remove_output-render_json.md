# JSON Renderer: `orbit deploy:step-remove`

[Back to `deploy:step-remove` technical contract.](1_deploy-step-remove.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "step": {
        "id": 12,
        "app": "docs",
        "instance": "production",
        "title": "Pull latest",
        "command": "git pull origin main",
        "order": 1,
        "timeout_seconds": 600,
        "retention": null
      }
    },
    "meta": {
      "action": "removed",
      "history_preserved": true
    }
  }
}
```

Missing destructive consent uses the shared validation shape:

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Use --force to remove this deployment step.",
    "meta": {
      "field": "force",
      "reason": "destructive_consent_required"
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "deploy.step_not_found",
    "message": "Deployment step 'Pull latest' was not found for instance 'docs.production'.",
    "meta": {
      "app": "docs",
      "instance": "production",
      "step": "Pull latest"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.step` | object | Removed deploy step entity. |
| `success.meta.action` | string | `removed`. |
| `success.meta.history_preserved` | boolean | Confirms deployment run history was not deleted. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `instance.not_found`, `deploy.production_app_required`, `deploy.step_not_found` | Stable command failure code. |
| `error.meta` | object | Field, missing permission, instance selector, step selector, or authorization context for automation. |
