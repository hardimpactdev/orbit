# JSON Renderer: `orbit schedule:run`

[Back to `schedule:run` technical contract.](1_schedule-run.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope via `$this->line(...)`.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "run": {
        "id": 18,
        "schedule": "laravel-scheduler",
        "scope": "app",
        "target": {
          "type": "app",
          "name": "docs",
          "node": "app-1"
        },
        "status": "completed",
        "exit_code": 0,
        "started_at": "2026-05-02T08:10:00Z",
        "finished_at": "2026-05-02T08:10:03Z"
      },
      "output": {
        "stdout": "No scheduled commands are ready to run.\n",
        "stderr": ""
      }
    },
    "meta": {
      "duration_ms": 3000
    }
  }
}
```

## Error Shape

```json
{
  "error": {
    "code": "schedule.run_failed",
    "message": "Schedule 'backups' exited with status 1.",
    "data": {
      "run": {
        "id": 19,
        "schedule": "backups",
        "scope": "node",
        "target": {
          "type": "node",
          "name": "app-1",
          "node": "app-1"
        },
        "status": "failed",
        "exit_code": 1,
        "started_at": "2026-05-02T08:15:00Z",
        "finished_at": "2026-05-02T08:15:07Z"
      },
      "output": {
        "stdout": "",
        "stderr": "Backup target is not mounted.\n"
      }
    },
    "meta": {
      "duration_ms": 7000
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.run` | object | Durable run-history record for the one-off execution. |
| `success.data.output` | object | Captured scheduled command output. |
| `success.meta.duration_ms` | integer | Runtime duration in milliseconds when known. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `schedule.not_found`, `schedule.run_failed`, `schedule.history_write_failed` | Stable command failure code. |
| `error.data.run` | object | Run record when execution reached the target node. |
| `error.data.output` | object | Captured output for scheduled process failures. |
| `error.meta` | object | Field, scope, caller, duration, or persistence context for automation. |
