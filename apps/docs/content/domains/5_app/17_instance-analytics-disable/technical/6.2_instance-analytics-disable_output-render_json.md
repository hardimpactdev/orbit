# JSON Renderer: `orbit instance:analytics disable`

[Back to `instance:analytics disable` technical contract.](1_instance-analytics-disable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

`--json` selects output and non-interactive input only; it never supplies consent.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

```json
{
  "success": {
    "data": {
      "app": {"name": "docs", "repository": null, "runtime": "php", "runtime_config": {"proxy_transport": "http"}, "php_version": "8.5", "dependency_audit_status": "unknown", "dependency_warning_count": 0, "dependency_danger_count": 0, "last_dependency_audit_at": null},
      "instance": "production",
      "serving_node": "app-prod-1",

        "enabled": false,

        "dashboard_url": "https://analytics.orbit",

    },

}
```

## Error Shapes

### Binding missing

```json
{
  "error": {
    "code": "analytics.binding_missing",
    "message": "Analytics is not enabled for instance 'docs.production'.",
    "meta": {
      "app": "docs", "instance": "production", "serving_node": "app-prod-1"
    }
  }
}
```

`app` is the canonical logical entity. Ambiguous bare app selectors fail with
`instance_required`; authorization failures identify `instance`,
`serving_node`, and `missing_permission=instance:write`.
