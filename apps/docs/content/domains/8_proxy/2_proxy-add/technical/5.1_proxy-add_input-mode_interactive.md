# Interactive Input Mode: `orbit proxy:add`

[Back to `proxy:add` technical contract.](1_proxy-add.md)

**Input mode:** Interactive.

## Mode Selection

This contract applies only when the process is attached to a TTY and `--json` is not present.

## Prompt Flow

Prompts render after gateway reachability is known and before any gateway write or backend apply.

| Prompt ID | Primitive | Rendered when | Validation |
| --- | --- | --- | --- |
| `proxy.node` | `datatable` | No `--node` and the serving node cannot be unambiguously resolved from gateway-visible state. | Visible active Ubuntu node with proxy capability. |
| `proxy.domain` | `text` | `domain` argument omitted. | Hostname or documented host/path route identity not owned by an app, instance, WebSocket binding, workspace, gateway, websocket service, S3 service, or tool route. |
| `proxy.route_shape` | `select` | Neither `--upstream` nor `--redirect` was supplied. | `upstream` or `redirect`. |
| `proxy.upstream` | `text` | Route shape is `upstream` and `--upstream` is absent. | HTTP or HTTPS upstream URL. |
| `proxy.redirect` | `text` | Route shape is `redirect` and `--redirect` is absent. | Absolute HTTP or HTTPS redirect URL. |
| `proxy.redirect_code` | `select` | Route shape is `redirect` and `--code` is absent. | `301`, `302`, `307`, or `308`; default `302`. |
| `proxy.replace_custom_route` | `confirm` | Existing custom route differs from requested target. | Explicit replacement consent. |

Invalid prompt answers re-prompt until the value is valid or the operator aborts. Abort fails before side effects.
