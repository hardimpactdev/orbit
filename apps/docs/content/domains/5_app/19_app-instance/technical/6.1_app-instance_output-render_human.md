# Human Renderer: `orbit app:instance`

[Back to `app:instance` technical contract.](1_app-instance.md)

## Primitive

None. Destructive confirmation belongs to the interactive input-mode contract,
not the human renderer.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree is rendered. The command performs a single gateway API request
and is expected to complete in under one second after input is resolved.

## Success Output

For `list`, show a table of instances with app, name, driver, runtime mode, PHP
version, required extensions, and latest deployment status when present.

For `show`, print one instance summary with driver config and runtime metadata.

For `add`, print the created or updated instance name, driver, and any required
extensions recorded.

For interactive `remove`, first resolve the instance and authorize
`app:write` on its serving node. Unless `--force` is present, render
`app_instance_remove.confirm` naming the dotted instance and serving node. The
prompt states that the logical app and sibling instances remain. Declining
cancels without effects.

After removal, print the removed dotted instance and retained logical app.

## Failure Output

Failures render the gateway or validation message directly. When destructive
consent is missing for non-interactive `remove`, tell the caller to pass
`--force`. Authorization failures identify the selected instance and serving
node and occur before confirmation.
