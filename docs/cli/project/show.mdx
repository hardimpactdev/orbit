---
title: "orbit project:show"
sidebarTitle: "project:show"
description: "Show one Project with its source access, source defaults, task check, and task workspace routing. Human detail output labels the boolean `Task workspace routed`; JSON uses `task_workspace_routed`. Null `default_branch` or root values mean the source defaults are incomplete, and new Instance creation fails with `project.source_defaults_incomplete` until they exist. A null task check means tasks run no check command. Human output also lists the Project's Instances with ID, name, environment, Node, domain, and status. In a terminal, selecting an Instance opens `instance:show`."
---

```bash
orbit project:show <project> [--json]
```

JSON includes `task_pr_mode`: `review_before_pr`, `pr_when_done`, or null when the Project sets none and its task groups use the Gateway's default. Human output labels it `Task pull request mode`. See [Task group modes](/reference/tasks#task-group-modes).
