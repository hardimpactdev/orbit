# Human Renderer: `orbit metrics:enable`

[Back to `metrics:enable` technical contract.](1_metrics-enable.md)

**Renderer:** Human renderer.

## Primitive

None. Human output is plain success lines after the gateway write.

## Selection

Use this renderer when `--json` is absent.

## Progress Tree

No progress tree. The command waits for the gateway role assignment write, then
renders the success lines below. It does not stream step-by-step convergence
frames.

## Success Output

After the gateway role assignment or reconvergence completes, render:

```text
Metrics role enabled on '<node>'
Role: metrics
Status: <assignment-status>
```

- target node name;
- role value `metrics`;
- assignment status from the gateway response.

Runtime repair after enable remains with `doctor --family=process` and
`doctor --family=firewall_rule` as documented on the public page.

## Failure Output

Render standard validation, gateway, and authorization failures using the shared
command error renderer.
