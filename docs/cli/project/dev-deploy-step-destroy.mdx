sidebarTitle: "project:dev-deploy-step:destroy"
description: "Remove a named step. The remaining steps keep their order. `--yes` confirms without prompting and is required for JSON and noninteractive calls."
---

```bash
orbit project:dev-deploy-step:destroy <name> --project=ID [--yes] [--json]
orbit project:dev-deploy-step:destroy cache --project=4
```
