# Non-Interactive Input Mode: `orbit doctor --fix`

[Back to `doctor` technical contract.](1_doctor.md)

**Input mode:** Non-interactive.

Use this mode without a TTY, when `--json` is present, or when `--restore` or
`--adopt` is present. `--json` always forces non-interactive input mode.

## Required Direction

Non-interactive mode must have an explicit bulk direction:

```bash
orbit doctor --fix --restore
orbit doctor --fix --adopt
```

`--restore` and `--adopt` are mutually exclusive. If neither is present in
non-interactive mode, fail before probes with `error.code=validation_failed`.

## Behavior

- Run probes for the resolved scope.
- Select every finding that supports the requested bulk direction.
- Apply actions category by category in doctor order.
- Skip unsupported findings and include them in the final diagnostic.
- Fail when no selected finding supports the requested direction.
- Never prompt.
