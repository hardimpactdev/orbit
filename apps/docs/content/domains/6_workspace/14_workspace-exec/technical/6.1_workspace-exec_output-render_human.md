# Human Renderer: `orbit workspace:exec`

[Back to `workspace:exec` technical contract.](1_workspace-exec.md)

## Primitive

None. Human output is the underlying command's stdout and stderr streamed
through unchanged.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

No progress tree is rendered. `workspace:exec` is a thin wrapper around
`docker exec` and the underlying command's output is the renderer's output.
Wrapping it in a progress tree would hide what the operator actually wants
to see.

## Success Output

The underlying command's stdout is written to the parent process's stdout
stream and the underlying command's stderr is written to the parent
process's stderr stream. The two streams are kept distinct so shell
pipelines that redirect or branch on stderr behave the same way they would
against the command run directly. The process exit code is the underlying
command's exit code.

When the underlying output does not expose a split error stream
(non-terminal buffers in tests, for example) stderr falls back to the
combined output stream.

```text
$ orbit workspace:exec docs-feature -- php -v
PHP 8.5.0 (cli) (built: ...) (NTS)
```

## Failure Output

Wrapper failures emit a single prose line on stderr and exit `1`. The
matching JSON shapes live in
[`6.2_workspace-exec_output-render_json.md`](6.2_workspace-exec_output-render_json.md).

### Missing command

```text
A command to execute is required.
```

### Workspace not found

```text
Workspace 'missing' not found.
```

### Unsupported runtime

```text
Workspace 'docs-feature' parent app has runtime_kind=static; workspace:exec requires runtime_kind=php.
```

### Container not running

```text
Workspace 'docs-feature' runtime container is not running on node 'app-1'.
```

Authorization and gateway-availability failures originate at the gateway
client layer and are documented in the JSON renderer contract.

## Test Mapping

| Path | Coverage |
| --- | --- |
| `apps/gateway/tests/Feature/Commands/Workspaces/WorkspaceExecCommandTest.php` | Human-mode stream split, exit-code passthrough, and the prose failure lines (see notes). |

`WorkspaceExecCommandTest` must include one Symfony `CommandTester`
test invoked with `capture_stderr_separately=true` asserting that the
child's stdout and stderr land in distinct buffers. Additional tests
must cover exit-code passthrough for non-zero underlying exits and the
prose failure lines for every documented wrapper failure.
