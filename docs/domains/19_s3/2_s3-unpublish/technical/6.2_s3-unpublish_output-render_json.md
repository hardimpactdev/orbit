# JSON Renderer: `orbit s3:unpublish`

[Back to `s3:unpublish` technical contract.](1_s3-unpublish.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "s3": {
        "node": "storage-1",
        "private_endpoint": "https://s3.orbit",
        "public_endpoints": [],
        "backend_pool": ["http://storage-1.s3.orbit:9000"]
      }
    },
    "meta": {
      "host": "s3.example.com",
      "action": "unpublished",
      "already_absent": false
    }
  }
}
```

`success.meta.action` is `unpublished`. Idempotent no-op removal returns
`success.meta.already_absent=true`.

## Error Shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "--force is required to unpublish an S3 host in non-interactive mode.",
    "meta": {
      "field": "force",
      "reason": "destructive_consent_required"
    }
  }
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `success.data.s3.node` | string | Selected active s3 node. |
| `success.data.s3.private_endpoint` | string | Stable private endpoint, always `https://s3.orbit`. |
| `success.data.s3.public_endpoints` | string[] | Public S3 HTTPS endpoints after removal. |
| `success.data.s3.backend_pool` | string[] | Router-owned RustFS backend URLs. |
| `success.meta.host` | string | Removed host. |
| `success.meta.action` | `unpublished` | Command outcome. |
| `success.meta.already_absent` | boolean | Whether the host was already absent before the command ran. |
| `error.code` | `validation_failed`, `gateway_unavailable`, `authorization_failed`, `proxy.owned_route_denied`, `s3.unpublish_failed` | Stable command failure code. |
