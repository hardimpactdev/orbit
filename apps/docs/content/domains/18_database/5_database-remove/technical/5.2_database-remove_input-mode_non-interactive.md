# Technical Contract: `orbit database:remove` (Non-Interactive Input)

This contract defines behavior for **non-interactive input mode** (e.g., CI, scripts, or when `--json` is present).

[Back to the canonical contract.](1_database-remove.md)

**Input mode:** Non-interactive.

Use this input mode when either condition is true:

- the command is running without a TTY;
- `--json` is present.

`--json` selects the JSON renderer and forces this input mode even when the
process has a TTY.

## Primitive References

None. Non-interactive mode never prompts.

## Behavior

- **Validation**: When `--force` is absent, the command fails before side effects with `error.code=validation_failed`.
- **No Prompts**: The command will never wait for user input.
- **Destructive Consent**: `--json` forces this mode but does not satisfy destructive consent; `--force` is still required.
