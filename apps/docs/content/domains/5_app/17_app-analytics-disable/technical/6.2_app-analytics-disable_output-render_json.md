# JSON Renderer: `orbit app:analytics disable`

[Back to `app:analytics disable` technical contract.](1_app-analytics-disable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Success Shape

```json
{
  "success": {
    "data": {
      "binding": {
        "app": "docs",
        "enabled": false,
        "internal_host": "analytics.orbit",
        "dashboard_url": "https://analytics.orbit",
        "public_hosts": [],
        "tracking_paths": ["/js/*", "/api/event"],
        "tracking_endpoints": []
      }
    },
    "meta": []
  }
}
```

## Error Shapes

### Binding missing

```json
{
  "error": {
    "code": "analytics.binding_missing",
    "message": "Analytics is not enabled for app 'docs'.",
    "meta": {
      "app": "docs"
    }
  }
}
```
