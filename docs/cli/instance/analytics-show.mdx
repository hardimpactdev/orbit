---
title: "orbit instance:analytics:show"
sidebarTitle: "instance:analytics:show"
description: "Show the tracking hosts of an Instance."
---

```bash
orbit instance:analytics:show <instance> [--json]
```

The output has the same shape as [`instance:analytics:enable`](/cli/instance/analytics-enable). An Instance without tracking hosts reports tracking as disabled, with no hosts and no script tag.
