# Human Renderer: `orbit gateway:list`

[Back to `gateway:list` technical contract.](1_gateway-list.md)

This page describes the human-rendered output for `gateway:list`.

**Renderer:** Human renderer.

## Primitive

None. Output is printed as plain text lines.

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered because `gateway:list` is a local-only read
command that does not contact the gateway API or perform external network work.

## Success Render

Human output prints the active gateway name followed by a table of configured
gateway entries. The active gateway entry is marked in the list.

## Error Render

Errors are rendered as concise prose messages.

### No gateways configured

```text
No gateways configured. Run orbit gateway:add first.
```
