```bash
orbit tasks:analyze <group> --subtask=43 --plan=plan.json --plan-sha256=<digest> --base=<base> --head=<head> --tree=<tree> --idempotency-key=feature.analysis.c1 [--json]
```

`--plan` reads the complete manifest from a local JSON file without normalizing it. `--plan-sha256` is its canonical RFC 8785 SHA-256, not the file's raw-byte digest. `--base` is the full initial merge-base recorded by provision; `--head` and `--tree` identify the exact HEAD and whole workspace, including untracked files. All object IDs and digests are full lowercase values. Reuse `--idempotency-key` only for an exact retry. A terminal can select a missing group or subtask and prompt for other required inputs; noninteractive and JSON runs require them.

`tasks:analyze` runs [fixed repository analysis](/reference/tasks#analyze-an-external-groups-repository) for one external group's current open child. The command carries the native `{subtask, plan, plan_sha256, base, head, tree}` request and requires an idempotency key. No caller command, environment, executable, model, or report path is accepted. The complete typed plan includes all cumulative feature paths, including new files and both rename endpoints, rather than repeated best-effort path hints.

Follow the operation with the shared display and existing `operation:show` and `operation:cancel`. JSON retains the complete keyed `{outcome, artifact, provenance}` result; the artifact is exact bounded UTF-8 content, digest, and byte length, never a log tail or shortened report. Human output must distinguish `ready`, `action_required`, `blocked`, and `changed` from operation status. Exit 0 or `succeeded` is not docs approval. Ctrl-C stops following; explicit cancellation reconciles descendants before releasing workspace ownership. No new prompt, progress primitive, arbitrary shell facility, or write-mode generator is authorized.

The existing `tasks:turn` carries optional native `analysis: {operation, plan_sha256}` evidence. Before the first accepted send it verifies fresh identity under the turn lease and persists the complete plan/report/provenance in the bounded combined prompt. Once Pi accepts the send, replay keeps that prompt and send identity despite intentional author edits. A local dispatch journal alone is not acceptance proof. Omission preserves ordinary turns; reviewer checked-candidate/CI admission remains unchanged.
