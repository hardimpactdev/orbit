# JSON Renderer: `orbit workspace:env`

[Back to `workspace:env` technical contract.](1_workspace-env.md)

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

Successful commands return a top-level `success` object. Failures return a
top-level `error` object with `code`, `message`, and `meta`.

## Success Shape

```json
{
  "success": {
    "data": {
      "scope": "workspace",
      "project": "billing",
      "instance": "development",
      "workspace": "feature-mail",
      "path": "/home/orbit/apps/billing/.worktrees/feature-mail/.env",
      "stored": true,
      "applied": true,
      "runtime_restarted": true,
      "variable": {
        "key": "MAIL_MAILER",
        "value": "smtp",
        "secret": false
      }
    },
    "meta": []
  }
}
```

`list` returns explicit rows under `variables`. `render` returns the effective
keyed map under `variables`. Secret database-derived values use `value=null`
and `secret=true`.

## Error Shape

```json
{
  "error": {
    "code": "workspace.env_apply_failed",
    "message": "Saved 'MAIL_MAILER' for workspace 'feature-mail' in the Orbit registry, but the workspace env file was not written.",
    "meta": {
      "workspace": "feature-mail",
      "key": "MAIL_MAILER",
      "phase": "env_write",
      "stored": true,
      "env_written": false,
      "applied": false,
      "runtime_restarted": false,
      "reason": "Env file path is invalid."
    }
  }
}
```

When the env file was written but cache clear or runtime restart failed,
`phase` is `runtime`, `env_written` is `true`, and the message states that the
env file was written while runtime application failed. `reason` is a plain
string; it is not an opaque nested JSON document.

Command-specific error codes are `workspace.not_found`,
`workspace.unsupported_for_production`, `workspace.env_apply_failed`, and
`validation_failed`. Shared authorization and gateway transport failures use
the shared JSON envelope contract.
