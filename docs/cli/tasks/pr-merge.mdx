Merge the published pull request of an external task group straight into its base branch with a squash merge. The Gateway first reads the PR, its checks and its reviews with read-only tokens and checks the gate: in manual mode, the configured reviewer's latest review must approve the exact head. It then mints a fresh write token. Swamp merges with the expected head SHA, so a moved head refuses. This is the merge step of [stage 4 of the command development pipeline](/reference/command-development-pipeline#4-pr-and-ci). There is no merge queue and no GitHub auto-merge. See [Ready and merge a task pull request](/reference/tasks#ready-and-merge-a-task-pull-request).

There is no `orbit` command yet. Use the API or the MCP tool `tasks-pr-merge`.

```bash
curl -X POST "$GATEWAY/api/v1/task-groups/42/pr-merge" \
  -H "Idempotency-Key: pr-merge-42-9f3c" \
  -d '{"head_sha": "9f3c0a1b2c3d4e5f60718293a4b5c6d7e8f90a1b"}'
```

The route needs a Node with an access grant to the Gateway and a required `Idempotency-Key`. The reply is `202` with the task; follow it with `operation:show` until it ends. A refusal at admission starts no task, so a caller can call the command again every few seconds until the approval arrives. That is the short poll: the Gateway has no webhooks.

| Input | Meaning |
| --- | --- |
| `group` | The numeric ID of an open external task group with a published, open pull request that is out of draft. |
| `head_sha` | The full SHA of the pull request head that was approved. A different head refuses the step. |

A merge conflict with the base branch refuses the merge. The author rebases, which reruns CI and the proof, and the gate starts again.

## Errors

| Code | Status | When |
| --- | --- | --- |
| `extension.disabled` | 409 | The tasks extension is off. |
| `tasks.group_closed` | 409 | The group has ended. |
| `operation.target_busy` | 409 | Another task holds the group. |
| `tasks_pr.no_pull_request` | 409 | The group has no published PR, or its PR is not open. |
| `tasks_pr.draft` | 409 | The PR is still a draft. Run `tasks-pr-ready` first. |
| `tasks_pr.head_moved` | 409 | The PR head is not `head_sha` at admission. A head that moves after admission ends the run with `tasks_pr.merge_refused`. |
| `tasks_pr.checks_not_passed` | 409 | The Project's merge check is not configured, or it did not pass on the head. |
| `tasks_pr.approval_missing` | 409 | The reviewer has not approved this head. `error.details.state` is `waiting`, `changes_requested` or `head_moved`. |
| `tasks_pr.github_unreadable` | 502 | The Gateway could not read the PR, its checks or its reviews. |
| `github.not_configured` | 409 | The GitHub App is not configured. |
| `tasks_pr.merge_refused` | run | GitHub refused the merge, for example a conflict with the base branch. |
