# Human Renderer: `orbit tool-logs`

[Back to `tool-logs` technical contract.](1_tool-logs.md)

**Renderer:** Human renderer.

## Primitive

- Direct line output via `$this->line(...)`.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`tool:logs` does not render a progress tree. Line-oriented log/stream commands
render the stream itself as their primary output. Prepending progress UI would
pollute downstream piping and `--follow` output.

## Success Output

Human output for `tool:logs` is line-oriented. The command prints each log line
in source order via `$this->line(...)`. When no log lines are returned by a
finite read, the command prints `No log lines found.` There is no tool-state
metadata block, no version table, no managed flag, and no progress tree —
detailed tool inspection belongs to `tool:show`; convergence belongs to
`doctor --family=tool`.

## Failure Output

Human-rendered failures show the failing field or condition, a concise prose error, and actionable recovery guidance when the operator can resolve the issue.
