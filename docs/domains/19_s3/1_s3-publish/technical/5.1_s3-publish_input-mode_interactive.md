# Interactive Input Mode: `orbit s3:publish`

[Back to `s3:publish` technical contract.](1_s3-publish.md)

**Input mode:** Interactive.

## Mode Selection

This contract applies only when the process is attached to a TTY and `--json`
is not present.

## Prompt Flow

Prompts render after gateway reachability is known and before any gateway write
or route apply.

| Prompt ID | Primitive | Rendered when | Validation |
| --- | --- | --- | --- |
| `s3.node` | `datatable` | `--node` is absent and more than one visible active s3 node exists. | Visible active node with the `s3` role. |
| `s3.host` | `text` | `host` argument omitted. | Public DNS hostname, not a URL, not a wildcard, and not already owned by a non-S3 route. |

Invalid prompt answers re-prompt until the value is valid or the operator
aborts. Abort fails before side effects.
