# Human Renderer: `orbit app:websocket enable`

[Back to `app:websocket enable` technical contract.](1_app-websocket-enable.md)

This page describes the human-rendered output for `app:websocket enable`.

**Renderer:** Human renderer.

## Primitive

None. Output is emitted as prose lines via `$this->line(...)`.

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered. The enable operation is a fast gateway write and
route sync; no slow external work is performed from the CLI side.

## Success Render

The success output presents the resulting binding fields as labeled key-value
output. The `binding:` label precedes the binding data, which includes the
`internal_host`, `public_hosts`, and `allowed_origins` values.

### Example output

```text
binding:
  app: docs
  internal_host: websocket.orbit
  public_hosts:
    - ws.docs.example.com
  allowed_origins:
    - https://docs.example.com
```

## Error Render

Errors are rendered as concise prose messages.
