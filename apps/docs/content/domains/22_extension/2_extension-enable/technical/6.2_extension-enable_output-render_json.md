# JSON Renderer: `orbit extension:enable`

[Back to `extension:enable` technical contract.](1_extension-enable.md)

**Renderer:** JSON renderer.

## Primitive

None. JSON output is emitted as a machine-readable envelope.

## Selection

Use this renderer when `--json` is present.

## Envelope

This renderer uses the shared [JSON Envelope](../../../README.md#json-envelope).

## Local Success

```json
{
  "success": {
    "data": {
      "extension": {
        "slug": "solo",
        "local_enabled": true,
        "gateway_enabled": true
      }
    },
    "meta": []
  }
}
```

## Gateway Success

```json
{
  "success": {
    "data": {
      "extension": {
        "slug": "solo",
        "enabled": true,
        "enabled_at": "2026-06-28T00:00:00Z"
      }
    },
    "meta": []
  }
}
```

## Gateway Enable Required

```json
{
  "error": {
    "code": "extension_gateway_enable_required",
    "message": "Gateway extension [solo] is disabled. Pass --gateway to enable it.",
    "meta": {
      "extension": "solo"
    }
  }
}
```
