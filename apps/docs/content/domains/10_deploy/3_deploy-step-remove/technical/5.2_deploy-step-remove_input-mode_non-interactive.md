# Non-Interactive Input Mode: `orbit deploy:step-remove`

[Back to `deploy:step-remove` technical contract.](1_deploy-step-remove.md)

**Input mode:** Non-interactive.

## Mode Selection

This contract applies without a TTY or when `--json` is present. `--json`
forces non-interactive input mode.

## Behavior

No prompts are rendered. `app` and `step` must resolve from arguments, and
`--force` is required before side effects. Missing app or step fails before
side effects with `error.code=validation_failed`. Missing `--force` fails
before side effects with `error.code=destructive_consent_required`.

`--json` selects the JSON renderer only. It does not change validation, does not
grant authorization, and does not imply destructive consent.
