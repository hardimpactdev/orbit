# Human Renderer: `orbit vpn-client:list`

[Back to `vpn-client:list` technical contract.](1_vpn-client-list.md)

**Renderer:** Human terminal renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../commands/ux/lists/table.md)

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

`vpn-client:list` performs gateway-local backend authentication and a backend
read, which may take longer than one second. After input resolution and before
backend authentication begins, render this progress tree:

```text
┌ Listing VPN clients
○ Validate gateway access
○ Authenticate VPN backend
○ Read VPN clients
└ Working...
```

## Success Output

Render a table with one row per client.

| Column | Meaning |
| --- | --- |
| Name | VPN backend client name. |
| Address | WireGuard client address. |
| Enabled | `yes` or `no`. |
| Kind | `admin`, `node`, or `unknown`. |
| Latest handshake | Timestamp or `never`. |

Empty results render `No VPN clients configured.`

## Failure Output

Human-rendered failures use one concise error line and no JSON envelope.
Backend authentication failures may include the stable backend reason when
available.
