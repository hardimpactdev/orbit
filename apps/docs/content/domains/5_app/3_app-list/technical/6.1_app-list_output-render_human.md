# Human Renderer: `orbit app:list`

[Back to `app:list` technical contract.](1_app-list.md)

This page describes the human-rendered output for `app:list`.

**Renderer:** Human renderer.

## Primitive

- Output table: [`Laravel\Prompts\table`](../../../../ux/commands/lists/table.md)

## Selection

Use this renderer by default when `--json` is absent.

## Progress Tree

No progress tree is rendered because `app:list` is expected to stay below one
second. It performs a fast gateway database read and does not perform slow
external work, network probes, or remote node application.

## Success Render

The success output is a table of apps grouped by their owning node. Node groups
are ordered alphabetically by node name (case-insensitive). Within each group,
apps are ordered alphabetically by app name (case-insensitive). Workspaces are
rendered immediately below their parent app as child rows prefixed with `├─ `
for intermediate rows and `└─ ` for the last child row. This matches the JSON
renderer's flat-array ordering, so callers reading either output form see the
same apps in the same relative order.

### Example output

```text
Node: app-1
+----------------+--------------------------------+----------+
| NAME           | URL                            | STATUS   |
+----------------+--------------------------------+----------+
| docs           | https://docs.test              | expected |
| └─ feature-a   | https://feature-a.docs.test    | active   |
| blog           | https://blog.test              | expected |
+----------------+--------------------------------+----------+

Node: app-2
+------+------------------+----------+
| NAME | URL              | STATUS   |
+------+------------------+----------+
| api  | https://api.test | expected |
+------+------------------+----------+
```

### Empty result

When no apps match the filters:

```text
No apps found.
```

## Error Render

Errors are rendered as concise prose messages.

### Invalid filter value

```text
Invalid value for --environment: 'staging'. Allowed values: development, production.
```

### Gateway unavailable

```text
Gateway connection is required to list apps.
```

Authorization failures originate at the API permission middleware and are
documented as part of the JSON renderer contract (see
[`6.2_app-list_output-render_json.md`](6.2_app-list_output-render_json.md)).
The command's human renderer does not own that failure shape, so it is not
covered here.
