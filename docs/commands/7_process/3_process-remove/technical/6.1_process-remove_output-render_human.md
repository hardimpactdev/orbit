# Human Renderer: `orbit process:remove [name]`

[Back to `process:remove` technical contract.](1_process-remove.md)

This page describes the human-rendered terminal output for `process:remove`.

**Renderer:** Human renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render the complete progress tree after input resolution and destructive
consent, before removal side effects begin.

```text
┌ Remove Process
○ Validate process
○ Remove runtime units
○ Remove process intent
└ Process `vite` removed
```

When runtime-unit cleanup fails after intent removal, mark the cleanup step as a
warning and keep the footer as a successful removal with drift.

## Success Output

```text
Process 'vite' removed from app 'docs'
```

When cleanup leaves repairable drift:

```text
Process 'vite' removed from app 'docs'
  Drift detected: process.runtime_unit_extra
```

## Failure Output

Human-rendered failures must show the failing field or phase, clear prose, no
JSON envelope, and next-step guidance only when the operator can act on it.

### Missing destructive consent

```text
Use --force to remove this process.
```

### Cancelled confirmation

```text
Operation cancelled.
```
