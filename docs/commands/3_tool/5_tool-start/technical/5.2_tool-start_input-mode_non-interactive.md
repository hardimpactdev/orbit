# Non-Interactive Input Mode: `orbit tool:start`

[Back to `tool-start` technical contract.](1_tool-start.md)

**Input mode:** Non-interactive.

## Selection

Use this mode when `--json` is present or the input stream is not interactive.
`--json` always selects this mode.

## Behavior

Non-interactive mode never prompts for a missing tool or target.

- Missing `[tool]` fails with `validation_failed` and `meta.field="tool"`.
- Missing target fails with `validation_failed` and
  `meta.fields=["target"]` after checking `--app`, `--node`, local
  `node:default`, and gateway-known self identity.
- `--app` accepts an app slug, app domain, or `<slug>.<node-tld>` selector.
- `--app` and `--node` must resolve to the same node.

The command fails before side effects when validation or target resolution
fails.
