# Interactive Input Mode: `orbit schedule:remove`

[Back to `schedule:remove` technical contract.](1_schedule-remove.md)

**Input mode:** Interactive.

## Mode Selection

This contract applies only when the process is attached to a TTY and `--json` is not present.

## Prompt Flow

Prompts render after gateway reachability is known and before any gateway removal or scheduler-side cleanup.

| Prompt ID | Primitive | Rendered when | Validation |
| --- | --- | --- | --- |
| `schedule.remove.schedule` | `datatable` | `name` argument omitted. | Existing visible schedule row. |
| `schedule.remove.confirm` | `confirm` | Always after the schedule is resolved unless `--force` is present. | Explicit destructive consent. |

The confirmation text names the schedule, scope, target, interval, and artifacts that will be removed.

Rejected confirmation fails before side effects with `error.code=destructive_consent_required`.
