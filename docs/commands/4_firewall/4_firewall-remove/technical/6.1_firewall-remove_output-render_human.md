# Human Renderer: `orbit firewall:remove`

[Back to `firewall-remove` technical contract.](1_firewall-remove.md)

**Renderer:** Human terminal renderer.

## Selection

Use this renderer when `--json` is not present.

## Progress Tree

Render an in-progress tree after input resolution and destructive confirmation,
before backend cleanup or gateway intent removal begins.

```text
┌ Remove Firewall Rule
○ Confirm destructive removal
○ Read gateway firewall intent
○ Remove backend firewall rule
○ Remove gateway firewall intent
└ Firewall rule `local-vite` removed from `app-1`
```

## Success Output

Render the removed rule name and node. If the rule was already absent from
gateway intent, render a concise idempotent absence message.

## Failure Output

Validation failures render the rejected field. Missing destructive consent
renders a direct message that `--force` is required in non-interactive mode.
Cleanup failures render the next doctor command for recovery.
