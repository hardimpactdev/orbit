The `proof` family runs the verification cases of Orbit commands. A proof builds a fresh test fleet in a VM, runs the cases of the commands that a commit changes with the CLI built from that commit, and reports a verdict for each case. Continuous integration uses it as a required check; see [the proof CI](/reference/feature-flow#the-proof-ci). The family belongs to the [tasks extension](/reference/tasks).

## Commands

| Command | Result |
| --- | --- |
| [`proof:run`](/cli/proof/run) | Run the cases that a commit selects, and report a verdict for each. |
